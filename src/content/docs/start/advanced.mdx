This is a guide for people who use AI often and now **want to work with it directly through code and the API**. Just follow the steps below from the top, one after another.

## Recommended learning path

1. [C14. Claude Code core features](/claude/c14-claude-code-features/)
2. [C15. Dividing work among models](/claude/c15-model-division/)
3. [C16. Getting started with the API](/claude/c16-api/)
4. [Developer Deep Dives](/dev/), tutorials 01 → 11

C14 through C16 are prerequisites for the Developer Deep Dives. After you read these three, you can move on to the Developer Deep Dives and jump straight into code without basic explanations.
