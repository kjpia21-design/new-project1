<PromptBox>

## 데이터·표

### CSV 먼저 점검하기

<PromptBox>
첨부한 CSV는 2026년 상반기 지점별 매출이야. 열은 날짜, 지점, 상품분류, 수량, 매출액이야. 먼저 아래만 해줘. 분석은 아직 하지 마.
1) 행 수와 열별 자료형
2) 빈칸·중복·형식이 섞인 값(예: 날짜 형식, 숫자 중간의 쉼표)
3) 이상해 보이는 값 5개
</PromptBox>

출처: [엑셀·CSV 데이터 분석을 AI에게 맡기기](/chat/03-data-analysis/)

### 데이터 정리 규칙 지정

<PromptBox>
방금 발견한 문제를 이렇게 처리해줘. 중복 행은 제거, 날짜는 YYYY-MM-DD로 통일, 매출액이 비어 있으면 지우지 말고 "누락"으로 표시. 처리 후 바뀐 행 수를 알려주고, 원본 데이터는 그대로 두고 정리본을 새로 만들어줘.
</PromptBox>

출처: [엑셀·CSV 데이터 분석을 AI에게 맡기기](/chat/03-data-analysis/)
