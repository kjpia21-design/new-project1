## 이 사이트는

**최신 AI 트렌드 따라 잡기**는 새로 나오는 AI 도구를 쉽게 설명하고, 단계별로 따라 할 수 있는 튜토리얼을 제공하는 한국어 사이트예요. 도구 이름과 메뉴 이름은 영어를 함께 적어 두었어요.

## 이렇게 구성돼 있어요

- **수준**: 입문 / 실무 / 고급 세 단계로 나눠, 내게 맞는 곳에서 시작할 수 있어요. 실무 활용자를 가장 먼저 배려해 만들고 있어요.
- **분야**: 아래 여덟 섹션으로 나뉘어 있고, 튜토리얼은 모두 90편이에요. (2026-10-31 기준)
  - **AI 첫걸음** (11편): 가입, 첫 질문, 사실 확인, 안전하게 쓰기, 요금제와 도구 고르기까지 AI를 처음 쓰는 분을 위한 입문 섹션이에요.
  - **Claude 완전 정복** (21편): 모델, 요금제, 앱 기능부터 Claude Code, API까지 Claude를 입문부터 고급까지 다루는 특별 섹션이에요.
  - **화제의 AI 에이전트** (6편): Meta Muse, Grok Bot, ChatGPT Dots 같은 개인 AI 에이전트를 한국 이용 여부와 안전 수칙 중심으로 알아봐요.
  - **개발자 심화** (11편): 도구 사용, Agent SDK, MCP 서버, CI 자동화, 평가, 사용량·비용 분석 API처럼 Claude를 코드와 API로 다루는 고급 편이에요.
  - **대화형 AI 기본기** (11편): 프롬프트, 문서 요약, 데이터 분석, 보고서 작성, 도구 고르기예요.
  - **코딩·에이전트** (9편): Claude Code, 클라우드 세션, Cursor, 반복 업무 위임을 다뤄요.
  - **이미지·영상·음성** (10편): 이미지·영상 생성, Canva, 녹음 정리, 음성 합성이에요.
  - **업무 자동화·생산성** (11편): Notion AI, 아침 브리핑, Zapier/Make, Google Workspace의 Gemini, 커넥터(MCP)예요.
- **Claude 최신 소식**: Claude 공식 채널의 업데이트를 최신순으로 모아, 실무자에게 의미 있는 변화만 쉬운 말로 정리해요.
- **튜토리얼**: 한 편마다 준비물, 단계별 따라하기(체크리스트), 복사해 쓰는 프롬프트, 자주 막히는 지점, 출처와 마지막 확인일을 담아요.

## 운영 방식

모든 콘텐츠는 GitHub 저장소에서 마크다운 파일로 관리하고, 변경 내용은 자동으로 이 사이트에 게시돼요.

## 최신 상태 유지 방식

AI 도구는 빨리 바뀌기 때문에, 두 가지 자동 점검으로 내용을 최신으로 유지해요. 두 점검 모두 바로 반영하지 않고 수정안을 풀 리퀘스트(PR)로 먼저 올려요. 운영자가 내용을 검토하고 합친 뒤에야 사이트에 반영돼요.

- **평일 업데이트 점검**: 평일마다 루틴이 Claude의 공식 업데이트 채널(API 릴리스 노트, Claude Code 변경 이력, Claude 앱 릴리스 노트, Anthropic 뉴스)을 확인해요. 새 소식이 있으면 [Claude 최신 소식](/claude-news/)과 관련 튜토리얼을 고치는 PR을 올려요.
- **월요일 전체 팩트체크**: 매주 월요일에는 튜토리얼에 나온 도구의 공식 문서와 변경 이력을 전체적으로 다시 확인해요. 메뉴 이름, 가격, 기능이 바뀌었으면 수정안을 PR로 올려요.

확인이 끝난 날짜는 각 튜토리얼의 **마지막 확인일**과 [최근 업데이트](/updates/)에서 볼 수 있어요.
