Anthropic의 공식 채널에서 나온 Claude 업데이트를 최신순으로 모았어요. 모델 출시, 가격, Claude Code와 앱의 새 기능처럼 실제로 쓰는 분에게 의미 있는 것만 골랐고, 사소한 버그 수정은 뺐어요. 공식 채널을 점검해 계속 갱신해요.

**마지막 업데이트: 2026-10-11**

- [Anthropic 뉴스](https://www.anthropic.com/news): 정책, 파트너십, 모델 발표

## 2026년 10월

<NewsItem date="10월 9일" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/dev/04-managed-agents/" tutorialLabel="개발자 심화 Managed Agents">
Managed Agents에 동적 워크플로(베타)가 생겼어요. 에이전트가 직접 여러 에이전트로 이뤄진 워크플로를 작성하고 실행해서, 복잡한 작업을 나눠 맡기기 쉬워져요.
</NewsItem>

<NewsItem date="10월 9일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c15-model-division/" tutorialLabel="C15 모델 분담 전략">
서브에이전트에 `autoCompactWindow` 설정과 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` 환경 변수가 추가됐어요. 서브에이전트가 쓸 모델을 따로 정해 비용을 조절할 수 있어요. 2.1.296 버전이에요.
</NewsItem>

<NewsItem date="10월 8일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code 핵심 기능">
훅에 `onFailure: "block"` 옵션이 생겼어요. 훅이 실패하면 작업을 막도록 설정할 수 있어서 안전 장치를 만들 때 유용해요. 2.1.295 버전이에요.
</NewsItem>

<NewsItem date="10월 7일" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/claude/c16-api/" tutorialLabel="C16 API 시작하기">

</NewsItem>

<NewsItem date="10월 7일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/claude/c01-overview/" tutorialLabel="C1 한눈에 보기">

</NewsItem>

<NewsItem date="10월 7일" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/claude/c15-model-division/" tutorialLabel="C15 모델 분담 전략">

</NewsItem>

<NewsItem date="10월 7일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/claude/c02-plans-limits/" tutorialLabel="C2 요금제와 한도">

<NewsItem date="10월 6일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code 핵심 기능">

</NewsItem>

<NewsItem date="10월 5일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c12-claude-code-overview/" tutorialLabel="C12 Claude Code 개요">

<NewsItem date="10월 2일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code 핵심 기능">
