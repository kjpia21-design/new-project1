## November 2026

<NewsItem date="Oct 31" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
Versions 2.1.314 (Oct 30) and 2.1.316 (Oct 31) are out. You can now set the effort level subagents run at with the `CLAUDE_CODE_SUBAGENT_EFFORT` environment variable, and turn off the `ultrathink` keyword with `CLAUDE_CODE_DISABLE_ULTRATHINK`. The `permissions.blockWritesOutsideWorkingDirectories` setting makes Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode. In the VS Code extension and the Desktop Code tab, long conversations left idle are now summarized (compacted) automatically. Server-managed settings for Team and Enterprise logins now apply without an approval prompt.
</NewsItem>

<NewsItem date="Oct 30" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/claude/c16-api/" tutorialLabel="C16 Claude API basics">
Fast mode for Claude Opus 4.8 is deprecated and will be removed on Nov 30, 2026. After that, requests to `claude-opus-4-8` with `speed: "fast"` return an error. To keep using fast mode, migrate to Claude Opus 5.5 (see the migration guide and the fast mode page in the developer docs). Claude Code 2.1.316 carries the same notice.
</NewsItem>

## October 2026

<NewsItem date="Oct 29" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/dev/02-cost-optimization/" tutorialLabel="Developer Deep Dives: Cost optimization">
A usage and cost analytics API (beta) is now available. You can filter and group token usage and cost for Claude Console and Claude Enterprise organizations by model, workspace, API key, and the user or service account that made the request. It uses the `analytics-usage-cost-2026-08-24` beta header. The reporting endpoints of the existing Usage and Cost API and Enterprise Analytics API are now legacy but remain supported. On Oct 28, the maximum request size for the Messages API and the token counting API increased from 32MB to 128MB (when calling the Claude API directly).
</NewsItem>

<NewsItem date="Oct 27" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c13-cloud-sessions/" tutorialLabel="C13 Claude Code cloud sessions">
In 2.1.312, the model picker for routines running in the cloud gained an option for choosing the effort level, and you can write cloud environment setup scripts in a Bash editor and move them with a copy button. In usage limit messages, the 5-hour window is now called the "5-hour limit" instead of the "session limit." Also, if WebFetch can't find a host in a cloud session, it now tells you the host may be outside the allowed network domains.
</NewsItem>

<NewsItem date="Oct 26" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
In 2.1.311, the `ultrathink` keyword in the terminal runs that turn at the xhigh effort level on Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1 (Anthropic API). A problem where requests over 200K tokens stopped with a "Usage credits required for 1M context" error was also fixed; now it compacts the conversation and continues. Also, the `DISABLE_COMPACT` setting now only works to turn compaction off.
</NewsItem>

<NewsItem date="Oct 23" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c13-cloud-sessions/" tutorialLabel="C13 Claude Code cloud sessions">
In 2.1.310, Enterprise custom roles can be granted cloud session and Remote Control permissions, so owners can set access by role. The cloud environment dialog gained a "Choose file" button for loading a setup script from a file, and the Monitor tool and plugin monitors now work on Bedrock, Vertex, and Foundry too.
</NewsItem>

<NewsItem date="Oct 22" channel="API" href="https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed" tutorial="/claude/c16-api/" tutorialLabel="C16 Getting started with the API">
"Claude Models on Google Cloud (Anthropic managed)" is here. It lets you use the Claude API operated by Anthropic through your own Google Cloud project, with access handled through Google Cloud IAM and billing through Google Cloud Marketplace. Claude Opus 5.5's fast mode is also available this way.
</NewsItem>

<NewsItem date="Oct 22" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
In 2.1.309, `claude ultrareview` requires workspace trust. In scripts, you need to add `--trust-workspace` or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`. Also, `sed -i` now goes through the normal Bash confirmation process and can't be undone with `/rewind`, and in the permission bypass mode of the Desktop app and VS Code, `rm` and `rmdir` are now rejected immediately without a confirmation prompt. The `/claude-api` skill creates Managed Agents subagent teams as `multiagent_20261001`.
</NewsItem>

<NewsItem date="Oct 22" channel="News" href="https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation" tutorial="/claude/c08-skills/" tutorialLabel="C8 Skills">
Anthropic announced that it is donating the Agent Skills open standard to the Agentic AI Foundation. It says more than 70 agent platforms have adopted the standard since it was published in December 2025. We couldn't confirm in official documentation that the way you use Skills in Claude is changing.
</NewsItem>

<NewsItem date="Oct 21" channel="Claude app" href="https://claude.com/resources/articles/claude-duet" tutorial="/claude/c01-overview/" tutorialLabel="C1 Claude at a glance">
A "Claude Duet" research preview has started for Pro and Max plans. It's a "proactive agent" app that sends you a morning summary, looks through your connected apps and handles tasks you give it, and asks for your approval before acting. As of 2026-10-21, it's available through a waitlist, starting with Pro and Max subscribers in the US. It works on the iOS and Android apps and on claude.ai, and runs separately from the existing Claude app. Usage counts against your plan's limits, and connected accounts are checked every few hours. The official post doesn't say whether it will be available in Korea.
</NewsItem>

<NewsItem date="Oct 21" channel="API" href="https://platform.claude.com/docs/en/api/migration-2026-10-21" tutorial="/claude/c16-api/" tutorialLabel="C16 Getting started with the API">
API version `2026-10-21` is out. The new SDKs and the `ant` CLI (Python 2.0.0, TypeScript 1.0.0, and others) use this version by default, and the license for the SDKs and CLI changed from MIT to Apache 2.0. Upgrading an SDK to a new major version may bring incompatible changes, so check the previous guide first. Claude Code 2.1.307 added `/claude-api api-version`, which helps move your code to the new version.
</NewsItem>

<NewsItem date="Oct 20" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/dev/04-managed-agents/" tutorialLabel="Developer Deep Dives: Managed Agents">
Organization admins can turn off web fetch on the Capabilities page in Claude Console. When it's off, API requests that include the web fetch tool return a 400 error, and `web_fetch` in Managed Agents also returns an error. When it's on, you can also set allowed and blocked domains, and web fetch and web search in Managed Agents must pass both the organization settings and the agent settings. User profiles, which distinguish requests by end customer, were also added.
</NewsItem>

<NewsItem date="Oct 20" channel="API" href="https://platform.claude.com/docs/en/manage-claude/inference-hooks">
"Inference hooks" for Claude Enterprise organizations have graduated from beta to general availability. An AI security server run by your organization inspects a user's prompt before it is sent to the model and decides whether to allow or block it. It applies to all of your organization's Claude products at once, including claude.ai, Cowork, and Claude Code, and only the Owner role can set it up. It doesn't apply to individual, Pro, or Max users.
</NewsItem>

<NewsItem date="Oct 19" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
2.1.304 added `/auto-mode-setup`, a setup helper that guides you on what auto mode should allow, based on your project and recent sessions. On Pro and Max plans, you now get a warning when reopening a long-idle conversation would use up a good chunk of your 5-hour usage limit. Code Review gained review levels (Quick, Standard, Deep), and an option to review every repository in a GitHub organization at once was added.
</NewsItem>

<NewsItem date="Oct 16" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
From 2.1.302, the subagent "fork" mode is on by default outside the terminal too. To turn it off, set `CLAUDE_CODE_FORK_SUBAGENT=0`. Prompt and agent hooks run up to 12 at a time per event. You can also choose the model used for auto mode's decisions with `CLAUDE_CODE_AUTO_MODE_MODEL`, and a notice says that the separate app Claude Design will only be available until December 14, 2026. (On Oct 18, 2.1.303 shipped containing only "bug fixes and stability improvements.")
</NewsItem>

Claude Opus 5.5's fast mode has left research preview. <NewsItem date="Oct 14" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/claude/c14-claude-code-features/" tutorialLabel="C14 Claude Code core features">
