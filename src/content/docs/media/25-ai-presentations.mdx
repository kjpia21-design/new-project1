<Summary>
- 세 도구 모두 **주제를 말하면 AI가 (필요하면 질문한 뒤) 슬라이드를 만드는** 흐름이에요. Gamma는 계획을 보여 주고 승인을 받아요. 결과는 초안이니 사람이 고쳐야 해요.
- **Gamma**는 발표 자료 전용 AI 서비스예요. **Claude**는 채팅에서 Slides 템플릿으로 만들고 PowerPoint로 내보내요. **Copilot**은 PowerPoint 안에서 바로 만들어요.
- 회사 양식을 지켜야 하면 **양식 파일에서 시작**하는 Copilot이 편하고, 빠른 초안은 Gamma가 편해요.
- AI 기능은 **크레딧·사용량**을 써요. Gamma 무료 플랜은 크레딧이 갱신되지 않아요 (2026-10-19 기준).
- 숫자·출처·고유명사는 AI가 틀릴 수 있어요. 발표 전에 꼭 직접 확인하세요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 발표 주제와 청중을 정리해 AI에게 **개요부터** 만들게 할 수 있어요.
- Gamma, Claude, PowerPoint의 Copilot 중 상황에 맞는 도구를 고를 수 있어요.
- 만든 초안을 **PowerPoint 파일(.pptx)** 로 내보내 마무리할 수 있어요.
- 발표 전에 사실·숫자·이미지 권리를 점검할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **개요(아웃라인)** | 슬라이드 제목과 핵심 내용만 나열한 뼈대예요. 슬라이드를 만들기 전에 고치는 게 가장 효율적이에요. |
| **Gamma** | AI로 발표 자료·문서·웹페이지를 만드는 별도 서비스예요. 만든 결과물을 "gamma"라고 불러요. |
| **Claude Slides** | Claude의 Artifacts 템플릿 중 하나예요. 노트나 보고서, 대화 내용으로 발표 자료를 만들어요. |
| **Copilot (PowerPoint)** | PowerPoint 안의 AI 도우미예요. Microsoft 365 구독과 조직 설정에 따라 보이지 않을 수 있어요. |
| **크레딧** | AI 기능을 쓸 때 소모되는 사용량 단위예요. 서비스마다 계산 방식이 달라요. |

### 세 도구는 어디가 다른가요

| 비교 | Gamma | Claude Slides | PowerPoint의 Copilot |
| --- | --- | --- | --- |
| 시작하는 곳 | gamma.app 대시보드 | 채팅 또는 Artifacts 탭 | PowerPoint 안의 Copilot Chat |
| 제작 흐름 | 질문 -> 계획 검토 -> 제작 (Plan 모드) | 채팅으로 요청하고 수정 요청 | 설명 입력 -> (청중·길이 등 질문, 건너뛰기 가능) -> 슬라이드 생성 |
| 내보내기 | PDF, PNG, PPTX 등 | PowerPoint, PDF, Google Slides | 이미 PowerPoint 파일 |
| 회사 양식 | 별도 테마 | 기존 덱을 올려 스타일을 따라 하게 요청 | 양식 파일에서 시작하면 테마 유지 |
| 비용 구조 | 크레딧 (무료는 갱신 안 됨) | Claude 플랜 안에서 사용 (소모량 수치는 공개되지 않아요) | Copilot이 포함된 Microsoft 365 구독 (가격은 확인하지 못했어요) |

<Aside type="note" title="확인되지 않은 점">
세 도구의 한국어 결과 품질은 공식 문서에서 확인하지 못했어요. Gamma의 한국어 지원 범위, Copilot의 한국어 지원 범위, 가격도 이 글에서는 확인하지 않아 쓰지 않았어요. 직접 한 번 만들어 보고 판단하세요. Claude Slides의 사용량 소모량도 공식 수치가 없어요.
</Aside>

## 단계별 따라하기

예제는 "신입 직원 대상 정보 보안 교육 15분 발표"예요. 어떤 도구를 쓰든 1~2단계는 같아요.

<Checklist items={[
  '주제·청중·시간·꼭 넣을 내용을 메모했어요',
  '개요를 만들게 하고 순서와 제목을 고쳤어요',
  '도구 한 가지로 슬라이드 초안을 만들었어요',
  '문구·숫자·이미지를 직접 점검했어요',
  '필요한 형식(PPTX, PDF)으로 내보냈어요',
]} />

<Steps>

1. **발표의 뼈대를 먼저 적기**

   AI에게 맡기기 전에 네 가지만 적어요. 주제, 청중, 발표 시간, 꼭 들어가야 할 내용이에요. 발표 시간이 15분이면 슬라이드는 보통 10장 안팎이 적당해요(사람마다 달라서 정답은 없어요).

   <PromptBox>
   신입 직원 20명에게 하는 15분짜리 정보 보안 교육 발표 자료를 만들려고 해. 슬라이드는 10장 이내로 하고, 꼭 들어갈 내용은 (1) 피싱 메일 구별법 (2) 비밀번호 관리 (3) 사고가 났을 때 신고 절차야. 먼저 슬라이드별 제목과 핵심 내용만 개요로 보여 줘. 내가 확인하면 그때 슬라이드를 만들어 줘.
   </PromptBox>

2. **개요를 고치기**

   개요 단계에서 순서를 바꾸고 빼고 싶은 장을 지워요. 슬라이드를 다 만든 뒤에 고치면 크레딧이 더 들고 디자인도 흐트러져요.

3. **도구로 초안 만들기 (셋 중 하나)**

   **A. Gamma**: 대시보드의 프롬프트 바에 주제를 쓰고 모드를 골라요. **Plan**은 질문과 계획 검토 후 만들고(기본), **Express**는 바로 초안을 만들어요. **Research**는 웹 출처를 먼저 모으고 Plan에서만 쓸 수 있어요. 메모를 붙여넣거나 파일을 첨부할 수도 있어요. 질문이 귀찮으면 "Decide for me"를 고를 수 있어요.

   **B. Claude**: 채팅에서 발표 자료를 요청하거나, 메시지 상자의 Output에서 Slides 템플릿을 골라요. 노트나 보고서를 같이 올리면 그 내용으로 만들어요. 만든 뒤에는 슬라이드를 직접 편집하거나 Claude에게 수정을 요청해요.

   **C. PowerPoint의 Copilot**: 아래 "가장 막히는 절차"를 따라가세요.

   <FlowSteps title="PowerPoint에서 Copilot으로 새 발표 자료 만들기" officialUrl="https://support.microsoft.com/en-us/PowerPoint/copilot/create-a-new-presentation-with-copilot-in-powerpoint" steps={[

     { where: '입력 상자', action: '만들고 싶은 발표를 설명해서 보내기', result: 'Copilot이 청중·길이·템플릿·이미지 종류를 물어볼 수 있어요 (답하거나 건너뛰어 Copilot에게 맡겨도 돼요)' },
     { where: 'Copilot', action: '자료를 모으고 선택한 템플릿으로 만들 때까지 기다리기', result: '슬라이드가 생성돼요' },
   ]} />

   Copilot이 보이지 않으면 구독이나 조직 설정에 포함되지 않았을 수 있다고 안내돼요. 이 경우 관리자에게 문의하세요. 2026-10-26 기준 공식 도움말에는 이전에 있던 Add Content > Agent Mode 단계 설명이 없고, 모델 선택기(기본 Auto)와 Brand Kit 선택 단계가 안내돼요. 화면이 다르면 최신 도움말과 실제 화면을 따르세요.

   <ScreenshotPlaceholder caption="Copilot Chat에서 모델 선택기와 입력 상자로 발표 자료를 요청하는 화면" officialUrl="https://support.microsoft.com/en-us/PowerPoint/copilot/create-a-new-presentation-with-copilot-in-powerpoint" />

4. **슬라이드를 직접 점검하기**

   - 숫자, 날짜, 법·규정 이름, 사람 이름이 맞는지 원문과 비교해요.
   - 한 슬라이드에 글이 너무 많으면 줄이거나 나눠 달라고 요청해요.
   - AI가 만든 이미지는 실제 상황과 다를 수 있어요. 사람 얼굴, 남의 로고가 나오면 바꾸세요.
   - Copilot이 만든 AI 이미지의 출처 표시는 2026-10-26 기준 이 도움말에서 확인되지 않아요(이전 확인 때는 발표자 노트에 "AI-generated"가 표시된다고 안내됐어요). 발표자 노트와 이미지를 직접 확인하세요.

5. **내보내고 마무리하기**

   - **Gamma**: 오른쪽 위 공유(Share) > 내보내기(Export)에서 PDF, PNG, PowerPoint를 골라요. "All cards"를 골라야 전체가 나와요. 무료 플랜에서 PDF·PPTX로 내보내면 "Made by Gamma" 배지가 붙어요. 유료 플랜(Plus, Pro, Ultra)이면 사라져요.
   - **Claude**: 내보내기(Export)에서 PowerPoint, PDF, Google Slides를 골라요.
   - **Copilot**: 이미 PowerPoint 파일이니 저장하면 돼요.

   <ScreenshotPlaceholder caption="Gamma의 Share > Export 메뉴에서 PowerPoint를 고르는 화면" officialUrl="https://help.gamma.app/en/articles/8022861-what-s-the-easiest-way-to-export-my-gamma" />

</Steps>

## 빠른 참조표

### Gamma 요금제 요약 (2026-10-19 기준, 공식 도움말에서 확인한 항목만)

| 항목 | Free | Plus | Pro |
| --- | --- | --- | --- |
| AI 크레딧 | 갱신 안 됨 (가입 시 400, 추천 1건당 200, 추천으로는 계정에 최대 2,000) | 월 1,000 | 월 4,000 |

| 항목 | 내용 |
| --- | --- |

## 자주 막히는 지점

### Copilot 아이콘이나 Brand Kit 선택이 안 보여요

- **원인**: Microsoft 365 구독이나 조직 설정에 Copilot이 포함되지 않았거나, 기능이 아직 내 계정에 롤아웃되지 않았을 수 있어요.
- **해결**: 공식 도움말의 "어떤 Copilot 라이선스가 있는지 확인" 안내를 따르거나 관리자에게 문의하세요. 대안으로 Gamma나 Claude로 먼저 초안을 만들 수 있어요.

### Gamma 무료 플랜에서 크레딧이 모자라요

- **원인**: 무료 플랜은 크레딧이 매달 채워지지 않아요.
- **해결**: 개요를 짧게 확정하고 한 번에 만들어 낭비를 줄이세요. 이미지 없이 만들기(Don't add images)나 이미지 자리표시자(Image placeholders)를 고를 수 있어요. 이미지 생성 비용은 모델을 고를 때 크레딧이 미리 표시돼요. 계속 쓸 거라면 유료 플랜을 비교하세요.

### 내보낸 PPTX의 글자 모양이나 효과가 달라요

- **원인**: PowerPoint가 Gamma의 일부 효과(그라데이션, 반투명 배경)를 그대로 지원하지 않아요.
- **해결**: 중요한 장은 PowerPoint에서 열어 눈으로 확인하고 고치세요. 모양이 꼭 같아야 하면 PDF로 내보내세요. 화면 그대로 공유할 때는 Gamma 링크로 발표할 수도 있어요.

### 슬라이드에 글이 너무 많아요

- **원인**: 요약 요청이 없으면 AI는 문장을 길게 쓰기 쉬워요.
- **해결**: "슬라이드당 핵심 3줄, 한 줄은 25자 안팎, 자세한 설명은 발표자 노트로"라고 요청하세요.

## 실전 팁

- **개요 단계에서 시간을 쓰세요.** 슬라이드를 만든 뒤 고치는 것보다 쉬워요.
- **자료를 붙여 넣으세요.** 근거 자료를 같이 주면 AI가 지어내는 내용이 줄어요. 그래도 틀릴 수 있으니 확인하세요. ([팩트체크 방법](/basics/04-fact-checking/))
- **외부로 나가는 자료는 개인정보·기밀을 먼저 가리세요.** Gamma의 개인 워크스페이스(Free, Plus, Pro, Ultra)는 기본값이 콘텐츠를 AI 학습에 허용하는 쪽이고, 계정 설정의 Data Controls 탭에서 끌 수 있어요. Business·Enterprise 등 조직 워크스페이스는 항상 학습에 쓰이지 않는다고 안내돼요 (2026-10-14 기준). 자세한 원칙은 [개인정보 지키기](/basics/05-privacy-safety/)에서 보세요.
- **이미지 권리를 확인하세요.** AI 이미지에 실존 인물이나 남의 로고가 나오면 쓰지 마세요. 이미지 생성 도구별 상업 이용 조건은 [12편](/media/12-canva-sns/)도 참고하세요.
- **발표 연습은 사람이 하세요.** 발표자 노트는 AI에게 초안을 맡겨도 되지만, 소리 내어 읽어 보며 내 말투로 바꾸세요.
