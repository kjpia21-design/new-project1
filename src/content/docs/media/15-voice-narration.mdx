- 이 편은 ElevenLabs를 중심으로, 간단한 대안으로 Canva의 텍스트 음성 변환을 소개해요. 두 서비스 모두 한국어가 지원 언어 목록에 있다고 안내돼요.
- **남의 목소리를 동의 없이 복제하면 안 돼요.** 복제는 **본인 목소리를 본인 동의로** 하는 것이 원칙이에요.
- ElevenLabs 이용약관은 무료 이용자는 비상업 목적으로만, 유료 구독자는 상업 목적으로도 쓸 수 있다고 정하고 있어요(2026-10-10 기준, 가격은 아래 표).
- 한국어 발음·억양 품질은 공식 문서로 보증되지 않아요. **반드시 직접 들어 보세요.**
</Summary>


## 이 튜토리얼로 할 수 있게 되는 것

- 홍보 영상용 내레이션 대본을 써서 음성 파일로 만들 수 있어요.
- 숫자·영문·고유명사 발음을 고치는 요령을 알 수 있어요.
- 음성 복제의 동의 규칙과 금지 사항을 이해할 수 있어요.
- 상업 이용 전에 확인할 약관 항목을 점검할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **TTS(텍스트 음성 변환)** | 글을 읽어 주는 음성으로 바꾸는 기술이에요. |
| **사전 제작 음성(premade voice)** | 서비스가 제공하는 기본 목소리예요. 복제와 달리 동의 문제가 적어요. |
| **음성 복제(Voice cloning)** | 특정 사람의 목소리 샘플로 닮은 목소리를 만드는 기능이에요. **그 사람의 동의가 필수**예요. |
| **Instant Voice Cloning(IVC)** | 짧은 샘플로 빠르게 만드는 복제 방식이에요. 공식 문서는 최소 1분, 깨끗한 오디오 약 1~2분을 권하고, 3분 넘게 녹음해도 개선이 적다고 안내해요. |
| **Professional Voice Cloning(PVC)** | 본인 음성 검증이 필요한 정밀 복제예요. 본인 목소리만 가능해요. |

<Aside type="caution" title="음성 복제의 원칙: 본인의 동의">
- 직원, 가족, 성우, 유명인의 목소리를 **본인 동의 없이 복제하지 마세요.** ElevenLabs의 금지 사용 정책(Prohibited Use Policy)은 "살아 있는 사람의 음성·신원·초상을 그 사람의 명시적이고 충분한 설명을 거친 동의(또는 다른 유효한 승인) 없이 복제·합성·사칭하는 것"을 금지하고, 고인의 경우에도 해를 끼칠 가능성이 있거나 사후 권리를 침해하는 방식이면 금지한다고 정해요. 단체 사칭이나 속이는 광고, 사기도 금지 대상이에요.
- IVC를 만들 때는 음성에 이름을 붙이고 **복제할 권리와 동의가 있음을 확인한 뒤** 저장하는 단계가 있어요(공식 문서). 본인 목소리를 복제하더라도 확인이 필요해요.
- PVC는 **동의가 있어도 타인 음성은 복제할 수 없고** 본인 목소리만 가능하며, 모든 PVC는 목소리가 본인 것임을 확인하는 검증을 거친다고 공식 문서가 안내해요. 다른 사람이 자기 목소리를 공유하고 싶다면 그 사람이 자기 계정에서 PVC를 만들고 검증한 뒤 비공개 공유 링크로 보내는 방식이에요.
- 정치 후보·선출 공직자를 승인 없이 사칭하는 것과 정치 캠페인(사전 서면 동의 없이)도 금지 항목이에요. 유명인 등 고위험 음성 복제를 차단하는 안전장치(No-Go Voices)가 있다는 설명은 도움말 원문을 열지 못해 확인하지 못했어요.
- 위반하거나 우회하려 하면 콘텐츠 삭제, 이용 제한·정지·해지 등의 조치가 있을 수 있고, 법적으로 필요하면 수사·규제 기관에 정보를 알릴 수 있다고 정책에 적혀 있어요.
- 내 목소리가 허락 없이 쓰였다고 생각하면 ElevenLabs의 "Unauthorized Use of Voice" 신고를 쓸 수 있다고 정책이 안내해요.
- OpenAI의 API 문서도 같은 원칙이에요. 녹음으로 사용자 지정 음성(custom voice)을 만들려면 음성 주인이 정해진 동의 문장을 직접 읽은 녹음이 필요하고(한국어 문장 포함. 2026-10-26 기준 문서에는 녹음 없이 텍스트 설명으로 음성을 만드는 prompt-to-voice 방식도 안내돼요), 음성 합성 가이드는 사용 정책상 최종 사용자에게 AI 음성임을 분명히 알려야 한다고 안내해요(developers.openai.com, 2026-10-10 확인). 사용 정책 원문(openai.com)은 열지 못했어요.
</Aside>

## 단계별 따라하기

예제는 [13편](/media/13-promo-video/)의 15초 영상에 입힐 내레이션이에요.

<Checklist items={[
  '대본을 짧게 쓰고 읽는 시간을 쟀어요',
  '사전 제작 음성을 골랐어요',
  '텍스트를 넣고 음성을 생성했어요',
  '숫자·영어·고유명사 발음을 고쳤어요',
  '상업 이용 조건과 AI 표시를 점검했어요',
  '영상에 합쳤어요',
]} />

<Steps>

1. **대본 쓰기**

   15초 영상이면 한국어로 약 50~60자 정도가 알맞아요(말 속도에 따라 달라요). 쉬운 문장, 한 문장 한 호흡으로 써요. Claude 같은 AI로 초안을 만들어도 좋아요.

   <PromptBox>
   카페 신메뉴 '유자 크림 라떼' 출시를 알리는 15초 영상의 내레이션 대본을 써 줘. 3문장, 전체 60자 안쪽. 따뜻하고 차분한 말투. 숫자와 영어는 소리 나는 대로 한글로 풀어서 써 줘(예: 1,000원 → 천 원).
   </PromptBox>

2. **음성 고르기**

   ElevenLabs에서 사전 제작 음성이나 라이브러리 음성을 골라 한국어 대본으로 미리 들어 봐요. Voice Library의 음성은 공유한 사람이 조건을 정할 수 있고, 일부는 유료 구독자만 쓸 수 있다고 공식 문서가 안내해요. 라이브러리 음성의 상업 이용 조건은 이번에 원문으로 확인하지 못했으니 음성별 상세 화면과 약관을 확인하세요. 메뉴 이름은 화면 안내를 따르세요.

   <ScreenshotPlaceholder caption="음성을 고르고 한국어 대본으로 미리 듣는 화면" officialUrl="https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech" />

3. **생성하고 들어 보기**

   텍스트를 붙여넣고 생성해요. 한 번에 넣을 수 있는 글자 수에 제한이 있어요(공식 모델 문서 기준 Multilingual v2와 Eleven v4는 요청당 10,000자로 약 10분, Eleven v3는 5,000자, Flash v2.5는 40,000자). 생성한 파일은 **끝까지 들어 보세요.**

4. **발음 고치기**

   - 숫자는 한글로 풀어요. (예: 1,000원 → 천 원)
   - 영어 상품명은 한글 발음으로 적거나 철자를 바꿔 보세요.
   - 어색한 곳은 문장을 나누거나 쉼표를 넣어 다시 생성해요.
   - 생성할 때마다 크레딧이 쓰이니 문장 단위로 고쳐 생성하세요.

5. **상업 이용·표시 점검**

   - 계정의 플랜이 **상업 이용**을 허용하나요? (무료는 비상업만)
   - 무료 플랜의 비상업 조건과 화면에 나오는 사용 조건을 지켰나요?
   - 복제 음성을 썼다면 본인 동의 기록이 있나요?
   - 광고나 안내에서 AI 음성이라는 점을 밝힐지 정했나요? ElevenLabs 정책은 법으로 요구되거나 알리지 않으면 상대를 오해하게 만들 경우 AI와 상호작용 중임을 분명히 밝히라고 하고, 탐지를 피하려고 ElevenLabs 워터마크·메타데이터 등 출처 신호를 지우거나 숨기는 것을 금지해요.

6. **영상에 합치기**

   음성 파일을 내려받아 [12편](/media/12-canva-sns/)의 Canva 같은 편집 도구에서 영상에 얹고 길이를 맞춰요. 간단한 영상은 Canva의 텍스트 음성 변환을 바로 쓸 수도 있어요.

</Steps>

## 자주 막히는 지점

### 숫자나 영어가 이상하게 읽혀요

- **원인**: 한국어 모델이 숫자·영문 혼용을 항상 자연스럽게 읽지는 못해요.
- **해결**: 한글로 풀어 적거나 문장을 나눠 다시 생성하세요.

### 크레딧이 금방 줄어요

- **원인**: 글자 수만큼 크레딧이 쓰여요(가격 페이지 FAQ: Multilingual v2 기준 글자 1개 = 크레딧 1).
- **해결**: 대본을 확정한 뒤 생성하고, 수정은 해당 문장만 다시 생성하세요.

### 내 목소리 복제가 안 돼요

- **원인**: 샘플 품질, 동의 확인 누락, 플랜 조건.
- **해결**: 조용한 환경에서 다시 녹음하고, 동의 확인 단계를 완료하세요. 플랜별 복제 가능 여부는 가격 페이지에서 확인하세요.

### 직원 목소리를 복제해 달라는 요청을 받았어요

- **원인**: 편의를 위한 요청이지만 동의가 없으면 정책 위반이 돼요.
- **해결**: 본인에게 용도와 범위를 설명하고 서면 동의를 받으세요. PVC로는 타인 음성을 만들 수 없고, 본인이 직접 만들어 검증한 뒤 공유하는 방식만 가능하다고 안내돼요. 동의를 받기 어려우면 사전 제작 음성을 쓰세요.

## 실전 팁

- **복제보다 사전 제작 음성이 간단하고 안전해요.**
- **본인 목소리를 복제하는 경우에도 사용 범위를 메모해 두세요.**
- **대본은 소리 내어 읽어 보고 다듬으세요.** 읽기 어려운 문장은 AI도 어색해요.
- **회사 공식 영상은 법무·홍보 확인을 거치세요.**
- **생성한 음성 파일과 사용 기록(음성 이름, 날짜, 플랜)을 보관하세요.**
