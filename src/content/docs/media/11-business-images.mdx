<Summary>
- 업무용 이미지는 **용도(어디에 쓰나), 비율, 분위기, 넣을 글자**를 먼저 정하고 요청하면 훨씬 잘 나와요.
- 이 편은 한국에서 쓸 수 있고 한국어를 지원하는 **Gemini 앱**(Nano Banana 계열)을 중심으로, **ChatGPT**를 대안으로 다뤄요.
- 생성한 이미지는 **저작권·초상권·상표를 직접 점검**해야 해요. 도구 약관은 사용자 책임을 분명히 하고 있어요.
- 실존 인물 얼굴, 남의 로고·캐릭터가 들어간 이미지는 **동의나 허락 없이 쓰지 마세요.**
- 요금제·한도·약관은 자주 바뀌어요. 이 글은 2026-10-10 기준이고, 확인하지 못한 부분은 공식 페이지 확인을 안내해요.
</Summary>

<Aside type="caution" title="OpenAI 약관 원문과 Adobe Firefly는 확인하지 못했어요">
Gemini 앱 내용은 Google 공식 도움말 원문으로, ChatGPT 이미지 생성 방법과 출처 표시(C2PA, SynthID)는 OpenAI의 ChatGPT 문서와 API 문서 원문으로 확인했어요(2026-10-10 기준). 하지만 OpenAI 이용약관·사용 정책 페이지(openai.com)와 Adobe Firefly 페이지는 접속이 막혀 원문을 열지 못했어요. 약관상 출력물 소유와 상업 이용 조건, Firefly 설명은 단정하지 말고 공식 페이지에서 직접 확인하세요.
</Aside>


## 이 튜토리얼로 할 수 있게 되는 것

- 블로그 썸네일, 행사 안내 이미지 같은 업무용 이미지를 AI로 만들고 대화로 고칠 수 있어요.
- 잘 나오는 이미지 요청문(프롬프트) 구조를 쓸 수 있어요.
- 게시 전에 저작권·초상권·상표 위험을 점검하는 체크리스트를 쓸 수 있어요.
- AI로 만들었다는 표시(워터마크·메타데이터)가 무엇인지 알고 대응할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **프롬프트** | 이미지를 만들어 달라는 설명 문장이에요. 프롬프트 일반 원칙은 [C4. 프롬프트 작성법](/new-project1/claude/c04-prompting/)과 같아요. |
| **이미지 편집(대화형)** | 만든 이미지에 "배경을 밝게", "글자를 빼 줘"처럼 이어서 요청해 고치는 방식이에요. |
| **SynthID** | Google이 AI 생성 이미지에 넣는 보이지 않는 워터마크예요. Gemini 앱에 이미지를 올려 Google AI로 만들었는지 물어볼 수 있다고 안내돼요. |
| **C2PA(콘텐츠 자격 증명)** | 이미지 출처 정보를 담는 메타데이터 표준이에요. OpenAI는 C2PA와 SynthID를 지원하는 출처 신호로 안내해요. C2PA는 편집·변환·스크린샷·플랫폼 업로드 과정에서 지워질 수 있고, SynthID는 이미지 자체에 들어가는 워터마크라 일부 변형에도 남을 수 있다고 해요. |
| **초상권·퍼블리시티권** | 사람의 얼굴·모습을 허락 없이 쓰지 못하게 하는 권리예요. 도구 약관도 동의 없는 실존 인물 재현을 제한해요. |

### 어떤 도구를 쓸까요

| | Gemini 앱 | ChatGPT | 그 밖의 선택지 |
| --- | --- | --- | --- |
| 한국 이용 | 웹 앱은 70개 이상 언어·230개 이상 국가·지역에서 제공되고 한국어와 South Korea(대한민국)가 목록에 있다고 안내돼요 | 한국 App Store에 앱이 등록돼 있고 언어 목록에 한국어가 있어요. 한국 원화 인앱 가격도 표시돼요(Go ₩13,000, Plus ₩29,000 등, 2026-10-10) | Canva(12편), Adobe Firefly(한국어 도움말 여부는 확인 못 함) |
| 무료 여부 | 무료로 쓸 수 있고(일일 한도가 있음), Google AI 요금제에서는 더 높은 모델과 높은 한도를 준다고 안내돼요. 모델 이름은 페이지마다 달라요(도움말은 Nano Banana 2·Pro, 소개 페이지는 Nano Banana 2.1도 언급) | OpenAI 문서는 웹의 이미지 사용 가능 여부와 한도가 요금제와 워크스페이스 설정에 따라 달라진다고 안내해요. Free는 월 $0, Go는 월 $8, Plus는 월 $20예요(Pricing 문서). 무료 플랜의 구체적 한도 숫자는 찾지 못했어요 | 서비스별 확인 |
| 소유권 안내 | 다른 사람의 저작권·개인정보 권리를 침해하지 말고, 생성물을 쓰거나 게시하기 전에 직접 판단하라고 안내 | OpenAI 문서는 생성 이미지에 OpenAI 크레딧 표기가 필요 없다고 안내하고, 조직 지침과 OpenAI 사용 정책을 따르라고 해요. 약관상 출력 소유 조항은 원문을 열지 못해 확인하지 못했어요 | Firefly는 자체 모델을 "상업적으로 안전"하다고 설명(베타 기능은 개인용 제한 가능) |

Gemini 열은 Google 공식 도움말 원문으로, ChatGPT 열은 OpenAI 문서와 App Store 등록 정보로 정리했어요. Firefly 열은 adobe.com을 열지 못해 공식 사이트 검색 결과를 바탕으로 한 설명이니 단정하지 마세요.

**나이 조건(Gemini, 개인 계정)**: 도움말은 이미지를 만들려면 만 13세(또는 해당 국가의 적용 연령) 이상이어야 하고, 이미지를 편집하려면 18세 이상이어야 한다고 안내해요. 학교 계정은 접근 제한이 다를 수 있어요.

## 단계별 따라하기

예제는 "사내 교육 세미나 안내 블로그의 16:9 썸네일"이에요.

  'Gemini 앱에서 첫 이미지를 만들었어요',
  '대화로 2~3번 고쳤어요',

  'AI 표시 여부를 정하고 파일을 저장했어요',

<Steps>

1. **요청 전에 네 가지를 정하기**

   - **용도와 비율**: 블로그 썸네일, 16:9, 가로형
   - **주제**: 교육 세미나(사람 얼굴 없이 책상 위 노트북과 메모지)
   - **분위기**: 밝고 깔끔한 사무 분위기, 파란색 계열
   - **글자**: 이미지 안에 한글을 직접 넣을지 여부. AI가 만든 글자는 깨질 수 있으니 **글자는 비워 두고 Canva 같은 편집 도구에서 올리는 편**이 안전해요.

2. **Gemini 앱에서 첫 이미지 만들기**

   Gemini 앱에 로그인하고 이미지 만들기를 골라요. 공식 도움말은 컴퓨터에서 gemini.google.com에 들어가 왼쪽 위의 사이드바를 열고 **Images**를 누른 뒤, 템플릿을 고르거나 프롬프트를 입력하라고 안내해요. 소개 페이지는 도구 메뉴의 "Create images"를 안내하기도 해요. 화면 구성은 바뀔 수 있으니 실제 화면을 따르세요. 프롬프트는 "만들어 줘" 같은 말로 시작하는 편이 좋고, 스타일(사실적인 사진, 수채화 등)을 적으면 도움이 된다고 해요.

   <PromptBox>
   블로그 썸네일용 이미지를 만들어 줘. 16:9 가로형. 주제는 사내 교육 세미나 안내야. 밝은 사무실 책상 위에 노트북과 메모지, 커피잔이 있는 장면이고 사람은 나오지 않게 해 줘. 파란색 계열의 깔끔한 분위기. 이미지 안에 글자는 넣지 마. 위쪽 3분의 1은 제목을 올릴 수 있게 비워 줘.
   </PromptBox>

   <ScreenshotPlaceholder caption="Gemini 앱에서 이미지 생성 요청을 보낸 화면" officialUrl="https://support.google.com/gemini/answer/14286560" />

   <FlowSteps title="Gemini에서 이미지 만들고 고치기" officialUrl="https://support.google.com/gemini/answer/14286560" steps={[
     { where: 'gemini.google.com 사이드바', action: 'Images 누르기', result: '템플릿 고르기 또는 프롬프트 입력' },
     { where: '만든 이미지', action: '왼쪽 사이드바의 Library에서 열기', result: '아래 Chat으로 이어서 고치기' },
     { where: '이미지 위에 마우스 올리기', action: 'Download full size 누르기', result: '이미지 저장' },
   ]} />

3. **대화로 고치기**

   마음에 들지 않는 부분만 짚어서 이어서 요청해요. 처음부터 다시 만드는 것보다 안정적이에요. 도움말에 따르면 만든 이미지는 왼쪽 사이드바의 **Library**에서 열어 아래의 Chat으로 이어서 고칠 수 있고, 내 기기의 이미지를 올려 편집을 요청할 수도 있어요(이미지 편집은 18세 이상). 유료 요금제는 이미지 아래 **More > Redo with Pro**로 Nano Banana Pro로 다시 만들 수 있어요. 저장은 이미지에 마우스를 올려 "Download full size"를 눌러요. 다운로드 해상도는 Google AI 요금제는 2K, 요금제가 없으면 1K라고 안내돼요.

   <PromptBox>
   방금 이미지에서 커피잔을 빼고, 노트북 화면은 빈 화면으로 바꿔 줘. 전체 톤은 조금 더 밝게 해 줘.
   </PromptBox>

4. **저작권·초상권·상표 점검**

   게시하기 전에 아래를 확인해요. 도구가 대신 책임져 주지 않아요.

   - 실존 인물(직원, 고객, 유명인)의 얼굴이나 닮은 얼굴이 있나요?
   - 기존 로고, 상표, 캐릭터, 작품과 비슷한 요소가 있나요?
   - 이미지 안에 읽을 수 있는 글자나 가짜 브랜드명이 들어가 있나요?
   - 사내 기밀 이미지(도면, 화면 캡처)를 참고 이미지로 올리지 않았나요?

   <Aside type="caution" title="초상권: 동의 없이는 쓰지 마세요">
   OpenAI의 ChatGPT 이미지 생성 문서는 실존 인물을 그릴 때 사용 허락이 있는지 확인하고, 특정 브랜드나 작가를 흉내 내지 말고 원본 느낌의 표현을 요청하라고 안내해요. 약관과 사용 정책의 정확한 문구는 원문을 열지 못했으니 공식 페이지에서 확인하세요. 다른 도구도 비슷한 방향이에요. 직원이나 고객 사진을 AI로 바꿔 홍보에 쓰려면 **본인에게 용도를 설명하고 서면으로 동의**를 받으세요.
   </Aside>

5. **저장하고 AI 표시 정하기**

   Gemini 소개 페이지는 보이지 않는 SynthID 워터마크와 눈에 보이는 워터마크를 쓴다고 설명해요. 다만 보이는 워터마크가 모든 요금제·화면에 붙는지는 도움말에서 확인하지 못했으니 저장한 파일을 직접 확인하세요. 회사 정책에 맞게 "AI로 생성한 이미지" 표기 여부를 정하세요. 표시를 일부러 지우거나 숨기는 것은 피하세요.

6. **(대안) ChatGPT로 만들어 비교하기**

   같은 프롬프트를 ChatGPT에도 넣어 결과를 비교해 보세요. 웹 채팅에서 이미지를 요청하고, 고치려면 참고 이미지를 첨부해 바꿀 부분과 그대로 둘 부분을 말하면 돼요. OpenAI 문서는 이미지 사용 가능 여부와 한도가 요금제와 워크스페이스 설정에 따라 다르다고 안내해요. 한도 숫자는 화면에 나오는 안내를 따르세요.

</Steps>

## 자주 막히는 지점

### 한글이 깨지거나 글자가 엉터리로 나와요

- **원인**: 이미지 모델은 글자를 정확히 그리지 못할 수 있어요.
- **해결**: 이미지에는 글자를 넣지 말고, 제목은 Canva([12편](/new-project1/media/12-canva-sns/))나 슬라이드에서 올리세요.

### 한도에 걸려 더 이상 안 만들어져요

- **원인**: Gemini 도움말은 Nano Banana 2 이미지에 일일 한도(quota)가 있고, 한도에 이르면 Pro로 다시 만들기도 안 된다고 안내해요. 구체적인 숫자는 도움말에 없어요.
- **해결**: 화면 안내를 확인하고 한도가 풀릴 때까지 기다리거나 요금제를 비교하세요. 프롬프트를 한 번에 잘 쓰면 시도 횟수가 줄어요.

### 만든 이미지가 기존 작품·브랜드와 비슷해 보여요

- **원인**: 모델이 학습한 스타일과 닮을 수 있어요.
- **해결**: 쓰지 말고 프롬프트에서 특정 작가·브랜드 이름을 빼고 다시 만드세요. 애매하면 법무 담당에게 문의하세요.

### 이미지가 AI 생성인지 확인하고 싶어요

- **원인**: 메타데이터는 스크린샷·변환으로 사라질 수 있어요.
- **해결**: Google 공식 블로그에 따르면 Gemini 앱에 이미지를 올려 Google AI로 만들거나 편집했는지 물어보면 SynthID를 확인해 줘요(Google AI 콘텐츠만 인식). Nano Banana Pro 이미지에는 C2PA 메타데이터도 들어간다고 안내돼요. OpenAI는 이미지나 오디오 파일에 OpenAI의 C2PA·SynthID 신호가 있는지 확인하는 웹 도구(openai.com/verify)와 API를 제공해요. 다만 "감지 안 됨" 결과가 OpenAI가 만들지 않았다는 뜻은 아니에요(메타데이터가 지워졌거나 워터마크가 훼손됐을 수 있고, 다른 회사 모델의 결과물은 감지하지 못해요).
