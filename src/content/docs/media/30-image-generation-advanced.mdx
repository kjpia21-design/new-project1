## What you'll be able to do after this tutorial

- Write prompts in a 5-part structure that fits your purpose.
- Specify aspect ratio, style, and composition, and fix only the parts you don't like.
- Make a series of images with the same character or the same tone.
- Know the basic principles that work even when you switch tools, and the items to check before commercial use.

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Prompt structure** | A way of writing that separates purpose, subject and action, scene, composition/style/aspect ratio, and what to exclude. |
| **Aspect ratio** | The width:height ratio (for example, 16:9, 2:3). The Gemini overview page shows an example of writing something like "2:3 aspect ratio" in the request. |
| **Partial edit** | Changing only part of an image without regenerating the whole thing. Gemini introduces "Local edits" as a Nano Banana 2 feature. ChatGPT's docs say you can select a specific area of an image and describe what to change. |
| **Reference image** | An image you upload to edit or to have the tool imitate its style. Only use images you have the rights to. |
| **Character consistency** | The ability to keep the same person or character looking the same across several images. Gemini's help page introduces it as a Nano Banana 2 feature. |

<Steps>

1. **Write the prompt in 5 parts**

   The Gemini overview page says to start from "create + subject + action + scene," then add detail, while thinking about composition, style, quality, and aspect ratio. ChatGPT's docs point to purpose and audience, the main subject and situation, background/composition/style, lighting and color, and what to exclude. Combine the two and you get the 5 parts below.

   | Part | Content | Example |
   | --- | --- | --- |
   | 1. Purpose | Where will it be used? | An intro image for a bakery's Instagram |
   | 2. Subject and action | Who is doing what? | A bear-shaped bread mascot baking bread |
   | 3. Scene | Background and mood | A small bakery in morning sunlight |
   | 4. Composition, style, ratio | How does it look? | Cute flat illustration, 1:1, mascot in the center |
   | 5. Exclusions | What to leave out | No text, logos, or real brands |

   <PromptBox>
   Create an intro image for a bakery's Instagram. A bear-shaped bread mascot wearing an apron is taking bread out of an oven. The background is a small bakery in morning sunlight. Soft flat illustration style in warm beige and brown tones, 1:1 aspect ratio, with the mascot large in the center. Don't include any text or logos. Make it an original design that doesn't resemble any existing character.
   </PromptBox>

   <ScreenshotPlaceholder caption="An image made with a 5-part prompt in the Gemini app" officialUrl="https://support.google.com/gemini/answer/14286560" />

2. **Replace vague phrases with specific ones**

   ChatGPT's docs say to use concrete visual language, such as where the light comes from, rather than vague reactions like "beautiful lighting." They also say to repeat any conditions that must be kept.

   | Vague | Specific |
   | --- | --- |
   | Pretty | Soft morning sunlight coming in from a window on the left |
   | Cute | Rounded outlines, big eyes, simple blocks of color |
   | Premium | Restrained colors, a composition with lots of white space, a matte texture |

3. **Do partial edits one at a time**

   ChatGPT's docs say to make small, specific edits one element at a time. They say that when editing, you need to state exactly **what to change and what to leave alone**.

   <PromptBox>
   Edit the attached image. Change only the bread the mascot is holding to a croissant. Keep the mascot's face, apron, background, lighting, colors, and crop exactly the same, and don't add any text or logos.
   </PromptBox>

   <FlowSteps title="Fix part of an image made in Gemini" officialUrl="https://support.google.com/gemini/answer/14286560" steps={[
     { where: 'Top left of gemini.google.com', action: 'Click Open Sidebar → Library', result: 'A list of your generated images' },
     { where: 'The image to fix', action: 'Click the image, then click Chat below', result: 'An input box to continue the request on that image' },
     { where: 'The input box below', action: 'Write one thing to change and what to keep, then click Submit', result: 'The edited image' },
   ]} />

4. **Make a series with the same character**

   Gemini's help page says Nano Banana 2 has the ability to keep a person or character looking the same across several images. To get better results, do the following.

   - When you like the first image, **write down that character's features and save them** (color, clothing, props, facial features).
   - In the next request, **paste the same description as is** and change only the scene.
   - If needed, upload the first image as a reference image. ChatGPT's docs say that when you use several reference images, you should explain their order and roles, like "Image 1 is the photo to edit, Image 2 is a style reference."
   - The official docs give no numbers for how well the same character is kept. Look at the results yourself, and if they drift, make the description more specific.

   <PromptBox>
   Image 1 is our bakery's mascot. Keep Image 1's face, beige body, brown apron, and small bread hat exactly as they are. This time, make a scene where the mascot is behind the counter handing a customer a bag of bread. 1:1 aspect ratio, the same flat illustration style, and no text or logos.
   </PromptBox>

5. **Handle text in images and informational images**

   ChatGPT's docs say to keep text in images short, specify the wording exactly in quotes, describe the font feel, size, color, and position, and state that no other text should be added. Gemini's help page says Nano Banana 2 has improved text rendering and Pro is more detailed for text and infographics. Even so, ChatGPT's docs say that for results with a lot of text or for print, you should **proofread every word yourself** and finish in a design tool if needed.

   <PromptBox>
   Add only the phrase "Fresh-baked today" in bold white sans-serif on a single line at the top center of the image. Don't add any other text, and don't change anything else in the image.
   </PromptBox>

   For Korean text, check by eye that the spelling and letter shapes are correct. We couldn't find separate figures for Korean text accuracy in the official docs.

## Quick reference

### Edit request sentence templates

| Situation | Sentence |
| --- | --- |
| Change just one thing | "Change only ○○ to △△, and keep □□ the same" |
| Adjust the mood | "Make it brighter," "reduce the saturation," "simplify the background" |
| Change while keeping the style | "Keep the composition and change only the style to watercolor" |
| Multiple reference images | "Image 1 is the photo to edit, Image 2 is a style reference. Keep Image 1's composition and objects" |
| Text | "Only the phrase '○○', in bold white sans-serif, top center, no other text" |

## Common sticking points

### Every edit turns into a different picture

- **Cause**: You changed several elements at once, or didn't say what to keep.
- **Fix**: Change only one thing at a time and list the elements to keep (face, background, lighting, crop). ChatGPT's docs recommend this approach too.

### The character looks different in every image

- **Cause**: The description changes each time, or there's no reference image.
- **Fix**: Save the character description and paste it as is. Upload the first image as a reference and write "keep ○○ from Image 1." If it still drifts, you can try Redo with Pro using Nano Banana Pro (requires a Google AI plan, and isn't available once you reach the Nano Banana 2 daily limit).

### The Korean text is wrong

- **Cause**: Text rendering may not be perfect.
- **Fix**: Keep the text short and specify it in quotes. If it's still wrong, leave the text out of the image and add it in Canva or similar.

### The image feels like an existing brand or artist

- **Cause**: The prompt has wording that evokes a specific brand or artist.
- **Fix**: Remove artist and brand names and ask for an "original design." ChatGPT's docs also say to ask for generic or original-feeling work instead of imitating a specific brand or artist.

## Practical tips

- **Manage your prompts as files.** Saving character descriptions, style sentences, and exclusion lists makes a series easy.
- **Try small first.** Once the composition is right, then raise the detail.
- **State the aspect ratio up front.** Changing it later can throw off the composition.
- **If you need a human face, get permission first.** ChatGPT's docs also say to confirm permission for real people.
- **Have your company set a policy on AI-generation labeling.** Gemini describes using an invisible SynthID watermark and a visible watermark. Don't deliberately remove the marks.
