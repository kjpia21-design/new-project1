<Summary>
- AI는 **초안을 잡아 주는 기획자**로 좋아요. 막연한 생각을 몇 분 만에 하루 단위 일정표, 예산표, 준비물 목록으로 바꿔 줘요. 하지만 수시로 바뀌는 정보의 정답지는 아니에요.
- 맡길 일 다섯 가지: **조건 정하기, 일정표 초안, 예산표, 준비물, 확인할 목록 만들기.** 아래에 복사해 쓸 프롬프트 6개가 있어요.
- **운영 시간, 가격, 교통 시간표, 비자·입국 규정은 바뀌어요.** AI가 알려 준 이런 정보는 해당 장소·운영사·정부의 공식 사이트에서 확인하기 전까지는 미확인으로 보세요. (2026-11-02 기준)
- 공식 문서로 확인한 것: **Claude**는 출처 인용과 함께 웹 검색을 할 수 있고(현지 맞춤 결과를 요청하면 IP로 추정한 위치를 쓸 수 있어요), **Gemini**는 Keep Activity(활동 저장)가 켜져 있으면 구글 지도·항공편·호텔의 공개 정보를 자동으로 쓰며, **ChatGPT**는 자체 웹 검색 도구가 있고 검색 결과는 신뢰할 수 없는 입력으로 다루라고 안내해요.
- 어느 서비스의 운영 시간·가격·예약 정보가 얼마나 최신이고 정확한지는 문서에서 **확인하지 못했어요.** 결제 정보나 여권 정보는 AI 대화에 입력하지 마세요.
</Summary>

## 이 튜토리얼을 마치면 할 수 있어요

- AI가 쓸모 있고 현실적인 제안을 하도록 여행 조건을 설명할 수 있어요.
- 내 속도·예산·일행에 맞는 하루 단위 일정표를 받을 수 있어요.
- 고쳐 쓸 수 있는 예산표와 준비물 목록을 만들 수 있어요.
- AI가 한 말을 공식 사이트에서 확인할 짧은 체크 목록으로 바꿀 수 있어요.
- 웹 검색·지도 기능에 대해 공식 문서가 말하는 것과 말하지 않는 것을 알 수 있어요.

이 튜토리얼은 **계획 세우기**에 집중해요. AI 검색 전반은 [AI 검색 제대로 쓰기](/ko/chat/22-ai-search/), 믿기 전에 사실을 확인하는 방법은 [AI 답변 믿어도 될까](/ko/basics/04-fact-checking/)를 보세요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **조건** | 여행의 고정 사실이에요. 날짜, 예산, 일행, 이동 불편 여부, 꼭 가고 싶은 곳 등. 많이 알려 줄수록 AI가 덜 추측해요. |
| **일정표** | 장소와 대략의 시간을 하루 단위로 정리한 계획이에요. 예약이 아니라 초안으로 보세요. |
| **웹 검색** | AI가 최신 페이지를 찾아보고 출처를 달아 주는 기능이에요. 없으면 학습한 내용으로 답하는데, 오래됐을 수 있어요. |
| **출처 인용** | 어떤 말이 어느 페이지에서 왔는지 알려 주는 링크예요. 직접 열어 확인하세요. |
| **공식 출처** | 관광지·항공사·철도 운영사·호텔의 사이트, 또는 규정을 정하는 정부 기관이에요. |
| **확인 목록** | 결제하거나 출발하기 전에 꼭 확인할 항목을 모은 짧은 목록이에요. |

### 검색·지도 기능: 확인한 범위 (2026-11-02 기준)

| 항목 | Claude | Gemini | ChatGPT |
| --- | --- | --- | --- |
| 웹 검색 | 최신 정보를 위해 인터넷을 검색하고 답변에 출처를 달아요. Team·Enterprise 플랜은 소유자가 조직 설정에서 먼저 켜야 해요. 새 Claude 환경에서는 토글이 없고 도움이 될 때 Claude가 알아서 검색한다고 적혀 있어요 | Google 검색의 공개 정보는 Keep Activity가 꺼져 있거나 로그아웃 상태여도 항상 써요 | 자체 웹 검색 도구가 있어요. 웹 ChatGPT에서는 검색을 쓸 때 결과와 출처가 대화에 나타나요. 워크스페이스 설정이 사용 여부를 제한할 수 있어요 |
| 지도·항공·호텔 | 웹 검색 문서에는 언급 없음 | 구글 지도·항공편·호텔의 공개 정보를 자동으로 써요. 이 정보는 Keep Activity가 켜져 있어야 해요 | 웹 검색 문서에는 언급 없음 |
| 위치 | 현지 맞춤 결과를 요청하면 IP로 추정한 위치를 쓸 수 있어요 | 확인하지 못함 | 확인하지 못함 |
| 검증 | 인용된 출처를 교차 확인하고 중요한 결정에는 신뢰할 만한 출처를 쓰라고 안내해요 | 언급 없음 | 모든 웹 결과를 신뢰할 수 없는 입력으로 다루라고 안내해요 |
| 사용량 한도 | 웹 검색과 웹 가져오기(fetch)는 사용량 한도에 포함돼요 | 확인하지 못함 | 확인하지 못함 |

<Aside type="note" title="확인하지 못한 점">
읽은 공식 문서에는 어느 서비스가 보여 주는 운영 시간·가격·예약 가능 여부·교통 시간표가 **얼마나 최신이고 완전한지**가 나와 있지 않았어요. **예약이나 결제를 대신해 주는지**도 직접 시험하지 않았어요. Gemini의 연결된 앱 문서에는 찾은 경험의 예약 같은 작업을 도울 수 있다고 적혀 있지만, 어떤 앱과 국가에서 되는지는 환경마다 달라요. 내 앱의 연결된 앱 설정에서 확인하세요. 어느 나라의 비자·입국 규정도 확인하지 않았어요.
</Aside>

<Aside type="caution" title="민감한 정보는 넣지 마세요">
여권 번호, 카드 번호, 예약 확인 코드, 집 주소는 AI 대화에 입력하지 마세요. 날짜와 대략의 예산처럼 계획에 필요한 것만 알려 주세요. 일행이 있다면 다른 사람의 정보를 넣기 전에 먼저 물어보세요. 개인정보 설정과 넣지 말아야 할 것은 [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)를 보세요. 가짜 예약 사이트와 지나치게 좋은 조건의 제안도 조심하세요. [AI 사기·딥페이크 피하는 법](/ko/basics/10-ai-scams-deepfakes/)을 참고하세요.
</Aside>

<Steps>

1. **조건부터 정하기**

   어디로, 언제, 누구와, 얼마로 가는지 적고, 어떤 여행을 원하는지 말하세요. AI는 아는 만큼만 맞출 수 있어요. 대괄호 부분을 내 상황으로 바꿔 쓰세요. 프롬프트 구조는 [질문 잘하는 법 기초](/ko/basics/03-asking-well/)와 [실무 프롬프트 작성법](/ko/chat/01-prompt-basics/)을 참고하세요.

   <PromptBox label="조건 정리 프롬프트">
   여행을 계획하고 있어. 목적지: [도시나 지역]. 날짜: [대략의 날짜, 일수]. 인원: [성인 2명, 7세 아이 1명]. 항공권 제외 총예산: [금액과 통화]. 속도: [여유롭게, 하루 핵심 활동 2개]. 필요한 점: [오래 걷기 힘듦, 채식]. 꼭 가고 싶은 곳: [목록]. 계획을 짜기 전에, 네 제안을 가장 크게 바꿀 질문을 최대 5개만 해 줘. 아직 계획은 짜지 마.
   </PromptBox>

   질문에 답한 다음 넘어가세요. 내가 가장 중요하게 여기는 부분을 AI가 추측하는 일을 막아 줘요.

2. **하루 단위 일정표 초안 받기**

   <PromptBox label="일정표 프롬프트">
   내 답변을 바탕으로 하루 단위 일정표 초안을 짜 줘. 하루마다 오전·오후·저녁과 장소 사이 대략의 이동 시간을 써 줘. 가까운 장소끼리 묶어 줘. 하루마다 비 오는 날 대안을 하나씩 넣어 줘. 운영 시간, 가격, 예약 필요 여부는 사실처럼 쓰지 말고, 내가 공식 사이트에서 확인해야 할 곳 옆에 [확인 필요] 표시를 붙여 줘.
   </PromptBox>

   웹 검색을 쓸 수 있다면 "웹을 검색하고 출처를 달아 줘"를 덧붙여도 돼요. Claude의 웹 검색 문서에는 프롬프트에 "Search the web"을 넣으면 검색을 확실히 하게 할 수 있다고 적혀 있어요. 인용된 링크는 직접 열어 보세요.

   <FlowSteps title="AI의 검색이 켜져 있는지 확인하기" officialUrl="https://support.claude.com/en/articles/10684626-enable-and-use-web-search" steps={[
     { where: '앱 (Claude / Gemini / ChatGPT)', action: '"웹에서 현재 운영 시간을 검색하고 출처를 달아 줘"처럼 최신 정보나 출처를 요청해요', result: '답변에 출처나 검색 표시가 있는지 보세요' },
     { where: 'Claude에 토글이 있는 경우', action: '대화창 왼쪽 아래 + 버튼을 눌러 Web search를 찾아요', result: '체크 표시가 있으면 켜진 거예요. 새 Claude 환경에는 토글이 없어요' },
     { where: 'Gemini', action: '사이드바의 Customize에서 Connectors를 열어 내가 쓸 수 있는 연결된 앱을 확인해요', result: '목록은 앱·기기·국가에 따라 달라요' },
     { where: '회사·학교 계정', action: '검색이나 앱이 꺼져 있는지 관리자에게 물어봐요', result: '워크스페이스 설정이 사용 여부를 제한할 수 있어요' },
   ]} />

3. **일행에 맞게 다듬기**

   처음부터 다시 하지 말고 작게 나눠서 고쳐 달라고 하세요.

   <PromptBox label="수정 프롬프트">
   일정표를 고쳐 줘: 하루 핵심 일정을 최대 [2]곳으로 줄이고, [장소]는 더 한적한 곳으로 바꾸고, [2일차와 4일차]에는 점심을 여유롭게 넣어 줘. [확인 필요] 표시는 그대로 두고. 그다음 가장 빡빡해 보이는 3일을 알려 줘.
   </PromptBox>

4. **예산표 만들기**

   <PromptBox label="예산 프롬프트">
   이 여행의 예산표를 만들어 줘. 항목은 숙박, 현지 교통, 식비, 체험, 입장권, 쇼핑, 예비비 10%야. 내가 이미 아는 숫자는 [1박 숙박비, 확정된 입장권]이야. 나머지는 낮은 추정치와 높은 추정치를 쓰고 "추정, 확인 필요"로 표시해 줘. 두 경우의 합계를 보여 주고, 초과할 가능성이 큰 두 항목을 알려 줘.
   </PromptBox>

   출처를 달지 않은 비용 숫자는 추측이에요. 공식 사이트나 예약 페이지의 실제 가격으로 바꿔 넣으세요. 계획을 돕는 용도이고, 재무 조언이 아니에요.

5. **준비물 목록 만들기**

   <PromptBox label="준비물 프롬프트">
   [목적지]에서 [월]에 [인원]이 [일수]일 지내는 여행의 준비물 목록을 만들어 줘. 서류, 옷, 건강, 전자기기, 기타로 묶어 줘. 규정에 따라 달라지는 것(예: 약, 변환 플러그, 배터리)에는 [확인 필요]를 붙이고, 그 규정을 사실처럼 쓰지 마.
   </PromptBox>

   날씨는 출발일 가까이에 기상 서비스에서 확인하세요.

6. **계획을 확인 목록으로 바꾸기**

   가장 중요한 단계예요.

   <PromptBox label="확인 목록 프롬프트">
   위 일정표와 예산표에서, 예약하거나 출발하기 전에 내가 확인해야 할 모든 항목을 뽑아 줘: 운영 시간과 휴무일, 입장권 가격과 사전 예약 필요 여부, 교통 시간표와 패스, 내 국적 기준 입국·비자 요건, 예방접종·건강 관련 규정, 아이나 약에 관한 현지 규정. 항목마다 어떤 종류의 공식 출처를 확인하면 되는지(예: 관광지 사이트, 철도 운영사, 대사관이나 출입국 관리 기관) 알려 줘.
   </PromptBox>

   목록을 공식 사이트에서 하나씩 확인하고, 알게 된 내용으로 계획을 고친 뒤 확인한 날짜를 적어 두세요.

</Steps>

| 더 나은 제안 | 조건 정리 프롬프트: 날짜, 일행, 예산, 속도, 필요한 점 |
| 현실적인 일정 | 일정표 프롬프트: 가까운 곳끼리 묶기, 비 오는 날 대안 |
| 믿을 수 있는 예산 | 아는 숫자는 직접 넣고 나머지는 추정으로 표시 |
| 덜 놀라기 | [확인 필요] 표시를 요청하고 확인 목록 만들기 |
| 최신 정보 | AI에게 웹 검색과 출처를 요청하고 링크 직접 열기 |
| 운영 시간·가격 | 해당 장소의 공식 사이트에서 다시 확인 |
| 비자·입국 규정 | AI가 아니라 목적지 정부의 공식 사이트로 확인 |
| 한도가 걱정될 때 | Claude 웹 검색은 사용량 한도에 포함돼요. [요금제와 사용량 한도](/ko/claude/c02-plans-limits/) 참고 |

## 자주 막히는 지점

### 일정표는 멋진데 실제로는 따라가기 어려워요

- **원인**: 프롬프트에 내 속도, 교통수단, 장소 사이의 거리가 없었어요.
- **해결**: "가까운 곳끼리 묶고, 이동 시간을 보여 주고, 하루 핵심 일정은 [2]곳까지"를 덧붙이세요. 경로는 지도에서 직접 비교해 보세요.

### AI가 알려 준 운영 시간이나 가격이 틀렸어요

- **원인**: AI가 학습 데이터나 오래된 페이지에 의존했을 수 있고, 시간과 가격은 바뀌어요.
- **해결**: [확인 필요] 표시를 요청하고 공식 사이트에서 확인하세요. 출처 없는 숫자는 추측으로 보고, 출처가 달린 페이지도 오래됐을 수 있다는 점을 기억하세요.

### 비자·입국 안내가 확신에 차 있는데 확인이 안 돼요

- **원인**: 규정은 국적, 목적, 날짜에 따라 달라지고 바뀔 수 있어요.
- **해결**: AI는 물어볼 질문 목록을 만드는 데만 쓰세요. 규정은 목적지 정부의 공식 사이트나 대사관에서 확인하세요. 이 글은 어느 나라의 입국 규정도 확인하지 않았어요.

### 유명한 곳만 계속 추천해요

- **원인**: 취향을 말하지 않으면 AI는 가장 흔한 추천으로 기울어요.
- **해결**: 피하고 싶은 것("단체 관광객이 많은 곳은 싫어")과 좋아하는 것("시장, 산책")을 말하고, 하루마다 덜 알려진 선택지 두 개를 요청하세요.

### 웹 검색을 썼는지 모르겠어요

- **원인**: 앱이 알아서 검색 여부를 정하고, 토글이 없는 경우도 있어요.
- **해결**: 프롬프트에 "웹을 검색하고 출처를 달아 줘"를 넣고 답변에 출처가 있는지 보세요. 없으면 미확인으로 다루세요.

## 실전 팁

- **초안은 AI로, 사실은 공식 사이트로.** 결제하기 전에 운영 시간·가격·교통·입국 규정을 다시 확인하세요.
- **확인한 날짜를 적어 두세요.** 정보가 바뀌니 "2026-11-02 확인" 같은 메모가 나중에 계획을 다시 볼 때 도움이 돼요.
- **여유를 두세요.** 계획에 자유 시간과 예산 여유분을 넣어 두세요.
- **예약 확인서는 직접 보관하세요.** 대화창이 아니라 내 이메일이나 파일에 두세요.
- **지도와 실시간 위치는 조심하세요.** 실시간 위치 공유는 선택이에요. 편한 만큼만 공유하세요.
- **중요한 여행은 사람에게 물어보세요.** 건강상 필요, 아이와의 장거리 여행, 복잡한 비자는 여행사나 공식 기관이 AI가 할 수 없는 확인을 해 줄 수 있어요.
