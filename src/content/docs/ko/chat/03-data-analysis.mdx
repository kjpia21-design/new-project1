<Summary>
- AI에게 표를 맡길 때는 **데이터 구조 설명 → 정제 → 질문 → 검산 → 결과 파일** 순서로 가세요.
- Claude는 **코드 실행·파일 생성** 기능으로 CSV·TSV를 분석하고 .xlsx와 차트(PNG)를 만들어 줘요 (2026-10-10 기준).
- 결과 숫자는 **엑셀에서 샘플 몇 건을 직접 검산**하세요. AI의 계산 과정(코드)을 보여 달라고 하면 확인이 쉬워져요.
- **개인정보와 회사 기밀은 올리기 전에 가리세요.** 도구마다 학습·보관 정책이 달라요.
- Gemini 앱도 업로드한 스프레드시트로 차트를 만들 수 있다고 안내해요(Gemini 도움말). ChatGPT는 OpenAI 문서 기준으로 Work 모드에서 파일을 올려 데이터를 분석하고 스프레드시트를 만들 수 있어요(2026-10-10). 파일 크기·행 수 한도는 찾지 못했어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 지저분한 CSV를 정리하고(중복, 빈칸, 형식 통일) 집계표를 만들 수 있어요.
- "어느 달이 가장 높은가?" 같은 질문을 말로 던져 답과 근거를 받을 수 있어요.
- 차트와 엑셀 파일을 결과물로 받을 수 있어요.
- 개인정보와 기밀 데이터를 안전하게 다루는 기준을 세울 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **코드 실행·파일 생성** | AI가 격리된 환경에서 코드를 돌려 계산하고 파일을 만드는 Claude의 기능이에요(Code execution and file creation). 그래서 큰 표도 눈대중이 아니라 계산으로 처리해요. |
| **비식별화** | 이름·연락처·계좌 같은 식별 정보를 지우거나 가명으로 바꾸는 일이에요. |
| **검산** | AI의 답을 엑셀 등 다른 방법으로 직접 확인하는 일이에요. |

Claude 공식 도움말 기준으로 이 기능은 Free·Pro·Max에서 기본으로 켜져 있어요. Team과 신규 Enterprise 조직도 기본 켜짐이지만 Owner가 끌 수 있어요. 개인 계정은 설정(Settings) > 기능(Capabilities)의 "Code execution and file creation", Team·Enterprise는 조직 설정(Organization settings) > Capabilities에서 확인해요. 화면은 바뀔 수 있으니 안내에 따르세요.

<Aside type="note" title="데이터 분석에 쓰는 형식">
공식 도움말은 데이터 분석용 업로드로 CSV와 TSV를 명시해요. XLSX를 올리려면 코드 실행·파일 생성이 켜져 있어야 해요. 생성되는 파일은 .xlsx, .pptx, .docx, PDF와 PNG 차트 등이고 업로드·다운로드 모두 파일당 30MB예요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '분석할 파일에서 개인정보를 가렸어요',
  '코드 실행·파일 생성 기능이 켜져 있는지 확인했어요',
  '열 이름과 의미를 AI에게 설명했어요',
  '정제 규칙을 확인한 뒤 분석을 시켰어요',
  '엑셀에서 샘플 3건 이상 검산했어요',
]} />

<Steps>

1. **데이터 준비와 비식별화**

   연습은 가상 데이터로 하세요. 실무 파일이라면 아래를 먼저 점검해요.

   - 이름, 전화번호, 이메일, 주소, 주민등록번호, 계좌·카드 번호 열을 지우거나 ID로 바꿨나요?
   - 단가·원가·거래처명처럼 경쟁사에 알려지면 곤란한 값이 있나요?
   - 회사 보안 지침이 외부 AI 서비스 사용을 허용하나요?

   Claude 공식 도움말은 금융 정보, 건강 기록, 비밀번호, 기밀 문서를 입력할 때 주의하라고 안내해요.

2. **파일 올리고 구조 설명시키기**

   파일을 첨부하고 먼저 읽기만 시켜요. 바로 분석부터 시키지 마세요.

   <PromptBox>
   첨부한 CSV는 2026년 상반기 지점별 매출이야. 열은 날짜, 지점, 상품분류, 수량, 매출액이야. 먼저 아래만 해줘. 분석은 아직 하지 마.
   1) 행 수와 열별 자료형
   2) 빈칸·중복·형식이 섞인 값(예: 날짜 형식, 숫자 중간의 쉼표)
   3) 이상해 보이는 값 5개
   </PromptBox>

   <ScreenshotPlaceholder caption="파일 첨부 후 구조를 점검한 결과" officialUrl="https://support.claude.com/en/articles/8241126-upload-files-to-claude" />

3. **정제 규칙을 정하고 확인받기**

   AI가 마음대로 지우거나 채우지 않게, 규칙을 내가 정해요.

   <PromptBox>
   방금 발견한 문제를 이렇게 처리해줘. 중복 행은 제거, 날짜는 YYYY-MM-DD로 통일, 매출액이 비어 있으면 지우지 말고 "누락"으로 표시. 처리 후 바뀐 행 수를 알려주고, 원본 데이터는 그대로 두고 정리본을 새로 만들어줘.
   </PromptBox>

4. **질문하고 근거 받기**

   질문은 구체적으로, 답에는 계산 방식을 함께 받으세요.

   <PromptBox>
   정리본으로 지점별·월별 매출 합계 표를 만들고, 전월 대비 증감률이 가장 크게 떨어진 지점 3곳을 알려줘. 각 결과에 어떤 열을 어떤 기준으로 합산했는지 한 줄씩 설명해줘.
   </PromptBox>

   코드 실행이 켜져 있으면 AI가 실제로 계산을 돌려요. 계산 방법이 궁금하면 "사용한 계산 단계를 보여줘"라고 요청하세요.

5. **차트와 결과 파일 받기**

   <PromptBox>
   위 지점별·월별 합계를 엑셀 파일(.xlsx)로 만들어줘. 시트 1은 정리본 데이터, 시트 2는 합계표, 시트 3은 지점별 월 매출 추이 선 그래프로 구성해줘.
   </PromptBox>

   공식 도움말의 예시 요청도 "PDF의 데이터를 엑셀로 옮기고 요약 차트를 만들어 줘" 같은 형태예요.

6. **검산하기**

   받은 엑셀을 열어 지점 하나와 달 하나를 골라 직접 합계를 내 보세요. 3건 이상 맞으면 안심할 수 있어요. 틀리면 어디서 달라졌는지 AI에게 되물으세요.

   <PromptBox>
   내가 엑셀에서 계산해 보니 강남점 3월 합계가 네 표와 달라. 3월 강남점에 포함한 행 목록을 보여주고, 날짜 형식이나 누락 처리 때문에 빠진 행이 있는지 확인해줘.
   </PromptBox>

</Steps>

## 자주 막히는 지점

### 엑셀(.xlsx)이 올라가지 않아요

- **원인**: 코드 실행·파일 생성이 꺼져 있을 수 있어요. Team·Enterprise는 Owner가 껐을 수 있어요.
- **해결**: Settings > Capabilities에서 켜세요. 조직 계정이면 관리자에게 문의하세요. 당장은 엑셀을 CSV로 저장해 올릴 수 있어요.

### 숫자가 엑셀과 달라요

- **원인**: 중복 제거나 누락 처리 기준, 날짜 형식 때문에 포함된 행이 다를 수 있어요.
- **해결**: 정제 규칙을 명시하고 포함된 행 목록을 보여 달라고 하세요.

### 파일이 너무 커요

- **원인**: 분석용 파일 한도가 파일당 30MB예요.
- **해결**: 필요한 열과 기간만 남기거나 월별로 나눠서 올리세요.

### 분석 중에 외부 데이터에 접근하려 해요

- **원인**: 공식 도움말은 네트워크 접근이 켜져 있으면 외부 파일·웹사이트에 숨은 악성 지시가 Claude로 하여금 신뢰할 수 없는 코드를 실행하거나 대화 데이터를 외부로 보내게 할 수 있다고 경고해요.
- **해결**: AI가 하는 일을 지켜보고, 예상 못 한 접근이 보이면 중단하세요. 사내 데이터를 다룰 때는 네트워크 접근 설정을 끄는 쪽이 안전해요. 출처가 불분명한 외부 파일은 올리지 마세요.

## 개인정보와 회사 기밀 데이터 주의점

- **올리지 않는 것이 기본이에요.** 고객 명단, 급여표, 건강 정보, 계약 원가표는 비식별화하거나 회사가 승인한 도구만 쓰세요.
- **학습 설정을 확인하세요.** Claude 가격 페이지는 Free·Pro·Max의 모델 학습 항목을 "Opt-out"으로, Team·Enterprise를 "None by default"로 표시해요. 도움말은 허용한 대화만 개선에 쓰이고 설정은 언제든 바꿀 수 있다고 설명해요. 시크릿(incognito) 채팅은 개선에 쓰이지 않아요. 실제 화면의 설정 이름은 안내에 따르세요.
- **조직 계정을 우선 검토하세요.** 업무 데이터는 개인 무료 계정보다 회사가 계약한 Team·Enterprise 같은 조직용 플랜이 정책 면에서 유리할 수 있어요. 정책은 계약마다 다르니 보안 담당자에게 확인하세요.
- **Gemini는 Keep Activity 설정을 확인하세요.** Gemini 개인정보 허브는 Keep Activity가 켜져 있으면 일부 대화를 사람이 검토해 서비스 개선에 쓸 수 있다고 밝혀요. 끄거나 임시 채팅을 쓰면 AI 모델 학습에 쓰이지 않는다고 안내하지만, 응답과 보호 목적의 처리는 계속된다고 해요. 기밀 정보는 넣지 마세요.
- **ChatGPT는 Data controls 설정을 확인하세요.** OpenAI 문서는 작업 중 ChatGPT가 쓰는 정보에 사용자가 고른 데이터 제어 설정이 적용된다고 안내하고, 설정 위치를 Settings > Data controls로 적어요. 개인 계정의 모델 학습 기본값과 보관 기간은 열 수 있는 OpenAI 문서에서 찾지 못해 적지 않았어요. Business 요금제는 "비즈니스 데이터로 기본적으로 학습하지 않는다"고 안내해요(Pricing 문서, 2026-10-10). 임시 채팅(temporary chat) 기능이 있다는 것은 단축키 안내에서 확인했지만, 저장·학습 처리 방식은 공식 도움말에서 확인하세요.
- **개인정보 보호법 등 법적 의무**는 회사 법무·보안 담당자가 판단할 일이에요. 이 튜토리얼은 법률 자문이 아니에요.

## 실전 팁

- **원본은 건드리지 마세요.** "정리본을 새로 만들어줘"라고 요청해 원본을 지키세요.
- **가정을 말하게 하세요.** "분석에 쓴 가정과 제외한 행을 마지막에 적어줘"를 습관으로 만드세요.
- **한 번에 하나씩 시키세요.** 정제, 집계, 차트를 나눠 요청하면 오류를 일찍 잡아요.
- **중요한 숫자는 두 번 확인하세요.** 보고서에 들어갈 숫자는 엑셀 함수로 한 번 더 계산해 보세요.
- **반복 분석은 지침으로 저장하세요.** Claude 프로젝트에 정제 규칙을 넣어 두면 매번 설명하지 않아도 돼요([C5](/ko/claude/c05-projects/)).
