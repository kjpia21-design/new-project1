<Summary>
- 좋은 이메일 프롬프트에는 네 가지가 들어가요. **받는 사람, 원하는 것, 말투, 바꾸면 안 되는 사실.** 이것만 알려 주면 첫 초안이 꽤 쓸 만해요.
- 거친 메모로 시작해도 괜찮아요. AI는 메모를 정돈된 글로 바꾸는 데 능하지만, 알려 준 내용만 쓸 수 있어서 **빈칸이 있으면 그럴듯한 내용을 지어내요.**
- 같은 글의 **말투를 바꿀 수 있어요** (더 공손하게, 더 단호하게, 더 짧게). 두 가지 버전을 받아서 골라 보세요.
- **답장**은 받은 메시지를 붙여 넣고 어떻게 답하고 싶은지 알려 주세요. 상대가 한 질문을 먼저 정리하게 하면 빠뜨리지 않아요.
- 실제 메일을 붙여 넣기 전에 **이름, 숫자, 기밀 내용을 지우세요** (아래 상자 참고). 초안은 꼭 직접 읽고 직접 보내세요.
- Gmail의 "Help me write"로 작성 창 안에서 같은 일을 할 수도 있어요. 다만 Gmail 도움말에 따르면 해당하는 Google Workspace 또는 Google AI 요금제가 필요하고, 개인 Google 계정은 미국에서만 쓸 수 있어요 (2026-11-01 기준).
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 몇 줄의 메모를 제목까지 있는 이메일로 바꿀 수 있어요.
- 초안의 말투를 더 공손하게, 더 직접적으로, 더 부드럽게, 더 짧게 바꿀 수 있어요.
- 받은 메시지의 질문을 빠짐없이 짚어 답장을 쓸 수 있어요.
- 직접 쓴 영어 비즈니스 이메일을 다듬고, 무엇이 왜 바뀌었는지 배울 수 있어요.
- 개인정보와 기밀을 붙여 넣지 않는 습관을 들일 수 있어요.

이 글은 **글쓰기 자체**를 다뤄요. 받은편지함을 요약하고 라벨을 정리하거나 Gmail·Outlook 안에서 AI를 쓰는 법은 [AI로 받은편지함 정리하기](/ko/automation/38-email-ai/)를, 긴 보고서와 제안서는 [보고서·제안서 초안 쓰고 다듬기](/ko/chat/04-write-reports/)를 보세요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **초안** | AI가 처음 써 준 버전이에요. 그대로 보내는 글이 아니라 출발점이에요. |
| **말투(톤)** | 글이 주는 느낌이에요. 격식 있게, 친근하게, 사과하는 투로, 단호하게 등이 있어요. |
| **경어 수준** | 높임의 정도예요. 가까운 동료에게 쓰는 글과 거래처에 쓰는 글은 달라요. |
| **고정 사실** | 날짜, 금액, 이름, 약속처럼 쓴 그대로 남아야 하는 내용이에요. |
| **자리표시자** | [거래처명]처럼 대괄호로 바꿔 둔 말이에요. AI가 쓴 뒤에 직접 채우면 실제 값을 붙여 넣지 않아도 돼요. |

Claude 공식 시작 가이드는 구체적으로 요청하고, 간단하게 시작하고, 후속 요청으로 다듬으라고 안내해요. 이메일 쓰기에 딱 맞는 조언이에요. Gmail 도움말도 "Help me write"에 대해 프롬프트가 구체적일수록 초안이 더 알맞아진다고 설명하면서, 받는 사람, 주제와 필요한 행동, "formal"이나 "casual" 같은 말투 단어를 넣으라고 해요.

<Aside type="caution" title="이런 내용은 대화창에 붙여 넣지 마세요">
실제 고객·동료의 이름과 연락처, 주민등록번호·계좌·카드 번호, 비밀번호, 특정인의 건강·법률 정보, 회사가 기밀로 정한 내용이에요. [거래처 A], [금액], [날짜]처럼 바꿔서 쓰고, 실제 값은 나중에 직접 채우세요. 이유와, 대화가 학습에 쓰이는지 정하는 설정은 [개인정보·회사 정보 지키며 AI 쓰기](/ko/basics/05-privacy-safety/)에 있어요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '이름, 숫자, 기밀 내용을 자리표시자로 바꿨어요',
  '받는 사람, 원하는 것, 말투를 AI에게 알렸어요',
  '바뀌면 안 되는 사실을 따로 적었어요',
  '말투가 다른 버전을 받아서 비교했어요',
  '최종 초안을 소리 내어 읽고 날짜·금액·이름을 확인했어요',
  '직접 보냈어요',
]} />

<Steps>

1. **메모를 적고 첫 초안 받기: 한국어 업무 이메일**

   표현은 신경 쓰지 말고 하고 싶은 말을 적은 뒤, 읽는 사람과 목적을 알려 주세요. 한국 업무 이메일은 보통 인사, 소속과 이름, 용건, 마무리 인사 순서로 써요.

   <PromptBox>
   거래처 [담당자명] 과장님께 보내는 한국어 업무 이메일을 써 주세요. 목적: 지난주에 보내 주기로 한 견적서를 이번 주 금요일까지 받을 수 있는지 여쭙는 것. 그대로 지켜야 할 사실: 견적서 요청일은 [날짜], 우리 쪽 검토 회의는 다음 주 월요일, 담당자는 저(마케팅팀 [내 이름]). 말투: 정중하지만 부담을 주지 않게, 해요체가 아니라 격식 있는 합쇼체. 구성: 인사, 소속·이름, 용건, 마무리 인사. 제목도 써 주세요. 200자 안팎.
   </PromptBox>

2. **다시 쓰지 않고 말투만 바꾸기**

   같은 내용을 다른 느낌으로 받아 보세요. 두 버전을 나란히 보면 고르기 쉬워요.

   <PromptBox>
   위 이메일을 두 가지 버전으로 다시 써 주세요. 버전 A: 오래 거래해서 친한 사이라 조금 더 부드럽고 편안하게. 버전 B: 이미 한 번 요청했는데 답이 없었으니 정중하지만 분명하게. 사실은 그대로 두고 둘 다 200자 안팎으로요.
   </PromptBox>

3. **받은 메시지에 답장 쓰기**

   개인정보를 지운 메시지를 붙여 넣고, 어떻게 답하고 싶은지 알려 주세요. 질문을 먼저 정리하게 하면 빠뜨리지 않아요.

   <PromptBox>
   아래는 제가 받은 이메일이에요.

   [이름을 지운 이메일 붙여넣기]

   먼저 이 메일 속 질문과 요청을 모두 글머리 기호로 정리해 주세요. 그다음 제 답장을 써 주세요. 제 답변: 화요일 회의는 참석 가능, 두 번째 요청은 예산이 마감되어 어려움, 세 번째는 금요일까지 확인 후 답변. 말투는 친절하고 정중하게. 제가 적은 것 이상으로 약속하지 마세요.
   </PromptBox>

4. **거절하거나 어려운 부탁하기**

   미루게 되는 메시지가 바로 이런 글이에요. 실제 입장을 알려 주고, 이유는 솔직하고 짧게 쓰게 하세요.

   <PromptBox>
   3월 12일 지역 행사의 발표 요청을 선약 때문에 정중히 거절하는 메시지를 써 주세요. 좋은 관계는 유지하고 다음 기회는 열어 두고 싶어요. 두 문장, 다섯 문장, 문자 메시지 길이의 세 가지 버전으로 써 주세요. 제가 알려 주지 않은 핑계는 만들어 내지 마세요.
   </PromptBox>

5. **영어 비즈니스 이메일 다듬기**

   영어는 먼저 내 방식대로 써 보고, 그다음 AI에게 다듬게 하세요. 무엇이 바뀌었는지 설명을 요청하면 표현 패턴을 배울 수 있어요.

   <PromptBox>
   아래는 해외 거래처에 보내려고 제가 쓴 영어 이메일이에요. 문법을 고치고 자연스럽고 전문적인 비즈니스 영어로 다듬어 주세요. 제 의도와 길이는 비슷하게 유지해 주세요. 그다음 가장 중요한 변경 3가지를 골라, 각각 왜 바꿨는지 한국어로 한 문장씩 설명해 주세요.

   [영어 초안 붙여넣기]
   </PromptBox>

6. **한국어 메모로 영어 이메일 쓰기**

   영어로 처음부터 쓰기 어렵다면 한국어로 하고 싶은 말을 적고 영어 초안을 받으세요.

   <PromptBox>
   아래 한국어 메모를 바탕으로 해외 거래처 [Name]에게 보내는 영어 이메일을 써 주세요. 정중하지만 간결한 비즈니스 영어로, 짧은 문장을 쓰고 어려운 표현은 피해 주세요. 제목도 써 주세요. 날짜와 숫자는 메모 그대로 쓰고, 없는 내용은 [ ]로 비워 두세요. 영어 초안 아래에 한국어로 핵심 내용을 두 줄 요약해 주세요. 제가 의도대로 쓰였는지 확인하려고요.

   [한국어 메모]
   </PromptBox>

7. **길이를 줄이고 용건을 앞으로 빼기**

   긴 메일은 훑어 읽혀요. 읽는 사람이 바로 볼 수 있게 요청을 앞에 두게 하세요.

   <PromptBox>
   이 이메일을 300자 이내로 줄여 주세요. 요청은 처음 두 문장 안에 쓰고, 기한은 굵게 표시하고, 마지막은 분명한 질문 하나로 끝내 주세요. 날짜와 숫자는 하나도 빼지 마세요.

   [초안 붙여넣기]
   </PromptBox>

8. **메신저 메시지와 독촉 메시지 쓰기**

   이메일뿐 아니라 메신저에서도 같은 방법이 통해요.

   <PromptBox>
   3일 전에 동료에게 자료를 보냈는데 답이 없어요. 읽어 봤는지 부담 없이 물어보고, 금요일까지 필요하다는 것도 알리는 짧고 친근한 메시지를 써 주세요. 두 문장으로, 메신저용과 이메일용 두 가지로요.
   </PromptBox>

9. **마지막으로 직접 점검하기**

   AI에게 문제점을 찾게 한 다음, 내 목소리로 한 번 더 읽어 보세요.

   <PromptBox>
   이 이메일에서 오해를 부를 수 있거나, 무례하게 들리거나, 읽는 사람에게 필요한 정보가 빠진 부분을 찾아 주세요. 고쳐 쓰지는 말고 문제점만 알려 주세요.
   </PromptBox>

</Steps>

## 빠른 참조표

| 원하는 것 | AI에게 알려 줄 것 |
| --- | --- |
| 첫 초안 | 받는 사람, 목적, 고정 사실, 말투, 길이 |
| 다른 말투 | "두 버전: 더 부드럽게, 더 분명하게. 사실은 같게." |
| 답장 | 받은 메시지, 내 답변 목록, "그 이상은 약속하지 마세요" |
| 정중한 거절 | 실제 이유(없으면 없다고), 지키고 싶은 관계, 여러 길이 |
| 영어 다듬기 | "제 의도는 유지하고, 중요한 변경 3가지와 이유를 설명해 주세요" |
| 줄이기 | "N자 이내, 요청 먼저, 날짜·숫자는 그대로" |
| 안전 점검 | "문제점만 알려 주세요, 고쳐 쓰지는 마세요" |

### 한국어 업무 이메일에서 자주 쓰는 구성

| 부분 | 예시 |
| --- | --- |
| 제목 | 용건이 보이게. 예: "[회사명] 견적서 송부 요청 (금요일까지)" |
| 호칭 | "[이름] 과장님께" 처럼 직함 뒤에 "님". 상대의 직함을 모르면 직접 확인하세요 |
| 인사와 소속 | "안녕하세요, 마케팅팀 [이름]입니다." |
| 용건 | 요청과 기한을 앞쪽에 |
| 마무리 | "바쁘시겠지만 확인 부탁드립니다. 감사합니다." |

이 구성은 일반적인 업무 메일 관례예요. 회사나 업계마다 다를 수 있으니 우리 조직의 기존 메일을 예로 보여 주고 "이 스타일로"라고 요청하는 게 가장 정확해요.

## 자주 막히는 지점

### 초안이 밋밋하거나 너무 딱딱해요

- **원인**: 읽는 사람이 누구인지, 평소 내 글이 어떤지 알려 주지 않았어요.
- **해결**: 내가 쓴 글 한두 문장을 예시로 붙이고 "이 문체에 맞춰 주세요"라고 하세요. 매번 적용하고 싶다면 [내 방식대로 답하게](/ko/chat/41-personalize-answers/)를 보세요.

### 알려 주지 않은 내용이 들어갔어요

- **원인**: 프롬프트에 빈칸이 있으면 AI가 그럴듯한 내용으로 채워요.
- **해결**: 고정 사실을 적고 "이 사실만 쓰고, 나머지는 [ ]로 비워 주세요"라고 하세요. 보내기 전에 날짜·금액·이름을 꼭 확인하세요.

### 영어는 맞는데 내 글처럼 안 느껴져요

- **원인**: "전문적으로"라고만 하면 길고 격식 있는 표현으로 기울어요.
- **해결**: "쉽고 친근한 비즈니스 영어, 짧은 문장, 전문 용어 없이"라고 요청하세요.

### 답장에서 원래 메일의 질문 하나가 빠졌어요

- **원인**: AI가 큰 요점에 답하고 작은 질문을 건너뛰었어요.
- **해결**: 3단계처럼 질문을 먼저 모두 정리하게 한 뒤 초안을 쓰게 하세요.

### 개인정보가 있어서 메일을 붙여 넣을 수 없어요

- **원인**: 스레드에 이름, 숫자, 기밀이 들어 있어요.
- **해결**: 자리표시자를 써서 상황을 내 말로 설명하거나, 붙여 넣기 전에 직접 고치세요. 너무 민감하면 그 한 통은 직접 쓰세요.

## 실전 팁

- **하고 싶은 일을 맨 앞에.** 짧은 프롬프트에서도 세부 내용보다 목적을 먼저 쓰세요.
- **제목도 요청하세요.** 제목이 중요하면 두세 가지 후보를 받으세요.
- **내 목소리를 남기세요.** AI가 쓴 뒤에 몇 단어는 직접 고쳐서 내 글처럼 만드세요. 나를 아는 사람은 갑자기 달라진 문체를 알아봐요.
- **대신 약속하게 두지 마세요.** 약속이나 금액이 들어가면 "제가 적은 것 이상은 약속하지 마세요"를 넣으세요.
- **서둘러 보내지 마세요.** 소리 내어 한 번 읽으면 어색한 부분 대부분이 걸러져요.
