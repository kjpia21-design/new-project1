<Summary>
- **브랜드 키트는 작은 결정 모음이에요.** 색 몇 가지, 글꼴 한두 개, 말투, 해야 할 것·하지 말아야 할 것을 한 장에 적어 두면 만드는 모든 것이 같은 모습·같은 목소리가 돼요.
- **AI는 선택지를 내놓는 데 강해요.** 결정은 내가 해요. 방향을 2~3개 받아 하나를 고르고, 한 번에 한 가지씩 고쳐요.
- **Claude Design으로 키트를 한 장짜리로 정리할 수 있어요.** 도움말은 목표·레이아웃·내용·대상을 적고, 채팅·인라인 댓글·직접 편집으로 다듬으라고 해요.
- **실제로 쓰기 전에 확인하세요.** 이름·로고의 상표와 저작권, 글꼴 라이선스, 가독성이에요. 이 확인은 도구 기능이 아니라 이 사이트의 권장이에요.
- **사업이나 공개 출시라면 최종 브랜드는 전문가 검토를 받으세요.**
</Summary>

<Aside type="caution" title="초안 키트는 검토를 마친 브랜드가 아니에요">
AI가 기존 브랜드와 너무 비슷한 이름·색 조합·슬로건을 제안할 수 있어요. 우리가 읽은 페이지 어디에도 도구가 이를 확인해 준다는 말은 없어요. 모든 결과를 초안으로 보고, 비슷한 이름과 로고를 직접 찾아보고, 인쇄·등록·출시 전에는 디자이너나 상표·지식재산 전문가에게 물어보세요.
</Aside>

## 이 튜토리얼을 마치면 할 수 있는 것

- AI가 이해할 수 있게 내 브랜드를 몇 문장으로 설명해요.
- 색·글꼴·말투 제안을 받아 한 세트로 좁혀요.
- 그 세트를 Claude Design 등으로 한 장짜리 브랜드 시트로 만들어요.
- 쓰기 전에 가독성·라이선스·비슷한 이름을 짧게 점검해요.

로고 초안은 [AI로 로고·아이콘 시안 만들기](/ko/media/35-logo-icon-drafts/)를, 도구 자체는 [Claude Design으로 시안·프로토타입 만들기](/ko/claude/c20-claude-design/)를 보세요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **브랜드 키트** | 브랜드가 어떻게 보이고 들리는지 적은 한 장짜리 안내서. 다른 사람과 미래의 나도 따라 할 수 있어요 |
| **팔레트** | 쓰는 몇 가지 색. 각 색에 역할(메인, 강조, 배경, 글자)이 있어요 |
| **헥스 코드** | `#1F4E79`처럼 쓴 색 표기. 도구 사이에 같은 색을 옮길 때 편해요 |
| **글꼴** | 글자 모양. 많은 글꼴에 라이선스 조건이 있어요 |
| **말투(톤)** | 글이 어떻게 들리는지: 친근함, 격식, 장난스러움 |
| **대비** | 글자가 배경에서 얼마나 또렷이 보이는지 |
| **상표** | 영업에 쓰는 이름·로고를 보호하는 법적 권리. 나라마다 규칙이 달라요 |

### 공식 페이지에서 확인한 것과 확인하지 못한 것

| 주제 | 읽은 페이지에서 확인한 내용 |
| --- | --- |
| Claude Design | Claude와 대화하며 디자인, 인터랙티브 프로토타입, 원페이저를 만들어요. 아티팩트를 시작하는 템플릿 중 하나이고 Free, Pro, Max, Ultra, Team, Enterprise 플랜에서 기본으로 켜져 있어요 |
| 프롬프트 쓰기 | 좋은 프롬프트에는 목표, 레이아웃, 내용, 대상이 들어가요. Claude가 되물을 수도 있어요 |
| 맥락 추가 | 스크린샷·이미지·기존 자료를 붙이고 "이런 느낌으로"라고 요청할 수 있어요 |
| 다듬기 | 큰 변경은 채팅, 특정 부분은 인라인 댓글, 빠른 시각 수정은 직접 편집 |
| 디자인 시스템 | 새 프로젝트는 조직의 디자인 시스템이 있으면 그것을 이어받아요. 페이지는 이미 설정돼 있다고 가정해요 |
| 내보내기 | 템플릿별로 달라요(예: 아티팩트 도움말은 디자인을 .zip, PDF, PowerPoint, HTML로 내보낸다고 해요) |
| 독립 버전 | claude.ai/design 독립 버전은 2026년 12월 14일에 종료된다고 안내돼요 |

Canva 도움말 페이지는 **읽지 못했어요**(기본 요청에 접근 거부 응답이 왔어요). 그래서 이 튜토리얼은 **Canva의 브랜드 키트나 다른 Canva 기능에 대해 아무 주장도 하지 않아요**. Canva를 쓴다면 내 계정에서 Canva 공식 도움말을 확인하세요. 또 조직이 아닌 개인 계정에서 브랜드 키트를 Claude Design의 재사용 디자인 시스템으로 저장할 수 있는지, 색상 내보내기 방식, 한도도 확인하지 못했어요. 내 계정에서 직접 확인하세요.

## 단계별 따라 하기

예시는 "모닝크럼"이라는 작은 가정 베이커리예요(연습용으로 지어낸 이름).

<Checklist items={[
  '내 브랜드를 3~5문장으로 적었다',
  '개인 정보(집 주소, 고객 이름)를 넣지 않았다',
  '방향을 2~3개 받은 뒤 하나를 골랐다',
  '글자와 배경의 대비를 확인했다',
  '비슷한 이름·로고가 있는지 검색했다',
  '쓸 글꼴의 라이선스를 확인했다',
]} />

<Steps>

1. **브랜드를 짧게 설명하기**

   쉬운 말로 답해요. 무엇인가요? 누구를 위한 건가요? 어떤 느낌이면 좋은지 형용사 세 개? 절대 이렇게 보이면 안 되는 건? 짧게 쓰고 매번 프롬프트에 붙여 넣어요.

2. **한 개가 아니라 2~3개 방향 받기**

   <PromptBox>
   나는 이웃에게 천연발효빵과 페이스트리를 파는 작은 가정 베이커리 "모닝크럼"을 운영해요. 느낌은 따뜻하고 솔직하고 단순해야 하고, 고급스럽거나 기업 같으면 안 돼요. 서로 다른 브랜드 방향 3가지를 제안해 주세요. 각각 한 줄 아이디어, 헥스 코드가 있는 4색 팔레트(메인·강조·배경·글자 역할 표시), 제목용 글꼴 스타일 하나와 본문용 글꼴 스타일 하나, 말투를 나타내는 단어 3개를 적어 주세요. 로고는 아직 만들지 마세요.
   </PromptBox>

   방향 하나를 고르거나 둘을 섞어요. 선택이 맥락에 남도록 같은 채팅에서 계속해요.

3. **세부 좁히고 확정하기**

   메시지 하나에 한 가지만 바꿔요. 예: "방향 2로 하되 강조색을 더 차분하게", "제목 글꼴 대안 두 가지". 최종 팔레트는 복사하기 쉽게 헥스 코드가 있는 표로 받아요.

4. **말투 규칙 쓰기**

   <PromptBox>
   방향 2를 바탕으로 모닝크럼의 말투 규칙을 써 주세요. 짧은 원칙 3개, 즐겨 쓰는 단어 5개, 피하는 단어 5개, 그리고 메뉴 문구·SNS 게시글·감사 인사 예시를 하나씩. 문장은 짧게요.
   </PromptBox>

   예시를 소리 내어 읽어 보세요. 나답지 않으면 어디가 다른지 말하고 다시 요청해요.

5. **한 장짜리 브랜드 시트로 정리하기**

   Claude Design 도움말에 따르면 대화에서, Artifacts 탭에서, 또는 메시지 상자에서 Output, Design을 골라 디자인을 시작할 수 있어요. 좋은 프롬프트에는 목표·레이아웃·내용·대상이 들어가요.

   <PromptBox>
   모닝크럼의 한 장짜리 브랜드 시트를 디자인으로 만들어 주세요. 목표: 나와 전단·게시글을 도와주는 사람이 보는 빠른 참고 자료. 레이아웃: 위에 제목, 한 줄로 색 견본(헥스 코드와 역할 표시), 글꼴과 샘플 문장, 그 아래 말투 규칙과 해야 할 것·하지 말아야 할 것을 두 열로. 내용: 이 채팅에서 정한 팔레트·글꼴·규칙을 그대로 사용. 대상: 나와 봉사자 한 명. 글은 짧고 읽기 쉽게요.
   </PromptBox>

   <ScreenshotPlaceholder caption="Claude 채팅 옆에 열린 한 장짜리 브랜드 시트 디자인" officialUrl="https://support.claude.com/en/articles/14604416-get-started-with-claude-design" />

   도움말이 설명하는 대로 다듬어요. 큰 변경은 채팅, 특정 부분은 인라인 댓글, 빠른 시각 수정은 직접 편집이에요. 댓글이 반영되지 않으면 피드백을 채팅에 붙여 넣으라고 안내돼요.

6. **가독성 확인하기**

   내 글자색을 배경색 위에 올려 보세요. 작은 크기에서도 잘 읽히나요? Claude Design 도움말에 따르면 글자색을 고를 때 색상 선택기가 배경 대비가 좋은지 나쁜지 알려 줘요. 다른 도구에서는 원하는 대비 검사 도구를 쓰세요. 색만으로 의미를 전달하지 마세요.

7. **실제로 쓰기 전에 이름·로고·글꼴 확인하기**

   - 이름과 슬로건을 검색엔진과 내 나라의 상표 검색 서비스에서 찾아봐요.
   - AI로 로고를 그렸다면 [AI로 로고·아이콘 시안 만들기](/ko/media/35-logo-icon-drafts/)와 [AI 결과물, 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요.
   - 글꼴마다 라이선스를 확인해요. 상업적으로, 인쇄물에, 웹사이트에 써도 되나요? AI가 "추천한" 글꼴이 무료가 아닐 수 있어요.
   - 나라마다 규칙이 달라요. 취미 수준을 넘으면 전문가에게 물어보세요.

8. **키트 저장해 두기**

   최종 시트, 헥스 코드, 말투 규칙을 한 폴더에 저장해요. 쓴 도구에서 내 디자인의 내보내기 옵션을 확인하고(아티팩트 도움말에 템플릿별로 나와 있어요) AI 서비스 밖에도 사본을 두세요. 브랜드가 바뀌면 키트부터 고쳐요.

</Steps>

## 한눈에 보는 요약

### 한 장짜리 브랜드 키트에 들어갈 것

| 항목 | 적을 내용 |
| --- | --- |
| 한 줄 소개 | 누구이고 누구를 위한 것인지 |
| 색상 | 헥스 코드와 역할이 있는 3~5색 |
| 글꼴 | 제목용·본문용 각 하나, 라이선스 메모 |
| 말투 | 원칙 3개, 쓰는 말·피하는 말, 예시 |
| 해야 할 것·하지 말아야 할 것 | 여백, 로고 사용, 섞지 않을 색 등 몇 가지 |
| 확인일 | 날짜와 검토한 사람 |

### 프롬프트 표현

| 필요 | 시도할 표현 |
| --- | --- |
| 선택지 먼저 | "서로 다른 방향 3가지를 제안해 주세요" |
| 한 번에 하나씩 | "나머지는 그대로 두고 강조색만 바꿔 주세요" |
| 복사할 수 있는 색 | "팔레트를 헥스 코드가 있는 표로 주세요" |
| 일관성 | "이 채팅에서 정한 팔레트와 규칙을 그대로 쓰세요" |
| 읽기 쉽게 | "글은 짧게, 모든 색 조합의 대비를 확인해 주세요" |

## 자주 막히는 부분

### 방향이 다 비슷해 보여요

- **원인**: 설명이 너무 일반적이었어요.
- **해결**: 브랜드가 아닌 것과, 좋아하는 스타일 참고(말로 설명하거나 도구가 허용하면 이미지 첨부)를 추가해요.

### 메시지마다 색이 달라져요

- **원인**: 모델이 팔레트를 재사용하지 않고 새로 만들었어요.
- **해결**: 최종 헥스 코드를 다시 붙여 넣고 "정확히 이 색만 쓰세요"라고 해요.

### 제안된 이름이 기존 브랜드와 비슷해요

- **원인**: 흔한 단어와 스타일은 브랜드마다 반복돼요.
- **해결**: 확정하기 전에 검색하고, 가까우면 다른 이름을 골라요.

### Claude Design이 안 보여요

- **원인**: 플랜, 조직 설정, 순차 제공 여부에 따라 달라요.
- **해결**: 위 "Get started" 도움말을 읽고 내 플랜과 조직 설정을 확인해요.

### 디자인 댓글이 반영되지 않는 것 같아요

- **원인**: 도움말에 댓글이 Claude가 읽기 전에 사라지는 간헐적 문제가 있다고 적혀 있어요.
- **해결**: 피드백을 채팅에 붙여 넣어요.

## 실전 팁

- **적을수록 좋아요.** 작은 프로젝트에는 4색과 글꼴 2개면 충분해요.
- **색마다 역할 이름을 붙이세요.** 나중에 제멋대로 고르는 걸 막아 줘요.
- **처음 설명글을 보관하세요.** 채팅이 길어지면 다시 붙여 넣어요.
- **시험 인쇄를 해 보세요.** 화면과 종이에서 색이 달라 보여요.
- **키트에 날짜를 적으세요.** 브랜드는 바뀌니 마지막 확인일을 남겨요.
