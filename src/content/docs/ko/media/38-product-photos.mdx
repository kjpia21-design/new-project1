<Summary>
- **실제 상품을 찍은 진짜 사진에서 시작하세요.** AI는 배경과 조명을 정리해 줄 수 있지만, 상품 자체는 고객이 받을 물건과 같아 보여야 해요.
- Gemini와 ChatGPT는 둘 다 **사진을 올리고 바꿀 점 하나를 글로 설명**하면 돼요. 바꿀 것과 **그대로 둘 것**을 함께 말해요.
- **Claude는 사진을 만들거나 고치지 않아요**(도움말 기준, 2026-11-04). 올린 사진은 볼 수 있으니 촬영 평가와 편집 요청문 작성에 쓰세요.
- **상품을 실제보다 좋아 보이게 만들지 마세요.** 색, 크기, 재질, 상태를 바꾸거나 없는 기능을 넣으면 구매자를 오인하게 해요.
- **판매 플랫폼의 이미지 규정**(배경, 크기, 글자, 로고)은 올리기 전에 그 플랫폼의 판매자 도움말에서 확인하세요. 이 튜토리얼은 어떤 플랫폼의 규정도 읽지 않았어요.
</Summary>

<Aside type="caution" title="사진은 구매자에게 하는 약속이에요">
구매자는 사진을 보고 결정해요. AI 편집이 실제 색, 크기, 질감, 상태, 구성품 수를 바꾸면 구매자는 본 것과 다른 물건을 받게 돼요. 소비자 보호 법규와 플랫폼 규정이 적용될 수 있고 나라와 플랫폼마다 달라요. 이 사이트는 그 내용을 읽지 않았으니 직접 확인하세요. 법률 자문이 아니라 일반 정보예요. 표시와 권리 문제는 [AI 결과물 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요.
</Aside>

## 이 튜토리얼을 마치면 할 수 있는 일

- 스마트폰과 간단한 준비물로 깔끔한 기본 사진을 찍어요.
- Gemini나 ChatGPT로 상품은 바꾸지 않고 배경이나 지저분한 물건을 정리해요.
- 보조 이미지(생활 장면, 크기 안내 배치 등)를 만들고 솔직하게 표시해요.
- 결과를 모두 실제 상품과 비교하고, 올려도 공정한지 판단해요.

이 편은 가게에 올릴 상품 사진이 주제예요. 일반 사진 보정은 [AI로 사진 보정·편집하기](/ko/media/36-photo-editing/), 광고·썸네일은 [업무용 이미지 생성](/ko/media/11-business-images/)을 보세요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **기본 사진** | 실제 상품을 찍은 진짜 사진. 모든 AI 편집은 여기서 시작해요. 손대지 않은 사본을 남겨 두세요. |
| **대표 이미지** | 구매자가 가장 먼저 보는 사진. 플랫폼마다 규정이 있는 경우가 많으니 확인하세요. |
| **보조 이미지** | 세부 컷, 생활 장면, 크기 안내 같은 추가 이미지. |
| **참고 이미지** | 스타일이나 배치를 이끄는 두 번째 이미지. 예를 들어 마음에 드는 배경 분위기예요. |
| **부분 편집** | 이미지 일부만 빠르게 바꾸는 것. Gemini 도움말은 "local edits"를 Nano Banana 2 기능으로 꼽아요. |

### 도구별 공식 페이지 내용

| | Gemini 앱 | ChatGPT | Claude |
| --- | --- | --- | --- |
| 올린 사진 편집 | 가능. 이미지를 올리고 편집을 요청 | 가능. 참고 이미지를 첨부하고 편집을 요청 | **불가.** 사진이나 일러스트를 만들지 않아요 |
| 특정 영역 편집 | 부분 편집(local edits) | 영역을 선택하고 바꿀 점을 설명 | 해당 없음 |
| 이미지 조합 | 여러 이미지를 올려 새 이미지 만들기 | 참고 이미지 여러 장을 순서로 구분 | 해당 없음 |
| 나이 조건(개인 계정) | 이미지 생성·편집은 만 18세 이상 | 읽은 페이지에 없음 | 해당 없음 |
| 다운로드 | 원본 크기 다운로드: Google AI 요금제 2K, 없으면 1K | 읽은 페이지에 없음 | 해당 없음 |
| 사진으로 할 수 있는 일 | 해당 없음 | 해당 없음 | 올린 이미지 보기·분석 |

편집한 이미지가 원본 해상도를 유지하는지, AI 표시나 워터마크가 붙는지, 특정 쇼핑몰이 이를 어떻게 다루는지는 우리가 읽은 페이지에 **나와 있지 않아요**. 요금제·사용 한도·국가별 제공 여부도 다르니 내 계정에서 확인하세요.

<Steps>

1. **먼저 기본 사진을 잘 찍기**

   시작 사진이 또렷할수록 AI 편집이 잘 돼요. 아래는 공식 페이지의 내용이 아니라 이 사이트의 실용적인 제안이에요.

   - 창가 빛처럼 부드럽고 고른 빛을 쓰세요. 반사가 생기는 강한 플래시는 피하세요.
   - 종이나 천 같은 밋밋한 바닥 위에 상품을 놓아요.
   - 상품이 화면을 채우게 하고, 카메라를 수평으로 고정하고, 렌즈를 닦아요.
   - 앞·뒤·옆, 세부 클로즈업, 동전이나 자 옆에 둔 크기 비교 컷 등 여러 각도로 찍어요.
   - 화면 속 색이 실제 물건과 같은지 확인하세요.

   파일을 새 폴더에 복사해 사본으로 작업하세요. 올리기 전에 배경에 얼굴, 집 번호, 주소가 보이는 택배, 화면이 찍혀 있는지 살펴봐요. 올린 파일은 서비스로 전달되니 [개인정보·보안 기초](/ko/basics/05-privacy-safety/)도 보세요.

2. **Claude에게 촬영 평가 받기(선택)**

   Claude는 사진을 고치지 못하지만, 도움말에 따르면 올린 이미지를 보고 분석할 수 있어요. 이 활용은 이 사이트의 제안이에요.

   <PromptBox>
   첨부한 도자기 머그컵 상품 사진을 봐 줘. 덜 전문적으로 보이게 하는 점을 최대 3가지 알려 줘(조명, 배경, 지저분한 물건, 구도, 그림자). 각각에 대해 이미지 편집 도구에 줄 짧은 편집 요청문을 하나씩 써 줘. 요청문마다 바꿀 것과 그대로 둘 것을 적고, 머그컵의 실제 모양·색·유약은 바꾸지 않게 해 줘.
   </PromptBox>

3. **Gemini로 배경 정리하기**

   Gemini 도움말은 올린 이미지를 채팅에서 편집을 요청해 고치는 방법을 설명해요. 만 18세 미만은 이미지 편집을 쓸 수 없어요.

   <FlowSteps title="Gemini 앱에서 사진 편집하기" officialUrl="https://support.google.com/gemini/answer/14286560" steps={[
     { where: 'gemini.google.com 왼쪽 위', action: '사이드바 열기, 라이브러리(Library) 클릭 후 이미지를 클릭. 또는 기기에서 이미지 업로드', result: '채팅으로 이어갈 이미지가 열려요' },
     { where: '이미지 아래', action: '채팅(Chat) 클릭', result: '아래에 입력창이 나타나요' },
     { where: '입력창', action: '편집 요청을 입력하고 제출(Submit) 클릭', result: '편집된 이미지' },
   ]} />

   <ScreenshotPlaceholder caption="Gemini 앱에서 이미지 아래 입력창에 편집 요청을 쓰는 화면" officialUrl="https://support.google.com/gemini/answer/14286560" />

   <PromptBox>
   첨부한 내 수제 도자기 머그컵 사진을 편집해 줘. 배경만 밋밋한 밝은 회색 면으로 바꿔 줘. 머그컵은 그대로 둬. 모양, 크기, 색, 유약 질감, 흠집이나 자국, 컵 아래 그림자도 그대로야. 글자, 로고, 소품, 다른 물건은 넣지 마.
   </PromptBox>

4. **또는 ChatGPT로 거슬리는 물건 하나 지우기**

   ChatGPT 가이드는 참고 이미지를 첨부하고, 바꿀 점을 설명하고, 그대로 둘 것을 말하라고 해요. 특정 영역을 선택해 그 영역의 변경을 설명할 수도 있고, 한 번에 요소 하나씩 조정하면 나머지가 흐트러지지 않는다고 해요.

   <PromptBox>
   첨부한 이미지를 편집해 줘. 탁자 왼쪽의 구겨진 종이만 지우고, 그 자리는 나무 탁자와 어울리게 채워 줘. 머그컵, 탁자, 조명, 색, 잘린 범위, 다른 모든 세부는 그대로 유지해. 글자나 로고는 넣지 마.
   </PromptBox>

5. **보조 이미지는 솔직하게 만들기**

   ChatGPT 가이드에는 이미지 1이 상품 사진이고 이미지 2가 스타일 참고인 예시 프롬프트가 있어요. Gemini 도움말은 Nano Banana 2가 여러 참고 이미지를 받을 수 있다고 해요. 보조 장면으로 쓰임새를 보여 줄 수는 있지만, 실제 상품 사진을 대신할 수는 없어요.

   <PromptBox>
   이미지 1은 내 도자기 머그컵 상품 사진이야. 이미지 2는 따뜻한 부엌 식탁 장면의 스타일 참고야. 이미지 1의 머그컵은 모양, 크기, 색, 유약, 자국까지 그대로 유지해. 이미지 2 같은 스타일로 아침 창가 빛이 드는 나무 탁자 위에 놓아 줘. 나중에 글자를 넣을 수 있게 가운데는 비워 둬. 글자와 로고는 넣지 말고, 머그컵은 바꾸지 마.
   </PromptBox>

   실제 사진이 아닌 장면을 쓴다면 상세 설명에 "연출 이미지이며 조명에 따라 실제와 다를 수 있음"처럼 밝히는 것을 고려해 보세요. 표시가 필요한지는 플랫폼과 나라에 따라 다른데, 우리는 확인하지 않았어요.

6. **쓰기 전에 실제 상품과 비교하기**

   <Aside type="caution" title="상품을 화면 옆에 놓고 보세요">
   실제 상품을 화면 옆에 들고 색, 비율, 개수, 질감, 자국, 손잡이나 라벨 같은 부분을 확인하세요. AI 편집은 요청하지 않은 세부를 바꿀 수 있어요. 다른 점이 있으면 다시 편집하거나 원본을 쓰세요. 상품에 없는 기능이나 품질을 보여 주는 이미지는 올리지 마세요.
   </Aside>

   - **규정.** 판매 플랫폼 판매자 도움말에서 대표 이미지 요건을 확인하세요. 우리는 읽지 않았으니 짐작하지 마세요.
   - **약관.** Gemini 도움말은 이미지를 생성하면 Google 서비스 약관과 금지된 사용 정책에 동의한 것이고, 결과물을 믿거나 게시하거나 쓰기 전에 스스로 판단하라고 해요. 업무·학교 계정은 다를 수 있어요. ChatGPT 가이드는 조직의 지침과 OpenAI 사용 정책에 맞게 쓰라고 하고, OpenAI 크레딧 표기는 선택이라고 해요.
   - **초상.** 사람이 나오면 ChatGPT 가이드는 그 사람의 모습을 써도 되는지 허락을 확인하라고 해요. 허락이 없다면 상품 이미지에 사람을 넣지 마세요.
   - **브랜드.** ChatGPT 가이드는 특정 브랜드·제품·작가를 흉내 내지 말고 독창적인 표현을 요청하라고 해요. 다른 회사의 로고를 넣지 마세요.
   - **다운로드.** Gemini에서는 이미지에 마우스를 올리고 원본 크기 다운로드(Download full size)를 누르세요. 원본과 편집본은 알아보기 쉬운 이름으로 보관하세요.

</Steps>

## 자주 막히는 부분

### 상품의 색이나 모양이 바뀌었어요

- **원인**: 그대로 둘 것을 말하지 않았거나 여러 변경을 한꺼번에 요청했어요.
- **해결**: 한 번에 하나만 요청하고 "상품의 모양, 크기, 색은 그대로"라고 적으세요. 계속 달라지면 원본 사진을 쓰세요.

### 글자나 로고가 생겼어요

- **원인**: 모델이 마음대로 넣었어요.
- **해결**: "글자, 로고, 다른 물건은 넣지 마"를 추가하세요. 글자는 나중에 디자인 도구에서 넣으세요.

### Gemini에서 편집 옵션이 안 보여요

- **원인**: 나이(만 18세 이상), 계정 종류, 앱의 지원 언어·국가, 모델 설정에 따라 달라요.
- **해결**: Gemini 도움말의 "What you need" 부분에서 내 계정 조건을 확인하세요.

### Claude가 사진을 안 고쳐 줘요

- **원인**: Claude는 사진을 만들거나 고치지 않아요.
- **해결**: Claude로는 평가와 요청문을 만들고, 편집은 Gemini나 ChatGPT에서 하세요.

### 플랫폼에서 이미지가 거절됐어요

- **원인**: 플랫폼마다 대표 이미지 규정이 있어요.
- **해결**: 플랫폼 판매자 도움말의 규정을 읽고 다시 찍거나 고치세요. 우리는 어떤 플랫폼 규정도 읽지 않았어요.

## 실전 팁

- **버전에 이름 붙이기.** `mug-original`, `mug-bg-gray`, `mug-scene1`처럼 하면 되돌아가기 쉬워요.
- **진짜 사진을 남기기.** 대표 이미지에는 실제 상품을 보여 주고, 연출 장면은 그 뒤에 두세요.
- **일관성 지키기.** 같은 상품군에는 같은 배경과 빛을 쓰세요.
- **흠을 숨기지 않기.** 머그컵에 작은 자국이 있다면 클로즈업 사진을 넣으면 반품과 불만을 줄일 수 있어요.
- **돌려받은 파일 확인하기.** 원래 크기로 열어 가장자리와 작은 부분을 살펴보세요.
