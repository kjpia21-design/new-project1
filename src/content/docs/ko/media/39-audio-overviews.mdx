<Summary>
- **오디오 개요(Audio Overview)**는 올린 자료를 AI 진행자들이 대화로 풀어 주는 음성이에요. Google은 진행자의 의견이 아니라 자료 내용을 객관적으로 반영하도록 만든 것이라고 설명해요.
- 긴 문서를 출퇴근길 등에 **듣는** 방법이에요. 정확해야 하는 내용을 읽는 일을 대신하지는 못해요.
- 형식(Deep Dive, Brief, Critique, Debate), 언어(80개 이상, 목록에 한국어 포함), 길이를 고르고, 프롬프트로 초점을 줄 수 있어요.
- Google은 목소리를 포함해 오디오가 AI가 만든 것이라 **부정확하거나 소리가 어색할 수 있다**고 안내해요. 이름·숫자·날짜는 원문과 대조하세요.
- 사용 한도는 플랜에 따라 다르고 정해진 주기로 다시 채워져요. 요금과 플랜 세부 내용은 여기서 확인하지 못했어요.
</Summary>

<Aside type="note" title="이 글은 '듣기'에 집중해요">
노트북 만들기, 인용 확인하며 질문하기, 플래시카드는 [Gemini Notebook(구 NotebookLM)으로 내 자료 기반 공부·정리하기](/ko/chat/21-notebooklm/)에서 다뤄요. 이 글은 문서를 오디오로 바꾸는 일만 다뤄요. Google 도움말은 이 서비스를 "Gemini Notebook"이라고 부르고, 이 사이트의 예전 글은 NotebookLM이라고 해요. 같은 서비스로 보고 따라 하세요.
</Aside>

<Aside type="caution" title="올리기 전에">
넣은 자료는 Google 서비스의 소스가 돼요. 다른 사람의 개인정보, 회사 기밀, 쓸 권리가 없는 자료는 올리지 마세요. 소스 도움말도 권리가 없는 문서는 올리지 말라고 안내해요. [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)와 [AI 결과물, 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요. 회사·학교 계정은 관리자가 허용한 경우에만 쓸 수 있어요.
</Aside>

## 이 글을 마치면 할 수 있는 것

- 문서 하나 이상으로 오디오 개요를 만들어요.
- 목적에 맞는 형식·언어·길이를 골라요.
- 짧은 프롬프트로 다룰 주제와 눈높이를 조정해요.
- 오디오를 원문과 대조하고, 공유·다운로드할 때 주의할 점을 알아요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **노트북 / 소스** | 노트북은 추가한 소스를 담는 곳이에요. 오디오는 이 소스로 만들어져요. |
| **Studio 패널** | 오디오 개요 같은 결과물을 만드는 영역이에요. |
| **Deep Dive** | 기본 형식. 진행자 둘이 소스의 주제를 풀어서 서로 연결해 이야기해요. |
| **The Brief** | 진행자 한 명이 핵심을 2분 이내로 전해요. |
| **The Critique** | 진행자 둘이 에세이나 설계 문서 같은 자료를 건설적으로 평가해요. |
| **The Debate** | 진행자 둘이 주제를 놓고 형식을 갖춰 주고받으며 토론해요. |
| **대화형 모드** | 음성으로 대화에 끼는 기능이에요. Google 문서에 따르면 현재 영어만 돼요. |

### Google 도움말 내용 (2026-11-04 기준)

| 항목 | 도움말 내용 |
| --- | --- |
| 소스 종류 | PDF, Word(docx), 텍스트, Markdown, CSV, PowerPoint(pptx), Google 문서·슬라이드·스프레드시트, ePub, 이미지, 오디오 파일, 웹 주소, 공개 YouTube 영상, 붙여넣은 텍스트 등 |
| 소스 크기 | 소스당 최대 50만 단어, 업로드 파일은 200MB |
| 소스 개수 | 무료 사용자는 노트북당 최대 50개 |
| 언어 | 80개 이상 출력 언어. 기본값은 Google 계정의 선호 언어 |
| 길이 | Shorter, Default, Longer(Longer는 영어만) |
| 생성 시간 | "몇 분" 걸리고 백그라운드에서 진행 |
| 만들 수 있는 사람 | 노트북 편집 권한이 필요 |
| 재생 | 재생 속도 변경 가능, 다른 작업을 하며 들을 수 있음 |
| 모바일 | 모바일 앱은 이 기능에 제한이 있을 수 있음 |

## 따라 하기

예시는 "내가 쓴 20쪽짜리 보고서를 출퇴근길에 들을 짧은 오디오 요약으로 바꾸기"예요.

<Checklist items={[
  '문서가 내 것이거나 쓸 권리가 있어요',
  '개인정보나 기밀이 들어 있지 않아요',
  '형식과 언어를 골랐어요',
  '앞부분만이 아니라 끝까지 들었어요',
  '이름·숫자·날짜를 원문과 대조했어요',
  '공유하기 전에 누가 노트북에 접근하는지 확인했어요',
]} />

<Steps>

1. **노트북을 만들고 소스 추가하기**

   Gemini Notebook을 열어(채팅 설정 안내에 나온 주소는 notebook.google.com이에요) 노트북을 만들고 Add sources로 자료를 넣어요. 소스가 적고 관련성이 높을수록 오디오 초점이 또렷해져요. 오디오에 담고 싶은 자료만 넣으세요.

   <FlowSteps title="노트북에 소스 추가하기" officialUrl="https://support.google.com/gemininotebook/answer/16215270" steps={[
     { where: 'Gemini Notebook', action: '내가 소유한 노트북을 열거나 새로 만들기', result: '빈 노트북' },
     { where: '왼쪽', action: 'Add sources를 눌러 파일·텍스트·웹 주소 선택', result: '소스 패널에 소스가 나타나요' },
     { where: '소스 패널', action: '원하는 소스만 포함되어 있는지 확인', result: '오디오가 이 자료를 바탕으로 만들어져요' },
   ]} />

2. **Studio 패널에서 Audio Overview 고르기**

   Studio 패널에서 Audio Overview를 눌러요. 생성 패널에서 형식, 언어, 길이를 고르고 프롬프트를 쓸 수 있어요. 오디오는 백그라운드에서 만들어지니 그동안 다른 일을 해도 돼요.

   | 목적 | 시도해 볼 형식 |
   | --- | --- |
   | 주제를 깊이 이해하기 | Deep Dive |
   | 회의 전 빠른 정리 | The Brief |
   | 내 초안에 대한 피드백 | The Critique |
   | 쟁점의 양쪽 입장 보기 | The Debate |

3. **짧은 프롬프트로 방향 잡기**

   Google 문서에 따르면 프롬프트로 특정 주제에 집중하거나 전문성 수준을 조정할 수 있어요.

   <PromptBox label="Audio Overview 프롬프트 칸에 넣을 말">
   세 가지 핵심 결론과 예산 부분에 집중해 주세요. 보고서를 읽지 않았고 이 분야가 처음인 사람에게 설명하듯 말해 주세요. 수치는 또렷하게 말하고, 보고서가 불확실하다고 한 부분은 짚어 주세요.
   </PromptBox>

   프롬프트는 강조점을 바꿀 뿐이에요. 모든 내용이 빠짐없이, 정확하게 담긴다는 보장은 아니에요.

4. **듣고 나서 확인하기**

   <Aside type="caution" title="들었다고 검증한 게 아니에요">
   Google은 오디오 개요에 부정확한 내용이나 소리 오류가 있을 수 있다고 밝혀요. 자신 있는 목소리 때문에 틀린 말도 맞게 들릴 수 있어요. 행동에 옮길 숫자·날짜·이름·권고는 적어 두고 원문에서 확인하세요. [AI 답변 믿어도 될까: 사실 확인하는 법](/ko/basics/04-fact-checking/)을 보세요.
   </Aside>

   오디오가 재생되는 동안에도 노트북을 계속 쓰며 인용을 보고 소스에 질문할 수 있어요. More 메뉴에서 재생 속도를 바꿀 수 있어요.

5. **다시 불러오기, 공유, 다운로드**

   - **다시 불러오기**: Studio 패널에서 이전 오디오를 찾아 Load를 눌러요. 점 세 개 메뉴의 View custom prompt로 썼던 프롬프트를 볼 수 있어요.
   - **링크 공유**: 오디오 플레이어의 Share. 도움말은 받는 사람과 노트북이 공유되어 있거나, 전체 노트북에 접근할 수 있는 공개 상태인지 확인하라고 해요. 공개 공유는 일반(소비자) 계정에서만 켜져 있고 Workspace Enterprise·Education 계정에서는 꺼져 있어요.
   - **노트북 전체 공유**: 받는 사람은 Studio 패널에서 오디오를 찾고, 내 소스도 함께 보게 돼요.
   - **다운로드**: Download를 눌러 파일을 보내요. Play Books 전자책을 소스로 쓴 노트북은 출판사 제한으로 다운로드가 막힐 수 있다고 해요.
   - 오디오를 삭제하면 이전 공유 링크는 더 이상 작동하지 않아요.

6. **선택: 대화에 끼어들기**

   대화형 모드에서는 음성으로 진행자에게 질문할 수 있어요. Google 문서에 따르면 현재 영어만 되고, 새로 만든 오디오 개요에만 쓸 수 있으며, 지연이나 소리 오류가 있을 수 있어요. 공유 링크로는 다른 사람이 대화에 참여할 수 없어요.

</Steps>

## 한눈에 보기

| 필요한 것 | 방법 |
| --- | --- |
| 짧은 요약 듣기 | The Brief 선택 |
| 다른 언어 | 생성 패널에서 언어 선택(기본값은 Google 계정 설정을 따라요) |
| 더 짧게/길게 | Shorter, Default, Longer(Longer는 영어만) |
| 한 챕터에 집중 | 프롬프트를 쓰거나 그 소스만 선택 |
| 한도를 다 썼을 때 | 새로 채워질 때까지 기다리거나 Generate later(웹만) |
| 사용량 확인 | Settings > Usage |

### 사용 한도 (Google 도움말 기준)

한도는 연산량 기준이고 5시간마다 새로 채워지며 주간 한도가 있어요. 플랜이 없으면 기본 한도, AI Plus는 2배, AI Pro는 4배, AI Ultra는 구독에 따라 AI Pro의 5배 또는 20배예요. Google은 한도가 바뀔 수 있다고 해요. 요금은 확인하지 못했어요.

## 자주 막히는 곳

### Audio Overview 버튼이 없거나 시작되지 않아요

- **원인**: 노트북 편집 권한이 없거나, 모바일 앱의 제한이거나, 계정·국가가 지원 대상이 아닐 수 있어요.
- **해결**: 내가 소유한 노트북을 쓰고, 웹 버전을 써 보고, 계정 종류별 이용 가능 여부는 Google 도움말에서 확인하세요.

### 오디오가 다른 언어로 나와요

- **원인**: 기본값이 Google 계정의 선호 언어예요.
- **해결**: 생성 전에 생성 패널에서 언어를 고르세요.

### 중요한 내용이 빠졌어요

- **원인**: 진행자는 요약하지, 전부 읽어 주지 않아요.
- **해결**: 프롬프트에 주제를 적거나, 소스를 줄이거나, 그 부분은 직접 읽으세요.

### 사용 한도에 걸렸어요

- **원인**: 한도는 연산량 기준이고 생성은 많이 써요.
- **해결**: 5시간 새로 채워지길 기다리거나, 웹에서 Generate later를 쓰거나, 높은 플랜을 고려하세요.

## 실전 팁

- **노트북 하나에 목적 하나.** 관련 있는 소스 몇 개가 더 촘촘한 오디오를 만들어요.
- **1차 훑어보기로 쓰기.** 오디오로 어디를 자세히 읽을지 정하고, 중요한 부분은 직접 읽으세요.
- **글 원본을 남기기.** 인용할 내용은 소스 텍스트로 작업하세요.
- **사람이 녹음한 것처럼 보이지 않게.** 오디오를 공유할 땐 AI가 만들었다고 밝히세요.
- **이 글에서 해 보지 않은 것.** 글을 쓰며 실제로 오디오를 생성해 보지는 않았어요. 위 내용은 2026-11-04에 읽은 Google 도움말 기준이고, 실제 오디오 길이·음질·화면의 버튼 이름은 다를 수 있어요.
