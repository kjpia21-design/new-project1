<Summary>
- **DeepL**과 **파파고**는 번역 전용 서비스라 파일(Word, PPT, PDF 등)을 올리면 서식을 유지한 번역본을 줘요. **Claude**는 대화로 말투·용어·독자를 지정해 번역하고 다듬을 수 있어요.
- **기밀 문서는 무료 서비스에 붙여넣지 마세요.** 서비스마다 데이터를 저장하거나 개선에 쓰는 조건이 달라요. 쓰기 전에 공식 안내를 확인하세요.
- AI 번역은 **초안**이에요. 숫자, 날짜, 고유명사, 법적 표현은 반드시 사람이 확인하세요.
- 한도와 기능은 요금제마다 달라요. 아래 수치는 2026-10-14 기준이고, 화면 표시가 우선이에요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 문서 종류와 목적에 맞게 DeepL, 파파고, Claude 중 하나를 고를 수 있어요.
- 파일을 올려 서식을 유지한 채 번역할 수 있어요.
- 회사 기밀이나 개인정보가 든 문서를 어떻게 다룰지 판단할 수 있어요.
- 번역 결과를 체크리스트로 검토할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **기계 번역 서비스** | DeepL, 파파고처럼 번역에 특화된 서비스예요. 파일을 올리면 서식을 유지해서 번역해 줘요. |
| **대화형 AI 번역** | Claude처럼 채팅으로 요청하는 방식이에요. 독자, 말투, 용어를 설명하면 거기에 맞춰요. |
| **용어집(Glossary)** | "고객사 = client"처럼 쓸 번역어를 미리 정해 두는 목록이에요. DeepL과 파파고에 있어요. |
| **역번역** | 번역 결과를 다시 원래 언어로 번역해 의미가 맞는지 확인하는 방법이에요. |
| **모델 개선·품질 개선 동의** | 내가 입력한 내용을 서비스가 개선에 써도 되는지에 대한 설정이에요. |

### 세 도구는 어디가 다른가요

| 비교 | DeepL | 파파고 | Claude |
| --- | --- | --- | --- |
| 강점 | 파일 번역, 용어집, 사업자용 플랜 | 텍스트·이미지·문서·음성·웹사이트 번역을 한 곳에서 | 말투·독자·용어를 대화로 지정, 번역 후 요약·검토 |
| 문서 번역 | PDF, Word, PowerPoint 등 (플랜별 파일 수·크기 제한) | PDF, DOCX, XLSX, PPTX, HWPX, 파일당 20MB까지 | 파일을 올려 번역을 요청하고 결과 파일을 받을 수 있어요 (파일당 30MB) |
| 한국어 | DeepL API 지원 언어에 한국어가 포함돼요 | 네이버가 제공하는 서비스예요 | 이 글에서 공식 문서로 품질을 확인하지는 않았어요 |

<Aside type="note" title="확인되지 않은 점">
DeepL 도움말 센터(support.deepl.com)는 자동 접근이 막혀 열지 못했어요. 그래서 DeepL은 공식 사이트의 요금제·보안·문서 번역 페이지로 확인했어요. 파파고는 서비스 화면의 안내 문구를 확인했고, 도움말 센터 글 본문은 열지 못했어요. 번역 품질의 우열은 공식 근거가 없어서 쓰지 않았어요. 중요한 문서는 두 도구로 번역해 비교해 보세요.
</Aside>

## 단계별 따라하기

예제는 "영문 공급 계약 안내문(Word 파일)을 한국어로 번역해 팀에 공유"하는 상황이에요.

<Checklist items={[
  '문서에 기밀·개인정보가 있는지 먼저 확인했어요',
  '서비스의 데이터 정책을 확인하고 도구를 골랐어요',
  '번역 도구로 번역을 실행했어요',
  '용어와 말투를 정리해 다시 다듬었어요',
  '숫자·날짜·고유명사를 원문과 대조했어요',
  '필요하면 담당자(법무·현지 직원)에게 검수받았어요',
]} />

<Steps>

1. **문서의 민감도 점검하기**

   번역을 맡기기 전에 문서에 다음이 있는지 확인해요.

   - 회사 기밀: 계약 조건, 단가, 미공개 제품·재무 정보
   - 개인정보: 이름과 연락처, 주민등록번호, 계좌 정보
   - 비밀유지 의무가 있는 고객·거래처 자료

   있다면 3단계의 "기밀 문서 다루기"를 먼저 읽고 도구를 고르세요. 회사에 AI·번역 도구 사용 규정이 있으면 그 규정이 먼저예요. 일반 원칙은 [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)를 보세요.

2. **도구 고르기**

   - **짧은 문장·이메일**: 세 도구 모두 괜찮아요. 말투를 지정하고 싶으면 Claude가 편해요.
   - **서식이 중요한 파일**: DeepL이나 파파고의 문서 번역이 편해요.
   - **용어를 통일해야 하는 문서**: DeepL·파파고의 용어집을 쓰거나, Claude에게 용어표를 같이 주세요.

3. **기밀 문서 다루기 (번역 전에 꼭 확인)**

   무료 번역 서비스에 기밀 문서를 붙여넣거나 올리면 그 내용이 서비스 회사로 전송돼요. 아래 공식 안내를 기준으로 판단하세요. 계정 종류와 시기에 따라 달라질 수 있으니 번역 전에 직접 확인하세요.

   | 서비스 | 공식 안내에서 확인한 내용 (2026-10-14 기준) |
   | --- | --- |
   | **DeepL** | 요금제 비교 표에 "No data training"(데이터 학습 없음) 항목이 있고, 유료 플랜(Individual 이상)에는 표시되지만 무료 버전은 비활성(회색) 표시예요. 기업 보안 안내는 "동의 없이 텍스트를 저장하거나 모델 학습에 쓰지 않는다"고 설명해요. 무료 버전의 정확한 데이터 처리 조건은 확인하지 못했으니 화면의 약관을 보세요. |
   | **파파고** | 화면 아래의 "품질 개선 동의"에 동의하면 번역 요청 데이터(텍스트, 음성, 이미지, 문서 등)가 저장되어 서비스 개선과 연구·개발에 쓰일 수 있다고 안내돼요. 동의는 언제든 바꿀 수 있고, 바꾼 시점부터 적용돼요. 기본 동의 상태는 확인하지 못했어요. |
   | **Claude** | 개인용 계정(Free, Pro, Max)은 모델 개선 설정을 허용한 경우에 대화가 개선에 쓰여요. 시크릿(incognito) 채팅은 모델 개선에 쓰이지 않아요. 공식 도움말도 기밀 비즈니스 문서를 공유할 때 신중하라고 권해요. 팀·기업 계정은 정책이 다르니 관리자 안내를 따르세요. |

   <FlowSteps title="파파고에서 품질 개선 동의 확인하기" officialUrl="https://papago.naver.com/" steps={[
     { where: 'papago.naver.com 화면 맨 아래', action: '"품질 개선 동의"(영문: Consent to improving quality) 누르기', result: '동의 안내가 열려요' },
     { where: '안내 창', action: '내용을 읽고 원하지 않으면 동의 상태 끄기', result: '변경한 시점부터 적용돼요' },
   ]} />

   그래도 확신이 없으면 이렇게 하세요.

   - **가려서 번역하기**: 이름, 금액, 회사명을 "A사", "OOO원"처럼 바꾸고 번역한 뒤 다시 채워요.
   - **회사가 허용한 도구만 쓰기**: 사내 계약된 유료·기업 플랜이 있으면 그것을 쓰세요.
   - **번역하지 않기**: 법적 구속력이 큰 계약서는 번역가·법무 담당자에게 맡기세요.

   <ScreenshotPlaceholder caption="파파고 화면 아래의 '품질 개선 동의' 링크" officialUrl="https://papago.naver.com/" />

4. **번역 실행하기**

   **파일 번역 (DeepL·파파고)**: 문서 번역 화면에 파일을 끌어다 놓고 언어를 골라요. 파파고는 PDF, DOCX, XLSX, PPTX, HWPX를 파일당 20MB까지 지원한다고 안내돼요. DeepL은 요금제에 따라 월 파일 수와 파일 크기 한도가 달라요(아래 참조표). 번역본을 내려받은 뒤 반드시 파일을 열어 표, 줄 바꿈, 이미지를 눈으로 확인하세요.

   **대화로 번역 (Claude)**: 독자, 말투, 용어를 같이 알려 주세요.

   <PromptBox>
   아래 영어 계약 안내문을 한국어로 번역해 줘. 독자는 영어를 모르는 우리 팀 동료야. 말투는 정중한 "합니다"체로 하고, 아래 용어표를 따라 줘: supplier = 공급업체, lead time = 납기, purchase order = 발주서. 번역하기 어렵거나 뜻이 두 가지로 읽히는 문장은 번역문 아래에 따로 표시해 줘. 원문에 없는 내용은 추가하지 마.

   (여기에 본문을 붙여넣기)
   </PromptBox>

   Word 파일을 통째로 번역하려면 파일 생성 기능이 켜져 있어야 해요(Free, Pro, Max는 설정(Settings) > 기능(Capabilities)의 "Code execution and file creation"). 파일당 30MB까지예요. 결과 파일의 서식은 직접 확인하세요.

5. **번역 결과 검토하기**

   AI 번역은 매끄러워 보여도 틀릴 수 있어요. 아래를 순서대로 확인하세요.

   - **숫자·날짜·단위·통화**: 원문과 하나씩 대조해요. 가장 위험한 부분이에요.
   - **고유명사**: 회사명, 제품명, 사람 이름, 지명이 올바르게 옮겨졌는지 봐요.
   - **용어 일관성**: 같은 말이 문서 안에서 같은 번역어로 쓰였는지 봐요.
   - **빠진 문장·덧붙인 문장**: 문단 수와 문장 수를 원문과 비교해요.
   - **부정문·조건문**: "~하지 않는 한", "단,"처럼 의미가 뒤집히기 쉬운 표현을 봐요.
   - **말투와 높임**: 독자에게 맞는지(상사, 고객, 동료) 봐요.
   - **법적·의료·재무 문서**: 반드시 전문가나 현지 담당자에게 검수받으세요.

   역번역도 도움이 돼요. 한국어 결과를 다시 영어로 번역해 보고 원문과 뜻이 다르면 그 문장을 다시 살펴보세요.

   <PromptBox>
   방금 번역한 한국어 문장을 원문과 한 문장씩 비교해서, 의미가 달라졌거나 빠졌거나 덧붙은 부분, 숫자·날짜가 다른 부분을 표로 정리해 줘. 확실하지 않은 곳은 "확인 필요"라고 표시해 줘.
   </PromptBox>

   Claude에게 검토를 시켜도 그 검토 역시 AI의 결과예요. 마지막 확인은 사람이 하세요. 확인 방법은 [AI 답변 사실 확인하는 법](/ko/basics/04-fact-checking/)에 있어요.

</Steps>

## 빠른 참조표

### DeepL 플랜별 한도 (2026-10-14 기준, DeepL 요금제 페이지)

| 항목 | 무료 버전 | Individual | Team | Business |
| --- | --- | --- | --- | --- |
| 텍스트 번역 (월) | 50,000자 | 300,000자 | 사용자당 1,000,000자 | 무제한 |
| 파일 번역 (월) | 1건 | 3건 | 20건 | 100건 |
| 파일 크기 | 5MB까지 | 30MB까지 | 30MB까지 | 100MB까지 |
| 용어집 | 1개 (항목 5개) | 1개 (항목 5개) | 5개 (언어쌍당 1,000개) | 무제한 |

DeepL 문서 번역 페이지(2026-10-26 기준)는 무료 계정이 Word·PowerPoint·PDF 중 한 파일을 5MB 이하, 월 100,000자 이하로 번역할 수 있다고 따로 안내해요. 가격은 지역마다 달라서 쓰지 않았어요. 위 숫자는 독일 화면 기준이니, 한국에서 보이는 표를 확인하세요. Enterprise 한도는 별도 협의로 안내돼요.

### 파파고 문서 번역

| 항목 | 내용 |
| --- | --- |
| 지원 형식 | PDF, DOCX, XLSX, PPTX, HWPX |
| 파일 크기 | 파일당 20MB까지 |
| 특징 | 원본 표와 이미지를 유지한다고 안내돼요. 번역 후 화면에서 바로 수정할 수 있어요 |
| 용어집 | 문서 번역 화면에 용어집 사용 옵션이 있어요 |
| 한도 | 월 번역 횟수를 모두 쓰면 알림이 나와요. 구체적 횟수는 확인하지 못했어요 |
| Plus | 일부 기능은 PAPAGO PLUS 전용으로 표시돼요. 세부 내용은 화면에서 확인하세요 |

### 검토 체크 한눈에 보기

| 항목 | 확인 방법 |
| --- | --- |
| 숫자·날짜 | 원문과 나란히 놓고 대조 |
| 고유명사 | 공식 표기(회사 홈페이지 등) 확인 |
| 용어 | 용어표 작성 후 검색(Ctrl+F)으로 통일 |
| 누락 | 문단·표·각주 수 비교 |
| 의미 반전 | 부정·조건 문장 따로 읽기 |
| 전문 분야 | 전문가 검수 |

## 자주 막히는 지점

### 번역본의 서식이 깨졌어요

- **원인**: 표, 텍스트 상자, 특수 글꼴이 많은 문서는 번역 후 줄 길이가 달라져 서식이 어긋나기 쉬워요. 한국어는 영어보다 길거나 짧아질 수 있어요.
- **해결**: 번역본을 열어 직접 조정하세요. PDF는 서식 복원이 어려울 수 있으니, 원본(Word 등)이 있으면 원본으로 번역하는 편이 낫다고 보는 게 안전해요.

### 파일이 올라가지 않아요

- **원인**: 파일 크기나 형식, 월 파일 수 한도에 걸린 거예요.
- **해결**: 파파고는 20MB, DeepL 무료 버전은 5MB까지예요. 문서를 나눠서 올리거나 요금제를 확인하세요.

### 같은 용어가 번역마다 달라요

- **원인**: AI는 문맥에 따라 다르게 옮길 수 있어요.
- **해결**: DeepL·파파고의 용어집을 쓰거나, Claude에 용어표를 먼저 주세요. 번역 후 주요 용어를 검색해서 통일하세요.

### 말투가 너무 딱딱하거나 어색해요

- **원인**: 독자와 상황을 알려 주지 않았어요.
- **해결**: Claude에게 "고객에게 보내는 이메일이야. 정중하지만 부담스럽지 않은 말투로"처럼 독자와 목적을 알려 주고 다시 요청하세요.

### 이미 기밀 문서를 무료 서비스에 올렸어요

- **원인**: 사용 전 정책을 확인하지 않았어요.
- **해결**: 숨기지 말고 회사의 보안·정보 담당자에게 알리세요. 서비스 화면의 기록 삭제, 데이터 사용 동의 해제 같은 설정을 확인할 수 있지만, 이미 전송된 데이터가 어떻게 처리되는지는 서비스 약관과 개인정보처리방침을 보세요.

## 실전 팁

- **번역 전에 원문부터 정리하세요.** 오타와 애매한 문장이 번역 오류로 이어져요.
- **긴 문서는 나눠서 번역하세요.** 검토하기 쉽고 오류를 찾기 쉬워요.
- **용어표를 문서와 함께 보관하세요.** 다음 번역 때 그대로 재사용할 수 있어요.
- **두 도구로 번역해 비교하세요.** 다른 곳이 의미가 갈리는 지점이에요.
- **중요한 문서는 사람 검수 단계를 일정에 넣어 두세요.**
- **파일의 개인정보를 지우거나 가린 뒤 올리세요.** 문서 속성(작성자)과 숨은 메모도 확인하세요.
