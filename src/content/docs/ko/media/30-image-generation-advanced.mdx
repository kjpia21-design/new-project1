## 이 튜토리얼로 할 수 있게 되는 것

- 목적에 맞게 프롬프트를 5단 구조로 쓸 수 있어요.
- 비율·스타일·구도를 지정하고, 마음에 안 드는 부분만 골라 고칠 수 있어요.
- 같은 캐릭터나 같은 톤으로 이미지 시리즈를 만들 수 있어요.
- 도구를 바꿔도 통하는 기본 원리와, 상업 이용 전 확인할 항목을 알 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **프롬프트 구조** | 용도, 주제·행동, 장면, 구도·스타일·비율, 제외할 것을 나눠 쓰는 방식이에요. |
| **비율(aspect ratio)** | 가로:세로 비율(예: 16:9, 2:3)이에요. Gemini 소개 페이지는 요청문에 "2:3 aspect ratio"처럼 적는 예시를 보여 줘요. |
| **부분 수정** | 이미지 전체를 다시 만들지 않고 일부만 바꾸는 방식이에요. Gemini는 Nano Banana 2의 기능으로 "Local edits"를 소개해요. ChatGPT 문서는 이미지의 특정 영역을 고르고 바꿀 내용을 적을 수 있다고 안내해요. |
| **참고 이미지** | 편집하거나 스타일을 따라 하게 하려고 올리는 이미지예요. 올릴 땐 권리가 있는 이미지만 쓰세요. |
| **캐릭터 일관성** | 여러 장에서 같은 인물·캐릭터의 모습을 유지하는 기능이에요. Gemini 도움말이 Nano Banana 2의 기능으로 소개해요. |

### 도구별로 확인된 것

| | Gemini 앱 | ChatGPT | Midjourney |
| --- | --- | --- | --- |
| 시작 경로 | 컴퓨터에서 gemini.google.com → 왼쪽 위 Open Sidebar → Images(소개 페이지는 도구 메뉴의 Create images도 안내) | 웹 채팅에서 이미지를 요청하고 참고 이미지를 첨부 | 공식 문서를 열지 못해 확인하지 못했어요 |
| 비율·스타일 | 요청문에 스타일(photorealistic, watercolor 등)과 비율을 적으라고 안내 | 프레이밍, 크기, 조명, 색, 재질을 필요할 때 적으라고 안내 | 확인하지 못했어요 |
| 부분 수정 | Library에서 이미지 선택 → Chat에서 요청. 기기의 이미지를 올려 편집도 가능 | 영역을 골라 그 부분의 변경을 설명 | 확인하지 못했어요 |
| 여러 참고 이미지 | 여러 장을 올려 합성 가능. Nano Banana 2 Lite는 다중 참고·다중 편집용이 아니라고 안내 | 순서로 구분(Image 1, Image 2)하고 관계를 설명 | 확인하지 못했어요 |
| 한도·요금 | 일일 한도가 있고 숫자는 도움말에 없어요. Google AI 요금제는 다운로드 2K, 없으면 1K | 웹의 이미지 사용 가능 여부와 한도는 요금제·워크스페이스 설정에 따라 달라요 | 확인하지 못했어요 |

모델 이름은 Gemini 도움말(Nano Banana 2, Pro, 2 Lite)과 소개 페이지(Nano Banana 2.1)가 달라요. 화면에 보이는 모델 이름을 따르세요. 나이 조건 등 기본 사항은 [11편](/ko/media/11-business-images/)을 참고하세요.

## 단계별 따라하기

예제는 "동네 베이커리 SNS용 마스코트 캐릭터 시리즈 3장"이에요.

  '비율과 스타일을 지정해 첫 이미지를 만들었어요',
  '바꿀 것 하나만 골라 부분 수정을 해 봤어요',
  '캐릭터 설명을 고정해 두 번째·세 번째 이미지를 만들었어요',
  '상업 이용과 권리 점검표를 확인했어요',
]} />

<Steps>

1. **프롬프트를 5단으로 쓰기**

   Gemini 소개 페이지는 "만들어 줘 + 주제 + 행동 + 장면"에서 시작해 구체적으로 늘리고, 구도·스타일·품질·비율을 함께 생각하라고 안내해요. ChatGPT 문서는 용도·대상, 주인공과 상황, 배경·구도·스타일, 조명·색, 제외할 것을 짚어 줘요. 둘을 합치면 아래 5단이 돼요.

   | 단 | 내용 | 예시 |
   | --- | --- | --- |
   | 1. 용도 | 어디에 쓰나 | 빵집 인스타그램 소개 이미지 |
   | 2. 주제·행동 | 누가 무엇을 하나 | 곰 모양 빵 마스코트가 빵을 굽는 모습 |
   | 3. 장면 | 배경·분위기 | 아침 햇살이 드는 작은 베이커리 |
   | 4. 구도·스타일·비율 | 어떻게 보이나 | 귀여운 플랫 일러스트, 1:1, 마스코트는 가운데 |
   | 5. 제외 | 넣지 않을 것 | 글자, 로고, 실제 브랜드 없음 |

   <PromptBox>
   빵집 인스타그램 소개용 이미지를 만들어 줘. 곰 모양 빵 마스코트가 앞치마를 두르고 오븐에서 빵을 꺼내는 모습이야. 배경은 아침 햇살이 드는 작은 베이커리. 부드러운 플랫 일러스트 스타일, 따뜻한 베이지와 갈색 계열, 1:1 비율, 마스코트는 가운데에 크게. 글자와 로고는 넣지 마. 기존 캐릭터를 닮지 않은 원본 디자인으로 해 줘.
   </PromptBox>

   <ScreenshotPlaceholder caption="Gemini 앱에서 5단 프롬프트로 이미지를 만든 화면" officialUrl="https://support.google.com/gemini/answer/14286560" />

2. **막연한 표현을 구체적인 말로 바꾸기**

   ChatGPT 문서는 "아름다운 조명" 같은 막연한 반응 대신 빛이 어디서 오는지처럼 구체적인 시각 표현을 쓰라고 안내해요. 꼭 지켜야 할 조건은 반복해서 적으라고도 해요.

   | 막연한 말 | 구체적인 말 |
   | --- | --- |
   | 예쁘게 | 부드러운 아침 햇살이 왼쪽 창에서 들어오는 |
   | 귀엽게 | 둥근 윤곽선, 큰 눈, 단순한 색 면 |
   | 고급스럽게 | 절제된 색, 여백 많은 구도, 무광 질감 |

3. **한 번에 하나만 부분 수정하기**

   ChatGPT 문서는 작고 구체적인 수정을 한 요소씩 하라고 안내해요. 편집할 때는 **무엇을 바꾸고 무엇을 그대로 둘지**를 정확히 말해야 한다고 해요.

   <PromptBox>
   첨부한 이미지를 수정해 줘. 마스코트가 든 빵만 크루아상으로 바꿔 줘. 마스코트의 얼굴, 앞치마, 배경, 조명, 색감, 크롭은 그대로 유지하고, 글자나 로고는 추가하지 마.
   </PromptBox>

   <FlowSteps title="Gemini에서 만든 이미지 일부 고치기" officialUrl="https://support.google.com/gemini/answer/14286560" steps={[
     { where: 'gemini.google.com 왼쪽 위', action: 'Open Sidebar → Library 누르기', result: '만든 이미지 목록' },
     { where: '고칠 이미지', action: '이미지를 누르고 아래의 Chat 누르기', result: '이미지에 이어 요청하는 입력창' },
     { where: '아래 입력창', action: '바꿀 것 하나와 그대로 둘 것을 적고 Submit 누르기', result: '수정된 이미지' },
   ]} />

4. **같은 캐릭터로 시리즈 만들기**

   Gemini 도움말은 Nano Banana 2가 여러 이미지에서 인물·캐릭터의 모습을 유지하는 기능을 가지고 있다고 안내해요. 효과를 높이려면 아래처럼 하세요.

   - 첫 이미지가 마음에 들면 **그 캐릭터의 특징을 글로 적어 저장**해요(색, 옷, 소품, 얼굴 특징).
   - 다음 요청에 같은 설명을 **그대로 붙이고** 장면만 바꿔요.
   - 필요하면 첫 이미지를 참고 이미지로 올려요. ChatGPT 문서는 여러 참고 이미지를 쓸 때 "이미지 1은 편집할 사진, 이미지 2는 스타일 참고"처럼 순서와 역할을 설명하라고 안내해요.
   - 같은 캐릭터가 얼마나 유지되는지는 공식 문서에 수치가 없어요. 결과를 직접 보고 어긋나면 설명을 더 구체적으로 고치세요.

   <PromptBox>
   이미지 1은 우리 빵집 마스코트야. 이미지 1의 얼굴, 베이지색 몸, 갈색 앞치마, 작은 빵 모자를 그대로 유지해 줘. 이번에는 마스코트가 카운터 뒤에서 손님에게 빵 봉투를 건네는 장면으로 만들어 줘. 1:1 비율, 같은 플랫 일러스트 스타일, 글자와 로고는 넣지 마.
   </PromptBox>

5. **이미지 속 글자와 정보 이미지 다루기**

   ChatGPT 문서는 이미지 속 글자를 짧게 하고, 문구를 따옴표로 정확히 지정하며, 글꼴 느낌·크기·색·위치를 적고, 다른 글자는 넣지 말라고 명시하라고 안내해요. Gemini 도움말은 Nano Banana 2가 글자 표현이 나아졌고 Pro는 글자나 인포그래픽에서 더 세밀하다고 소개해요. 그래도 ChatGPT 문서는 글자가 많거나 인쇄용인 결과물은 **모든 단어를 직접 검수**하고 필요하면 디자인 도구에서 마무리하라고 해요.

   <PromptBox>
   이미지 맨 위 가운데에 “오늘의 갓 구운 빵”이라는 문구만 굵은 흰색 고딕체로 한 줄로 넣어 줘. 다른 글자는 추가하지 말고 이미지의 나머지는 바꾸지 마.
   </PromptBox>

   한글 문구는 맞춤법과 글자 모양이 정확한지 눈으로 확인하세요. 한국어 글자 정확도에 대한 별도 수치는 공식 문서에서 찾지 못했어요.

6. **상업 이용 전 점검하기**

   아래는 공식 문서에서 **확인된 문구만** 정리한 거예요.

   | 도구 | 확인된 내용 | 확인하지 못한 내용 |
   | --- | --- | --- |
   | Gemini 앱 | 도움말은 Google 서비스 약관과 금지된 사용 정책(Prohibited Use Policy)을 따르고, 타인의 저작권·개인정보 권리를 침해하지 말며, 결과물을 쓰거나 게시하기 전에 직접 판단하라고 안내해요. 업무·학교 계정은 약관이 다를 수 있어요 | 결과물의 소유·상업 이용을 직접 밝히는 문장은 열어 본 도움말과 소개 페이지에서 찾지 못했어요 |
   | ChatGPT | 문서는 OpenAI 크레딧 표기가 필요 없고, 실존 인물은 허락을 확인하며, 조직 지침과 OpenAI 사용 정책을 따르라고 안내해요 | 이용약관의 출력물 소유 조항은 openai.com이 막혀 확인하지 못했어요 |
   | Midjourney | 확인하지 못했어요 | 요금제별 상업 이용 조건, 결과물 공개 여부 등 모두 공식 문서에서 확인하지 못했어요 |

   <Aside type="caution" title="약관은 요금제·계정 종류에 따라 달라질 수 있어요">
   회사 업무에 쓰거나 광고로 돈을 쓰기 전에는 쓰는 도구의 **현재 약관과 요금제별 조건**을 직접 읽으세요. 소유권을 약관이 정해도 저작권 보호 여부는 나라마다 달라요. 저작권·윤리 일반은 [AI 결과물 저작권·윤리 기초(basics/09)](/ko/basics/09-ai-copyright-ethics/)에서 정리하고 있어요.
   </Aside>

</Steps>

| 스타일 유지하며 바꾸기 | "구도는 그대로 두고 스타일만 수채화로" |
| 여러 참고 이미지 | "이미지 1은 편집할 사진, 이미지 2는 스타일 참고. 1의 구도와 물체를 유지해 줘" |
| 글자 | "문구는 ‘○○’만, 굵은 흰색 고딕, 위쪽 가운데, 다른 글자는 넣지 마" |

## 자주 막히는 지점

### 수정할 때마다 다른 그림이 되어 버려요

- **원인**: 한 번에 여러 요소를 바꾸거나 유지할 것을 말하지 않았어요.
- **해결**: 한 번에 하나만 바꾸고, 그대로 둘 요소(얼굴, 배경, 조명, 크롭)를 나열하세요. ChatGPT 문서도 이 방식을 안내해요.

### 캐릭터가 장마다 달라져요

- **원인**: 설명이 매번 달라지거나 참고 이미지가 없어요.
- **해결**: 캐릭터 설명을 저장해 두고 그대로 붙이세요. 첫 이미지를 참고 이미지로 올리고 "이미지 1의 ○○를 유지"라고 적으세요. 그래도 어긋나면 Nano Banana Pro로 다시 만들기(Redo with Pro)를 시도해 볼 수 있어요(Google AI 요금제 필요, Nano Banana 2 일일 한도에 이르면 불가).

### 한글 문구가 틀려요

- **원인**: 글자 렌더링이 완벽하지 않을 수 있어요.
- **해결**: 문구를 짧게 하고 따옴표로 지정하세요. 그래도 틀리면 이미지에서는 글자를 빼고 Canva 등에서 올리세요.

### 이미지가 기존 브랜드나 작가 느낌이에요

- **원인**: 프롬프트에 특정 브랜드나 작가를 연상시키는 표현이 있어요.
- **해결**: 작가·브랜드 이름을 빼고 "원본 디자인"을 요청하세요. ChatGPT 문서도 특정 브랜드·작가 모방 대신 일반적이거나 원본 느낌의 표현을 요청하라고 해요.

## 실전 팁

- **프롬프트를 파일로 관리하세요.** 캐릭터 설명, 스타일 문장, 제외 목록을 저장해 두면 시리즈가 쉬워요.
- **먼저 작게 시도하세요.** 구도가 맞으면 그 뒤에 디테일을 올리세요.
- **비율은 처음에 말하세요.** 나중에 바꾸면 구도가 틀어질 수 있어요.
- **사람 얼굴이 필요하면 허락부터** 받으세요. ChatGPT 문서도 실존 인물은 허락 확인을 안내해요.
- **AI 생성 표시 정책**은 회사에서 정하세요. Gemini는 보이지 않는 SynthID 워터마크와 보이는 워터마크를 쓴다고 소개해요. 표시를 일부러 지우지 마세요.
