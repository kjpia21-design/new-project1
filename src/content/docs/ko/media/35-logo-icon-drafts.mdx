<Summary>
- AI는 **여러 방향의 거친 시안을 빠르게** 뽑는 데 좋아요. 결과물은 완성된 브랜드 마크가 아니라 **반응해 볼 초안**으로 보세요.
- 요청은 **한 번에 아이디어 하나**씩: 이름, 느낌, 모양, 색 두세 가지, 빼야 할 것(글자, 실제 브랜드, 기존 캐릭터)을 적어요.
- **한 번에 하나만** 고치고, 그대로 둘 것을 함께 말해요. 공식 이미지 가이드도 수정할 때 이 방식을 권해요.
- 실제로 쓰기 전에 세 가지를 확인해요: **기존 마크와 닮지 않았는지, 파일을 실제로 쓰고 고칠 수 있는지, 전문가가 봤는지** (2026-11-02 기준).
- 법률 자문이 아니라 일반 정보예요. 우리가 연 공식 페이지에는 AI가 인쇄용·벡터 로고 파일을 만들어 준다는 말이 없어서, 그렇다고 단정하지 않아요.
</Summary>

<Aside type="caution" title="로고는 그림 한 장 이상이에요">
로고는 사업을 구별하는 표시라서 일반 일러스트보다 실수하기 쉬워요. 미국 상표청은 상표가 상품이나 서비스의 출처를 나타내며, 상품을 설명하기만 하는 상표보다 창의적이고 독특한 상표가 보호받기 쉽다고 설명해요. 간판·포장·광고에 쓸 거라면 **전문가 검토**(디자이너, 상표는 변리사나 각 나라의 상표 담당 기관)를 미리 계획하세요. 이 튜토리얼은 좋은 요청서와 첫 시안까지 돕는 글이고, 최종 브랜드를 만들어 주지는 않아요.
</Aside>

## 이 튜토리얼을 마치면 할 수 있는 일

- AI 도구가 알아듣는 짧은 로고·아이콘 요청서를 쓸 수 있어요.
- Claude Design이나 Gemini로 서너 가지 방향을 뽑아 비교할 수 있어요.
- 고른 방향에서 마음에 든 부분을 잃지 않고 다듬을 수 있어요.
- 간단한 사용 전 점검을 하고, 언제 전문가에게 넘길지 알 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **로고** | 사업이나 프로젝트를 나타내는 표시예요. 보통 심볼, 워드마크(이름을 꾸민 글꼴로 쓴 것), 또는 둘 다예요. |
| **아이콘** | 앱, 버튼, 소셜 미디어 프로필에 쓰는 작고 단순한 상징이에요. 아주 작아도 알아볼 수 있어야 해요. |
| **시안 vs. 최종본** | 시안은 방향을 고르는 용도예요. 최종본은 닮은 마크가 있는지 확인하고, 다듬고, 필요한 형식으로 넘긴 파일이에요. |
| **상표** | USPTO는 상품이나 서비스의 출처를 나타내는 단어, 문구, 기호, 디자인 또는 그 조합이라고 설명해요. |
| **참고 이미지** | 결과를 이끌려고 올리는 이미지예요. 사용 권리가 있는 이미지만 쓰세요. |

### 각 도구의 공식 페이지가 말하는 것

| | Claude Design | Gemini 앱 | ChatGPT |
| --- | --- | --- | --- |
| 용도(페이지 기준) | 대화로 디자인, 인터랙티브 프로토타입, 원페이저 등 시각 작업을 만들어요 | Nano Banana 모델로 이미지를 만들고 편집해요 | 자연어로 이미지를 만들고 편집해요 |
| 시작 | 아무 대화, Artifacts 탭, Claude Code | 컴퓨터에서 gemini.google.com, 사이드바 열기, 이미지 | 채팅에서 이미지 요청 |
| 다듬기 | 큰 변경은 채팅, 한 곳은 인라인 코멘트, 간단한 수정은 캔버스 직접 편집 | 라이브러리에서 이미지 선택, 채팅 클릭, 수정 내용 입력 | 작고 구체적인 수정, 또는 영역을 선택해 변경 설명 |
| 결과 꺼내기 | 내보내기 버튼: .zip, PDF, PPTX, Google Slides, 독립 HTML, 다른 도구 전송, Claude Code로 인계 | 원본 크기 다운로드(Google AI 요금제는 2K, 없으면 1K) 또는 Docs로 내보내기 | 읽은 페이지에서 다루지 않음 |
| 로고, SVG, 투명 배경 | **언급 없음** | **언급 없음** | **언급 없음** |

우리가 읽은 Claude Design 페이지에는 "로고"라는 말이 없고 PNG나 SVG 내보내기도 없어요. Gemini 페이지도 투명 배경이나 벡터 파일이 되는지 말하지 않아요. 그래서 아래 로고 관련 내용은 모두 일반 도구를 **이 사이트가 이렇게 써 보라고 제안하는 방법**이지, 각 회사가 설명한 기능이 아니에요. Claude Design 기본은 [C20](/ko/claude/c20-claude-design/), 이미지 프롬프트 일반은 [이미지 생성 심화](/ko/media/30-image-generation-advanced/)를 보세요.

<Aside type="note" title="먼저 확인할 조건">
Gemini 앱 도움말에 따르면 개인 계정으로 이미지를 만들고 편집하려면 만 18세 이상이어야 하고, 만들기만 하려면 만 13세(또는 해당 국가의 적용 연령) 이상이어야 해요. 앱의 지원 언어·국가에 따라서도 제공 여부가 달라요. Claude Design은 Free, Pro, Max, Ultra, Team, Enterprise 요금제에서 쓸 수 있고, 사용량은 Claude 전체와 같은 한도에 포함돼요 (2026-11-02 기준).
</Aside>

## 따라 하기

예시는 "Page Turners라는 동네 독서 모임의 로고와 앱 아이콘"이에요.

<Checklist items={[
  '이름, 대상, 느낌, 모양, 색, 피할 것을 담은 요청서를 썼다',
  '여러 방향을 만들고 하나를 골랐다',
  '고른 시안을 한 번에 하나씩 다듬었다',
  '작은 크기와 흑백으로 테스트했다',
  '기존 마크와 비교하고 도구의 약관을 읽었다',
  '전문가가 마무리할지 정했다',
]} />

<Steps>

1. **도구를 열기 전에 요청서부터 쓰세요**

   Claude Design 도움말은 목표·배치·내용·대상을, ChatGPT 이미지 가이드는 목적이나 대상, 주제, 배경과 스타일, 들어가면 안 되는 것을 포함한 제약을 구체적으로 쓰라고 해요. 이걸 로고에 맞게 바꿔 보세요.

   | 항목 | 예시 |
   | --- | --- |
   | 이름과 용도 | "Page Turners", 동네 독서 모임, SNS 프로필과 전단지용 |
   | 대상과 느낌 | 성인, 친근하고 따뜻하고 약간 장난기 있게 |
   | 모양 아이디어 | 펼친 책, 접힌 페이지 모서리, 단순한 말풍선 |
   | 색 | 두세 가지: 짙은 초록과 크림색 |
   | 피할 것 | 실제 브랜드, 기존 캐릭터, 사진 같은 질감, 아주 작은 디테일 |

2. **하나가 아니라 여러 방향을 뽑으세요**

   Claude Design 도움말은 방향이 확실하지 않으면 2~3가지 안을 보여 달라고 하라고 해요. 비교가 짐작보다 빠르기 때문이에요. Gemini와 ChatGPT에서도 같은 방식이 통해요. 뚜렷이 다른 콘셉트를 따로 요청하고 하나를 고르세요.

   <PromptBox>
   "Page Turners"라는 동네 독서 모임의 로고 아이디어가 필요해요. 대상은 성인이고, 친근하고 따뜻한 느낌이에요. 서로 다른 3가지 방향을 보여 주세요: (1) 단순한 펼친 책 심볼, (2) 접힌 페이지 모서리가 있는 워드마크만, (3) 동그란 배지. 짙은 초록과 크림색, 납작한 도형, 작아도 읽히는 굵고 단순한 선으로 해 주세요. 기존 로고·브랜드·캐릭터를 따라 하지 말고 사진은 쓰지 마세요.
   </PromptBox>

   Gemini 앱에서는 gemini.google.com에서 왼쪽 위 사이드바 열기를 누르고 이미지를 선택해 프롬프트를 입력해요. 도움말은 "그려줘, 만들어줘" 같은 말로 시작하고, 만화 일러스트 같은 스타일과 주제·배경을 구체적으로 쓰라고 권해요.

   <ScreenshotPlaceholder caption="Gemini 앱의 이미지 화면에서 요청 시작하기" officialUrl="https://support.google.com/gemini/answer/14286560" />

   Claude Design에서는 아무 대화에서나 여러 콘셉트를 나란히 놓은 "브랜드 시트"나 원페이저를 요청해 비교할 수 있어요. 이건 이 사이트의 제안이고, 도움말은 디자인과 원페이저를 일반적으로 설명해요.

3. **방향을 하나 골라 한 번에 하나씩 고치세요**

   ChatGPT 가이드는 작고 구체적인 수정을 하고, 한 번에 요소 하나만 조정해야 나머지가 흐트러지지 않으며, 무엇을 바꾸고 무엇을 그대로 둘지 정확히 말하라고 해요. Gemini 도움말은 "로컬 편집"을 이미지 일부를 빠르게 바꾸는 Nano Banana 2 기능으로 소개해요.

   <PromptBox>
   첨부한 로고를 수정해 주세요. 책의 색만 크림색에서 더 연한 민트색으로 바꿔 주세요. 모양, 선 굵기, 배치, 배경은 완전히 그대로 두고 글자나 다른 요소는 추가하지 마세요.
   </PromptBox>

   <FlowSteps title="Gemini 이미지 다듬기" officialUrl="https://support.google.com/gemini/answer/14286560" steps={[
     { where: 'gemini.google.com 왼쪽 위', action: '사이드바 열기, 라이브러리 클릭', result: '만든 이미지 목록' },
     { where: '고른 이미지', action: '이미지를 클릭하고 아래의 채팅 클릭', result: '그 이미지에서 이어서 요청할 입력창' },
     { where: '입력창', action: '바꿀 것 하나와 유지할 것을 쓰고 제출 클릭', result: '수정된 이미지' },
   ]} />

   Claude Design이라면 큰 변경(다른 모양 등)은 채팅, 한 곳은 인라인 코멘트, 간단한 시각 수정은 직접 편집을 쓰세요. 도움말에 따르면 인라인 코멘트가 가끔 보이지 않을 수 있는데, 그럴 땐 같은 내용을 채팅에 붙여 넣으세요.

4. **이미지 안의 글자는 조심하세요**

   ChatGPT 가이드는 이미지 속 글자를 짧게 하고, 정확한 문구를 따옴표 안에 넣고, 글꼴 느낌·크기·색·위치를 설명하라고 해요. Gemini 도움말은 Nano Banana 2가 지원 언어 전반에서 글자 표현이 나아졌다고 하지만, ChatGPT 가이드는 제작에 꼭 필요한 글꼴이라면 모든 단어를 직접 검토하고 디자인 도구에서 마무리하라고 덧붙여요. 워드마크는 철자를 한 글자씩 확인하세요. 이름이 틀리면 글자 없는 심볼만 만들고, 이름은 Canva 같은 디자인 도구에서 직접 넣으세요([Canva 튜토리얼](/ko/media/12-canva-sns/) 참고).

   <PromptBox>
   "Page Turners"라는 글자만 둥근 산세리프 글꼴, 짙은 초록색으로 심볼 아래 한 줄에 넣어 주세요. 다른 글자는 넣지 말고 심볼은 바꾸지 마세요.
   </PromptBox>

5. **로고가 실제로 쓰이는 방식으로 테스트하세요**

   시안을 프로필 사진 크기 정도로 줄여 보고, 흑백으로도 보고, 밝은 배경과 어두운 배경에 모두 올려 보세요. 알아보기 어렵다면 더 단순하게 요청하세요.

   <PromptBox>
   첨부한 심볼을 가로 48픽셀에서도 읽히도록 단순하게 만들어 주세요. 세부 묘사는 빼고 색은 두 가지 이하로 하세요. 펼친 책 아이디어와 전체 모양은 유지하고 글자는 넣지 마세요.
   </PromptBox>

   아이콘은 단색 배경 위에 뚜렷한 모양 하나를 요청하세요. 투명 배경이나 벡터 파일을 받을 수 있는지는 우리가 읽은 공식 페이지에 나와 있지 않으니, 가정하지 말고 실제로 받은 파일을 확인하세요.

6. **실제로 쓰기 전에 확인하세요**

   <Aside type="caution" title="닮음, 권리, 전문가 검토">
   간판, 제품, 웹사이트, 광고에 시안이 나가기 전에 아래를 점검하세요.
   </Aside>

   - **닮은 마크.** 내 분야에서 비슷한 마크가 있는지 검색하세요. USPTO는 상표 권리가 특정 상품·서비스와 함께 쓰는 방식에 묶여 있고, 상표는 그 출처를 나타낸다고 설명해요. 실제로는 내 분야에서 남의 마크와 가까우면 문제가 될 수 있다는 뜻이에요. 해당 국가의 공식 상표 데이터베이스를 쓰세요. 한국 상표 검색 사이트(KIPRIS)는 이 작업 환경에서 열리지 않아서 여기서 설명하지 않아요.
   - **남의 마크를 요청하지 마세요.** ChatGPT 가이드는 특정 브랜드·제품·작가·작품을 흉내 내지 말고 일반적이거나 독창적인 디자인을 요청하며, 조직의 지침과 OpenAI 이용 정책에 맞게 쓰라고 해요.
   - **약관.** Gemini 도움말은 이미지를 만들 때 Google 서비스 약관과 금지된 사용 정책에 동의한 것이며, 타인의 저작권·개인정보 권리를 침해하지 말고, 생성물을 믿거나 게시하거나 쓰기 전에 판단하라고 해요. 직장·학교 계정은 약관이 다를 수 있어요. 해당 페이지에서 생성한 로고의 소유권이나 상표 등록 가능 여부를 말하는 문장은 찾지 못해서 단정하지 않아요. 저작권과 윤리 일반은 [AI 결과물, 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요.
   - **내 기여.** 그 튜토리얼에서 정리한 한국 저작권 안내에 따르면 사람의 창작적 기여가 없는 AI 결과물은 등록이 어려워요. 로고가 사업에 중요하다면 스케치, 요청서, 수정 기록을 남기고 전문가에게 내 경우에 어떻게 적용되는지 물어보세요.
   - **전문가 검토.** 디자이너에게 최종 형태를 다듬고 필요한 파일 형식으로 받으세요. 상표 등록이나 본격 사용 전에는 변리사나 해당 국가 상표 담당 기관에 상담하세요.

</Steps>

## 자주 막히는 지점

### 방향이 다 비슷해요

- **원인**: 요청서가 너무 일반적이거나 구체적인 모양이 없어요.
- **해결**: 구체적인 모양 아이디어 3가지를 적고 아이디어마다 콘셉트 하나씩 요청하세요.

### 이름 글자가 틀려요

- **원인**: 글자 표현이 항상 정확하지는 않아요.
- **해결**: 정확한 문구를 따옴표에 넣고 짧게 하며 직접 검토하세요. 그래도 안 되면 글자 없는 심볼을 만들고 디자인 도구에서 이름을 넣으세요.

### 수정할 때마다 그림 전체가 바뀌어요

- **원인**: 여러 가지를 한꺼번에 요청했거나 유지할 것을 말하지 않았어요.
- **해결**: 한 번에 요소 하나만 바꾸고 유지할 것을 나열하세요.

### 유명한 브랜드와 닮았어요

- **원인**: 프롬프트에 브랜드·작가·캐릭터 이름을 썼거나 우연히 닮았어요.
- **해결**: 그런 이름을 빼고 독창적인 디자인을 요청한 뒤, 쓰기 전에 비슷한 마크를 검색하세요.

### 투명 배경이나 벡터 파일을 못 받아요

- **원인**: 우리가 읽은 공식 페이지는 이런 결과물을 설명하지 않아요.
- **해결**: 가정하지 말고 받은 파일을 확인하세요. 깔끔한 벡터 로고가 필요하면 고른 시안을 디자이너가 다시 그리게 하세요.

## 실전 팁

- **요청서를 저장하세요.** 좋은 시안마다 요청서와 프롬프트를 남기면 반복하거나 만든 과정을 설명할 수 있어요.
- **작은 크기부터 비교하세요.** 크게 볼 때 좋은 디자인도 48픽셀 아이콘에서는 무너지는 경우가 많아요.
- **개인정보를 넣지 마세요.** 사람 사진이나 사적인 문서를 참고 이미지로 올리지 마세요.
- **만든 방식을 솔직하게.** ChatGPT 가이드는 OpenAI 크레딧 표기는 선택이지만 필요하면 에셋을 어떻게 만들었는지 설명해도 된다고 해요. AI로 만든 결과물 표기에 대한 조직 방침도 확인하세요.
- **시안을 디자인 의뢰서로 쓰세요.** 가장 쓸모 있는 결과는 디자이너에게 넘길 수 있는 분명한 방향인 경우가 많아요.
