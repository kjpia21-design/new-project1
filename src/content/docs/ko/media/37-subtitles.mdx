<Summary>
- YouTube **자동 자막은 음성 인식으로 만들어지고 틀릴 수 있어요.** 발음, 억양, 사투리, 배경 소음 때문이에요. YouTube 도움말은 항상 검토하고 고치라고 해요.
- 자막 파일에는 말한 내용과 **시간 정보(타임스탬프)**가 들어 있어요. **SubRip(.srt)**는 YouTube가 받는 기본 형식 중 하나이고, 일반 UTF-8 텍스트에 스타일 표시는 없어요.
- 이 글의 순서: 초안 만들기, **직접 고치기**, 파일 내려받기, **Claude로 문장 다듬기·번역**(시간 정보는 그대로).
- Claude 도움말의 업로드 가능 형식 목록에는 .srt가 없어요(TXT 등은 있음). 텍스트를 채팅에 붙여 넣는 건 이 사이트의 제안이고, 도움말이 보장하는 방법은 아니에요.
- 내 영상이거나 허락받은 영상만 자막을 달고 번역하세요. AI 번역은 초안이에요. 공개할 내용은 그 언어를 잘 아는 사람이 확인하세요.
</Summary>

<Aside type="caution" title="권리와 정확성이 먼저예요">
자막은 영상 속 말을 그대로 옮기는 것이라 영상과 같은 권리 문제를 안고 있어요. 다른 사람의 영상을 허락 없이 올리거나 번역하지 마세요. [AI 결과물, 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요. 자동으로 만든 글은 이름, 숫자, 민감한 발언을 틀리게 옮길 수 있으니 공개 전에 확인하세요. 법률 자문이 아니라 일반 정보예요.
</Aside>

## 이 튜토리얼을 마치면 할 수 있는 일

- YouTube Studio에서 영상의 자동 자막을 확인하고 검토해요.
- 자막 편집기에서 고치고 자막 파일을 내려받아요.
- SRT 파일이 어떻게 생겼는지 알고, 구조를 깨뜨리지 않고 다뤄요.
- Claude로 문장을 다듬거나 번역하고, 결과를 확인해요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **자막(subtitles/captions)** | 영상과 함께 보이는 글. YouTube 도움말은 청각 장애나 난청이 있는 시청자와 다른 언어를 쓰는 시청자에게 도움이 된다고 해요. |
| **자동 자막** | YouTube가 음성 인식으로 만드는 자막. 품질이 다를 수 있어요. |
| **자막 파일** | 말한 내용과 시간 코드가 든 파일. 형식에 따라 위치·스타일 정보도 담아요. |
| **SRT(.srt)** | SubRip 파일. 블록마다 번호, 시작·끝 시간, 글이 있어요. |
| **더빙** | 소리를 다른 언어로 바꾸는 것. 자막과 달라서 여기서는 다루지 않아요. |

### 자동 자막에 대한 YouTube 페이지 내용

| 항목 | 페이지 내용 |
| --- | --- |
| 품질 | 머신러닝으로 만들어 품질이 다를 수 있음. 항상 검토하고 수정 |
| 언어 | 영어, 한국어 등 긴 목록 제공(전체 목록은 페이지 참고) |
| 나타나는 시점 | 가능하면 영상에 자동으로 게시됨. 업로드 직후에는 준비되지 않았을 수 있음 |
| 안 나오는 이유 | 복잡한 소리를 아직 처리 중, 지원하지 않는 언어, 영상이 너무 김, 음질이 나쁨, 음성을 인식 못 함, 시작 부분의 긴 무음, 말이 겹치거나 여러 언어가 동시에 나옴 |
| 라이브 스트림 | 영어만, 개별 라이브 스트림에서만 |

페이지에는 영상 길이 한도나 정확도 퍼센트가 없어요. "너무 길다"고만 나오니 내 영상은 YouTube Studio에서 직접 확인하세요.

## 단계별 따라 하기

예시는 "한국어로 말한 3분짜리 제품 시연 영상에 영어 자막 달기"예요.

<Checklist items={[
  '내 영상이거나 자막·번역 허락을 받은 영상이에요',
  '영상에서 쓰는 언어를 알고 있어요',
  '자동 자막을 열어 모든 줄을 읽었어요',
  '이름, 숫자, 전문 용어를 고쳤어요',
  'AI 도구에 파일 내용을 보낼 때 번호와 시간 정보를 그대로 두게 했어요',
  '번역 언어를 아는 사람이 번역을 확인했어요',
]} />

<Steps>

1. **YouTube Studio에서 영상의 자막 열기**

   YouTube Studio에 로그인해 왼쪽 메뉴에서 자막(Subtitles)을 고르고 영상을 선택하세요. 자동 자막이 가능하면 영상의 기본 언어로 "자막" 아래에 나와요. 파일 업로드, 대본을 넣는 자동 싱크(Auto-sync), 직접 입력으로 내 자막을 추가할 수도 있어요.

   <FlowSteps title="YouTube Studio에서 자동 자막 검토하기" officialUrl="https://support.google.com/youtube/answer/6373554" steps={[
     { where: 'YouTube Studio 왼쪽 메뉴', action: '자막(Subtitles) 선택', result: '내 영상 목록' },
     { where: '영상 목록', action: '영상 클릭', result: '그 영상의 자막 화면' },
     { where: '자막(Subtitles) 아래', action: '자동 자막 옆 더보기(More) 클릭', result: '검토·수정·삭제 옵션' },
   ]} />

2. **자동 자막 직접 고치기**

   도움말은 자동 자막을 검토하고 제대로 옮겨지지 않은 부분을 고치라고 해요. 자막 편집기에서 줄을 클릭해 글을 바꾸고 게시(Publish)를 누르세요. 자동 자막은 복제 후 편집(Duplicate and edit)과 계속(Continue)을 눌러 고칠 수 있는 초안을 만들어요. 필요하면 [박수]처럼 소리 정보를 넣어 시청자가 상황을 알게 하세요.

   고유명사, 제품 이름, 숫자, 한 단어가 의미를 바꾸는 곳을 특히 꼼꼼히 보세요.

3. **자막 파일 내려받기**

   자막 화면에서 언어 옆 편집(Edit)을 누르고 옵션(Options)에서 자막 다운로드(Download subtitles)를 고르세요. YouTube가 받는 기본 형식은 형식 안내 페이지에 나와요. SubRip(.srt), SubViewer(.sbv, .sub), MPsub, LRC, Videotron Lambda(.cap)예요. SRT와 SBV는 기본 시간 정보만 있으면 되고 일반 텍스트 편집기로 열 수 있어요. 다운로드 버튼이 어떤 형식을 주는지는 우리가 읽은 페이지에서 확인하지 못했어요.

   SRT 블록은 이렇게 생겼어요(YouTube 페이지의 예시).

   ```text
   1
   00:00:00,599 --> 00:00:04,160
   >> ALICE: Hi, my name is Alice Miller and this is John Brown
   ```

4. **Claude로 문장 다듬기·번역하기**

   글을 Claude에 붙여 넣고 규칙을 분명히 말하세요. 글만 바꾸고 숫자와 시간 코드는 바꾸지 말라는 규칙이에요. Claude 도움말의 업로드 문서 형식에는 TXT, PDF, DOCX 등이 있고 .srt는 없어서, 붙여 넣는 쪽이 안전해요. .txt 사본으로 저장해 올려 볼 수도 있지만, Claude가 구조를 제대로 읽는지는 페이지가 보장하지 않아요.

   <PromptBox>
   아래는 한국어 SRT 자막 파일이야. 글 줄만 자연스러운 영어로 번역해 줘. 블록 번호와 시간 줄은 그대로 두고, 블록 수도 같게 해 줘. 자막 한 개는 두 줄 안에 읽을 수 있게 짧게 써 줘. 제품 이름은 번역하지 말고 그대로 둬: [이름 목록]. 불분명한 줄은 지어내지 말고, 가장 가까운 번역 뒤에 [?]를 붙여 줘.

   [여기에 SRT 붙여넣기]
   </PromptBox>

   아주 긴 파일은 몇십 블록씩 나눠 보내세요. Claude 도움말도 큰 문서는 작은 부분으로 나누라고 해요.

5. **번역 확인하기**

   <Aside type="caution" title="AI 번역은 초안이에요">
   기계 번역은 말투, 관용구, 단위, 이름을 놓칠 수 있어요. 자막을 공개한다면 그 언어를 아는 사람이 읽어 보게 하세요. 블록 수와 시간 정보가 원본과 맞는지도 확인하세요.
   </Aside>

   - **개수.** 블록 수가 원본과 같아야 해요.
   - **시간.** 번역이 길어지면 보이는 시간 안에 읽기 어려울 수 있어요. 줄이세요.
   - **용어.** 제품 이름과 숫자를 검색해 확인하세요.
   - **인코딩.** YouTube 페이지는 기본 SRT·SBV 파일이 일반 UTF-8이어야 한다고 해요. 고친 파일을 UTF-8로 저장하세요.

6. **번역한 자막을 영상에 추가하기**

   YouTube Studio에서 자막을 고르고 영상을 클릭한 뒤 언어 추가(ADD LANGUAGE)로 언어를 고르세요. "자막" 아래 추가(ADD)를 누르고 파일 업로드(Upload file)를 선택해요. 시간 있음(With timing, 예: SRT)이나 시간 없음(Without timing)을 고르고 계속(Continue), 파일 선택, 저장(Save)을 누르세요. 시간 정보 없이 대본만 있다면 페이지가 설명하는 자동 싱크(Auto-sync)를 쓸 수 있는데, 대본이 음성 인식이 지원하는 언어이고 영상 속 말과 같은 언어여야 해요.

</Steps>

## 자주 막히는 지점

### 자동 자막이 안 나와요

- **원인**: YouTube는 여러 이유를 들어요. 아직 처리 중, 지원하지 않는 언어, 영상이 너무 김, 음질 나쁨, 시작 부분의 긴 무음, 겹치는 말이나 여러 언어 혼용이에요.
- **해결**: 잠시 기다렸다가 다시 확인하세요. 그래도 안 되면 파일을 올리거나, 대본으로 자동 싱크를 쓰거나, 직접 입력하세요.

### Claude가 .srt 파일을 안 받아요

- **원인**: 도움말의 지원 문서 형식 목록에 .srt가 없어요.
- **해결**: 글을 채팅에 붙여 넣거나 .txt 사본을 써 보세요. .txt 사본이 구조를 유지하는지는 페이지가 보장하지 않아요.

### 시간 정보가 바뀌었거나 줄이 빠졌어요

- **원인**: 구조를 유지하라고 말하지 않았거나, 한 번에 보내기에 파일이 너무 길었어요.
- **해결**: "번호와 시간을 그대로 둬" 규칙을 다시 적고 더 작게 나눠 보내세요. 끝나면 블록 수를 비교하세요.

### 업로드가 실패해요

- **원인**: 페이지에 따르면 기본 SRT 파일은 스타일 표시 없는 일반 UTF-8이어야 하고, 지원하는 형식이어야 해요.
- **해결**: UTF-8로 다시 저장하고 스타일을 지우고 형식 목록을 확인하세요.

### 번역이 딱딱해요

- **원인**: 직역이거나 맥락이 부족했어요.
- **해결**: Claude에 시청자가 누구이고 영상이 무엇에 관한 것인지 알려 주고, 그 언어를 아는 사람이 검토하게 하세요.

## 실전 팁

- **원래 언어 자막을 먼저.** 원본이 틀리면 번역도 같은 실수를 반복해요. 먼저 고치세요.
- **용어집 만들기.** 이름과 용어 목록이 있으면 다음 영상도 일관돼요.
- **작게 나눠 작업하기.** 실수를 찾기 쉬워요.
- **더빙과 헷갈리지 않기.** YouTube에는 다국어 오디오와 자동 더빙 기능이 따로 있어요. 이 글은 글자 자막만 다뤄요.
- **비공개 녹음.** 회의 대본을 AI 도구에 붙여 넣으면 그 글이 서비스로 전달돼요. [개인정보·보안 기초](/ko/basics/05-privacy-safety/)를 보세요.
