<Summary>
- **일이 두 가지예요.** 차트는 정확한 숫자가 필요하니 데이터를 다루는 도구(Claude 아티팩트, Gemini Canvas, 스프레드시트)에서 만들어요. 인포그래픽은 디자인된 설명 그림이라 이미지 도구로 초안을 잡을 수 있어요.
- **숫자는 반드시 원본과 대조하세요.** 그럴듯해 보이는 차트도 값, 라벨, 축이 틀릴 수 있어요. 막대 하나하나를 표와 비교해요.
- **ChatGPT 가이드는 글이 많은 이미지의 모든 단어를 검토**하고, 중요한 글자 작업은 디자인 도구에서 마무리하라고 해요.
- **정직한 축과 비율을 쓰세요.** 막대는 0에서 시작하고, 차트끼리 비교할 땐 눈금을 맞춰요. 공식 설명이 아니라 이 사이트의 권장이에요.
- **예쁜 차트를 얻으려고 개인·기밀 데이터를 채팅에 붙여 넣지 마세요.**
</Summary>

<Aside type="caution" title="보기 좋은 차트가 맞는 차트는 아니에요">
AI는 틀린 숫자, 잘못 붙은 열 이름, 잘린 축으로도 그럴듯한 차트를 그려요. 확인한 공식 페이지 세 곳은 만들고 고치는 방법을 설명할 뿐, 도구가 데이터를 검증해 준다고는 하지 않아요. 결과는 초안으로 보고 직접 확인하세요. 사업·건강·법률·재정 결정의 근거로 쓸 차트라면 전문가의 검토를 받으세요.
</Aside>

## 이 튜토리얼을 마치면 할 수 있는 일

- 질문에 맞는 차트 종류(비교, 추세, 전체 중 비율)를 고를 수 있어요.
- 작은 표를 Claude나 Gemini로 차트로 만들고 말로 고쳐 달라고 할 수 있어요.
- 이미지 도구로 한 장짜리 인포그래픽 레이아웃 초안을 만들 수 있어요(글은 짧게).
- 공유 전에 값, 라벨, 단위, 축을 원본과 대조할 수 있어요.

파일 전체를 분석하려면 [엑셀·CSV 데이터 분석을 AI에게 맡기기](/ko/chat/03-data-analysis/), 엑셀·시트 안의 AI는 [엑셀·구글 시트에 AI 붙이기](/ko/automation/23-spreadsheet-ai/)를 보세요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **원본 데이터** | 내가 가진 처음 표예요. 바꾸지 말고 보관하세요. 모든 차트는 이것과 맞아야 해요. |
| **축** | 아래나 옆의 눈금이에요. 축이 잘리면 작은 차이가 크게 보여요. |
| **기준선** | 막대 차트가 시작하는 곳이에요. 막대는 0에서 시작해요. |
| **차트** | 데이터의 정확한 값을 그린 그림이에요. |
| **인포그래픽** | 숫자 몇 개, 아이콘, 짧은 글을 섞어 디자인한 설명 그림이에요. |
| **아티팩트** | Claude가 만들어 채팅 옆에 열어 주는 결과물로, 고치고 공유할 수 있어요. |
| **Canvas** | 문서, 앱, 슬라이드, 코드를 만들거나 고치는 Gemini 앱의 옆 패널이에요. |

### 도구별 공식 페이지 내용

| | Claude | Gemini 앱 | ChatGPT |
| --- | --- | --- | --- |
| 만드는 곳 | 아티팩트가 채팅 옆에 열려요. 도움말은 대시보드, 다이어그램, 작은 상호작용 도구를 만들 수 있다고 안내해요 | Canvas에서 문서, 앱, 슬라이드, 코드를 만들거나 고쳐요 | 이미지 생성으로 설명 그림, 포스터, 라벨이 있는 다이어그램, 타임라인 초안을 잡을 수 있어요 |
| 이후 수정 | Claude에게 요청하거나, 템플릿 아티팩트는 직접 편집해요 | 입력창에 요청, 코드 직접 편집, 선택해서 묻기(Select & ask). 변경은 자동 저장돼요 | 한 번에 하나씩 요청해요. 글이 많으면 검토하라고 안내해요 |
| 공유·내보내기 | 템플릿 아티팩트는 내보내기(예: 문서를 Word·PDF로) 가능. 공유는 나만, 초대한 사람, 링크가 있는 누구나 중에서 정해요 | 읽은 페이지에는 없어요 | 읽은 페이지에는 없어요 |
| 플랜·설정 | 설정의 Capabilities에서 "Cloud code execution and file creation"이 켜져 있어야 해요 | Gemini 앱에 로그인해야 해요 | 이미지 사용 가능 여부와 한도는 플랜과 워크스페이스 설정에 따라 달라요 |

각 도구가 지원하는 차트 종류, 업로드 크기·행 수 한도, ChatGPT·Gemini가 스프레드시트에서 차트를 만드는 방식은 **확인하지 못했어요.** ChatGPT Canvas 페이지와 데이터 분석 페이지를 읽으려 했지만 찾을 수 없어서 이 튜토리얼은 그 내용을 다루지 않아요. 내 계정에서 직접 확인하세요.

## 단계별 따라 하기

예시는 "작은 가게의 월별 판매량을 막대 차트와 한 장 요약으로 만들기"예요.

<Checklist items={[
  '원본 표를 바꾸지 않고 저장해 두었다',
  '데이터에 개인 정보(고객 이름, 계좌번호 등)가 없다',
  '차트가 답해야 할 질문을 정했다',
  '숫자를 말로 설명하지 않고 정확히 붙여 넣었다',
  '모든 값·라벨·단위를 원본과 대조했다',
  '막대 차트의 축이 0에서 시작하는지 확인했다',
]} />

<Steps>

1. **질문과 차트 종류를 정하기**

   한 문장으로 적어요. "어느 달 판매량이 가장 많았는지 보여 줘." 그다음 종류를 골라요. 아래는 이 사이트의 제안이에요.

   - **항목 비교:** 막대 차트
   - **시간에 따른 변화:** 선 차트
   - **전체 중 비율:** 쌓은 막대 하나, 또는 조각이 몇 개 안 되는 원 차트
   - **측정값 두 개:** 눈금이 둘인 차트 하나보다 차트 두 개

2. **Claude에서 표로 차트 만들기**

   Claude 도움말에 따르면 아티팩트를 쓰려면 설정의 Capabilities에서 "Cloud code execution and file creation"이 켜져 있어야 해요(새 설정 화면에서는 "Create and edit files"). 숫자가 정확하도록 작은 표를 그대로 붙여 넣으세요.

   <PromptBox>
   아래 표로 아티팩트에 막대 차트를 만들어 줘. 숫자는 정확히 이대로 쓰고 반올림이나 추정은 하지 마. 각 막대에 값을 표시하고, 아래 축은 월, 세로축은 0에서 시작하게 하고, 제목은 "월별 판매량(개)"로 해 줘. 월, 판매량: 1월 120, 2월 95, 3월 140, 4월 110, 5월 180, 6월 160. 차트 아래에 그린 값을 모두 나열해서 내가 확인할 수 있게 해 줘.
   </PromptBox>

   <ScreenshotPlaceholder caption="Claude 채팅 옆에 열린 막대 차트 아티팩트" officialUrl="https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them" />

   고치려면 채팅에서 요청하세요. 예: "6월 막대만 다른 색으로 바꾸고 숫자는 그대로 둬." 도움말에 따르면 템플릿으로 만든 아티팩트는 직접 편집할 수도 있어요.

3. **또는 Gemini Canvas에서 만들기**

   <FlowSteps title="Gemini 앱에서 Canvas 시작" officialUrl="https://support.google.com/gemini/answer/16047321" steps={[
     { where: 'gemini.google.com', action: '입력창 아래에서 Canvas를 선택', result: '옆 패널에 결과를 만드는 채팅' },
     { where: '입력창', action: '표를 붙여 넣은 프롬프트를 입력하고 Submit 클릭', result: 'Canvas 패널에 차트가 나타나요' },
     { where: 'Canvas 패널', action: '선택해서 묻기(Select & ask)로 부분을 가리키거나 코드를 직접 편집', result: '변경은 자동 저장돼요' },
   ]} />

   프롬프트는 2단계와 같은 것을 써요. 도움말은 Canvas를 문서, 앱, 슬라이드, 코드용으로 설명해요. 거기서 차트를 작은 앱으로 만드는 방식은 이 사이트의 제안이에요.

4. **ChatGPT 이미지 생성으로 인포그래픽 초안 만들기**

   ChatGPT 가이드는 이미지 생성이 설명 그림, 포스터, 라벨이 있는 다이어그램, 타임라인 초안에 도움이 된다고 해요. 정보의 위계와 레이아웃을 설명하고, 라벨은 간결하게, 선명한 글자 렌더링을 요청하라고 해요. 또 정확한 글은 따옴표 안에 넣고 다른 글을 허용하는지도 밝히라고 해요.

   <PromptBox>
   작은 가게의 상반기 판매 요약 인포그래픽 초안을 깔끔하게 만들어 줘. 레이아웃은 위에 제목, 한 줄에 큰 숫자 칸 세 개, 칸마다 단순한 아이콘이야. 글은 이것만 써: 제목 "상반기 한눈에 보기", 라벨 세 개 "최고의 달: 5월", "합계: 805개", "평균: 134개". 다른 단어나 숫자, 로고는 넣지 마. 따뜻하고 차분한 색을 쓰고 여백을 넉넉히 줘.
   </PromptBox>

   결과는 레이아웃 스케치로 보세요. 가이드는 글이 많으면 모든 단어를 검토하고, 중요한 글자 작업은 디자인 도구에서 마무리하라고 해요.

5. **모든 숫자를 원본과 대조하기**

   <Aside type="caution" title="믿지 말고 비교하세요">
   원본 표를 결과 옆에 놓고 값, 라벨, 단위, 제목, 항목 순서를 하나씩 확인하세요. 예시에서 120 + 95 + 140 + 110 + 180 + 160 = 805이고 805 / 6은 약 134라서 인포그래픽의 합계와 평균은 손으로 검산할 수 있어요. 내 자료도 같은 계산을 해 보세요. 다르면 수정을 요청한 뒤 다시 확인하거나, 스프레드시트에서 차트를 만드세요.
   </Aside>

6. **공유 전에 축과 비율 확인하기**

   - 막대는 0에서 시작해요. 두 배 높은 막대는 두 배 값이어야 해요.
   - 차트 두 개를 나란히 놓을 땐 눈금을 같게 해요.
   - 색은 적게 쓰고 글자가 잘 읽히게 해요. 색만으로 구분하지 마세요.
   - 제목이나 부제에 단위와 기간을 적어요.
   - 데이터 출처를 밝혀요.
   - 3D 효과와 조각이 많은 원 차트는 피해요.

   이 내용은 공식 페이지의 설명이 아니라 이 사이트의 실무 제안이에요.

7. **공유·내보내기는 신중하게**

   Claude 도움말에 따르면 템플릿 아티팩트에는 "Export"가 있고, 공유 범위는 나만, 초대한 사람, 링크가 있는 누구나 중에서 정할 수 있어요. 링크를 보내기 전에 누가 열 수 있는지 확인하세요. 예전 방식(legacy) 아티팩트는 코드를 보거나 복사하거나 내려받을 수 있다고 안내해요. ChatGPT 이미지는 먼저 결과를 검토하세요. 가이드는 OpenAI 표기는 선택이고, 조직 지침과 사용 정책을 따르라고 해요.

</Steps>

| 일 | 선택지 |

## 자주 막히는 부분

### 막대 높이나 라벨이 틀렸어요

- **원인**: 모델이 데이터를 잘못 읽거나 반올림하거나 순서를 바꿨어요.
- **해결**: 표를 다시 붙여 넣고 "숫자는 정확히 이대로"라고 말한 뒤 그린 값을 나열하게 해서 원본과 비교하세요.

### 인포그래픽의 글자가 깨졌어요

- **원인**: 이미지 도구는 특히 긴 글에서 글자를 틀릴 수 있어요.
- **해결**: 따옴표 안에 짧은 단어를 적게 넣고 모든 글자를 확인하세요. 최종 글자는 디자인 도구에서 넣어요.

### 차트는 극적인데 실제 변화는 작아요

- **원인**: 축이 0에서 시작하지 않을 수 있어요.
- **해결**: 0 기준선을 요청하고 숫자와 비교하세요.

### 아티팩트나 Canvas가 안 보여요

- **원인**: 기능은 플랜, 설정, 로그인에 따라 달라요.
- **해결**: Claude는 Capabilities 설정을, Gemini는 도움말의 로그인 조건을 확인하세요.

### 데이터가 기밀이에요

- **원인**: 붙여 넣거나 올린 데이터는 서비스로 전달돼요.
- **해결**: 이름과 식별 정보를 지우거나 가짜 샘플 숫자를 쓰세요. [개인정보·보안 기초](/ko/basics/05-privacy-safety/)를 보세요.

## 실전 팁

- **원본 표를 보관하세요.** 나중에 다시 확인할 수 있게 차트 옆에 저장해요.
- **메시지 하나에 차트 하나.** 한 번에 요청을 적게 할수록 뜻밖의 결과가 줄어요.
- **반올림은 의도적으로.** 소수점 몇 자리인지 말해요.
- **숫자를 되돌려 받으세요.** 그린 값 목록은 검증하기 쉬워요.
- **출처와 날짜를 적으세요.** 공개하는 모든 차트에요.
