<Summary>
- 채팅창의 AI는 데이터를 한 번 보고 답해 줘요([대화형 3편](/ko/chat/03-data-analysis/)). Claude Code를 쓰면 분석이 **폴더 안의 스크립트 파일**로 남아서 다음 달에도 다시 돌릴 수 있어요.
- 흐름은 **데이터 복사 → 파일 설명부터 시키기 → 질문 정하기 → 스크립트 작성·실행 → 차트와 요약 보고서를 새 파일로 저장 → 숫자를 직접 확인**이에요.
- 공식 모범 사례는 Claude에게 **실행해 볼 수 있는 검사**를 주고, "다 됐어요"만 듣지 말고 **증거(실행한 명령과 출력)를 달라고** 하라고 해요(2026-10-31 확인).
- **원본은 그대로 둬야 해요.** 파일 이름 변경·이동·삭제 명령은 `/rewind`로 안 돌아오니 먼저 폴더를 백업하세요(이유는 [코딩 8편](/ko/coding/35-file-automation/)에 있어요).
- 이 페이지를 위해 이 실습을 Claude Code로 직접 실행해 보지는 않았어요. 프롬프트와 예시 파일은 이 사이트가 만든 예시이고, 여러분 컴퓨터에서 나오는 결과는 달라질 수 있어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 분석 전에 Claude Code에게 **CSV를 읽고 구조(열, 형식, 빈칸, 이상한 값)를 설명**하게 할 수 있어요.
- 합계·그룹별 집계·비교를 하는 **재사용 가능한 분석 스크립트**와, **차트 이미지·짧은 보고서**를 새 파일로 받을 수 있어요.
- 자신만만한 요약을 그냥 믿지 않고 **직접 해 볼 수 있는 교차 확인**으로 결과를 검증할 수 있어요.
- Claude Code가 맞는 경우와 채팅창·스프레드시트 AI가 더 나은 경우를 구분할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 이 실습에서의 뜻 |
| --- | --- |
| **분석 스크립트** | 데이터를 읽고 계산해서 결과를 쓰는 작은 프로그램 파일이에요(예: 파이썬 파일). Claude가 쓰고, 나중에 다시 실행할 수 있어요. |
| **원본을 건드리지 않는 분석** | 스크립트는 원본 파일을 **읽기만** 하고, 결과는 `report.md`, `chart.png` 같은 **새 파일**로 저장해요. |
| **검증 단계** | "그룹별 합계를 더하면 전체 합계와 같다"처럼 통과/실패로 나오는 확인이에요. |
| **계획 모드** | 파일을 바꾸지 않고 조사해서 계획만 제안하는 모드예요. `Shift+Tab`으로 바꿔요. |
| **비대화형 모드(`claude -p`)** | 프롬프트 하나를 실행하고 답을 출력해서 스크립트 안에서 Claude Code를 쓸 수 있어요. 이 편에서는 선택 사항으로만 소개해요. |

### Claude Code, 채팅, 스프레드시트 AI 중 무엇을 쓸까요?

| 상황 | 잘 맞는 도구 |
| --- | --- |
| 파일 하나, 한 번만 묻고 바로 답을 보고 싶을 때 | 파일 업로드가 되는 채팅 AI([대화형 3편](/ko/chat/03-data-analysis/)) |
| 계속 고치는 시트 안에서 계산할 때 | 엑셀·구글 시트에 내장된 AI([23편](/ko/automation/23-spreadsheet-ai/)) |
| 폴더 속 여러 파일을 합치거나 이름을 바꿀 때 | [코딩 35편](/ko/coding/35-file-automation/) |
| 다음 달 파일에도 **다시 돌릴 스크립트와 보고서**가 데이터 옆에 남았으면 할 때 | **Claude Code (이 편)** |

<Aside type="note" title="확인하지 못한 것">
읽어 본 Claude Code 공식 문서에는 엑셀(.xlsx) 파일을 어떻게 읽고 쓰는지, 어떤 분석 라이브러리를 쓸 수 있는지 나와 있지 않았어요. 방법은 Claude가 정하고, 설치나 실행 전에 승인을 물어요. 그래서 **결과는 컴퓨터 환경에 따라 달라질 수 있어요**. .xlsx에서 문제가 생기면 엑셀에서 해당 시트를 CSV로 내보내 그 복사본을 분석하는 것이 안전한 우회 방법이에요.
</Aside>

## 따라 하기

<Steps>

1. **백업하고 연습 폴더 만들기**

   데이터가 든 폴더를 통째로 복사해 다른 위치에 붙여넣으세요(이름 끝에 `_backup`을 붙이면 헷갈리지 않아요). 그다음 `analysis-practice` 같은 새 폴더를 만들고 데이터 파일 하나를 **복사**해 넣으세요. 연습에는 직접 만든 작은 파일을 쓰세요. 예를 들어 다음 열을 가진 판매 목록이에요.

   ```csv
   date,region,product,units,unit_price
   2026-09-01,서울,노트,12,4500
   2026-09-01,부산,펜,40,800
   2026-09-02,서울,펜,25,800
   ```

   실제 고객 이름, 연락처, 급여는 연습 폴더에 넣지 마세요. 공식 데이터 사용 페이지(2026-10-31 확인)에 따르면 Free·Pro·Max·Ultra 계정은 모델 개선에 데이터 사용을 허용하는 설정에 따라 학습 사용 여부와 보관 기간(허용하면 5년, 허용하지 않으면 30일)이 달라지고, 이 설정은 `claude.ai/settings/data-privacy-controls`에서 바꿀 수 있어요. Team·Enterprise·API 계정은 상업용 약관을 따라요. 민감 정보의 기본 원칙은 [개인정보와 안전](/ko/basics/05-privacy-safety/)을 보세요.

2. **그 폴더에서 계획 모드로 시작하기**

   연습 폴더에서 터미널을 열고 `claude`를 실행하세요. `Shift+Tab`을 눌러 **계획 모드**로 바꿔요. 공식 권한 모드 문서(2026-10-31 확인)에 따르면 CLI에서는 `Shift+Tab`으로 모드를 바꿀 수 있고, 계획 모드는 승인하기 전까지 소스를 고치지 않고 조사해서 계획을 제안해요. 터미널이 처음이라면 [6편](/ko/coding/06-claude-code-start/)부터 보세요.

   ```sh
   cd ~/Desktop/analysis-practice
   claude
   ```

3. **먼저 파일을 설명하게 하기**

   결론부터 묻지 마세요. 파일에 뭐가 들어 있는지부터 물어요. 여기서 찾은 이상한 값이 나중의 틀린 합계를 막아 줘요.

   <PromptBox>
   이 폴더의 sales.csv를 보고 알려 주세요. (1) 열 이름과 각 열에 어떤 형식의 값이 들어 있는지 (2) 행이 몇 개인지 (3) 열마다 빈 칸이 몇 개인지 (4) 음수, 서로 다른 날짜 형식, 같은 상품이 두 가지 표기로 적힌 것처럼 이상해 보이는 값이 있는지. 아직 파일을 바꾸거나 만들지 마세요. 분석에 프로그램 설치가 필요하면 어떤 것인지 먼저 알려 주세요.
   </PromptBox>

   Claude가 패키지 설치(예: `pip`)를 승인해 달라고 하면 승인 화면의 이름을 읽어 보세요. 설치는 컴퓨터에 프로그램을 추가하는 일이라서, 무엇인지 이해될 때만 허용하세요. 모르겠으면 "이 명령이 뭘 하는지 설명해 줘"라고 물어보세요.

4. **질문과 확인 방법 정하기**

   질문 2~3개와, 답이 맞는지 어떻게 알지를 정하세요. 확인 방법을 미리 Claude와 정해 두는 것은 통과/실패로 나오는, 실행 가능한 검사를 주라는 공식 조언을 따르는 거예요(2026-10-31 확인).

   <PromptBox>
   sales.csv로 다음 질문에 답하고 싶어요. (1) 지역별·상품별 매출(units x unit_price) 합계 (2) 매출이 가장 높았던 주 (3) 데이터의 앞쪽 절반에서 뒤쪽 절반으로 가장 많이 늘어난 상품 세 가지. 코드를 쓰기 전에 짧은 계획을 제안하고, 스스로 결과에 돌려 볼 검사 두 가지(예: 지역별 합계를 더하면 전체 합계와 같은지)를 알려 주세요. 아직 아무것도 고치지 마세요.
   </PromptBox>

   계획을 읽고, 틀린 부분은 말로 고치세요. 예를 들어 "주는 월요일부터 시작해요", "units가 0인 행은 빼 주세요" 같은 식이에요.

5. **스크립트를 쓰고 실행하게 하고, 결과는 새 파일로 저장하기**

   `Shift+Tab`으로 계획 모드를 나오거나 계획을 승인해 주세요. 변경 전에 물어보는 기본 모드를 유지해서 파일 쓰기와 명령을 모두 보세요.

   <PromptBox>
   계획대로 진행해 주세요. 분석을 analyze_sales.py 스크립트로 쓰되, sales.csv는 읽기만 하고 절대 바꾸지 마세요. 스크립트는 (1) summary_by_region_product.csv (2) 지역별 매출 막대그래프 sales_by_region.png (3) 세 질문의 답을 쉬운 말로 요약하고 검사 목록과 결과를 적은 report.md를 저장해야 해요. 스크립트를 실행한 뒤 실행한 명령과 출력을 그대로 보여 주세요. 검사가 실패하면 고치기 전에 멈추고 설명해 주세요.
   </PromptBox>

   <ScreenshotPlaceholder caption="Claude Code가 스크립트 파일을 만들고 실행해도 되는지 승인을 묻는 화면" officialUrl="https://code.claude.com/docs/en/permission-modes" />

   승인 화면에서는 세 가지만 보세요. **(1) 만들어지는 파일이 작업 폴더 안에 있는지, (2) `sales.csv`를 읽기만 하고 쓰지는 않는지, (3) 요청하지 않은 `rm`이나 `mv` 명령이 없는지**예요.

6. **결과를 직접 확인하기**

   "다 됐어요"에서 멈추지 마세요. `report.md`, `summary_by_region_product.csv`, `sales_by_region.png`를 열어 보세요. 공식 모범 사례는 "테스트 모두 통과"라는 말만으로는 알 수 있는 게 거의 없고, 실행한 명령과 출력을 읽는 것이 쓸모 있는 증거라고 해요(2026-10-31 확인). 그리고 직접 표본 확인을 하세요.

   - 엑셀에서 한 지역만 필터링해서 몇 행의 units x unit_price를 손으로 더해 보세요. 요약표와 같나요?
   - Claude가 쓴 행 수가 3단계에서 확인한 행 수와 같나요?
   - 차트에서 가장 높은 막대가 요약표의 가장 큰 숫자와 같나요?

   다르면 본 그대로 정확히 말하세요.

   <PromptBox>
   서울 행을 손으로 더했더니 128,500인데 요약표에는 131,000이라고 나와요. 고치기 전에 원인부터 찾아 주세요. 서울 합계에 들어간 행을 보여 주고 차이를 설명해 주세요. 그다음 스크립트를 고쳐서 다시 실행하고, 명령과 출력을 다시 보여 주세요.
   </PromptBox>

   ]} />

7. **다시 쓸 수 있게 정리하기**

   결과가 맞으면 다음 달에 다시 돌릴 수 있게 짧은 안내문을 부탁하세요.

   <PromptBox>
   새 sales.csv로 analyze_sales.py를 실행하는 방법, 필요한 열, 만들어지는 파일을 설명하는 짧은 README.md를 추가해 주세요. 그다음 이 폴더에서 만들거나 바꾼 파일을 모두 나열하고, 원본 데이터 파일이 수정됐는지 알려 주세요.
   </PromptBox>

   "원본 데이터는 절대 수정하지 않기", "결과는 output 폴더에 저장하기" 같은 규칙을 매번 쓴다면 안내 노트(CLAUDE.md)에 적어 두세요. [6편](/ko/coding/06-claude-code-start/)과 [C14](/ko/claude/c14-claude-code-features/)에서 다뤄요.

</Steps>

## 안전하게 쓰는 습관

| 습관 | 이유와 방법 |
| --- | --- |
| **시작 전에 백업** | 공식 체크포인트 문서(2026-10-31 확인)에 따르면 `rm`·`mv` 같은 명령으로만 바뀐 파일은 `/rewind`가 추적하지 않아요. 체크포인트는 Git 같은 버전 관리를 대신하지도 않아요. |
| **원본은 읽기 전용** | "원본 파일은 절대 수정하지 마세요"라고 말하고, 승인 화면에서 원본에 쓰는 동작이 없는지 보세요. |
| **먼저 연습용 데이터로** | 흐름이 믿을 만해질 때까지 가상 데이터를 쓰세요. 사내 데이터를 외부 서비스에 쓸 수 있는지는 회사 규정을 먼저 확인하세요. |
| **증거를 요구** | 성공했다는 요약 대신 실행한 명령과 출력을 달라고 하세요. |
| **직접 검산** | 숫자 몇 개는 직접 다시 계산하세요. 자신 있는 보고서도 틀린 숫자를 담을 수 있어요. |
| **자동 승인은 천천히** | `acceptEdits` 모드는 파일 편집과 흔한 파일 명령을 묻지 않고 실행해요. 백업하고 스크립트를 믿게 된 뒤에만 쓰세요. |

## 한눈에 보기

### 요청 문장 패턴

| 상황 | 이렇게 말해 보세요 |
| --- | --- |
| 파일 이해 | "[파일]의 열, 형식, 빈칸, 이상한 값을 설명해 줘. 아무것도 바꾸지 마." |
| 계획 | "계획과, 스스로 결과에 돌려 볼 검사 두 가지를 제안해 줘. 아직 고치지 마." |
| 스크립트와 결과 | "[파일]을 읽기만 하고 [결과]를 새 파일로 저장하는 [스크립트 이름]을 써 줘. 실행하고 명령과 출력을 보여 줘." |
| 차트 | "[무엇]의 [막대/선] 차트를 [파일 이름]으로 저장해 줘. 축 이름과 제목을 붙여 줘." |
| 숫자 불일치 | "내가 손으로 계산한 합계는 [x]인데 네 결과는 [y]야. 고치기 전에 네 숫자에 들어간 행을 보여 줘." |
| 점검 | "만들거나 바꾼 파일을 모두 나열하고, 원본이 수정됐는지 알려 줘." |

### 자주 쓰는 키와 명령

| 키 / 명령 | 하는 일 |
| --- | --- |
| `Shift+Tab` | 권한 모드(계획 모드 포함) 바꾸기 |
| `Esc` 두 번(입력창이 비었을 때), `/rewind` | Claude의 편집 도구로 바뀐 내용을 되돌리는 메뉴 |
| `/clear` | 새 대화 시작(파일은 그대로) |

### 선택: 스크립트에서 실행하기

Claude Code는 `-p`로 비대화형 실행을 할 수 있어요. 공식 문서에는 `claude -p "<프롬프트>"` 형태가 나오고, 표준 입력과 출력이 다른 유닉스 도구처럼 동작한다고 해요(2026-10-31 확인). 예를 들어 매달 하는 작업에서 작은 요약을 프롬프트에 연결해 넣을 수 있어요. 고급 단계이니 공식 비대화형 모드 페이지를 먼저 읽고 연습용 데이터로 시험하세요. 이 페이지를 위해 직접 실행해 보지는 않았어요.

## 자주 막히는 곳

### 숫자가 내 스프레드시트와 달라요

- **원인**: 스크립트가 빈칸, 텍스트로 저장된 숫자, 중복 행을 시트와 다르게 다뤘을 수 있어요.
- **해결**: 그 숫자에 들어간 행과 쓴 규칙(예: "빈 units는 어떻게 처리했어?")을 물어보세요. 규칙을 고치고 다시 실행해 다시 확인하세요.

### Claude가 패키지를 설치하겠다고 해요

- **원인**: 분석이나 차트에 컴퓨터에 없는 라이브러리가 필요해서예요.
- **해결**: 승인 화면의 패키지 이름을 읽고, 이해되고 꼭 필요할 때만 허용하세요. 모르겠으면 설명을 부탁하거나, 이미 설치된 것만 쓰는 방법을 요청하세요.

### .xlsx 파일이 안 열리거나 시트가 빠졌어요

- **원인**: 공식 문서에서 Claude Code가 엑셀 파일을 어떻게 다루는지 확인하지 못했어요.
- **해결**: 필요한 시트를 CSV로 내보내 그 복사본을 분석하세요. 새로 생긴 것을 알 수 있게 만든 파일 목록을 달라고 하세요.

### CSV의 한글이 깨져 보여요

- **원인**: 파일 인코딩 문제일 수 있지만 공식 문서에서 원인을 확인하지 못했어요.
- **해결**: 어떻게 깨져 보이는지 정확히 설명하고, 엑셀에서 열었을 때 제대로 보이게 저장해 달라고 하세요. 원본은 그대로 두세요.

### 고칠수록 보고서가 나빠져요

- **원인**: 실패한 시도가 대화에 쌓였을 수 있어요.
- **해결**: 공식 모범 사례처럼 `/clear`로 새로 시작하고, 지금 상태와 원하는 결과를 더 구체적으로 설명하세요.

## 실전 팁

- **방법보다 질문을 먼저 말하세요.** "이거 분석해 줘"보다 "어느 지역이 가장 많이 늘었어?"가 잘 통해요.
- **결과는 `output` 폴더에 모으게** 프롬프트에서 말하면 다시 돌릴 때 데이터와 섞이지 않아요.
- **새 데이터는 질문을 하나씩.** 첫 확인이 통과하면 다음 질문을 더하세요.
- **보고서는 초안으로 보세요.** Claude는 패턴을 설명할 수 있지만 그것이 사업에 어떤 의미인지 판단하는 일은 여러분 몫이에요.
- **사용량이 걱정되면** [C2](/ko/claude/c02-plans-limits/)의 안내를 먼저 보세요.
