<Summary>
- Claude, Gemini, ChatGPT에는 검색을 여러 번 돌려 **출처가 달린 보고서**를 만들어 주는 모드가 있어요. 이름은 Research, Deep Research, deep research예요.
- 시작하는 곳이 달라요. Claude는 **+** 메뉴의 Research(웹 검색을 켜야 해요), Gemini는 **파일 추가** 메뉴의 Deep Research, ChatGPT는 Work 안의 **+** 메뉴에서 Deep research(계정에서 쓸 수 있을 때)예요.
- Gemini는 시작 전에 **고칠 수 있는 조사 계획**을 보여 줘요. 우리가 읽은 Claude·ChatGPT 페이지에는 계획 단계 설명이 없었어요.
- 보고서는 AI가 쓴 초안이에요. 이 글의 핵심은 **출처, 핵심 주장, 빠진 것 순서로 확인하는 루틴**이에요.
- 플랜·한도는 자주 바뀌고 일부 공식 페이지는 접근이 막혀 있었어요. 확인하지 못한 것은 확인 못 함으로 표시했어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 질문에 맞게 빠른 검색과 여러 출처 보고서 중 알맞은 쪽을 고를 수 있어요.
- 세 서비스에서 조사 보고서를 시작하고, 먼저 무엇을 설정할지 알 수 있어요.
- 끝난 보고서를 그대로 믿지 않고 세 단계로 확인할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **리서치 에이전트** | AI가 검색을 여러 번 하고, 찾은 내용을 보고 다음에 볼 것을 정해 긴 보고서를 쓰는 모드예요. 일반 대화 답변이나 한 번의 웹 검색과 달라요. |
| **출처** | 보고서가 근거로 삼은 웹페이지, 파일, 연결된 앱의 항목이에요. 좋은 보고서는 각 출처를 열어 볼 수 있어요. |
| **조사 계획** | AI가 무엇을 살펴볼지 적은 목록이에요. Gemini는 시작 전에 보여 줘요. |
| **근거 없는 주장** | 보고서에 있지만, 인용한 페이지에는 실제로 그렇게 적혀 있지 않은 문장이에요. |

서비스별 자세한 내용은 [C10. Claude Research](/ko/claude/c10-research/)와 [AI 검색 비교](/ko/chat/22-ai-search/)를 보세요. 이 글은 **세 서비스를 비교하고 결과를 확인하는 일**에 집중해요.

### 공식 페이지가 확인해 주는 것

| 서비스 | 공식 문서의 내용(요약) |
| --- | --- |
| Claude | Research는 서로 이어지는 여러 검색으로 질문을 깊이 조사해요. 웹, Claude Desktop, Claude Mobile의 유료 플랜(Pro, Max, Ultra, Team, Enterprise)에서 쓸 수 있고 웹 검색이 켜져 있어야 해요. Google Workspace 같은 커넥터도 쓸 수 있지만, Claude Mobile에서 시작한 조사는 오류 표시 없이 웹만 검색해요. |
| Claude | 한도는 일반 대화와 같지만 더 빨리 소진될 수 있어요. 대화에서 어떤 모델을 골랐든 Claude Opus 5.5로 실행하고, 필요하면 Claude Opus 4.8로 넘어가요. |
| Claude | "언제 쓰나" 페이지는 1~3분 동안 도구를 다섯 번 이상 써야 하는 폭넓은 자료 수집에 Research가 알맞다고 해요. 여러 출처를 인용과 함께 종합해 더 긴 보고서를 만들어 줘요. 단순한 사실 질문에는 웹 검색이 알맞아요. |
| Gemini | Deep Research는 만 18세 이상이고 로그인해야 써요. Google 검색이 기본 출처이고, Gmail, Drive, 업로드한 파일, NotebookLM 노트북을 더할 수 있어요. Gmail과 Drive는 Google Workspace 앱이 연결돼 있어야 해요. |
| Gemini | Gemini가 조사 계획을 만들고, **Edit plan**으로 고친 뒤 **Start research**를 눌러요. 보고서는 보통 5~10분 걸리고 복잡하면 더 걸려요. 기다리는 동안 채팅을 떠나도 돼요. |
| Gemini | 하루 요청 수와 동시 요청 수에 한도가 있고, Pro·Ultra는 한도가 더 높아요. 지난 보고서는 Keep Activity 설정이 켜져 있을 때만 찾을 수 있어요. 공유, Docs로 내보내기, 복사가 가능해요. |
| ChatGPT | ChatGPT 문서는 여러 출처를 조사하고 검토할 보고서가 필요한 질문에 Work의 deep research를 쓰라고 설명해요. 웹에서는 **+** 메뉴의 Deep research를 고르는데, 계정과 워크스페이스에서 쓸 수 있을 때만이에요. 데스크톱 앱에서는 Deep research 플러그인이에요. 보고서와 출처를 검토하고 후속 질문을 할 수 있어요. |
| ChatGPT | 웹 검색 결과는 모두 신뢰할 수 없는 입력으로 다루라고 해요. |

<Aside type="note" title="공식 내용과 이 사이트의 권장 사항">
위 표는 2026-11-02에 읽은 공식 페이지의 내용이에요. 아래의 루틴, 프롬프트, "무엇을 쓸까" 제안은 공식 요구가 아니라 **이 사이트의 권장 사항**이에요.
</Aside>

### 확인하지 못한 것

- **ChatGPT deep research의 이용 가능 플랜과 사용 한도.** OpenAI 도움말 문서와 소개 페이지는 기본 요청에 차단 페이지를 돌려줬고, 우회하지 않았어요. 읽은 문서 페이지에는 계정과 워크스페이스 설정에 따라 달라진다고만 나와요.
- **ChatGPT 보고서의 일반적인 소요 시간**, 그리고 시작 전에 고칠 수 있는 계획을 보여 주는지.
- **Gemini의 정확한 하루 한도 숫자.** 한도가 있다고만 나오고, 숫자는 열어 보지 않은 다른 페이지에 있어요.
- **Claude 보고서 소요 시간**은 안내 페이지의 "1~3분"(Research형 작업 기준) 외에는 확인하지 못했어요.
- 기능과 모델 이름은 자주 바뀌니 본인 화면을 확인하세요.

### 1. 정하기: 빠른 검색인가, 전체 보고서인가

Claude 안내에 따르면 단순한 사실 질문은 웹 검색, 여러 출처 비교는 Research가 맞아요. 보고서는 몇 분이 걸리고 Claude에서는 한도가 더 빨리 줄 수 있으니, 검색 한 번으로 풀리는 질문에는 쓰지 마세요. [AI 검색 비교](/ko/chat/22-ai-search/)와 같은 구분이에요.

### 2. 요청서를 분명하게 쓰기 (이 사이트의 권장)

질문이 흐리면 길고 흐린 보고서가 나와요. 질문, 읽을 사람, 기간, 지역, 원하는 형식을 적어 주세요.

<PromptBox>
10명 규모 팀이 스프레드시트에서 프로젝트 관리 도구로 옮겨야 하는지 조사해 줘. 흔히 쓰는 세 가지를 가격, 익히는 시간, 데이터 내보내기로 비교해 줘. 최근 12개월 안의 출처를 써 줘. 표를 먼저 보여 주고 짧은 추천을 쓰고, 모든 출처를 날짜와 함께 나열해 줘. 확인하지 못한 것은 표시해 줘.
</PromptBox>

### 3. 서비스별로 시작하기

| 서비스 | 시작 방법(읽은 페이지 기준) | 먼저 설정할 것 |
| --- | --- | --- |
| **Claude** | 웹 검색을 켜요. 채팅 왼쪽 아래 **+**를 누르고 **Research**를 골라요. 파란 표시가 나타나요. 조사를 안 하면 "research 도구를 써서..."라고 말해 보세요 | 커넥터를 쓰려면 Mobile이 아니라 웹이나 Desktop에서 시작해요 |
| **Gemini** | gemini.google.com에서 **파일 추가**, **Deep Research**를 열어요. 필요하면 파일을 더하고 **Sources**를 골라요. 제출하고, 필요하면 **Edit plan**, 그다음 **Start research** | 다른 출처로만 제한하려면 Google 검색을 해제해요. Gmail·Drive는 Workspace 연결이 필요해요 |
| **ChatGPT** | 웹: **Work**에서 채팅을 시작하고 **+**에서 **Deep research**를 골라요. 데스크톱: Work, Plugins, Deep research | 질문, 범위, 원하는 결과를 적고 파일이나 연결 앱 맥락을 더해요 |

<Aside type="caution" title="연결된 앱과 개인 정보">
Claude 도움말은 Research가 커넥터 도구를 매번 묻지 않고 자동으로 쓸 수 있다고 하고, Gemini는 Gmail과 Drive를 출처로 쓸 수 있어요. 질문에 개인 메일이나 파일이 필요 없다면 꺼 두세요([기초 12편](/ko/basics/12-privacy-settings/)).
</Aside>

### 4. 계획이 있으면 검토하기

Gemini는 시작 전에 계획을 보여 줘요. 원하지 않는 주제는 빼고 원하는 주제는 더하세요. 우리가 읽은 Claude·ChatGPT 페이지에서는 계획 단계 설명을 찾지 못했어요. 그 서비스들에서는 범위를 요청서에 적어 주세요.

### 5. 보고서를 세 단계로 확인하기 (이 사이트의 권장)

1. **출처.** 인용된 링크를 최소 다섯 개 열어 보세요. 실제로 있고, 관련 있고, 최신이고, 원자료나 믿을 만한 곳인가요?
2. **주장.** 결정이 달린 서너 개의 주장은 출처 페이지에서 뒷받침하는 문장을 찾아보세요. 못 찾으면 근거 없는 주장으로 보세요([기초 4편](/ko/basics/04-fact-checking/)).
3. **빈틈.** 보고서가 다루지 않은 것은 무엇인가요? 서로 엇갈리는 출처는요? 핵심 출처가 유료 벽 뒤에 있거나 열리지 않았나요?

<PromptBox>
보고서의 각 주장마다 출처 URL, 근거로 삼은 정확한 문장, 페이지를 직접 읽었는지 추론했는지를 알려 줘. 그리고 답하지 못한 질문과 서로 엇갈리는 출처를 나열해 줘.
</PromptBox>

### 6. 같은 질문을 두 서비스에서 돌려 보기

중요한 결정이라면 같은 요청서를 두 서비스에서 돌려 비교하세요. 차이가 나는 곳이 더 자세히 볼 곳이에요. 결과가 같아도 증거는 아니에요. 둘 다 같은 인기 페이지에 기댔을 수 있어요.

| 비교 항목 | 볼 것 |
| --- | --- |
| 쓴 출처 | 겹치는 것, 한쪽만 찾은 것 |
| 숫자 | 서로 다른 수치와 각각의 출처 페이지 |
| 결론 | 증거에 따라 추천이 바뀌는지 |
| 날짜 | 오래된 페이지가 무엇인지 |

### 7. 날짜를 붙여 저장하기

Gemini는 보고서를 공유하거나 Docs로 내보낼 수 있고, 지난 보고서는 Keep Activity가 켜져 있을 때만 찾을 수 있어요. 최종 글과 출처를 오늘 날짜와 함께 내 노트에 복사해 두세요. 원래 페이지는 바뀔 수 있어요.

## 자주 막히는 지점

### Claude가 조사를 하지 않는 것 같아요

- **원인**: Research를 켰는데 일반 답변을 했거나, 웹 검색이 꺼져 있어요.
- **해결**: 웹 검색을 켜고, 도움말 제안대로 "research 도구를 써서..."라고 말해 보세요.

### 커넥터가 쓰이지 않았어요

- **원인**: Claude Mobile에서 시작한 Research는 오류 표시 없이 웹만 검색해요.
- **해결**: Claude 웹이나 Desktop에서 시작하세요.

### 지난 Gemini 보고서를 못 찾겠어요

- **원인**: 지난 보고서는 Keep Activity가 켜져 있을 때만 찾을 수 있어요.
- **해결**: 설정을 확인하고, 중요한 보고서는 끝났을 때 바로 내보내 두세요.

### 보고서가 인용한 페이지에 그런 말이 없어요

- **원인**: AI가 출처를 잘못 읽거나 지나치게 요약할 수 있어요.
- **해결**: 정확한 문장을 요구하고, 페이지를 열어 보고, 근거 없는 주장은 빼세요.

## 실전 팁

- **범위를 좁히세요.** "X의 모든 것"보다 하나에 집중한 질문이 나아요.
- **날짜를 주세요.** "최근 12개월"처럼 말하면 오래된 페이지를 피할 수 있어요.
- **엇갈리는 내용을 물으세요.** 한 번도 의견이 갈리지 않는 보고서는 빈틈을 숨기고 있을 수 있어요.
- **비밀 정보를 넣지 마세요.** 조사 요청에도 마찬가지예요.
- **저작권.** 요약은 읽어도 되지만 긴 문장을 그대로 다시 게시하지 마세요([기초 9편](/ko/basics/09-ai-copyright-ethics/)).
- **기능은 자주 바뀌어요.** 이 글은 2026-11-02 기준이니 실제 화면을 확인하세요.
- 이 글을 쓰면서 도움말 페이지만 읽었고 조사 보고서를 직접 실행하지는 않았어요. 단계 설명은 공식 표현을 따른 것이지 우리가 직접 시험한 결과가 아니에요.
