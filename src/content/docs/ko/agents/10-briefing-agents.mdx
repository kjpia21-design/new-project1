<Summary>
- 에이전트는 한동안 스스로 일하기 때문에, 모호한 요청은 채팅 답변과 달리 엉뚱한 결과로 이어질 수 있어요. 좋은 **지시서**는 가장 값싼 안전장치예요.
- 확인한 공식 페이지 셋 모두 **원하는 결과를 설명하라**고 해요. Claude는 "describe the task you want Claude to complete", OpenAI는 "describe the result you need and the sources it should use", Gemini는 "tell Gemini your specific goals and when you want tasks completed"라고 해요.
- 이 글은 **목표·범위·완료 기준·금지 행동·확인 지점** 다섯 부분의 지시서를 소개해요. 이 다섯 부분은 **이 사이트의 권장**이고 공식 형식이 아니에요.
- 공식 페이지가 확인해 주는 재료도 있어요. 더 구체적인 지시를 더할 수 있고(OpenAI), 작업 도중 방향을 바꿀 수 있고(Claude, Gemini), 특정 결정은 확인이나 알림을 요청할 수 있어요(OpenAI, Gemini).
- 에이전트가 끝낸 뒤 결과를 확인하는 법은 [7편](/ko/agents/07-reviewing-agent-work/)에서 다뤄요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 모호한 요청을 에이전트가 따를 수 있는 지시서로 바꿀 수 있어요.
- 다섯 부분 템플릿을 채워 다른 작업에도 다시 쓸 수 있어요.
- 이 조언 중 공식 도움말에서 온 것과 이 사이트의 권장을 구분할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **지시서** | 에이전트가 시작하기 전에 주는 글이에요. 원하는 것, 한계, 끝났는지 아는 방법을 담아요. |
| **범위** | 에이전트가 쓸 수 있는 파일·사이트·앱·기간이에요. |
| **완료 기준** | 확인할 수 있게 적은 결과의 모습이에요. 형식, 개수, 위치, 보고할 내용을 포함해요. |
| **확인 지점** | 더 진행하기 전에 에이전트가 멈춰서 묻거나 알려 주길 바라는 순간이에요. |
| **방향 조정** | 작업이 진행되는 중에 지시를 더하거나 바꾸는 것이에요. |

### 공식 페이지는 무엇을 말하고, 무엇이 이 사이트의 권장일까요?

| 출처 | 공식 안내 (의역 또는 짧은 인용) |
| --- | --- |
| Claude Cowork 시작 안내 | 메시지 상자에서 "Cowork"를 고르고 Claude가 해 주길 바라는 작업을 설명하라고 해요. 그다음 Claude의 접근 방식을 검토하고 실행시켜요. 작업 중에도 끼어들어 방향을 바로잡거나 지시를 더할 수 있어요. |
| Claude Cowork 시작 안내 | 모든 Cowork 세션에 적용되는 전역 지침(말투, 출력 형식, 역할 배경)과, 데스크톱에서 로컬 폴더를 고를 때 프로젝트별 맥락을 더하는 폴더 지침을 설정할 수 있어요. |
| Claude Cowork 안전 가이드 | 예상 밖의 패턴을 지켜보라고 해요. 언급하지 않은 파일이나 사이트에 접근하는지, 요청 범위를 넘어 번지는지요. 넓은 접근 대신 전용 작업 폴더를 고려하라고 하고, 메시지 전송이나 구매처럼 되돌리기 어려운 일은 "Manually approve"로 바꾸라고 해요. |
| ChatGPT dot 문서 | 필요한 결과와 쓸 출처를 설명하라고 해요. 내장 안전장치와 앱 권한은 자동으로 적용되고, 더 구체적인 지시를 더할 수 있어요. 어떤 결과를 알려 줄지, 어떤 결정에 내 입력이 필요한지 말해 주라고 해요. |
| ChatGPT dot 문서 | 반복 작업은 무엇을 확인·갱신할지, 언제 실행할지(시간대와 종료일 포함), 어떤 변경에 알림을 보낼지, 결과를 어디에 전달할지 정하라고 해요. 저장한 내용을 dot에게 확인해 달라고 하라고 해요. |
| Gemini 작업 도움말 | 구체적인 목표와 완료 시점을 Gemini에게 말하라고 해요. 작업 중 접근 방식을 바꾸려면 추가 지시를 입력해요. Gemini가 요구하는 입력이 있는지 지켜보라고 하고, 민감하다고 여기는 정보나 행동이 걸린 작업·일정은 피하라고 해요. |

<Aside type="note" title="공식 안내와 이 사이트의 권장을 구분해요">
위 표는 페이지가 말하는 내용이에요. 다섯 부분 템플릿, "건너뛴 것까지 보고하게 하기" 습관, 예시 프롬프트는 **이 사이트의 권장**이에요. 공식 조언과 어긋나지 않지만 공식 요구 사항은 아니에요. 지시서 템플릿을 정해 둔 공식 페이지는 찾지 못했어요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '1. 목표를 막연한 주제가 아니라 결과로 적었다',
  '2. 에이전트가 쓸 수 있는 것(파일, 사이트, 앱, 기간)을 적었다',
  '3. "끝"의 모습과 보고할 내용을 적었다',
  '4. 에이전트가 하면 안 되는 일을 적었다',
  '5. 멈춰서 나에게 물어야 할 순간을 정했다',
  '6. 작업을 작게 줄여 먼저 시작했다',
  '7. 지시서를 남이 읽는 것처럼 한 번 다시 읽었다',
]} />

### 1. 목표: 주제가 아니라 결과를 말해요

"항공편 알아봐 줘"는 주제예요. "3월 5일 서울에서 도쿄로 가는 직항 세 개를 정해 둔 예산 이하로 찾아 표로 정리해 줘"는 결과예요. 공식 페이지 셋 모두 원하는 결과를 중심으로 작업을 설명해요.

### 2. 범위: 쓸 수 있는 것을 말해요

폴더, 써도 되는 사이트나 앱, 기간을 적어요. Cowork 안전 가이드는 전용 작업 폴더를 권하고, OpenAI는 dot이 쓸 출처를 설명하라고 해요. 범위가 좁으면 에이전트가 벗어났을 때 알아채기도 쉬워요.

### 3. 완료 기준: 확인할 수 있게 적어요

형식, 개수, 결과를 둘 곳, 마지막에 보고할 내용을 적어요. [7편](/ko/agents/07-reviewing-agent-work/)에서 같은 기준으로 결과를 확인하게 돼요.

### 4. 금지 행동: 하지 말 일을 적어요

예: 원본을 지우거나 옮기지 않기, 아무것도 보내지 않기, 아무것도 사지 않기, 계정에 로그인하지 않기, 설정을 바꾸지 않기. 공식 페이지는 내장 안전장치가 적용된다고 하면서도 더 구체적인 지시를 더할 수 있다고 해요(OpenAI). 직접 쓴 "하지 말 것" 목록은 권한 설정을 대신하지 않는 추가 층으로 보세요([5편](/ko/agents/05-agent-safety/) 참고).

### 5. 확인 지점: 언제 멈춰서 물을지 말해요

OpenAI는 어떤 결과를 알려 줄지, 어떤 결정에 내 입력이 필요한지 dot에게 말해 주라고 해요. Gemini는 일부 작업이 완료 전에 확인을 요구한다고 해요. 직접 정해 보세요. "누구에게든 연락하기 전에 물어봐", "시작 전에 계획을 보여 줘", "파일이 50개를 넘으면 멈추고 물어봐".

### 6. 합쳐서 써요

<PromptBox>
목표: "receipts" 폴더의 영수증 사진 12장을 날짜, 가게, 금액 열이 있는 스프레드시트 하나로 정리해 줘.
범위: "receipts" 폴더만 써. 다른 폴더나 웹사이트는 열지 마.
완료 기준: 영수증 한 장당 한 행이야. 끝나면 처리한 개수, 읽지 못한 영수증, 이 목록 밖에서 한 일이 있으면 그것까지 보고해 줘.
금지: 원본 사진을 옮기거나 이름을 바꾸거나 지우지 마. 스프레드시트를 누구에게도 보내지 마.
먼저 물어볼 것: 영수증이 불분명하거나 폴더 밖의 것을 써야 할 것 같으면 먼저 물어봐.
시작 전에 계획을 세 줄로 알려 줘.
</PromptBox>

### 7. 작게 시작하고 방향을 조정해요

12장 대신 3장처럼 작은 버전을 먼저 돌려 보세요. Claude와 Gemini 모두 작업 중에 지시를 더할 수 있다고 해요. 첫 결과가 어긋나면 지시서를 고치고 다시 실행해요.

## 자주 막히는 지점

### 에이전트가 예상 못 한 일을 했어요

- **원인**: 지시서에 금지 사항이 없었거나 범위가 넓었어요.
- **해결**: "하지 마" 줄을 명확히 더하고 범위를 좁혀요. 무엇을 확인할지는 [7편](/ko/agents/07-reviewing-agent-work/)을 보세요.

### 지시서가 너무 길어져 쓰기가 일이에요

- **원인**: 모든 경우를 다 담으려 했어요.
- **해결**: 다섯 부분을 한 줄씩만 쓰세요. 채운 템플릿을 메모로 저장해 고쳐 쓰세요. 늘 적용할 취향은 Claude의 전역·폴더 지침이 그 용도예요.

### 에이전트가 계속 질문해요

- **원인**: 확인 지점이 너무 넓거나 목표가 불분명해요.
- **해결**: "먼저 물어볼 것"을 진짜 결정으로만 좁히고, 열려 있는 질문은 지시서 안에서 답해 두세요.

## 실전 팁

- **지시서에 비밀번호, 일회용 코드, 카드번호를 쓰지 마세요.** 어떤 대화에서든 비밀 정보는 빼는 게 좋아요(이 사이트의 권장).
- **민감한 작업은 일정으로 걸지 마세요.** 예약 실행은 실시간으로 볼 수 없어서 Claude와 Gemini 모두 조심하라고 해요.
- **템플릿 메모를 하나 두고** 새 작업마다 복사해 쓰세요.
- **도구가 낯설 때는 실행보다 초안을 요청하세요.**
- **기능은 자주 바뀌어요.** 이 글은 2026-11-04 기준이고 메뉴 이름은 화면마다 다를 수 있어요.
