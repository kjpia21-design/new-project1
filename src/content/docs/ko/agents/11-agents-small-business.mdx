<Summary>
- 가게나 1인 사업을 하면 예약 요청 정리, 견적서 초안, 재고 목록 갱신, 비슷한 문의 답변처럼 같은 일이 반복돼요. AI 에이전트는 이런 일의 **준비**를 맡고, **결정**은 사람이 해요.
- **이 사이트의 권장**: 읽고 초안을 만드는 일(요약, 목록, 초안)부터 시작하고, 결제·환불·고객에게 메시지 보내기는 직접 해요.
- 공식 페이지도 같은 방향이에요. Claude 안전 가이드는 메시지 전송이나 구매처럼 되돌리기 어려운 일에는 "Manually approve"로 바꾸라고 하고, 메시지를 보내거나 구매하는 작업은 예약하지 말라고 해요. Gemini 페이지는 민감한 정보를 쓰는 작업을 피하라고 해요. OpenAI는 답장 초안을 쓰게 하는 것이 보낼 권한을 주는 것은 아니라고 해요.
- 고객 이름·연락처·결제 정보는 작업에 넣지 않는 것이 좋아요. Claude와 Gemini 모두 민감한 파일과 정보를 조심하라고 해요.
- 예시(예약·견적·재고)는 **이 사이트의 예시**이고, 각 회사가 소상공인용 기능으로 내세우는 것이 아니에요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 반복 업무를 "에이전트가 처리", "에이전트가 초안, 내가 결정", "내가 직접"으로 나눌 수 있어요.
- 소상공인 업무용 첫 에이전트 작업을 한계와 확인 지점까지 넣어 쓸 수 있어요.
- 어떤 조언이 공식 도움말에서 왔고 어떤 것이 이 사이트의 조언인지 구분할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **에이전트** | 작업을 설명하면 여러 단계를 스스로 처리하는 AI예요(파일 읽기, 앱 사용, 문서 만들기). |
| **초안 전용 작업** | 결과가 검토할 초안이나 목록뿐인 작업이에요. 보내거나 결제하거나 바꾸는 일은 없어요. |
| **예약 작업** | 정해진 때에 다시 실행되도록 저장한 작업이에요. |
| **승인 모드** | 행동하기 전에 에이전트가 얼마나 자주 물어야 하는지 정하는 설정이에요. |

### 공식 페이지는 무엇을 말하고, 무엇이 이 사이트의 권장일까요?

| 출처 | 공식 안내 (의역 또는 짧은 인용) |
| --- | --- |
| Claude Cowork 시작 안내 | Cowork는 유료 플랜에서 쓸 수 있어요. 여러 단계 작업을 맡기면 스프레드시트·슬라이드·문서 같은 결과물을 내줘요. 예시로 다운로드 폴더 정리, 영수증을 경비 보고서로 만들기, 파일 이름 일괄 변경, 메모·녹취록 요약, 수식이 든 스프레드시트 만들기가 나와요. 파일을 영구 삭제하기 전에는 반드시 명시적 허락을 받아요. |
| Claude Cowork 시작 안내 | 예약 작업은 클라우드에서 돌아가서 컴퓨터가 켜져 있지 않아도 돼요. 여러 단계 작업은 짧은 질문보다 사용량을 더 써요. 세션은 다른 사람과 공유할 수 없지만 만든 아티팩트는 개별로 공유할 수 있어요. |
| Claude Cowork 안전 가이드 | 전용 작업 폴더를 쓰고 백업을 두라고 하며, 재무 문서처럼 민감한 파일 접근은 피하라고 해요. 예약 작업은 간단하게 시작하고, 민감한 데이터와 결과가 큰 행동(내 이름으로 메시지 보내기, 구매 등)은 피하고, 실행할 때마다 결과를 확인하고, 안 쓰는 작업은 멈추라고 해요. 실수를 되돌리기 어려울 때는 "Manually approve"로 바꾸라고 해요. 보낸 메시지·구매·예약 작업이 한 행동의 책임은 사용자에게 있다고 해요. |
| ChatGPT dot 문서 | 필요한 결과와 쓸 출처를 설명하라고 해요. 어떤 결과를 알려 줄지, 어떤 결정에 내 입력이 필요한지 말해 주라고 해요. 반복 작업은 저장된 일정이 필요하고, 무엇을 확인·갱신할지, 언제(시간대와 종료일 포함), 어떤 변경에 알림을 줄지, 결과를 어디로 보낼지 정해요. 실행이 끝났다는 사실만으로 원하는 결과가 이뤄졌다는 보장은 아니므로 출력과 오류를 검토하라고 해요. |
| ChatGPT dot 문서(제어) | 계정에 영향을 주거나 정보를 공유할 수 있는 행동은 자동 검토를 거쳐요. 답장 초안을 쓰게 하는 것이 보낼 권한을 주는 것은 아니에요. 선택 사항인 사용자 지정 규칙에 "Ask before taking action"(고객에게 메시지 보내기가 예로 나와요)과 "Hand off to you"가 있어요. 작업을 멈춰도 이미 한 행동은 되돌려지지 않고, 일시 정지는 앞으로의 예약 실행을 취소하지 않아요. |
| Gemini 작업 도움말 | 개인 Google 계정, Google AI Pro 또는 Ultra 구독 등 조건이 있고(페이지에 목록이 있어요), EEA·나이지리아·스위스·영국에서는 쓸 수 없어요. 로그인 정보·결제 정보·민감한 정보를 작업 스레드에 직접 입력하지 말라고 해요. 민감한 작업의 예약은 피하라고 하고, 오프라인일 때 예약이 실행되면 의도치 않은 행동을 멈추지 못할 수 있다고 해요. PDF·DOCX·XLSX·PPTX 같은 파일을 만들 수 있어요. |

<Aside type="note" title="공식 안내와 이 사이트의 권장을 구분해요">
위 표는 페이지가 말하는 내용이에요. 업무를 나누는 방식, 예시 작업, "초안 먼저" 습관은 **이 사이트의 권장**이에요. 세 페이지 모두 소상공인 활용 사례를 따로 다루지 않았고, 각 제품의 플랜·지역·한국어 지원이 여러분 상황에 맞는지는 확인하지 못했어요. 결제하기 전에 최신 플랜·제공 지역 페이지를 확인하세요.
</Aside>

### 1. 업무를 적고 나누기

매주 반복하는 일을 적고 아래처럼 나눠요(이 사이트의 세 갈래 분류예요).

| 분류 | 예 | 이유 |
| --- | --- | --- |
| 에이전트가 처리 | 메모 더미를 깔끔한 목록으로, 복사한 스프레드시트로 월간 재고표 만들기, 사진 파일 이름 바꾸기 | 결과가 내 폴더에 남고 확인하기 쉬워요. |
| 에이전트가 초안, 내가 결정 | 예약 확인 문구, 견적서 초안, 자주 묻는 질문 답변 | 틀린 초안은 손해가 작지만 잘못 보낸 메시지는 그렇지 않아요. |
| 내가 직접 | 결제 받기, 환불, 가격 변경, 계약 조건, 고객 개인정보가 걸린 일 | 되돌리기 어렵고 책임이 나에게 있어요. |

### 2. 읽고 초안을 만드는 일 하나로 시작하기

복사본을 읽고 문서를 만드는 작업이 첫 작업으로 좋아요. Cowork 페이지에도 이런 모양의 예시(영수증을 경비 보고서로, 메모를 정리된 문서로)가 있어요.

### 3. 안전한 작업 공간 만들기

Cowork 안전 가이드가 권하듯 전용 폴더를 만들고 작업에 필요한 파일의 복사본만 넣어요. 원본은 다른 곳에 둬요. 먼저 고객 이름·전화번호·주소를 지워요(이 사이트의 권장, [5편](/ko/agents/05-agent-safety/) 참고). 비밀번호나 카드 번호는 작업에 절대 넣지 않아요.

### 4. 한계를 넣어 작업 쓰기

[10편](/ko/agents/10-briefing-agents/)의 다섯 부분 지시서를 써요. 가상의 데이터만 쓴 예약 정리 예시예요.

<PromptBox>
목표: "requests-copy.txt" 파일의 예약 요청 15건을 날짜, 시간, 서비스, 상태(명확, 불명확, 겹침) 열이 있는 표 하나로 만들어 줘.
범위: "bookings-work" 폴더만 써. 다른 폴더나 웹사이트는 열지 마.
완료 기준: 요청마다 한 행이 있는 표. 불명확하거나 겹치는 건이 몇 개인지, 건너뛴 것이 있으면 목록으로 보고해.
금지: 원본 파일을 고치지 마. 메시지를 보내거나 예약을 확정하지 마. 가격을 바꾸지 마.
먼저 물어볼 것: 두 요청이 겹치거나 요청이 애매할 때.
시작하기 전에 계획을 세 줄로 알려 줘.
</PromptBox>

### 5. 고객 답변은 초안만 쓰고 보내지 않기

<PromptBox>
"bookings-table.csv" 파일의 표만 근거로, 상태가 명확인 행마다 짧고 정중한 답장 초안을, 불명확인 행마다 확인 질문 초안을 써 줘. 한 문서에 행당 초안 하나씩 저장해. 아무것도 보내지 마. 가격·정책·영업시간을 추측해야 하는 곳은 빈칸으로 두고, 빈칸 목록을 마지막에 알려 줘.
</PromptBox>

초안은 직접 읽고 사실을 채운 뒤 내 계정에서 보내요. OpenAI 제어 페이지는 초안을 쓰는 것이 보낼 권한을 주지 않는다고 하고, Claude 안전 가이드는 메시지 전송에 수동 승인을 권해요.

### 6. 견적과 재고: 계산은 에이전트, 확인은 내가

견적이나 재고 목록은 가격표와 수량의 복사본을 주고 계산 과정을 보여 달라고 해요. 합계·세금·할인은 직접 확인해요. 가격, 세금 처리, 조건은 내 사업의 결정이에요([1인·소상공인 가이드](/ko/roles/solo-business/) 참고).

<PromptBox>
"stock-copy.xlsx" 복사본에서 수량이 "reorder at" 열의 숫자보다 적은 품목을 목록으로 만들어 줘. 어떻게 판단했는지 보여 주는 열을 추가해. 원본을 바꾸거나 주문하지 마. 빈 칸이나 읽을 수 없는 칸이 있는 행은 추측하지 말고 표시해.
</PromptBox>

### 7. 결과를 확인하고 반복 여부 정하기

"완료 기준" 줄과 비교하고 몇 행은 원본과 직접 대조해요. OpenAI 페이지는 실행이 끝났다는 사실이 결과가 이뤄졌다는 보장은 아니라고 해요. [7편](/ko/agents/07-reviewing-agent-work/)을 참고하세요. 여러 번 잘 돌아간 뒤에 예약을 생각하고, 아래 절을 먼저 읽어요.

## 막힐 때

### 초안에 내가 준 적 없는 가격이나 정책이 들어갔어요

- **원인**: 에이전트가 빈틈을 추측으로 채웠어요.
- **해결**: 추측하지 말고 빈칸으로 두라고 하고, 정책·환불 조건은 내가 붙여 넣는 글로 줘요.

### 사용량이 금방 떨어져요

- **원인**: 여러 단계 작업은 짧은 질문보다 사용량을 더 써요(Claude 페이지).
- **해결**: 관련 작업을 한 작업으로 묶어요. [9편](/ko/agents/09-agent-usage-limits/)을 참고하세요.

### 에이전트가 파일에 접근하지 못하거나 결과가 엉뚱한 곳에 있어요

- **원인**: 로컬 접근은 데스크톱 앱이 열려 있는지와 연결한 폴더에 달려 있어요(Claude 페이지).
- **해결**: 폴더 권한과 에이전트가 알려 준 저장 위치를 확인해요.

## 실전 팁
