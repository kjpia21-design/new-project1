- Claude에는 에이전트 성격의 기능이 여러 개 있고, 가장 큰 차이는 **어디서 일하느냐**예요. 문서와 파일(Cowork), 브라우저(Claude in Chrome), 컴퓨터 화면(컴퓨터 사용), 화상 회의(Meetings), Slack 채널(Claude Tag), 내가 만든 애플리케이션(Managed Agents)으로 나뉘어요.
- 플랜 조건이 많이 달라요. Cowork와 Claude in Chrome은 모든 유료 플랜에서 쓸 수 있어요. 컴퓨터 사용은 Pro·Max·Ultra에서 쓸 수 있고, Team·Enterprise에서는 2026-11-20에 베타로 들어왔어요. **Claude Meetings**와 **Claude Tag**는 Team·Enterprise 전용 베타예요. **Managed Agents**는 개발자용 API 제품이에요.
- 고르는 규칙은 간단해요. 일이 있는 곳에 닿는 가장 가벼운 도구를 쓰세요. 컴퓨터 사용 도움말은 커넥터, 브라우저, 화면 조작 순서를 안내하고, 화면 조작은 가장 느리고 오류가 나기 쉽다고 해요.
- 상태는 빨리 바뀌어요. 아래 표는 **2026-11-22**에 읽은 공식 페이지 기준의 스냅샷이고 약속이 아니에요.
- 각 줄에는 자세한 편 링크가 있어요. 새로 나온 Meetings, Team·Enterprise 컴퓨터 사용, self-hosted 편도 표에서 이어져요.
</Summary>

## 이 글을 읽고 나면

- Claude의 에이전트형 기능을 한 문장씩 설명할 수 있어요.
- 각 기능을 어떤 플랜에서 쓰는지, 어느 것이 아직 베타인지 알 수 있어요.
- 회의 기록, 웹 양식, Slack 요청 같은 일에 맞는 기능을 고를 수 있어요.
- 이 사이트에서 다음에 열어 볼 편을 알 수 있어요.

## 고르는 방법

일이 있는 곳에서 출발하고, 그다음 플랜을 확인하세요.

| 일이 있는 곳 | 먼저 써 볼 것 | 이유 |
| --- | --- | --- |
| 파일, 문서, 맡겨 두는 조사 | Cowork | 여러 단계를 거쳐 완성된 파일로 끝나는 일에 맞게 만들어졌어요 |
| 웹사이트 | Claude in Chrome | 브라우저 탭 안에서 움직여요 |
| 커넥터도 웹 버전도 없는 데스크톱 앱 | 컴퓨터 사용 | 커넥터와 브라우저가 닿지 않을 때의 대안이에요 |
| 화상 회의 | Meetings | 통화에 들어가 회의 페이지에 기록과 결과물을 남겨요 |
| Slack 스레드 | Claude Tag | 요청과 결과가 스레드에 남아요 |
| 내 제품이나 백엔드 | Managed Agents | API라서 세션을 언제 시작할지 내 코드가 정해요 |

컴퓨터 사용 도움말도 같은 우선순위를 안내해요. 커넥터가 있으면 그것을, 그다음 브라우저, 마지막으로 화면 조작(가장 느리고 오류가 나기 쉬움)이에요.

### 공식 페이지가 주의하라고 한 것

- **Meetings:** 도움말은 Claude를 추가하기 전에 통화의 모든 사람이 기록되는 데 동의하는지 확인하라고 해요. ZDR, HIPAA 대응 구성, CMEK 조직을 포함해 일부 조직에서는 쓸 수 없어요. 오디오가 아니라 기록(트랜스크립트), 요약, 화면 설명을 저장해요.
- **Team·Enterprise 컴퓨터 사용:** 관리자 도움말은 Claude와 사용자 앱 사이에 샌드박스가 없고, 화면의 내용이 의도하지 않은 동작을 일으킬 수 있다고 해요. 스크린샷은 대화와 함께 저장되고 개인·기밀 정보가 담길 수 있어요.
- **Claude Tag:** 채널에서 한 작업은 채널에 보여요. 청구와 데이터는 [C28](/ko/claude/c28-claude-tag/)을 보세요.
- **Managed Agents:** 개요 문서에 ZDR·HIPAA 대상이 아니라고 적혀 있어요.

## 자주 막히는 지점

### 내 계정에 기능이 없어요

- **원인:** 점진적으로 제공되고, 일부는 오너가 먼저 켜야 해요.
- **해결:** 조직 오너에게 물어보고, 링크한 도움말에서 내 플랜 조건을 확인하세요.

### 어떤 도구를 써야 할지 모르겠어요

- **원인:** 웹 페이지처럼 한 일에 여러 기능이 닿을 수 있어요.
- **해결:** 컴퓨터 사용 도움말의 순서(커넥터, 브라우저, 화면 조작)를 따르세요.

### 우리 조직에서 막혀 있어요

- **원인:** Meetings와 컴퓨터 사용은 ZDR, HIPAA 대응 구성, CMEK를 켜지 못하는 설정으로 안내해요.
- **해결:** 조직 설정이라서 관리자에게 문의하세요. 우회할 방법을 찾지 마세요.

## 실전 팁

- **일에 가장 가까운 도구부터 쓰세요.** 커넥터로 되는 일을 화면 조작에 맡기지 마세요.
- **베타는 베타로 대하세요.** 중요한 일에는 수동 대안을 남겨 두세요.
- **듣는 기능은 동의를 확인하세요.** 녹음·기록 규칙은 지역마다 달라요. 이 글은 법률 조언이 아니에요.
- **민감한 앱은 멀리 두세요.** 공식 안전 안내는 은행·의료·정부 앱에는 화면 조작을 쓰지 말라고 해요.
- **날짜를 다시 확인하세요.** 이 표는 낡아요. 링크한 릴리스 노트가 가장 믿을 만해요.
