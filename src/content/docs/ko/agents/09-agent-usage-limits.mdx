## 이 튜토리얼로 할 수 있게 되는 것

- 에이전트 작업이 채팅보다 한도를 더 쓰는 이유를 설명할 수 있어요.
- 세 서비스의 플랜·한도 표현을 헷갈리지 않고 읽을 수 있어요.
- 몇 가지 습관으로 사용량을 확인하고 아끼며, 언제 더 내는 게 맞는지 판단할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **사용 한도** | 정해진 시간 동안 서비스를 쓸 수 있는 양이에요. 일정에 따라 초기화돼요. |
| **세션 한도 / 5시간 한도** | Claude와 ChatGPT가 5시간 뒤 초기화되는 한도를 부르는 말이에요. Claude는 첫 메시지를 보낼 때 시작해요. |
| **주간 한도** | 더 긴 두 번째 한도예요. Claude는 계정마다 정해진 시각에 매주 초기화돼요. |
| **길이 한도(컨텍스트 창)** | 채팅 하나가 한 번에 담을 수 있는 양이에요. 사용 한도와 달라요. |
| **크레딧 / 사용 크레딧** | 포함된 한도를 다 쓴 뒤 결제해서 쓰는 추가 사용량이에요. Claude는 표준 API 요금으로 청구해요. |
| **토큰** | 모델이 읽고 쓰는 작은 글자 단위예요. 프롬프트, 파일, 기록, 도구 결과, 답변 모두 포함돼요. |

## 에이전트 작업이 더 쓰는 이유

공식 페이지는 에이전트 작업 하나당 비용을 알려 주지 않아요. 아래는 공식 설명이 뒷받침하는 추론이지 측정한 수치가 아니에요.

- **Claude**는 대화의 길이와 복잡도, 쓰는 기능, 모델, 노력(effort) 수준에 따라 사용량이 달라진다고 해요. 자동 컨텍스트 관리가 일어나는 긴 대화는 한도를 더 쓰고, 도구와 커넥터는 토큰을 많이 쓴다고도 해요.
- **ChatGPT**는 작은 스크립트는 한도의 일부만 쓰지만, 오래 걸리는 작업이나 맥락을 많이 들고 가는 긴 세션은 메시지당 훨씬 더 쓴다고 해요. 모델 선택, 맥락, 추론, 도구 사용, 검색, 캐싱이 모두 영향을 주니 프롬프트 길이만으로는 믿을 만한 추정이 안 된다고 해요.
- **Gemini**는 짧은 대화를 사용량 매우 낮음, 긴 대화나 큰 파일 분석을 중간, Deep Research를 높음으로 분류해요. 여러 단계의 검색과 여러 차례의 추론을 하기 때문이에요.

에이전트는 이걸 한꺼번에 합쳐요. 여러 단계, 도구, 파일, 늘어나는 기록이에요. 채팅에는 넉넉하던 플랜이 에이전트에는 더 빨리 바닥날 수 있어요.

## 공식 페이지 내용, 서비스별

### Claude (claude.com/pricing, 2026-11-04 기준)

| 플랜 | 표시된 가격 | 사용량 설명 |
| --- | --- | --- |
| Free | $0 | 5시간마다, 매주 제한된 사용량 |
| Pro | 연간 결제 시 월 $17(선결제 $200), 월 결제 시 $20 | Free보다 많은 사용량(5시간마다, 매주). Fable은 사용 크레딧으로 결제 |
| Max | 월 $100 | Pro의 5배 사용량(5시간마다, 매주). Fable은 주간 한도의 절반까지 포함. 월 $100 API 크레딧 |
| Ultra | 월 $200 | 인증된 계정은 5시간 한도 없음. 주간 Pro의 10배 사용량. 월 $200 API 크레딧 |

가격 페이지는 표시된 가격에 해당하는 세금이 빠져 있고, 한도에 닿는 속도는 모델, 채팅 길이, 파일 크기에 따라 달라진다고 해요. 도움말은 모든 Claude 화면(claude.ai, Claude Code, Claude Desktop)의 사용량이 같은 한도에 합산되고, 주간 한도는 모든 모델에 적용되며 일부 플랜에는 Fable 주간 한도가 따로 있다고 덧붙여요.

**한도에 닿으면:** 초기화를 기다리거나 업그레이드해요(새 플랜의 한도가 바로 적용돼요). Pro, Max, Ultra에서 사용 크레딧을 켜 두면 월 지출 한도나 잔액이 바닥날 때까지 표준 API 요금으로 계속 쓸 수 있어요. 구독료와 따로 청구돼요. Max와 Ultra에 포함된 월 API 크레딧은 별개라서, Claude·Claude Code·Cowork의 사용 크레딧에는 적용되지 않아요. 도움말은 Research가 포함 한도를 넘으면 크레딧을 쓰고 토큰을 빨리 쓸 수 있다고 해요.

### ChatGPT (learn.chatgpt.com/docs/pricing, 2026-11-04 기준)

읽은 페이지는 **ChatGPT Work와 Codex**의 가격 페이지예요. 둘은 사용량을 공유하고 Free, Go, Plus, Pro, Business, Edu, Enterprise 플랜에 포함돼요.

| 플랜 | 표시된 가격 |
| --- | --- |
| Free | $0 |
| Go | 월 $8 |
| Plus | 월 $20 |
| Pro | 월 $100부터(월 $100, $200, $500 플랜) |
| Business | 사용자당 월 $20(연간 결제), 월 결제 시 $25(2명 이상) |

Plus와 표준 Business에 대해 **5시간당 로컬 메시지 추정치**를 모델별로 보여 주는데 차이가 커요. 예를 들어 한 모델은 5~45개, 나열된 가장 가벼운 모델은 350~3,000개예요. 고정된 메시지 한도가 아니고 주간 한도도 적용될 수 있으며, Pro 플랜에는 현재 5시간 한도가 없다고 해요. 작업 도중 한도에 닿으면 공정 사용 범위에서 그 턴은 계속할 수 있고, Plus와 Pro 사용자는 추가 크레딧을 살 수 있어요. 현재 한도와 초기화 시각은 사용량 대시보드에서 볼 수 있어요. API 토큰 가격은 구독 사용량과 별개예요.

### Gemini (support.google.com/gemini, gemini.google/subscriptions, 2026-11-04 기준)

| 플랜 | 표시된 가격 | 사용량 설명 |
| --- | --- | --- |
| 무료(AI 플랜 없음) | $0 | 표준 한도, 컨텍스트 창 32k 토큰 |
| Google AI Plus | 월 $4.99 | 표준 한도의 2배, 128k |
| Google AI Pro | 월 $19.99 | 표준 한도의 4배, 100만 토큰 |
| Google AI Ultra | 월 $99.99(AI Pro 한도의 5배) 또는 월 $199.99(20배) | 구독에 따라 AI Pro 한도의 5배 또는 20배, 100만 토큰 |

도움말은 한도가 연산량 기준이고, 주간 한도에 닿을 때까지 5시간마다 새로 채워지며, 수요 같은 사정으로 예고 없이 바뀔 수 있다고 해요. AI 플랜이 있는데 한도에 닿으면 Flash-Lite로 대화를 이어 갈 수 있어요. 플랜이 없으면 Deep Research처럼 연산이 많이 드는 기능은 수요가 몰릴 때 쓸 수 없을 수 있어요. 한도를 보려면 gemini.google.com에서 설정, Usage Limits로 가요.

### 확인하지 못한 것

- **세 서비스의 원화 가격.** 읽은 페이지는 미국 달러로 표시됐고, Gemini 구독 페이지가 어느 통화·지역 기준이었는지 확인하지 못했어요.
- **ChatGPT 일반 채팅의 한도.** 읽은 가격 페이지는 Work와 Codex에 대한 것이고, 일반 채팅의 메시지 수 표는 찾지 못했어요.
- **Gemini 기능별 정확한 일일 숫자.** 도움말은 횟수가 아니라 배수만 알려 줘요.
- 나라나 회사·학교 계정에 따라 플랜이나 한도가 다른지.

### 1. 사용량 화면 찾기

Claude는 설정, Usage예요. Gemini는 gemini.google.com의 설정, Usage Limits예요. ChatGPT는 가격 페이지에서 안내하는 사용량 대시보드예요. 큰 작업 전에 한 번 보고 시작점을 알아 두세요.

### 2. 작은 작업부터 해 보기 (이 사이트의 권장)

에이전트에 40쪽짜리 일을 맡기기 전에 작은 버전을 돌리고 사용량 화면을 전후로 비교해 보세요. 일반적인 추정보다 내 숫자가 정확해요.

<PromptBox>
시작하기 전에, 어떤 단계로 할 계획인지, 어떤 도구나 파일을 쓸지, 더 작은 버전으로 해도 가치의 대부분을 얻을 수 있는지를 세 줄로 알려 줘. 내가 OK 할 때까지 기다려 줘.
</PromptBox>

### 3. 모델과 노력 수준을 의식적으로 고르기

Claude 도움말은 노력 수준이 높을수록 토큰을 더 쓰니 일상 작업에는 낮추라고 하고, 추가 사용량 페이지는 대부분의 작업에 Haiku나 최신 Sonnet을 권해요. ChatGPT 페이지는 더 작은 모델이나 더 좁은 작업 범위를 권해요. 무거운 모델은 품질이 중요한 곳에만 쓰세요.

### 4. 에이전트가 들고 갈 짐 줄이기

Claude 페이지가 소개하는 절약 방법은 이래요. 필요 없는 연결 앱 끄기, 최신 정보가 필요 없으면 웹 검색하지 말라고 하기, 안 쓰는 프로젝트 파일 지우기, 프로젝트 지침 짧게 쓰기, 필요 없을 때 확장 사고 끄기, 새 주제는 새 대화로 시작하기예요. Gemini 페이지도 새 채팅 팁을 줘요. 모두 공식 제안이고, 얼마나 아끼는지는 적혀 있지 않아요.

### 5. 더 낼지 판단하기

| 상황 | 페이지가 설명하는 선택지 |
| --- | --- |
| 가끔 한도에 닿음 | 초기화를 기다려요 |
| 같은 플랜에서 자주 닿음 | 가격 페이지에서 다음 플랜의 배수를 비교해요 |
| 한 번뿐인 큰 작업 | Claude 사용 크레딧이나 ChatGPT 크레딧, 월 상한을 정해 두고 |
| 팀·업무용 | 서비스가 따로 가격을 정한 Business·Team 플랜 |

Claude의 추가 사용량 페이지는 보수적인 월 상한으로 시작하라고 해요. 사용 크레딧은 별도로 청구되고 추가 요금으로 나와요. 일부 지역에서는 크레딧이 만료될 수 있어요(페이지에 따르면 일본은 2026-09-10부터 구매 후 6개월). 한국은 확인하지 못했어요.

### 6. 작업 뒤 돌아보기

사용량 화면을 다시 열어 보세요. 예상보다 훨씬 많이 썼다면 이유(긴 기록, 많은 파일, 웹 검색, 무거운 모델)를 적어 두고 다음에 바꾸세요.

## 자주 막히는 지점

### 경고가 떴는데 끊기지 않았어요

- **원인**: Claude 사용 크레딧을 켜 두면 크레딧으로 넘어간 뒤에도 "한도에 가까워지고 있다"는 알림이 남아 있을 수 있어요.
- **해결**: "Now using credits" 표시를 확인하고 지출 상한을 점검하세요.

### 긴 채팅에서 사용량이 더 빨리 줄어요

- **원인**: 모델이 매 턴 기록을 다시 읽고, Claude는 자동 컨텍스트 관리가 한도를 더 써요.
- **해결**: 새 채팅을 시작하고 짧은 요약을 붙여 넣으세요.

### 모바일 앱으로 구독했는데 크레딧을 켤 수 없어요

- **원인**: Claude는 모바일 앱으로 구독했다면 웹 버전에서만 사용 크레딧을 켤 수 있다고 해요.
- **해결**: Claude 웹 앱에서 켜세요.

## 실전 팁

- **여기 적힌 숫자를 약속으로 여기지 마세요.** 서비스는 재량으로 한도를 바꿀 수 있어요.
- **통하는 가장 싼 도구를 쓰세요.** 웹 검색이나 일반 채팅으로 풀리는 질문이 많아요([에이전트 1편](/ko/agents/01-agents-compared/)).
- **상한을 정하세요.** 종량 결제 같은 것을 켜기 전에요.
- **다시 돌리기 전에 결과를 검수하세요.** 잘못된 실행을 반복하면 처음과 같은 비용이 들어요([에이전트 7편](/ko/agents/07-reviewing-agent-work/)).
- **가격에는 세금이 빠져 있고**(페이지에 그렇게 적힌 경우) 나라마다 다를 수 있어요.
- 이 글을 쓰면서 공식 페이지만 읽었고, 사용량을 재 보려고 에이전트 작업을 직접 돌리지는 않았어요.
