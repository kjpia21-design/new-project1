<Summary>
- [5편](/ko/agents/05-agent-safety/)은 **시작 전에 무엇을 허용할지**를 다뤘어요. 이 글은 **에이전트가 "다 했어요"라고 한 뒤 무엇을 확인할지**를 다뤄요.
- 세 회사 모두 공식 문서에서 AI가 실수할 수 있다고 말해요. OpenAI의 dot 문서는 한 걸음 더 나아가 **실행이 끝났다는 것만으로는 요청한 결과가 달성되거나 전달됐다고 확인되지 않는다**고 해요.
- 검수는 세 번에 나눠요. **(1) 무엇을 했는지(기록), (2) 결과가 맞는지(표본 확인), (3) 그 밖에 무엇을 건드렸는지(부작용)**.
- 서비스마다 나중에 진행 상황·파일·결과를 볼 곳이 있어요. Claude의 작업 화면과 "Scheduled" 페이지, ChatGPT dot의 **Activity**와 **Scheduled**, Gemini 작업 스레드의 작업 패널이에요.
- 아래 점검표와 "얼마나 확인할지" 기준은 공식 요구가 아니라 **이 사이트의 권장 사항**이에요. 공식 문서의 말은 그렇게 표시했어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 서비스별로 에이전트가 한 일이 어디에 기록되는지 찾아서 읽을 수 있어요.
- 끝난 결과를 짧게 표본 확인하고, 일의 중요도에 맞춰 확인 정도를 조절할 수 있어요.
- 이상 신호를 알아채고, 멈춰도 이미 끝난 일은 되돌려지지 않는다는 점까지 알고 다음 행동을 정할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **결과 검수** | 에이전트가 끝냈다고 한 뒤에 완성된 결과물과 그 영향을 확인하는 일이에요. 행동 전에 허락하는 "승인"과는 달라요. |
| **표본 확인** | 전부 다시 읽는 대신 몇 가지(합계, 임의의 몇 행, 이름, 날짜)를 골라 원본과 맞춰 보는 방법이에요. |
| **부작용** | 부탁한 결과물 말고 바뀐 모든 것이에요. 옮기거나 지운 파일, 보낸 메시지, 방문한 사이트, 바뀐 설정 같은 것들이요. |
| **범위 이탈** | 부탁한 것보다 많이 하거나, 말하지 않은 파일·사이트를 건드리는 일이에요. |

### 공식 문서는 무엇을 말하고, 무엇이 이 사이트의 권장일까요?

| 출처 | 공식 문서의 내용(요약) |
| --- | --- |
| Claude Cowork 안전 가이드 | 명령 하나하나를 모두 검증할 수는 없으니, 예상 밖의 패턴을 지켜보세요. 말하지 않은 파일이나 사이트에 접근하나요? 작업 범위가 요청을 넘어 커지나요? 이상하면 바로 작업을 멈추세요. |
| Claude Cowork 안전 가이드 | 예약 작업은 실행할 때마다 결과를 확인하세요(지난 실행은 "Scheduled" 페이지에서 볼 수 있어요). 쓰지 않는 작업은 일시 중지하거나 삭제하세요. |
| Claude in Chrome 권한 가이드 | 어떤 모드도 사용자의 판단을 대신하지 못해요. 돈, 내 이름으로 나가는 메시지, 중요한 파일처럼 결과가 큰 일은 가까이서 지켜보며 확인하거나 "Manually approve"로 돌아가세요. |
| ChatGPT dot 문서 | 실행이 끝난 뒤에도 출력과 보고된 오류를 확인하세요. 실행 완료만으로는 요청한 결과가 달성됐거나 전달됐다고 확인되지 않아요. |
| ChatGPT dot 문서 | 작업을 멈춰도 이미 끝난 행동은 되돌려지지 않아요. |
| Gemini 문서 | Gemini는 아직 배우는 중이라 실수할 수 있어요. 오프라인일 때 일정이 실행되면 의도하지 않은 행동을 막지 못할 수 있어요. 작업 스레드의 작업 패널에서 Gemini가 읽거나 수정한 파일을 확인할 수 있어요. |

<Aside type="note" title="공식 안내와 이 사이트의 권장을 구분해요">
위 표는 공식 페이지에 적힌 내용이에요. 이 글의 나머지, 예를 들어 "세 줄 확인하기", 중요도 단계, 프롬프트는 **이 사이트의 실무 권장**이에요. 합리적인 방법이지만 공식 요구는 아니니 내 일에 맞게 조절하세요.
</Aside>

### 1. 맡기기 전에 "끝"의 모습을 정해요

요청이 모호하면 결과를 확인하기도 어려워요. 원하는 결과, 형식, 건드리면 안 되는 것을 적어 두세요. [5편](/ko/agents/05-agent-safety/)의 "하지 말 것을 쓰기"와 이어지는 내용이고, Cowork 공식 도움말도 원하는 결과·형식·입력 자료를 함께 쓰라고 해요([C19](/ko/claude/c19-cowork/)).

<PromptBox>
"영수증" 폴더의 사진 12장을 날짜·가게·금액이 있는 스프레드시트로 정리해 줘. 원본은 옮기거나 지우지 마. 끝나면 (1) 처리한 영수증 수, (2) 읽지 못했거나 확신이 없는 것, (3) 내가 부탁한 것 외에 한 일을 보고해 줘.
</PromptBox>

### 2. 보고를 받되 직접 확인해요 (이 사이트의 권장)

에이전트에게 한 일과 확신 없는 부분을 목록으로 달라고 하면 어디를 볼지 지도가 생겨요. 다만 보고서도 같은 에이전트가 쓴 것이니 **증거가 아니라 안내판으로** 보세요. ChatGPT dot 문서도 실행 완료가 결과를 확인해 주지 않는다고 비슷하게 말해요.

### 3. 활동 기록을 읽어요

서비스마다 진행 상황과 결과를 돌아보는 곳이 있어요. 화면의 이름은 다를 수 있어요.

| 서비스 | 볼 곳(공식 문서 기준) | 살필 것 |
| --- | --- | --- |
| **Claude Cowork** | 작업 화면에 진행 상황과 추론이 보여요. 예약 작업은 왼쪽 사이드바의 "Scheduled" 페이지 | 말하지 않은 파일·사이트, 요청을 넘어 커지는 범위 |
| **Claude in Chrome** | 실행 중 사이드 패널에서 동작을 지켜봐요. Manual 모드에서는 동작마다 승인해요 | 예상 못 한 사이트, 모르는 권한 요청 |
| **ChatGPT dot** | 데스크톱 앱에서 dot 프로필을 열고 **Activity**를 선택하면 진행 상황·파일·결과가 보여요. **Scheduled**에는 예약 작업의 지시, 시간, 전달 위치가 있어요 | 결정을 기다리는 작업, 위임된 작업, 잊어버린 예약 |
| **Gemini** | 작업 스레드를 열고 작업 패널(진행 칩)에서 단계와 진행 상황을 봐요. "Files"에서 Gemini가 읽거나 수정한 파일을 확인할 수 있어요 | 건드릴 줄 몰랐던 파일, 건너뛴 단계 |

<Aside type="caution" title="dot 문서: 초안 작성은 보내도 된다는 허락이 아니에요">
dot 문서는 답장 초안을 써 달라고 해도 그것을 보내도 된다는 권한을 주는 것은 아니라고 해요. 검수할 때는 초안이 있는지만이 아니라 실제로 무언가 **보내졌는지**도 확인하세요.
</Aside>

### 4. 결과를 표본 확인해요

전부 다시 읽지 말고 몇 가지를 골라 원본과 비교하세요. Cowork 도움말도 표의 합계·날짜·이름은 직접 표본 확인하라고 해요([C19](/ko/claude/c19-cowork/)).

| 결과물 | 빠른 확인(권장) |
| --- | --- |
| **스프레드시트·표** | 합계 하나를 직접 다시 계산해요. 임의의 3행을 원본과 비교해요. 행 수가 입력 개수와 맞는지 봐요. 빈 행이나 중복 행을 찾아요 |
| **요약·보고서** | 원문에서 숫자나 인용 2~3개를 검색해요. 주장마다 출처를 달라고 하고 링크를 직접 열어요([기초 4편](/ko/basics/04-fact-checking/)) |
| **메일·메시지 초안** | 받는 사람, 제목, 날짜, 금액, 이름을 읽어요. 내가 요청하지 않았다면 발송되지 않았는지 확인해요 |
| **정리·이름 변경한 파일** | 전후 파일 개수를 비교해요. 몇 개를 열어 봐요. 폴더 밖으로 옮겨진 것이 없는지 봐요 |
| **양식 작성·예약** | 확인 화면을 직접 열어요. 날짜, 이름 철자, 수량, 표시된 가격을 확인해요 |
| **웹페이지를 쓴 조사** | 인용한 페이지를 직접 열어요. 게시 날짜와 요약대로 쓰여 있는지 확인해요 |

<PromptBox>
요약에 쓴 숫자와 주장마다 근거가 된 정확한 파일이나 URL과 해당 문장을 적어 줘. 직접 읽은 것이 아니라 추론한 것은 따로 표시해 줘. 아직 아무것도 바꾸지 마.
</PromptBox>

### 5. 부작용을 확인해요

실수는 대개 여기서 드러나요. 결과물 **말고** 에이전트가 한 일을 찾아보세요.

- **보냄·공유**: 보낸편지함, 공유 링크, 캘린더 초대, 남긴 댓글.
- **이동·삭제**: Cowork는 어떤 모드에서도 파일을 영구 삭제하기 전에 묻지만, 옮기기와 덮어쓰기는 다르니 전후를 비교하세요.
- **변경**: 설정, 권한, 구독, 저장된 로그인.
- **방문**: 말하지 않은 웹사이트. Cowork 안전 가이드는 이것을 작업을 멈춰야 할 신호로 들어요.
- **비용**: 긴 작업 뒤 사용량이 예상보다 빨리 줄었는지([5편](/ko/agents/05-agent-safety/)).

### 6. 중요도에 맞춰 확인 정도를 정해요 (이 사이트의 권장)

| 중요도 | 예 | 확인 정도 |
| --- | --- | --- |
| **낮음** | 아이디어 목록, 나만 볼 대충 쓴 초안 | 훑어보기 |
| **보통** | 다른 사람이 볼 메모·표, 메일 초안 | 원본과 3~5개 표본 확인 |
| **높음** | 돈, 법률, 건강, 내 이름으로 나가는 메시지, 중요한 파일 | 직접 원본과 대조해요. 사후 검수만이 아니라 행동 전 승인을 쓰고, 전문가 상담도 고려해요([기초 13편](/ko/basics/13-sensitive-questions/)) |

Chrome 권한 가이드의 표현도 같은 방향이에요. 돈, 내 이름의 메시지, 중요한 파일은 가까이서 지켜보며 확인하거나 Manual 모드를 쓰라고 해요.

### 7. 반복 작업은 매번 확인해요

한 번 확인했던 작업도 웹사이트, 파일 형식, 일정이 바뀌면 나중에 깨질 수 있어요. Cowork 가이드와 dot 문서는 모두 예약 실행의 결과를 확인하고 쓰지 않는 예약은 일시 중지하거나 삭제하라고 해요. Gemini 문서는 오프라인일 때 실행되는 일정은 멈추지 못할 수 있으니 민감한 작업은 예약하지 말라고 경고해요([6편](/ko/agents/06-browser-agents/)).

## 빠른 참조표

### 실행 중이나 실행 후의 이상 신호

| 신호 | 할 일 |
| --- | --- |
| 활동 기록에 말하지 않은 파일·사이트가 보여요 | 작업을 멈추고 무엇에 접근했는지 확인해요. Cowork 가이드는 이상하면 바로 멈추라고 해요 |
| 페이지나 메일에 "AI에게 X를 시키라"는 글이 있어요 | 숨은 지시(프롬프트 인젝션)일 수 있어요. 멈추고 그 단계는 직접 처리해요 |
| 보고는 "완료"인데 결과물이 안 보여요 | 됐다고 가정하지 마세요. 결과물이 어디 있는지 물어요. dot 문서는 완료가 전달을 확인해 주지 않는다고 해요 |
| 숫자가 너무 딱 떨어지거나 행이 빠졌어요 | 원본과 비교해요. 처리하지 못한 것의 목록을 달라고 해요 |
| 승인하지 않은 것이 보내졌거나 바뀌었어요 | 권한을 회수하고, 받은 사람에게 직접 연락하고, 승인을 더 엄격하게 해요([5편](/ko/agents/05-agent-safety/)) |

### 실수를 발견했을 때

1. 실행 중인 작업을 **멈춰요.** ChatGPT dots에서 Pause는 주요 작업만 멈추니, Activity와 Scheduled에서 위임된 작업과 예약도 따로 멈춰요.
2. **멈춘다고 되돌려지지 않아요.** dot 문서는 작업을 멈춰도 이미 끝난 행동은 되돌려지지 않는다고 해요.
3. **현실의 영향은 직접 바로잡아요**(받는 사람에게 연락, 백업에서 파일 복원, 예약 취소).
4. 다시 시도하기 전에 **권한을 좁히거나 Manual 승인으로 바꿔요.**
5. 에이전트에게 **무엇이 잘못됐는지 알려** 그 부분만 다시 하게 하고, 다시 검수해요.

## 자주 막히는 지점

### 검수하는 데 직접 하는 것만큼 걸려요

- **원인**: 작업이 너무 크거나, 전부 확인하려고 했을 수 있어요.
- **해결**: 작업을 작게 나누고, 1단계의 보고 형식을 쓰고, 표본 확인만 하세요. 확인이 늘 직접 하는 것보다 오래 걸린다면 맡기기에 맞지 않는 일일 수 있어요.

### 에이전트의 보고와 실제 결과가 달라요

- **원인**: 보고는 에이전트가 쓴 것이라 틀릴 수 있어요.
- **해결**: 요약 글보다 파일, 보낸편지함, 활동 기록을 믿으세요.

### Activity나 진행 화면이 안 보여요

- **원인**: 플랜, 기기, 단계적 배포에 따라 메뉴가 달라요. 이름도 자주 바뀌어요.
- **해결**: 사용하는 서비스의 공식 페이지(출처 링크)를 확인하고 내 화면의 표기를 보세요. 모든 제품에 똑같은 기록 화면이 있는지는 확인하지 못했어요.

## 실전 팁

- **맡기기 전에 저장해 두세요.** Cowork 가이드가 백업과 전용 작업 폴더를 권하니, 중요한 파일은 먼저 백업하세요.
- **빨리 검수하세요.** 문제는 같은 날 고치기가 쉬워요.
- **반복 작업은 짧은 기록을 직접 남기세요.** 무엇을 확인했고 무엇이 잘못됐는지요.
- **신뢰는 천천히 넓히세요.** 읽기 전용, 초안, 승인이 필요한 행동, 그 다음에야 더 넓은 자율 순서로요([6편](/ko/agents/06-browser-agents/) 참고).
- **자신 있게 말한다고 더 믿지 마세요.** 말투의 확신은 증거가 아니에요.
- **검수 대화에 비밀 정보를 붙여 넣지 마세요.** 비밀번호와 일회용 코드는 대화에 두지 않아요.
- **기능은 자주 바뀌어요.** 이 글은 2026-11-02 기준이니 실제 화면을 확인하세요.
