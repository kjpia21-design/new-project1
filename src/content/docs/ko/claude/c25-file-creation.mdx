<Summary>
- Claude는 비공개 샌드박스에서 코드를 실행해 **Excel(.xlsx), PowerPoint(.pptx), Word(.docx), PDF** 파일을 만들어 내려받게 해 줘요. Google Drive에 바로 저장할 수도 있어요. 공식 문서는 웹, Claude Desktop, Claude Mobile에서 **모든 플랜**(Free, Pro, Max, Ultra, Team, Enterprise)에 제공된다고 안내해요(2026-11-02 기준).
- Free·Pro·Max·Ultra는 기본으로 켜져 있고, Team·Enterprise는 조직 Owner가 **Organization settings > Capabilities**에서 끌 수 있어요. 직접 켜려면 **Settings > Capabilities > Code execution and file creation**을 쓰세요(새 설정 화면에서는 "Create and edit files"로 표시돼요).
- 파일 크기 한도는 업로드·다운로드 모두 **파일당 30MB**예요.
- 평소 플랜 사용 한도에서 차감되고, 파일 생성은 일반 대화보다 한도를 더 많이 써요.
- 네트워크 접근은 보안과 맞바꾸는 설정이에요. 아래 보안 안내를 읽고, Claude가 만든 파일은 항상 직접 확인한 뒤 쓰세요.
</Summary>

이 글은 *대화로 파일 만들기*를 다뤄요. Excel·PowerPoint 프로그램 안에서 쓰는 방법은 [C21. Excel·PowerPoint](/ko/claude/c21-office-agents/)을, 대화형 페이지·앱은 [C6. 아티팩트](/ko/claude/c06-artifacts/)를 보세요.

## 이 글을 마치면 할 수 있는 것

- 파일 생성 기능을 켜거나, 꺼져 있는 이유를 확인해요.
- 스프레드시트, 보고서, 슬라이드, PDF를 일상 말로 요청해 내려받아요.
- 문서를 다른 형식으로 바꾸거나 PDF에서 데이터를 뽑아내요.
- 민감한 자료를 올리기 전에 네트워크 접근 설정과 보안 주의점을 이해해요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Code execution and file creation** | Claude에게 비공개 컴퓨팅 환경(샌드박스)을 줘서 Python·JavaScript 같은 코드를 쓰고 실행해 문서·스프레드시트·슬라이드를 만들게 하는 설정이에요. |
| **샌드박스** | 격리된 컨테이너예요. 공식 문서에 따르면 샌드박스 환경은 사용자끼리 절대 공유되지 않아요. |
| **네트워크 이그레스** | 샌드박스가 인터넷에 접근할 수 있는지예요. 끔, 패키지 관리자만, 패키지 관리자와 지정 도메인, 모든 도메인 중에서 고를 수 있어요. |
| **지원 파일 형식** | Excel(.xlsx), PowerPoint(.pptx), Word(.docx), PDF예요. 차트는 PNG 같은 이미지 파일로 만들 수 있어요. |

<Aside type="caution" title="왜 중요할까요">
공식 문서는 외부 파일이나 웹사이트에 숨긴 지시문이 Claude를 속여 신뢰할 수 없는 코드를 실행하게 하거나, 대화 속 데이터를 외부 서버로 보내게 할 수 있다고 경고해요. Claude의 작업을 지켜보다가 예상 밖의 데이터에 접근하면 멈추라고 권해요. 익숙해지기 전에는 기밀 파일을 올리지 마세요.
</Aside>

<Steps>

1. **기능 켜기**

   Free, Pro, Max, Ultra 플랜의 웹·데스크톱에서는 **Settings > Capabilities**를 열고 **Code execution and file creation**을 켜요(새 설정 화면에서는 **Create and edit files**). iOS·Android 앱에서는 왼쪽 사이드바의 이니셜이나 이름을 눌러 Settings를 열고 **Capabilities**에서 켜고 끌 수 있어요. Team·Enterprise는 조직 Owner가 **Organization settings > Capabilities**에서 관리해요.

   <ScreenshotPlaceholder caption="Settings > Capabilities의 Code execution and file creation 토글" officialUrl="https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude" />

2. **원하는 파일을 설명하기**

   필요한 것을 그대로 말하면 돼요. 예를 들어 "월별 지출을 관리하는 Excel 스프레드시트를 만들어 줘", "이 문서를 PowerPoint 발표 자료로 바꿔 줘"처럼요. 구조·내용·서식을 구체적으로 적을수록 좋아요. Claude가 파일을 만들면 대화에서 바로 내려받아요.

   <PromptBox label="수식이 들어간 스프레드시트">
   월별 가계부 Excel 파일을 만들어 줘. 시트 1은 수입·지출 항목과 계획 금액·실제 금액 열. 시트 2는 합계와 계획 대비 차이를 숫자를 직접 적지 말고 수식으로 계산. 항목별 지출 차트 하나 추가. 내가 바꿔 넣을 수 있게 예시 숫자를 넣어 줘.
   </PromptBox>

3. **내 자료에서 시작하기**

   CSV, 문서, PDF를 올리고 다른 형식의 결과를 요청해요. 공식 문서의 예로는 CSV로 차트가 들어간 Word·PDF 보고서 만들기, Word 문서를 프레젠테이션으로 바꾸기, 스프레드시트를 Word 보고서로 설명하기, PDF의 데이터를 Excel로 뽑고 요약 차트 만들기가 있어요.

   <PromptBox label="문서를 슬라이드로">
   첨부한 Word 문서를 8장 안팎의 PowerPoint로 바꿔 줘. 슬라이드당 핵심 메시지 하나, 짧은 글머리표, 마지막 장에는 남은 질문 목록. 문서에서 뺀 부분이 있으면 알려 줘.
   </PromptBox>

4. **같은 대화에서 다듬기**

   공식 문서는 결과물을 검토하고 다듬어야 할 수 있다고 하고, 한 대화에서 여러 파일을 다룰 수 있으며 대화 중에는 파일을 계속 내려받을 수 있다고 해요. "제목 줄을 굵게", "요약을 첫 슬라이드로 옮겨 줘"처럼 말로 고쳐 달라고 하고 새 버전을 내려받으세요.

   <FlowSteps title="검토 반복" officialUrl="https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude" steps={[
     { where: '대화', action: '파일을 요청하고 내려받기' },
     { where: 'Office 앱 또는 PDF 뷰어', action: '열어서 숫자·수식·이름·레이아웃 확인' },
     { where: '대화', action: '고칠 점을 설명하고 새 버전 요청', result: '수정된 파일 내려받기' },
   ]} />

5. **저장하거나 공유하기**

   파일을 내려받거나 Google Drive에 바로 저장할 수 있어요. 휴대폰에서 Download를 누르면 시스템 미리보기나 별도 앱(예: .docx는 Word 앱)에서 열려요. 공식 문서에 따르면 이 기능으로 만든 파일 결과물이 들어간 대화의 공개 공유는 Free, Pro, Max, Ultra에서 막혀 있어요.

</Steps>

## 플랜과 조직 설정

| 플랜 | 기본값 (공식 도움말) | 네트워크 접근 |
| --- | --- | --- |
| Free, Pro, Max, Ultra | 기본 켜짐 | 켜져 있어 승인된 출처에서 패키지를 설치할 수 있어요 |
| Team | 기본 켜짐, Owner가 끌 수 있음 | 문서 안에서 기본값이 엇갈려요. 한 곳은 기본 꺼짐, 다른 곳은 패키지 관리자만 켜짐 |
| Enterprise | 새 조직은 기본 켜짐, Owner가 끌 수 있음 | 기본 꺼짐. Owner가 켜고 도메인을 제어할 수 있음 |

Owner는 Organization settings > Capabilities에서 네트워크 설정을 네 가지 중에 고를 수 있어요. 끔(사전 설치 패키지만), 패키지 관리자만, 패키지 관리자와 지정한 도메인, 그리고 Anthropic의 법적 차단 목록을 뺀 모든 도메인이에요. 공식 문서는 "모든 도메인"을 가장 위험한 옵션이라 하고, 네트워크를 끈 상태에서 시작해 단계적으로 넓히라고 권해요. 또 MCP 연동이 켜져 있으면 이 설정과 상관없이 그 연결로 네트워크 통신이 가능하다고 덧붙여요.

## 한도와 알아둘 점

- **파일 크기**: 업로드·다운로드 파일당 30MB예요. 30MB가 넘는 PDF는 컨텍스트 창에 올리지 않고 컴퓨팅 환경에서 처리할 수 있다고 해요.
- **사용량**: 플랜 한도에서 차감되고, 일반 대화보다 더 많이 써요.
- **아티팩트**: 파일 생성을 켜도 계속 쓸 수 있어요. 다만 이제 컴퓨팅 환경에서 아티팩트를 만들기 때문에 화면이 조금 다를 수 있어요.
- **언어**: 문서는 인터페이스와 생성 파일에서 여러 언어와 지역 표기 규칙을 지원한다고 해요. 언어별 목록은 없으니 작은 파일로 먼저 시험해 보세요.
- **데이터 분석**: 같은 환경에서 Python 분석, PNG 차트 만들기, CSV·TSV 읽기가 가능해요.

<Aside type="note" title="확인하지 못한 것">
문서 제목은 "create and edit"이지만 본문은 대부분 파일 생성과 형식 변환을 설명해요. 올린 Excel·Word·PowerPoint 파일을 그 자리에서 고치는 단계별 설명이나, 기존 파일을 바꿀 때 무엇이 유지되는지는 나와 있지 않아요. 중요한 파일의 수정은 새 버전으로 받고 원본을 따로 보관해 비교하세요. 이 글은 기능을 직접 실행해 보지 않았고, 모든 내용은 공식 문서에서 가져왔어요.
</Aside>

## 한눈에 보기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 켜기(개인 플랜) | Settings > Capabilities > Code execution and file creation |
| 모바일에서 켜고 끄기 | 이니셜·이름 > Settings > Capabilities |
| 조직에서 끄기 | Owner: Organization settings > Capabilities |
| 데이터를 샌드박스 안에만 두기 | Owner: Allow network egress 끄기 |
| CSV로 보고서 만들기 | 올리고 차트가 있는 Word·PDF 보고서 요청 |
| 형식 바꾸기 | 파일을 올리고 원하는 형식 요청 |

## 자주 막히는 부분

### 옵션이 안 보이거나 파일을 안 만들어 줘요

- **원인**: 설정이 꺼져 있거나 조직 Owner가 껐어요.
- **해결**: Settings > Capabilities를 확인하세요. Team·Enterprise는 Owner에게 Organization settings > Capabilities를 확인해 달라고 하세요.

### 패키지를 설치하지 못하거나 데이터를 가져오지 못해요

- **원인**: 네트워크 이그레스가 꺼져 있거나 제한돼 있어요(Enterprise 기본값).
- **해결**: Owner에게 패키지 관리자나 특정 도메인을 허용할 수 있는지 물어보거나, 데이터를 대화에 직접 붙여 넣으세요.

### 사용 한도가 금방 닳아요

- **원인**: 파일 생성은 일반 대화보다 한도를 더 써요.
- **해결**: 결과물을 적게, 더 정확히 요청하고 수정 사항은 한 번에 모아서 요청하세요.

### 숫자나 수식이 이상해요

- **원인**: 모델 출력에는 실수가 있을 수 있어요.
- **해결**: 파일에서 다시 계산해 보고, 수식마다 설명을 요청하고, 공유 전에 원본 자료와 대조하세요.

### 파일이 30MB를 넘어요

- **원인**: 업로드·다운로드 모두 파일당 30MB 한도예요.
- **해결**: 파일을 나누거나 압축하세요. 큰 PDF는 컴퓨팅 환경에서 처리할 수 있다고 문서에 나와 있어요.

## 실전 팁

- 구조(시트, 열, 슬라이드 수)를 먼저 말하고 스타일은 나중에 말하세요.
- 가짜 숫자가 든 연습 파일로 시작하고, 나중에 실제 값으로 바꾸세요.
- 원본은 따로 보관하고 Claude의 결과는 확인할 초안으로 보세요.
- 비밀번호, 고객 개인정보, 인사 파일은 올리지 마세요. [개인정보·회사 정보를 지키며 AI 쓰기](/ko/basics/05-privacy-safety/)를 보세요.
- 조직이 네트워크를 제한했다면 Claude가 데이터를 가져오길 기대하지 말고 업로드한 파일로 작업하세요.
