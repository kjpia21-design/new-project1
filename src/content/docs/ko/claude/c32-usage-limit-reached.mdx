<Summary>
- 한도는 **두 종류**예요. 시간이 지나며 쓸 수 있는 양인 **사용량 한도**와, 한 대화가 길어질 수 있는 정도인 **길이 한도**예요. 해결 방법이 다르니 어느 쪽인지부터 확인하세요.
- 유료 플랜에는 **첫 메시지를 보낸 뒤 5시간 후에 리셋되는 세션 한도**와 **계정마다 정해진 고정 시각에 리셋되는 주간 한도**가 있어요. **Settings > Usage**에서 둘과 리셋 시각을 볼 수 있어요. 인증된 Ultra 계정에는 5시간 한도가 없어요.
- 사용량 한도에 걸리면 **리셋을 기다리거나**, **사용량 크레딧**(표준 API 요금으로 쓴 만큼 결제, 유료 플랜 전용)을 켜거나, **한도가 더 높은 플랜**으로 바꿀 수 있어요. 새 플랜의 한도는 바로 적용돼요.
- 덜 쓰려면 **새 주제는 새 대화로 시작**하고, 필요 없는 도구·커넥터를 끄고, 노력(effort) 수준을 낮추고, 가벼운 모델을 고르고, 프로젝트 파일을 정리하세요(2026-11-23 기준 공식 도움말).
</Summary>

작업 중에 "한도에 도달했어요"라는 안내가 뜨면 당황스럽지만, 오류인 경우는 드물어요. 이 글은 짧은 문제 해결 순서예요. 플랜 전체 비교는 [C2. 플랜과 사용량 한도](/ko/claude/c02-plans-limits/), 무료 서비스 활용은 [무료로 AI 최대한 활용하기](/ko/basics/16-free-ai-tips/)를 보세요. 출처에 적은 공식 도움말을 2026-11-23에 읽었고, 페이지가 말하지 않는 부분은 그렇다고 밝혀요.

## 이 글을 마치면 할 수 있는 것

- 사용량 한도와 길이 한도를 구분해요.
- 다음 리셋 시각을 찾아요.
- 기다리기, 사용량 크레딧, 플랜 변경, 덜 쓰기 중 하나를 골라요.
- 한도가 더 늦게 오도록 습관을 만들어요.

## 먼저 알아둘 개념

| 용어 | 뜻 (공식 도움말, 2026-11-23 기준) |
| --- | --- |
| **사용량 한도** | 일정 기간 Claude와 주고받을 수 있는 양이에요. 유료 플랜에는 세션 한도와 주간 한도가 있어요. |
| **세션 한도(5시간 한도)** | 첫 메시지를 보낼 때 기간이 시작되고, 5시간 뒤에 한도가 모두 리셋돼요. 인증된 Ultra 계정에는 없어요. |
| **주간 한도** | 모든 모델에 적용돼요. 일부 플랜에는 Fable 전용 주간 한도가 따로 있어요. 계정마다 정해진 고정 시각에 매주 리셋되고, Claude를 쓰기 시작한 때와는 상관없어요. |
| **길이 한도** | 컨텍스트 창, 즉 한 대화에서 Claude가 다룰 수 있는 양과 관련돼요. 기다려서가 아니라 새 대화를 시작해서 해결해요. |
| **사용량 크레딧** | 포함된 한도를 다 쓴 뒤 표준 API 요금으로 쓴 만큼 결제하는 방식이에요. 일부 화면에서는 "extra usage"라고도 해요. |

<Aside type="note" title="한도는 하나로 공유돼요">
도움말은 claude.ai, Claude Code, Claude Desktop 등 모든 Claude 화면에서의 사용이 같은 사용량 한도에 합산된다고 해요. 그래서 긴 Claude Code 작업 때문에 채팅에서 한도가 찼다고 나올 수 있어요.
</Aside>

## 단계별 따라 하기

<Steps>

1. **어느 한도인지 가리기**

   **새** 대화는 시작할 수 있다면 그 채팅의 **길이 한도**일 가능성이 커요. 공식 페이지는 새 대화를 시작하거나 프로젝트를 쓰라고 안내해요. 새 채팅도 막힌다면 **사용량 한도**(세션 또는 주간)예요. 안내 문구는 화면과 플랜에 따라 달라요. 읽은 페이지에는 claude.ai의 정확한 메시지 문구가 없으니 화면에 뜬 문구를 따르세요(확인하지 못함).

2. **Settings > Usage 열기**

   Pro, Max, Ultra, Team, 좌석 기반 Enterprise 플랜에서는 **Settings > Usage**에 **현재 세션**(남은 시간 포함)과 **주간 한도** 진행 막대, 다음 주간 리셋 시각이 보여요. 세션은 첫 메시지부터 5시간이라 시계 기준 정각이 아니에요. 주간 리셋 요일과 시각은 구독을 시작한 때나 쓰기 시작한 때와 상관없이 그대로예요.

   Claude Code에서는 Enterprise 좌석 사용자가 "limit reached, resets at time" 같은 메시지를 보고, 그동안 `/model`로 가벼운 모델로 바꿀 수 있다고 도움말이 안내해요. API 키 사용자는 하드 스톱 없이 토큰별로 과금돼요.

3. **계속할 방법 고르기**

   | 방법 | 이럴 때 | 도움말 내용 |
   | --- | --- | --- |
   | **기다리기** | 잠시 쉬어도 될 때 | 세션은 시작 5시간 뒤에 모두 리셋되고, 주간 한도는 계정의 고정 시각에 리셋돼요. |
   | **사용량 크레딧** | 지금 계속하고 싶을 때 | Pro·Max·Ultra는 Settings > Usage에서 켜요. 표준 API 요금으로 청구되고 구독료와 별도 청구예요. "Adjust limit"로 월 지출 한도를 정하세요. |
   | **플랜 변경** | 자주 한도에 걸릴 때 | 유료 플랜일수록 한도가 높아요. 업그레이드하면 새 플랜 한도가 바로 적용돼요. [C2](/ko/claude/c02-plans-limits/) 참고. |
   | **덜 쓰기** | 언제든 도움 | 4단계 참고. |

   **Team·좌석 기반 Enterprise** 플랜에서는 **Owner 또는 Primary Owner**만 사용량 크레딧을 켤 수 있어요(Organization settings > Usage). 멤버인데 계속할 수 없다면 Owner에게 물어보세요. **사용량 기반 Enterprise**는 포함된 허용량이 없어서 첫 토큰부터 API 요금으로 청구돼요.

   사용량 크레딧을 켜기 전에 공식 페이지를 읽어 보세요. 사용량 크레딧은 (예외를 빼고) **환불되지 않고**, 유효한 유료 플랜이 있어야 쓸 수 있다고 해요. 2026년 12월 7일 이후 구매분은 보통 구매 후 12개월 뒤 만료되고, 그 전에 산 크레딧은 만료되지 않는다고 적혀 있어요. 만료 규정은 나라마다 다를 수 있어요. 또 한도 임박 알림이 잠시 남아 있다가 "Now using credits"로 바뀌는데, 그건 중단된 것이 아니라고 해요.

4. **다음에는 덜 쓰기**

   공식 페이지가 꼽는 습관이에요. 모든 플랜에 해당해요.

   - **새 주제는 새 대화로 시작하세요.** 긴 대화에서 자동 컨텍스트 관리가 작동하면 한도를 더 쓰고, 긴 채팅에서 한도가 가까우면 새 대화를 시작해 보라고 도움말이 안내해요.
   - **관련 질문은 한 메시지로 묶고** 배경 정보를 먼저 주세요. 짧은 왕복을 줄여요.
   - **자주 쓰는 문서는 프로젝트에** 넣으세요. 프로젝트 내용은 캐시돼 재사용 때 한도에 덜 반영되지만, 한동안 쓰지 않으면 캐시가 만료돼요. 안 쓰는 프로젝트 파일은 지우고 프로젝트 지침은 짧게 유지하세요.
   - **필요 없는 도구는 끄세요.** 필요 없는 대화에서는 연결한 앱을 끄고, 최신 정보가 필요 없으면 웹 검색을 하지 말라고 하세요. 도움말은 도구와 커넥터를 토큰을 많이 쓰는 것이라고 해요.
   - **노력(effort) 수준을 낮추세요.** 일상 작업에는 낮은 수준을, 생각(thinking) 토글이 있는 모델에서는 필요 없을 때 끄세요.
   - **가벼운 모델을 고르세요.** 사용량 크레딧 안내는 대부분의 작업에 Opus보다 Haiku나 최신 Sonnet을 권해요. Claude Code 안내는 Opus가 Sonnet보다 할당량을 훨씬 많이 쓴다고 해요.
   - **Claude Code에서는** 작업을 바꿀 때 `/clear`, 긴 작업을 이어갈 때 `/compact`, 붙여넣기 대신 파일 경로 지정, CLAUDE.md는 간결하게 유지하세요.

   <PromptBox label="여러 번 묻지 말고 한 번에 요청하기">
   한 메시지에 작업 세 가지를 줄게요. 순서대로 하고 답은 짧게 해 주세요. 첫째, 아래 글을 다섯 줄로 요약해 주세요. 둘째, 글에 남은 질문을 정리해 주세요. 셋째, 보낸 사람에게 두 줄 답장을 써 주세요. 불분명한 점은 하나씩 묻지 말고 마지막에 한꺼번에 알려 주세요.
   </PromptBox>

</Steps>

<Aside type="caution" title="한도는 바뀔 수 있어요">
도움말은 Anthropic이 수용 능력을 관리하려고 재량으로 사용량 한도를 조정할 수 있고, 끊김 없는 서비스를 보장하지 않는다고 해요. 오늘의 수치와 동작은 2026-11-23 시점의 스냅숏으로 보고, 내게 적용되는 내용은 Settings > Usage에서 확인하세요.
</Aside>

## 확인하지 못한 것

<Aside type="note" title="확인하지 못한 항목 (2026-11-23 기준)">
직접 한도 메시지를 띄워 보지는 않았어요. 읽은 페이지에는 claude.ai의 정확한 메시지 문구, 세션당 메시지·토큰 수, 무료 플랜에 같은 리셋 규칙이 적용되는지가 나와 있지 않아요(사용량 도움말은 유료 플랜에 두 한도가 있다고 설명해요. 무료 플랜은 [C2](/ko/claude/c02-plans-limits/)에서 정리한 내용을 보세요). 메뉴 이름은 도움말 기준이라 내 화면이나 앱과 다를 수 있어요.
</Aside>

## 자주 막히는 부분

### 사용량 크레딧을 켰는데 멈춘 것처럼 보여요

- **원인**: 전환되는 순간에도 한도 임박 알림이 남아 있을 수 있어요. 잔액이 있으면 다음 요청이 처리되면서 "Now using credits"로 바뀌어요.
- **해결**: 요청을 다시 보내고 Settings > Usage에서 잔액과 월 지출 한도를 확인하세요.

### 주간 한도 리셋 시각이 어중간해요

- **원인**: 리셋은 첫 메시지 기준이 아니라 계정에 정해진 고정 시각이에요.
- **해결**: Settings > Usage의 리셋 시각을 보고 일정을 짜세요.

### 업그레이드하면 언제 적용되나요

- **해결**: 공식 페이지는 새 플랜의 한도가 바로 적용된다고 해요.

## 실전 팁

- 큰 작업을 시작하기 전에 Settings > Usage를 먼저 확인하세요.
- 사용량 크레딧을 처음 쓸 때는 월 지출 한도를 낮게 잡고 나중에 조정하세요.
- 공식 문서에서 찾지 못한 숫자는 확인하지 못한 것으로 다루세요.
