<Summary>
- App Store나 Play Store에서 **Claude by Anthropic**을 설치해요. 공식 문서 기준 지원 버전은 **iOS/iPadOS 18.0 이상**, **Android 8.0(Oreo) 이상**이에요(2026-11-02 기준).
- **받아쓰기**는 말을 글자로 바꿔 입력하고 Claude는 글로 답해요. **음성 모드**는 말로 주고받는 대화예요(베타). 둘 다 모든 플랜에서 쓸 수 있다고 안내돼요.
- 음성 대화도 평소 사용 한도에서 차감돼요. 대화 내용은 글 기록으로 채팅 기록에 저장돼요.
- iPhone 추가 기능: **위젯**(새 대화·받아쓰기·카메라), Siri·Spotlight·공유·단축어에서 쓰는 **"Ask Claude"**, **"Analyze Photo with Claude"** 컨트롤. Android: Claude가 **메시지·이메일·캘린더·시계·지도 앱**과 연동돼요.
- Claude가 써 준 초안은 보내거나 저장하기 전에 대상 앱에서 꼭 직접 확인하세요.
</Summary>

이 글은 휴대폰 앱을 다뤄요. 휴대폰 AI의 첫걸음은 [휴대폰에서 AI 쓰기](/ko/basics/07-ai-on-phone/)를, 컴퓨터용 앱은 [C22. 데스크톱 앱](/ko/claude/c22-desktop-app/)을 보세요.

## 이 글을 마치면 할 수 있는 것

- 맞는 앱을 설치하고 내 휴대폰이 지원되는지 알아요.
- 받아쓰기와 음성 모드 중에 고르고 언어를 설정해요.
- 사진이나 파일을 보내고 물어봐요.
- iPhone 위젯·단축어를 설정하거나 Android 앱과 함께 써요.
- 개인 정보가 대화에 들어가지 않게 지켜요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **받아쓰기(Dictation)** | 말을 입력창의 글자로 바꿔 줘요. 글로 된 프롬프트를 보내고 Claude도 글로 답해요. |
| **음성 모드(Voice mode)** | 내가 말하면 Claude도 말로 답하는 대화예요. 베타예요. 웹 검색과 연결한 도구를 쓸 수 있어요. |
| **핸즈프리 / 눌러서 말하기** | 음성 모드의 두 방식이에요. 핸즈프리는 계속 듣는 기본값이고, 눌러서 말하기는 버튼을 누른 채 말해요. |
| **앱 인텐트·단축어(iOS)** | "Ask Claude"는 Siri, Spotlight, 공유 메뉴, 단축어 앱이 앱을 열지 않고 부를 수 있는 동작이에요. |
| **위젯** | 홈 화면이나 오늘 보기에 두는 타일로, 대화·받아쓰기·카메라 버튼이 있어요(iOS). |

## 단계별 따라하기

<Steps>

1. **앱 설치하기**

   App Store(iOS)나 Play Store(Android)에서 "Claude by Anthropic"을 검색해 받기·설치를 눌러요. iOS 문서에는 Microsoft Intune을 쓰는 Enterprise 조직용 관리형 앱 "Claude for Intune"도 나와요. 조직에서 요청하지 않았다면 일반 앱을 설치하세요. 앱이 안 보이면 공식 문서는 지원하지 않는 지역, 기기, OS 버전일 수 있다고 안내해요.

   <ScreenshotPlaceholder caption="App Store와 Play Store의 Claude by Anthropic" officialUrl="https://support.claude.com/en/articles/9266462-install-claude-for-ios" />

2. **받아쓰기로 말해서 입력하기**

   새 대화를 열고 입력창 오른쪽의 마이크 아이콘을 눌러요. 처음에는 언어를 골라요. 말한 뒤 화살표를 누르면 보내지고, X를 누르면 보내지 않고 취소돼요. 언어는 오른쪽 위 이니셜을 눌러 "Speech Input Language"에서 바꿔요. 문서가 안내하는 언어는 영어, 프랑스어, 독일어, 힌디어, 이탈리아어, 일본어, 한국어, 포르투갈어, 러시아어, 스페인어, 튀르키예어, 우크라이나어이고 영어 외 언어는 베타예요. 문서에 따르면 음성을 글자로 바꾼 뒤 녹음은 삭제되고, 사본을 보관하거나 생성 모델 학습에 쓰지 않아요.

3. **음성 모드로 대화하기**

   입력창의 음성 모드 아이콘(마이크 옆 음파 모양)을 누르고 목소리를 골라요. 핸즈프리가 기본이고 조용한 곳에서 가장 잘 돼요. 잘못 알아들으면 눌러서 말하기로 바꾸세요. 같은 대화에서 글과 음성을 오갈 수 있어요. 음성 모드에서도 Gmail, Google Calendar, Google Docs, Slack 같은 연결한 도구를 쓸 수 있어요(Free 플랜은 도구 하나 연결). 말하기 언어는 Settings > Capabilities > Voice > Spoken language(없으면 Settings > General > Voice > Language)에서 바꿔요. 앱 표시 언어를 바꿔도 음성 언어는 바뀌지 않아요.

   <PromptBox label="손이 바쁠 때 질문">
   요리 중이라 타자를 못 쳐. 머핀 레시피에서 버터를 올리브유로 바꾸는 방법을 한 단계씩 알려 주고, 다음 단계로 넘어가기 전에 나한테 물어봐 줘.
   </PromptBox>

4. **사진과 파일 보내기**

   업로드 문서는 JPEG, PNG, GIF, WebP 이미지와 PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON, XLSX 문서를 지원한다고 해요(XLSX는 코드 실행 및 파일 생성을 켜야 해요). 대화 업로드는 파일당 500MB, 대화당 20개, 이미지 8000x8000 픽셀, PDF 1000쪽까지예요. 문서는 컴퓨터 브라우저의 "+" 버튼을 설명하고 휴대폰 메뉴는 따로 설명하지 않으니, 앱에서 같은 첨부 버튼을 찾아보세요.

   <PromptBox label="사진을 보여 주고 묻기">
   손글씨로 쓴 장보기 목록 사진이야. 글자로 옮겨서 마트 코너별 체크리스트로 묶어 주고, 잘 안 읽힌 글자는 알려 줘.
   </PromptBox>

5. **iPhone: 위젯, Ask Claude, 사진 컨트롤**

   홈 화면 편집 모드에서 Claude 위젯을 추가해요(편집 > 위젯 추가 > Claude). 버튼으로 새 대화 시작, 받아쓰기 모드로 앱 열기, 사진 찍어 보내기를 할 수 있어요. "Ask Claude" 인텐트는 Siri, Spotlight, 공유 메뉴에서 쓰고, 단축어 앱의 재료로도 쓸 수 있어요(예: 공유한 글을 보내 요약하는 "Claude로 요약" 단축어). "Analyze Photo with Claude"는 제어 센터나 잠금 화면에 추가해요. 이 기능은 iOS 18 이상이 필요하고, 앱을 열 때 보이는 기본 모델을 쓰며, 사용 한도에서 차감돼요.

6. **Android: 휴대폰 앱과 함께 쓰기**

   공식 문서에 따르면 Claude는 메시지·이메일 초안을 앱에 미리 채워 열어 주고, 장소를 지도에 보여 주고, 캘린더 일정을 읽고 만들고, 알람과 타이머를 설정할 수 있어요. 기존 메시지나 이메일을 읽지 않고, 연락처에 직접 접근하지 않으며, Android에서는 미리 알림을 만들 수 없어요. Health Connect 읽기는 베타이고 Pro·Max·Ultra만, Android 14 이상, 미국 사용자로 제한돼요. 문서는 Claude가 의료기기가 아니므로 건강 문제는 면허 있는 전문가와 상의하라고 안내해요.

   <FlowSteps title="Android에서 안전하게 넘기기" officialUrl="https://support.claude.com/en/articles/11869629-use-claude-with-android-apps" steps={[
     { where: 'Claude 대화', action: '받는 사람, 날짜, 시간을 적어 초안 요청' },
     { where: '대화 속 카드', action: '카드를 눌러 메시지·이메일 앱 열기' },
     { where: '메시지·이메일 앱', action: '미리 채워진 내용을 직접 읽고 고치기', result: '맞을 때만 보내기' },
   ]} />

</Steps>

<Aside type="caution" title="말하거나 보내기 전에">
음성 대화의 글 기록은 텍스트 대화처럼 채팅 기록에 저장돼요. 비밀번호, 카드 번호, 주민등록번호 같은 신분 정보, 다른 사람의 개인 정보는 소리 내어 읽거나 사진으로 찍지 마세요. 기본은 [개인정보·회사 정보를 지키며 AI 쓰기](/ko/basics/05-privacy-safety/)를 보세요.
</Aside>

## 한도와 알아둘 점

- **사용량**: 음성 대화, iOS의 "Ask Claude"와 위젯 사용은 사용 한도에서 차감돼요.
- **음성 모드와 모델**: 플랜에서 제공하는 모델을 따라요. 문서는 특정 모델 하나가 음성 모드에서 아직 쓸 수 없다고 적어요.
- **Cowork·Claude Code**: 받아쓰기는 되지만 음성 모드는 안 돼요(음성 문서 기준).
- **Enterprise**: 음성 모드를 끄려면 Support에 문의하라고 안내해요.
- **Android 위치**: Team·Enterprise 구성원은 현재 위치 도구를 쓸 수 없어요.

<Aside type="note" title="확인하지 못한 것">
앱을 직접 설치하거나 실행해 보지 않았어요. 읽은 공식 문서에는 휴대폰에서 사진·파일을 붙이는 정확한 메뉴가 없으니 내 화면에서 확인하세요. Android "앱 연동" 문서에 대응하는 iOS 문서는 읽은 범위에서 찾지 못해서, iOS의 캘린더·메시지·건강 연동은 말하지 않았어요. 기능 이름, 플랜, 메뉴 경로는 자주 바뀌니 링크한 문서를 다시 확인하세요.
</Aside>

## 한눈에 보기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 말하고 글로 답 받기 | 입력창의 마이크 아이콘(받아쓰기) |
| 말로 대화하기 | 음파 아이콘(음성 모드) |
| 받아쓰기 언어 바꾸기 | 이니셜 > Speech Input Language |
| 음성 언어 바꾸기 | Settings > Capabilities > Voice (또는 Settings > General) |
| 시끄러운 곳 | 음성 모드를 눌러서 말하기로 전환 |
| iPhone에서 글 빠르게 요약 | 공유 메뉴 또는 단축어 > Ask Claude |
| Android에서 이메일 초안 | 대화에서 요청하고 카드 누르기 |

## 자주 막히는 부분

### 스토어에서 앱이 안 보여요

- **원인**: 지원하지 않는 지역, 기기, OS 버전이에요(iOS 18.0 이상, Android 8.0 이상 필요).
- **해결**: OS 버전을 확인하세요. Intune을 쓰는 Enterprise 사용자는 IT 팀에 어떤 앱을 설치할지 물어보세요.

### Claude가 제 말을 잘못 알아들어요

- **원인**: 소음, 마이크 권한, 또는 언어 설정이에요.
- **해결**: 조용한 곳으로 가거나 눌러서 말하기를 쓰고, 마이크 권한을 확인하고, 설정에서 음성 언어를 맞추세요.

### 음성이 끊기거나 멈춰요

- **원인**: 불안정한 연결, 배터리 부족, 사용 한도 도달이에요.
- **해결**: 연결을 확인하고, 음성 모드를 나갔다 다시 들어가고, 사용 한도를 확인하세요.

### Claude가 말을 끊어요

- **원인**: 말 사이의 쉬는 시간이나 주변 소음이에요.
- **해결**: 덜 쉬고 말하거나 눌러서 말하기로 바꾸세요.

## 실전 팁

- 길게 타자 칠 내용은 받아쓰기, 아이디어 구상이나 연습은 음성 모드가 어울려요.
- 아침에 짧은 음성 브리핑을 받되 시간과 이름은 직접 확인하세요.
- 메시지나 일정 초안을 부탁할 때는 누구에게, 언제, 얼마나를 말하세요.
- 연습용 사진에는 얼굴이나 개인 정보가 있는 문서가 나오지 않게 하세요.
