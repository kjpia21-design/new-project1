Anthropic의 공식 채널에서 나온 Claude 업데이트를 최신순으로 모았어요. 모델 출시, 가격, Claude Code와 앱의 새 기능처럼 실제로 쓰는 분에게 의미 있는 것만 골랐고, 사소한 버그 수정은 뺐어요. 공식 채널을 점검해 계속 갱신해요.

<NewsItem date="11월 24일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/ko/claude/c06-artifacts/" tutorialLabel="C6 아티팩트">
Claude가 만들어 준 아티팩트를 Mac이나 Windows 컴퓨터에 앱으로 설치할 수 있게 됐어요(베타). 자체 창과 아이콘이 생기고 다른 앱처럼 열려요. 설치해도 같은 아티팩트라서, 아티팩트를 고치면 앱도 바뀌어요. 도움말 문서 기준으로 Free, Pro, Max, Ultra, Team, Enterprise 플랜에 순차 배포 중이고, Mac용 또는 Windows용 Claude 6.28899.0 이상이 필요해요. 설치하려면 Claude Desktop에서 아티팩트를 열고, 제목 메뉴를 열거나 아티팩트를 오른쪽 클릭한 뒤 "Install as app"을 골라요. 앱은 알림 표시, 키보드 단축키, 다른 창 위에 띄우기, 메뉴 막대나 시스템 트레이 항목 추가를 쓰기 전에 먼저 허락을 받아야 해요. 가장 높은 권한인 컴퓨터 전체 접근(full access)을 허용하면 앱이 프로그램을 실행하고 파일을 읽고 바꾸고 지울 수 있어요. Anthropic이 앱을 미리 검토하지 않으니, 만든 사람을 모두 믿을 수 있는 앱에만 허용하세요. Team 플랜에서는 관리자가 켜기 전까지 컴퓨터 전체 접근이 꺼져 있고, Enterprise 플랜에서는 Owner가 Organization settings > Artifacts에서 켜기 전까지 기능 전체가 꺼져 있어요. 자세한 내용은 [Install an artifact as an app](https://support.claude.com/en/articles/18516354-install-an-artifact-as-an-app)에 있어요.
</NewsItem>

<NewsItem date="11월 24일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/ko/claude/c07-connectors/" tutorialLabel="C7 커넥터">
Claude가 연결해 둔 앱으로 파일을 보내거나, 그 앱이 제공하는 파일을 저장할 수 있게 됐어요(베타). 예를 들어 방금 만든 발표 자료를 클라우드 저장소에 올릴 수 있어요. 파일 전송은 Pro, Max, Ultra 플랜에 순차 배포 중이고, Team과 Enterprise 플랜에서는 Owner가 Organization settings > Connectors에서 켜기 전까지 꺼져 있어요. 도움말 문서 기준으로 Free 플랜은 나중에 지원될 예정이에요. 새 Claude 화면의 채팅(웹, Claude Desktop, iOS, Android)과 Claude Code에서 동작하고, 시크릿(incognito) 채팅과 예약 작업에서는 동작하지 않아요. 앱이 커넥터 디렉터리에 있고 개발사가 파일 지원을 추가한 경우에만 쓸 수 있어서, 직접 추가한 커스텀 커넥터에서는 안 돼요. Claude는 앱마다 첫 파일을 보내기 전에 물어봐요. 자세한 내용은 [Send files to connected apps and save files from them](https://support.claude.com/en/articles/18534325)에 있어요. 같은 날 월간 리캡(monthly recap, 설정의 Reflect)이 베타를 마쳤어요. Free, Pro, Max, Ultra 플랜에서 웹, Claude Desktop, iOS, Android로 볼 수 있어요. 지난 한 달 동안 Claude를 어떻게 썼는지 보여 주고, 메모리가 켜져 있을 때만 나타나요. 이제 Claude Code 세션과 클라우드의 Cowork 작업도 리캡에 반영되고, 저장된 리캡을 그 페이지에서 지울 수 있어요. 자세한 내용은 [See your monthly recap](https://support.claude.com/en/articles/15672559-see-your-monthly-recap)에 있어요.
</NewsItem>

<NewsItem date="11월 23일" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/ko/claude/c01-overview/" tutorialLabel="C1 Claude 한눈에 보기">
Claude Opus 4.5(`claude-opus-4-5-20251101`, 날짜 없는 ID `claude-opus-4-5` 포함)의 지원 중단(deprecated)이 예고됐고, Claude API에서 2027년 1월 22일에 퇴역해요. Anthropic은 Claude Opus 5.5(`claude-opus-5-5`)로 옮기라고 권해요. 다른 플랫폼은 날짜가 다를 수 있으니 [Model deprecations](https://platform.claude.com/docs/en/about-claude/model-deprecations) 페이지에서 확인하세요. 이와 별개로 Claude Sonnet 4.5는 예정대로 2026년 11월 30일에 퇴역해요. 같은 날 Enterprise Frontier Safeguards가 베타로 나왔어요. Claude Platform, Claude Platform on AWS, Claude Models on Google Cloud(Anthropic 관리형)에서 자격이 되는 조직이 쓸 수 있어요. Claude의 가장 뛰어난 모델들에 적용되는 Zero Data Retention으로, Anthropic은 프롬프트와 응답을 보관하지 않고 암호화된 사본이 조직의 클라우드 계정에 있는 버킷으로 가요. 자세한 내용은 [Enterprise Frontier Safeguards 문서](https://platform.claude.com/docs/en/manage-claude/enterprise-frontier-safeguards/overview)에 있어요.
</NewsItem>

<NewsItem date="11월 20일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/ko/claude/c18-automate-recurring/" tutorialLabel="C18 반복 업무 자동화">
2.1.330 버전부터 반복 예약 작업과 `/loop`가 세션이 계속 실행되는 동안 7일이 아니라 최대 30일까지 돌고, 끝날 때 알려 줘요. 이 버전 전에 만든 작업은 그대로 7일에 끝나요. 루트, 홈, 최상위 폴더, 작업 폴더를 겨냥한 `rm` 명령은 승인을 묻는 경우가 늘었고, 물어볼 사람이 없으면 거부돼요. easel이라는 기본 제공 mod가 생겨서, 요청하면 차트를 그리고 MCP 지표 결과 아래에도 차트를 그려요. macOS와 Linux에서 Pro, Max, 그리고 제공되는 경우 Team과 Enterprise가 쓸 수 있어요(자동 차트는 `/config`에서 꺼요). Anthropic의 Enterprise Admin Console로 관리되는 조직은 `claude auth login`으로 로그인하면 조직 설정이 적용돼요. `/login`이 보여 주는 로그인 링크가 훨씬 짧아졌고, 프롬프트 훅의 `model`에 `haiku`, `sonnet` 같은 모델 별칭을 쓸 수 있어요. 2.1.329에서 없앴던 `max_tokens` 자동 재시도도 이 버전에서 되돌아왔어요.
</NewsItem>

<NewsItem date="11월 20일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/ko/claude/c31-computer-use-team/" tutorialLabel="C31 Team·Enterprise 컴퓨터 사용">

<NewsItem date="11월 19일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/ko/coding/42-code-review-ai/" tutorialLabel="병합 전에 AI로 코드 리뷰하기">
같은 날 버전이 두 개 나왔어요. 2.1.328 버전에서는 대부분의 모델에서 `/code-review`가 버그와 `CLAUDE.md` 위반만 보고해요(재사용, 단순화, 효율 정리는 `/simplify`로 실행해요). 지적마다 Important, Pre-existing, Nit 표시가 붙고, 요약 끝에 수정 제안이 들어가요. 2.1.329 버전에서는 대상을 주지 않은 `/code-review`가 대부분의 모델에서 브랜치 전체를 기본 브랜치와 비교해 검토하고, `/code-review <PR 번호>`는 `gh pr diff`로 풀 리퀘스트를 읽거나 읽지 못하면 그렇다고 알려 줘요. 전에는 말없이 체크아웃된 브랜치를 검토하는 경우가 있었어요. auto 모드는 이제 Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry, Claude apps gateway의 Claude Opus 4.6과 Sonnet 4.6에서도 쓸 수 있고, 거기서 권한 모드를 정하지 않은 대화형 세션은 auto 모드로 시작해요(`disableAutoMode`로 끌 수 있어요). `"onFailure": "block"`은 `mcp_tool` 훅에서도 동작해요. `/tasks`에는 이 세션의 예약 작업, `/loop` 깨우기, 목표(goal), 대화의 포크가 함께 나오고, 신뢰 확인 창은 폴더의 훅이 어디에 선언돼 있는지 경고해 줘요. 업데이트한 뒤 확인할 것이 두 가지 있어요. 이전 버전에서 저장한 예약 작업은 로그인한 새 세션에서 대부분 다시 예약해야 하고, macOS의 컴퓨터 사용(computer use)은 더 새로운 안전 규칙을 따라서 일부 동작이 거부되고 일부 앱은 접근 범위가 줄어요. 2.1.329는 `~/.claude.json`이 가끔 기본값으로 초기화되던 문제와 macOS에서 로그아웃이 반복되던 문제도 고쳤어요.

<NewsItem date="11월 17일" channel="Claude Code" href="https://code.claude.com/docs/en/changelog" tutorial="/ko/coding/40-settings-permissions/" tutorialLabel="Claude Code 설정과 권한">
2.1.327 버전은 2.1.326에 이어 권한 확인을 더 엄격하게 해요. `/install-github-app`은 저장소를 바꾸기 전에 확인을 받고, `ExitWorktree`는 저장하지 않은 작업이 있을 수 있는 워크트리를 지우기 전에 물어보고, `/export`는 이미 있는 파일을 덮어쓰기 전에 물어봐요. 경로 확인에서 일부 심볼릭 링크를 거부하고, 작업 폴더 안으로 보는 범위가 바뀌어서 일부 경로는 이제 권한을 물어요. auto 모드는 `Bash(pnpm dlx *)`처럼 아무 패키지나 실행할 수 있는 허용 규칙을 더 많이 무시하고, 안내 문구에는 요금이 붙는 분류기 요청으로 대체하는 동작이 다음 릴리스에서 없어진다고 나와요(그 동작들은 대신 물어보거나 거부돼요). 설정 쪽에서는 `claude mcp add-json <이름> -`이 서버 JSON을 표준 입력으로 읽어서 토큰을 명령줄에 남기지 않을 수 있고, `/status`가 문제가 있는 에이전트, 스킬, 명령어, 키 바인딩 파일과 무시된 권한 설정을 목록으로 보여 주고, `/config`는 다른 설정이 해당 줄을 덮어쓸 때 알려 줘요. 전체 화면이 아닌 렌더러의 이름이 `/tui classic`으로 바뀌었어요(`/tui default`도 계속 동작해요). VS Code에서는 탐색기 오른쪽 클릭 메뉴의 "Claude Code: Add to Chat"으로 고른 파일과 폴더를 채팅에 @ 멘션할 수 있어요. 프로젝트 범위의 `claude mcp add`와 `claude mcp remove`가 `.mcp.json`의 다른 최상위 키를 지우던 문제도 고쳤어요.
</NewsItem>

<NewsItem date="11월 17일" channel="Claude 앱" href="https://support.claude.com/en/articles/12138966-release-notes" tutorial="/ko/claude/c22-desktop-app/" tutorialLabel="C22 데스크톱 앱 제대로 쓰기">
Claude Desktop에 릴리스 채널(release channel)이 생겼어요. 앱이 업데이트될 때 어떤 버전을 받을지 정하는 설정이에요. Stable이 기본값이고, 테스트를 더 거친 새 버전을 덜 자주 받아요. Latest는 하루에 한 번쯤 새 버전을 받아요. Mac과 Windows용 Claude에서 모든 요금제가 쓸 수 있고(4.29.0 버전 이상), 설정 > 데스크톱 앱(Settings > Desktop app)의 Release channel에서 바꿔요. Linux, Microsoft Store로 설치한 앱, IT 팀이 Claude 정책을 설정한 컴퓨터에서는 쓸 수 없어요. Stable로 되돌려도 버전이 내려가지 않아요. 더 새로운 Stable 버전이 나올 때까지 지금의 Latest 버전에 머물고, 그동안 Stable 업데이트를 받지 못해요. 자세한 내용은 [Install Claude Desktop](https://support.claude.com/en/articles/10065433-install-claude-desktop)의 "Choose a release channel" 항목에 있어요.
</NewsItem>

<NewsItem date="11월 17일" channel="API" href="https://platform.claude.com/docs/en/release-notes/overview" tutorial="/ko/claude/c16-api/" tutorialLabel="C16 Claude API 기초">
연결 결제(Linked billing)가 베타로 나왔어요(베타 헤더 `user-profiles-billing-2026-10-01`).
