- Slack에 AI를 붙이는 길은 두 가지예요. **Slack 자체의 AI**(요약, 검색 답변, 리캡, Slackbot)와 **Claude Tag**(채널에서 @Claude를 불러 일을 맡기는 기능)예요.
- Slack AI는 **내가 볼 수 있는 대화만** 사용한다고 안내돼요. 기능은 플랜에 따라 달라서 요약은 유료 플랜 전반, 검색 답변·리캡·번역·Slackbot은 Business+ 이상으로 안내돼요(2026-10-31 기준).
- Claude의 Slack 연동은 **2026-08-03부터 Claude Tag로 바뀌었어요.** Claude Team·Enterprise 플랜의 베타 기능이고, 개인 플랜(Free·Pro·Max)에서는 쓸 수 없다고 안내돼요.
- Claude Tag의 채널 작업은 **조직에 사용량 기준으로 과금**돼요. 설정은 Owner만 할 수 있어요.
- 어느 쪽이든 결과는 **출처를 눌러 원문을 확인**하고, 기밀이 든 채널은 AI에 넘길지 회사 규정부터 확인하세요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 긴 채널·스레드를 **요약**하고, 자연어로 **검색 답변**을 받는 방법을 알 수 있어요.
- 내 플랜과 관리자 설정에서 **어떤 AI 기능이 보이는지** 판단할 수 있어요.
- Slackbot에게 일을 맡기는 프롬프트를 쓰고, **반복 작업(Tasks)** 개념을 이해할 수 있어요.
- Claude Tag가 무엇이고 **누가 설정하고 누구에게 비용이 가는지** 알고, 도입 전에 확인할 것을 정리할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Slack AI** | Slack에 들어 있는 AI 기능 묶음이에요. 대화 요약, 검색 답변, 리캡, 파일 요약, 번역, 허들 노트, Slackbot 등이 있어요. |
| **Slackbot** | Slack이 소개하는 "개인용 업무 에이전트"예요. 내가 볼 수 있는 Slack 정보를 바탕으로 질문에 답하고 문서 초안 등을 만들어요. |
| **리캡(Recap)** | 선택한 채널에서 놓친 내용을 매일 아침 요약해 주는 기능이에요. |
| **Claude Tag** | 채널에서 @Claude를 태그해 일을 맡기는 Claude의 Slack 기능이에요. Team·Enterprise 플랜에서 베타로 안내돼요. |
| **Owner(소유자)** | Claude 조직에서 Claude Tag의 접근과 채널을 설정할 수 있는 역할이에요. Admin 역할은 설정할 수 없다고 안내돼요. |

Claude 도움말에 따르면 "Claude in Slack"은 2026-08-03에 새 Claude Tag로 바뀌었어요. 그 전에 쓰던 설명을 따라 하기보다, 아래 Claude Tag 안내를 기준으로 확인하세요.
</Aside>

## Slack 자체의 AI

### 플랜별 기능 (2026-10-31 기준)

Slack 도움말의 표를 풀어서 정리했어요. 표에서 열 정렬을 글로만 확인한 항목이 있어서, 내 워크스페이스에 실제로 보이는지는 꼭 확인하세요.

| 기능 | 어떤 플랜에서 안내되나요 |
| --- | --- |
| 대화(채널·DM)·스레드 요약, 허들 노트, 자동 검색 필터 | Pro, Business+, Enterprise+ |
| 검색 답변, 리캡, 파일 요약, 번역, 워크플로 자동화, 캔버스 콘텐츠 생성 | Business+, Enterprise+ |
| Slackbot | Business+, Enterprise+ (Pro 등은 제한적 미리보기일 수 있다고 안내돼요) |
| 엔터프라이즈 검색 | Enterprise+ |

- 구버전 Business+나 Slack AI 추가 상품이 없는 Enterprise Grid는 Pro 기능만 쓸 수 있다고 안내돼요.
- 가격은 이 글에서 다루지 않아요. 공식 도움말은 가격을 Slack 요금 페이지나 영업팀에서 확인하라고 안내해요.
- 한국어로 된 대화를 요약할 때의 품질, 지원 언어 범위는 이번에 공식 문서에서 확인하지 못했어요. 직접 써 보고 판단하세요.

<Aside type="caution" title="관리자가 끌 수 있어요">
워크스페이스의 소유자와 관리자는 AI 기능을 제한하거나 끌 수 있어요. 기능이 보이지 않으면 플랜뿐 아니라 관리자 설정도 확인하세요.
</Aside>

### 자주 쓰는 기능과 위치

| 하고 싶은 일 | 위치 (데스크톱) |
| --- | --- |
| 채널·DM 요약 | 대화 위 점 세 개 아이콘 > **Summarize channel** 또는 **Summarize conversation** |
| 스레드 요약 | 스레드 위 **Summarize** |
| 검색 답변 | 검색창에 질문을 쓰고 Enter. 결과 위에 AI 답변과 출처가 나와요 |
| 놓친 내용 모아 보기 | 사이드바 **Recap**. 포함할 채널은 **Manage Recap**에서 정해요 |
| 파일 요약 | .pdf .docx .pptx .xlsx 파일이 올라오면 자동 요약. 끄기: 프로필 > Preferences > **AI** |
| 메시지 번역 | 프로필 > Preferences > Language & region에서 번역 언어를 정한 뒤, 메시지의 점 세 개 > **Translate message** |
| Slackbot | 오른쪽 위 또는 사이드바의 **Slackbot** |

요약은 안 읽은 메시지, 최근 7일, (데스크톱에서) 직접 정한 기간 중에서 골라요. 요약과 답변에는 출처를 보는 **More details**나 인용이 붙어요.

### Slackbot에게 일 맡기기

Slackbot 도움말은 프롬프트를 **짧고 정확하게** 쓰고, 참고할 채널·파일 링크 같은 맥락을 포함하라고 안내해요. 주제가 바뀌면 새 대화를 시작하라고도 해요.

<PromptBox>
#프로젝트-런칭 채널에서 지난 7일 동안 결정된 사항과 아직 결정되지 않은 사항을 나눠서 정리해 줘. 각 항목마다 근거가 된 메시지 링크를 붙이고, 내가 답해야 할 질문이 있으면 따로 모아 줘.
</PromptBox>

<PromptBox>
오늘 오후 3시 팀 회의를 위한 안건 초안을 만들어 줘. #팀-주간 채널의 이번 주 대화와 아래 캔버스 링크의 지난 회의록을 참고하고, 안건은 5개 이내로, 각 안건마다 논의할 질문 1개씩 적어 줘.

[지난 회의록 캔버스 링크]
</PromptBox>

<PromptBox>
이 스레드의 논의를 읽고 합의된 내용, 이견이 남은 내용, 다음 단계와 담당자를 표로 정리해 줘. 스레드에 없는 담당자나 날짜는 만들지 말고 "미정"으로 적어 줘.
</PromptBox>

- Slackbot이 캔버스를 수정하려 하면 **Confirm을 눌러야** 내용이 추가되고, **Cancel**을 누르면 바뀌지 않는다고 안내돼요. 작업 중 방향이 틀리면 **Stop**으로 멈출 수 있어요.
- **Tasks**로 반복 작업을 만들 수 있어요(예: 매주 안건 초안). 작업당 하루 최대 3번 실행된다고 안내돼요.
- **Deep research**를 켜면 채널·파일·웹 등 여러 소스를 모아 더 긴 보고서를 만든다고 안내돼요.
- 메시지 수와 쓸 수 있는 기능은 플랜별로 다르고, 한도는 별도 도움말(Slackbot limits and credit usage)에 있어요. 이 글에서는 열어 확인하지 못했어요.

### Slack AI의 데이터 처리 (Slack 도움말 기준)

- AI 기능은 **그 시점에 내가 접근할 수 있는 데이터만** 써요. 내가 속하지 않은 비공개 채널이나 DM은 요약·검색 답변·Slackbot 응답에 나오지 않는다고 안내돼요.
- 고객 데이터는 Slack이 제어하는 인프라를 벗어나지 않고, LLM 학습에 쓰이지 않는다고 안내돼요.
- 대화 요약과 검색 답변은 일시적인 응답으로 저장되지 않고, 리캡 데이터는 90일 보관된다고 안내돼요. 워크플로가 만든 채널 요약은 조직의 보관 설정을 따라요.

## Claude Tag: 채널에서 @Claude에게 일 맡기기

### 무엇이고 누가 쓰나요

Claude 도움말에 따르면 Claude Tag는 Slack에서 **세 가지 접점**을 가져요.

- **채널 태그**: 채널에서 @Claude를 불러 일을 맡기고, 스레드에서 진행 과정을 같이 봐요.
- **DM**: @Claude와 일대일로 대화해요.
- **AI 어시스턴트 패널**: Slack의 AI 어시스턴트 머리글에서 Claude 아이콘을 눌러 열어요.

| 항목 | 안내된 내용 (2026-10-31 기준) |
| --- | --- |
| 플랜 | **Team, Enterprise**. 베타. Free, Pro, Max, Ultra 같은 개인 플랜에서는 쓸 수 없어요. |
| 채널 작업의 신원·비용 | Claude가 조직의 신원으로, 관리자가 그 채널에 설정한 도구와 접근 범위 안에서 일해요. 비용은 **조직**에 청구돼요. |
| DM·패널 | 내 Claude 계정에 켜 둔 기능(웹 검색, 연결한 도구 등)으로 일해요. |
| Claude 좌석 | Slack 사용자마다 Claude 좌석이 필요하지 않아요. 채널 작업은 사용량 기준이고 좌석당 추가 요금이 없다고 안내돼요. |
| 설정 권한 | **Primary Owner 또는 Owner**만 해요. Admin 역할은 안 돼요. |
| 처음 접근 범위 | 외부 시스템에 대한 접근 없이 시작하고, 관리자가 필요한 서비스를 연결해요. |
| 실행 환경 | 내 컴퓨터가 아니라 임시 샌드박스에서 실행돼요. |

### 비용과 접근 통제 (관리자가 확인할 것)

- 비용은 **사용량 기반**이에요. 조직 전체 한도와 채널별 한도를 둘 수 있고, 한도의 75%와 95%에서 관리자에게 알림이 간다고 안내돼요. 한도를 넘는 작업은 조용히 잘리지 않고 거절돼요.
- **누가 쓸 수 있는지**는 Member Access에서 정해요: Slack 워크스페이스 전체, Claude 조직 구성원만, 또는 역할에 따라(Enterprise).
- 접근 범위는 조직, 워크스페이스, 비공개 채널 세 단계로 나눠 설정하고, 민감한 연결은 비공개 채널에 따로 둘 수 있어요.
- **게스트가 있는 채널**은 기본값이 Restrict라서 Claude가 응답하지 않아요.
- **메모리**: Claude Tag는 채널·워크스페이스별로 맥락을 기억하고, Owner가 보고 수정·삭제할 수 있어요.
- **활동 기록**: Owner는 Organization settings > Claude Tag > Activity에서 예약·일회성 작업과 네트워크 호출을 볼 수 있어요.
- Slack에서 시작한 대화는 Claude 대화 기록과 분리되고, Slack 보관 정책을 따라요. 연동을 끊거나 앱을 지우면 30일 안에 Claude 쪽 대화가 삭제된다고 안내돼요.

개인 사용자는 직접 설정할 수 없어요. 회사에서 Claude Tag를 쓰고 싶다면 Claude 조직의 Owner에게 요청하세요.

### 채널에서 부르는 프롬프트 예시

<PromptBox>
@Claude 이 채널에 있는 이번 주 고객 문의 스레드를 읽고 문의 유형별로 건수를 세어 줘. 같은 문제가 반복되는 것이 있으면 따로 표시하고, 근거가 된 스레드 링크를 붙여 줘. 내용을 추측하지 말고 스레드에 있는 것만 사용해.
</PromptBox>

<PromptBox>
@Claude 위 스레드에서 합의된 내용을 결정 기록 문서 초안으로 정리해 줘. 결정 사항, 이유, 담당자, 기한 항목으로 나누고, 스레드에 없는 정보는 "미정"으로 적어 줘. 문서는 올리기 전에 내게 먼저 보여 줘.
</PromptBox>

공식 문서는 Claude Tag가 모니터링 확인, 문의 분류, 문서 속 답 찾기, 데이터 질문, 스레드를 문서·티켓으로 정리하기, 버그 수정 초안 같은 일에 쓰인다고 소개해요. 문서 검색이나 데이터 질문처럼 외부 서비스가 필요한 일은 **관리자가 해당 연결을 설정해 둬야** 해요.

  '(해당될 때) 우리 조직의 Claude Tag 설정과 접근 범위를 관리자에게 확인했어요',
]} />

<Steps>

1. **내 워크스페이스에서 보이는 기능 확인하기**

   채널 위 점 세 개 메뉴에 **Summarize channel**이 있는지, 사이드바에 **Recap**과 **Slackbot**이 있는지 봐요. 안 보이면 플랜이나 관리자 설정 때문일 수 있어요.

2. **채널이나 스레드를 요약하고 출처 확인하기**

   범위를 안 읽은 메시지나 최근 7일로 정해 요약을 만들어요. **More details**를 눌러 어떤 메시지가 근거인지 확인하세요. 요약에서 빠진 중요한 메시지가 있는지 원문도 훑어보세요.

3. **검색창에 질문하기**

   "지난주 마케팅 회의 슬라이드 누가 올렸지?"처럼 일상 말로 물어요. 답변 위의 인용에 마우스를 올려 원문을 미리 보고, 다른 사람에게 공유하기 전에는 내용을 한 번 읽고 **Share anyway**를 누르세요.

4. **Slackbot에게 정리를 맡기고 대조하기**

   위의 프롬프트를 가상 채널에서 시험해 보세요. 담당자·날짜·숫자가 원문에 있는 것인지 대조하세요.

5. **리캡 설정하기 (선택)**

   **Recap**을 열어 포함할 채널을 고르고 켜면 매일 아침 요약이 와요. 요약 대상 채널을 뮤트할지도 선택할 수 있어요. 보관 기간(90일)을 알고 쓰세요.

6. **Claude Tag 도입 전 점검하기 (해당되는 조직)**

   Owner에게 아래를 물어보세요: 어떤 채널에서 켜는지, 누가 쓸 수 있는지, 한도는 얼마인지, 게스트 채널은 어떻게 하는지, 연결된 도구는 무엇인지. 연습 채널에서 먼저 시작하고 비용과 결과를 보면서 넓히는 걸 권장해요.

</Steps>

## 개인정보·기밀 주의

Slack에는 고객 정보, 인사 이야기, 계약 내용이 섞여 있어요. 더 자세한 원칙은 [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)에 있어요.

- **회사 규정이 우선**이에요. AI 기능을 켜기 전에 정보보안 담당자나 관리자에게 승인된 범위를 확인하세요.
- Slack AI는 내가 볼 수 있는 대화만 쓰지만, 요약을 **다른 사람에게 공유하면** 내가 볼 수 있던 내용이 그들에게도 전달돼요. 비공개 채널의 내용이 섞이지 않았는지 공유 전에 보세요.
- Claude Tag의 **채널 작업은 모두가 볼 수 있는 스레드**에서 진행돼요. 민감한 요청은 공개 채널이 아닌 곳에서 하세요.
- 주민등록번호, 계좌·카드번호, 비밀번호는 Slack 대화에도 AI에도 넣지 마세요.
- 인사 평가, 징계, 법적 분쟁 같은 주제의 요약·판단은 사람이 최종 결정하세요.

## 자주 막히는 지점

### Summarize나 Slackbot이 보이지 않아요

- **원인**: 플랜에 포함되지 않았거나 관리자가 접근을 제한했을 수 있어요. 게스트는 기능이 다를 수 있다고 안내돼요.
- **해결**: 워크스페이스 관리자에게 AI 기능 접근 설정을 물어보세요.

### 요약에 빠진 내용이 있어요

- **원인**: 선택한 기간에 포함되지 않았거나, AI가 중요하다고 보지 않았을 수 있어요.
- **해결**: 기간을 넓히고 More details로 근거를 확인하세요. 중요한 결정은 원문을 직접 읽으세요.

### 개인 Claude 계정(Free·Pro·Max)으로 Slack 연동을 하고 싶어요

- **원인**: Claude Tag는 Team·Enterprise 플랜용이고 개인 플랜에서는 쓸 수 없다고 안내돼요.
- **해결**: 개인 플랜에서 Slack과 연결하는 별도의 공식 경로는 이번에 확인하지 못했어요. 대화 내용을 복사해 Claude 대화에 붙여넣어 요약을 맡기는 방법이 있지만, **붙여넣기 전에 개인정보와 기밀을 가리세요.**

### @Claude가 채널에서 응답하지 않아요

- **원인**: 해당 채널에 Claude가 추가되지 않았거나, Member Access 설정으로 제한됐거나, 게스트가 있는 채널의 기본값(Restrict)일 수 있어요. 한도에 도달했을 수도 있어요.
- **해결**: Owner에게 채널 구성과 한도를 확인해 달라고 요청하세요. 한도 때문이면 Slack 안에서 관리자에게 추가를 요청할 수 있다고 안내돼요.

### 비용이 얼마나 나올지 모르겠어요

- **원인**: 좌석제가 아니라 사용량 기반이에요.
- **해결**: 작은 한도로 시험 운영을 하고 채널별 사용량 내역을 확인한 뒤 조정하세요.

## 실전 팁

- **기간과 범위를 지정**: "최근 7일", "이 스레드만"처럼 범위를 정하면 쓸모 있는 요약이 나와요.
- **출처 링크를 요청**: 결과에 근거 메시지 링크를 붙이게 하면 확인이 쉬워요.
- **모르는 건 '미정'으로**: 담당자·날짜를 지어내지 않도록 프롬프트에 적어 두세요.
- **작게 시작**: 반복 작업(Tasks)이나 Claude Tag는 연습 채널에서 먼저 시험하세요.
- **공유 전 읽기**: AI 답변을 채널에 올리기 전에 한 번 읽어 보세요.
