<Summary>
- 구글 시트에서 **확장 프로그램 > Apps Script**를 고르면 그 스프레드시트에 묶인(바운드) 스크립트가 열려요. 바운드 스크립트는 사용자 지정 메뉴를 만들고, 파일을 열 때 반응할 수 있어요.
- 시트에 AI를 붙이는 방법은 **두 가지로 달라요**. 하나는 구글이 만든 Gemini(Ask Gemini 패널, `=AI()` 함수)이고, 다른 하나는 **내 스크립트가 `UrlFetchApp`으로 Claude API 같은 AI API를 직접 부르는 방식**이에요.
- API를 직접 부를 때 API 키는 코드나 셀이 아니라 **스크립트 속성**(프로젝트 설정)에 보관해요.
- 셀 안의 사용자 지정 함수는 **30초 제한**이 있고, 일반 스크립트 실행은 6분이에요(공식 할당량 페이지, 2026-11-01 기준). AI 호출은 **사용자 지정 메뉴**로 시작하는 편이 안전해요.
- 이 글의 예제 코드는 **직접 실행해 보지 않았어요**. 출처에 적은 공식 문서를 바탕으로 조립했으니, 가상 데이터를 넣은 복사본에서 먼저 시험해 보세요.
</Summary>

<Aside type="caution" title="API 사용료는 따로 청구되고, 셀 내용이 구글 밖으로 나가요">
스크립트에서 Claude API를 부르면 고른 셀의 글이 Anthropic의 API로 전송돼요. API는 사용한 만큼 청구되고 Claude 구독과는 별개예요. 이 글은 가격을 다루지 않으니 공식 가격 페이지에서 직접 확인하세요. 개인정보나 기밀이 든 셀은 보내지 마세요. [개인·회사 정보를 지키며 AI 쓰기](/ko/basics/05-privacy-safety/)를 참고하세요.
</Aside>

## 이 글을 읽고 나면

- 스프레드시트에서 Apps Script 편집기를 열고 첫 스크립트를 실행할 수 있어요.
- **시트에 내장된 Gemini**와 **내 스크립트의 AI API 직접 호출**의 차이를 설명하고, 상황에 맞게 고를 수 있어요.
- 선택한 셀을 Claude에게 보내 옆 칸에 답을 적어 주는 사용자 지정 메뉴를 만들 수 있어요.
- API 키를 안전하게 보관하고 주요 한도(시간, 하루 할당량)를 이해해요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Apps Script** | 시트 같은 Workspace 앱을 확장하는 구글의 JavaScript 기반 도구예요. 브라우저 편집기에서 코드를 써요. |
| **바운드 스크립트** | **확장 프로그램 > Apps Script**로 만든, 스프레드시트 하나에 붙은 스크립트예요. 메뉴는 바운드 스크립트만 만들 수 있어요. |
| **사용자 지정 메뉴** | `onOpen` 함수에서 추가하는 메뉴예요. 항목마다 스크립트의 함수가 실행돼요. |
| **사용자 지정 함수** | 스크립트에 쓴 뒤 `=DOUBLE(A1)`처럼 셀에서 쓰는 함수예요. 일반 스크립트보다 제약이 커요. |
| **스크립트 속성** | 편집기 **프로젝트 설정**에서 여는 프로젝트용 키-값 저장소예요. 공식 문서는 주로 설정값 보관에 쓴다고 설명해요. |
| **UrlFetchApp** | 웹 주소(API)를 요청하는 Apps Script 서비스예요. |
| **시트의 Gemini / `=AI()`** | 시트 안에 들어 있는 구글의 AI 기능이에요. 구글 쪽에서 실행되고, 코드를 쓰거나 API 키를 관리할 필요가 없어요. |

### 시트에 AI를 붙이는 두 가지 방법

| | 시트에 내장된 Gemini | 내 스크립트로 API 호출 |
| --- | --- | --- |
| 위치 | Ask Gemini 패널, `=AI()` 함수 | Apps Script로 만든 사용자 지정 메뉴나 버튼 |
| 코드 | 필요 없음 | 필요함 (JavaScript) |
| 필요 조건 | 자격 있는 Google Workspace 또는 Google AI 요금제 | 해당 AI 서비스의 API 키와 직접 관리할 스크립트 |
| 장점 | 설정 없이 바로 | 프롬프트, 모델, 결과가 들어갈 위치를 내가 정해요 |
| 주의 | 요금제와 관리자 설정에 따라 쓸 수 있는지 달라요 | 키, 비용, 할당량을 직접 관리해야 해요 |

내장 Gemini 기능은 [엑셀·구글 시트에 AI 붙이기](/ko/automation/23-spreadsheet-ai/)와 [구글 Workspace와 Gemini](/ko/automation/19-google-workspace-gemini/)에서 다뤄요. 이 글은 오른쪽 열에 집중해요.

<Aside type="note" title="스크립트 작성도 Gemini가 도와줄 수 있어요">
구글 Apps Script 문서에는 코드를 생성·수정·디버깅해 주는 **스크립트 편집기의 Gemini 사이드 패널**이 나와요. 2026-11-01 기준 그 페이지는 Gemini 베타 프로그램에 등록된 고객만 쓸 수 있다고 하고, 라이선스 조건과 관리자 설정을 안내해요. 쓸 수 없다면 아래 코드를 붙여 넣거나, 아무 대화형 AI에게 한 줄씩 설명해 달라고 해도 돼요.
</Aside>

1. **스프레드시트에서 편집기 열기**

   구글 시트에서 **확장 프로그램 > Apps Script**를 고르세요. 이 스프레드시트에 묶인 스크립트가 만들어져요. 공식 가이드는 바운드 스크립트가 사용자 인터페이스를 바꾸거나 스프레드시트가 열릴 때 반응할 수 있다고 설명해요.

   <ScreenshotPlaceholder caption="구글 시트의 확장 프로그램 > Apps Script" officialUrl="https://developers.google.com/apps-script/guides/sheets" />

2. **첫 테스트 함수 실행**

   기본 코드를 지우고 공식 가이드를 바탕으로 한 아래 짧은 예제를 붙여 넣으세요. 시트의 데이터를 읽어 로그에 적어요.

   ```javascript
   function logRows() {
     const sheet = SpreadsheetApp.getActiveSheet();
     const data = sheet.getDataRange().getValues();
     for (let i = 0; i < data.length; i++) {
       Logger.log('Row ' + (i + 1) + ': ' + data[i][0]);
     }
   }
   ```

   **실행**을 누르면 처음에는 코드가 쓰는 서비스에 대한 권한 승인 창이 떠요. 공식 문서에 따르면 필요한 권한은 코드를 스캔해서 정해지고, 나중에 구글 계정 설정에서 접근 권한을 해제할 수 있어요. 그다음 **실행 로그**에서 출력을 확인하세요.

3. **API 키를 스크립트 속성에 저장**

   편집기 왼쪽의 **프로젝트 설정**을 누르고, **스크립트 속성**에서 **스크립트 속성 추가**를 골라 속성 이름에 `ANTHROPIC_API_KEY`, 값에 키를 붙여 넣은 뒤 **스크립트 속성 저장**을 누르세요. (공식 가이드는 이 방법으로 최대 50개까지 추가할 수 있다고 해요.)

     { where: 'Apps Script 편집기', action: '왼쪽 메뉴에서 프로젝트 설정 클릭', result: '설정 페이지가 열려요' },

   키를 셀, 코드, 스크린샷에 붙여 넣지 마세요. 키가 유출됐다고 의심되면 Claude Console에서 삭제하고 새로 만드세요.

   (화면 문구는 영어 UI 기준 이름을 한국어로 옮긴 것이에요. 한국어 UI의 실제 표기는 공식 문서에서 확인하지 못했어요.)

4. **Claude를 부르는 함수 추가**

   이 함수는 Anthropic Messages API 문서의 요청 형식(`POST https://api.anthropic.com/v1/messages`, `x-api-key`·`anthropic-version`·`content-type` 헤더)과 구글 레퍼런스의 `UrlFetchApp.fetch` 옵션(`method`, `contentType`, `headers`, `payload`, `muteHttpExceptions`)을 따라요.

   ```javascript
   const MODEL = 'claude-sonnet-5-5'; // 사용 전에 현재 모델 목록을 확인하세요

   function askClaude_(prompt) {
     const key = PropertiesService.getScriptProperties().getProperty('ANTHROPIC_API_KEY');
     if (!key) {
       throw new Error('Add ANTHROPIC_API_KEY in Project Settings > Script Properties.');
     }
     const response = UrlFetchApp.fetch('https://api.anthropic.com/v1/messages', {
       method: 'post',
       contentType: 'application/json',
       headers: { 'x-api-key': key, 'anthropic-version': '2026-10-21' },
       payload: JSON.stringify({
         model: MODEL,
         max_tokens: 200,
         messages: [{ role: 'user', content: prompt }],
       }),
       muteHttpExceptions: true,
     });
     const code = response.getResponseCode();
     if (code !== 200) {
       throw new Error('API error ' + code + ': ' + response.getContentText().slice(0, 200));
     }
     const data = JSON.parse(response.getContentText());
     return data.content[0].text.trim();
   }
   ```

   공식 문서에서 확인한 점(2026-11-01 기준)이에요.

   - Claude API는 `anthropic-version` 헤더가 필요해요. 버전 페이지는 가능하면 최신인 `2026-10-21`을 쓰라고 권해요. 이 버전에서는 `temperature`, `top_p`, `top_k` 매개변수가 제거됐다고 안내해서, 코드에 넣지 않았어요.
   - 모델 ID `claude-sonnet-5-5`는 모델 개요 페이지에 나와 있어요. 모델 라인업은 바뀌니 쓰기 전에 그 페이지를 확인하세요.
   - 응답은 블록 목록인 `content`에 들어 있고, 글로 된 답이면 첫 블록의 `text`에 있어요.
   - `muteHttpExceptions: true`로 두면 `fetch`가 예외를 던지지 않고 응답을 돌려줘서, 읽기 쉬운 오류 메시지를 만들 수 있어요.

5. **선택한 셀을 분류하는 사용자 지정 메뉴 추가**

   ```javascript
   function onOpen() {
     SpreadsheetApp.getUi()
       .createMenu('AI tools')
       .addItem('Classify selected reviews', 'classifySelected')
       .addToUi();
   }

   function classifySelected() {
     const range = SpreadsheetApp.getActiveRange();
     const values = range.getValues();
     const results = values.map(function (row) {
       const text = String(row[0]).trim();
       if (!text) return [''];
       const prompt =
         'Classify this customer review as Praise, Complaint, or Question. ' +
         'Answer with one word only.\n\nReview: ' + text;
       return [askClaude_(prompt)];
     });
     range.offset(0, 1, results.length, 1).setValues(results);
   }
   ```

   스크립트를 저장하고 스프레드시트를 새로고침하세요. 공식 메뉴 가이드는 파일을 열 때 메뉴가 보이게 하려면 `onOpen`에 메뉴 코드를 쓰라고 해요. **AI tools** 메뉴가 생겨요. A열의 후기 셀(예: A2:A6)을 선택하고 **AI tools > Classify selected reviews**를 고르세요. 처음에는 외부 서비스에 접속하므로 권한 승인을 물어요.

   <PromptBox>
   이 Apps Script 코드를 초보자도 알 수 있게 한 줄씩 설명해 줘. 내 스프레드시트에서 어떤 데이터가 밖으로 나가는지, API 키는 어디에서 읽는지, API가 오류를 돌려주면 어떻게 되는지도 알려 줘.
   </PromptBox>

6. **결과와 로그 확인**

   B열의 라벨이 후기와 맞는지 비교하세요. 오류가 나면 편집기의 **실행 내역**이나 **실행 로그**를 열어 보세요. 위 코드는 HTTP 상태 코드가 든 오류를 던지므로, 키 문제인지 사용량 제한인지 구분하기 쉬워요.

7. **한 번에 적은 양만 돌리기**

   위 함수는 셀마다 요청을 하나씩 차례로 보내요. 처음에는 5~10칸으로 시작하세요. 구글 할당량 페이지에는 실행당 시간 제한과 URL Fetch 호출의 하루 한도가 있어요(아래 표). 수백 행이 필요하면 나눠서 돌리거나 개발자에게 도움을 요청하세요.

</Steps>

| URL Fetch 호출 | 하루 20,000회(개인 계정), 100,000회(Workspace 계정) | 예제 코드는 셀당 요청 1회 |
| URL Fetch 응답 크기 | 호출당 50 MB | |
| 트리거 총 실행 시간 | 하루 90분(개인), 6시간(Workspace) | 시간 기반 트리거를 추가할 때 중요해요 |

할당량은 바뀔 수 있어요. 현재 값은 [공식 할당량 페이지](https://developers.google.com/apps-script/guides/services/quotas)에서 확인하세요.

### 메뉴로 할까, 사용자 지정 함수로 할까?

| | 사용자 지정 메뉴 (이 글) | 셀 안의 사용자 지정 함수 |
| --- | --- | --- |
| 실행 방식 | 메뉴 항목을 눌러 실행 | 셀이 계산될 때 시트가 호출 |
| 시간 제한 | 6분 | 30초 |

| AI 호출에 적합한가 | 적합: 실행 시점을 내가 정해요 | 위험: 재계산 때 호출이 반복될 수 있어요 (공식 설명이 아니라 이 사이트의 주의 사항) |

## 자주 막히는 지점

### 메뉴가 안 보여요

- **원인**: 스크립트가 이 스프레드시트에 묶여 있지 않거나(script.new로 만든 경우), `onOpen`이 아직 실행되지 않았어요.
- **해결**: 시트 안에서 **확장 프로그램 > Apps Script**로 스크립트를 만들고, 저장한 뒤 스프레드시트를 새로고침하세요. 메뉴는 바운드 스크립트만 만들 수 있어요.

### "ANTHROPIC_API_KEY" 오류나 HTTP 401이 나와요

- **원인**: 속성 이름이 다르거나, 값에 공백이 섞였거나, 키가 삭제됐어요.
- **해결**: 프로젝트 설정 > 스크립트 속성에서 이름을 확인하고, 필요하면 Claude Console에서 새 키를 만드세요.

### 중간에 멈추거나 시간이 초과됐다고 해요

- **원인**: 한 번에 너무 많은 셀을 돌렸거나, 사용자 지정 함수(30초 제한)에서 시작했어요.
- **해결**: 한 번에 선택하는 셀을 줄이고, 셀 수식 대신 메뉴를 쓰세요.

### 결과가 들쭉날쭉하거나 틀려요

- **원인**: 프롬프트가 느슨하거나 후기가 모호해요.
- **해결**: 지시를 더 엄격하게 쓰고(정해진 라벨, 한 단어만), 몇 행으로 시험하고, 결과는 직접 확인하세요. [프롬프트 잘 쓰는 법](/ko/claude/c04-prompting/)을 참고하세요.

### 키 관리나 코드 없이 구글 내장 AI를 쓰고 싶어요

- **원인**: 키를 관리하거나 코드를 쓰고 싶지 않아요.
- **해결**: 요금제에 포함돼 있다면 Ask Gemini 패널이나 `=AI()` 함수를 써 보세요. [엑셀·구글 시트에 AI 붙이기](/ko/automation/23-spreadsheet-ai/)를 참고하세요.

## 실전 팁

- **복사본에서 작업하세요.** 스크립트는 셀을 덮어쓸 수 있고 되돌리기 어려운 변경도 있어요. 복제한 시트에서 시험하세요.
- **키는 비밀번호처럼 다루세요.** 스크립트 속성에 보관하고, 쓰면 안 되는 사람과 스크립트를 공유하지 말고, 채팅에 키를 붙여 넣지 마세요. 공식 문서에서는 스크립트 속성을 누가 읽을 수 있는지 확인하지 못했으니, 편집자 수를 줄이는 것은 이 사이트의 권장 사항이에요.
- **필요한 것만 보내세요.** AI가 읽어야 하는 셀만 넘기고, 이름·주소·사람을 알아볼 수 있는 숫자는 보내지 마세요.
- **사용량을 기록하세요.** 보낸 셀 수를 세어 두면 청구액을 짐작할 수 있어요. API 가격은 이 글이 아니라 공식 가격 페이지에 있어요.
- **실행하지 않은 코드라는 점을 기억하세요.** 이 글의 예제는 직접 실행하지 않았어요. 실제 업무에 쓰기 전에 연습 데이터로 직접 돌려 보세요.
- **API 기본을 익히세요.** [C16. Claude API](/ko/claude/c16-api/)에서 키, 호출, 비용을 다뤄요.
