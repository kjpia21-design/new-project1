<Summary>
- 흐름은 **뽑을 항목 정하기 → PDF 몇 개 올리기 → 청구서(또는 품목) 한 줄씩 표로 받기 → 모든 숫자 검산 → 시트에 붙이기**예요.
- Claude는 PDF(와 CSV, XLSX 등)를, Gemini는 대부분의 파일 형식을 받아요. 우리가 읽은 ChatGPT 문서에는 파일과 이미지를 첨부한다는 설명만 있고 업로드 한도는 없어요(2026-11-04 확인).
- Anthropic 설명으로 Claude는 100쪽 이하 PDF는 텍스트와 시각 요소를, 101~1,000쪽은 텍스트만 분석해요. Gemini는 한 번에 파일 10개까지 올릴 수 있어요.
- **PDF에는 거래처 이름, 계좌 정보, 단가가 들어 있는 경우가 많아요.** 서비스에 올려도 되는 문서인지 확인하고, 표에 필요 없는 정보는 가리세요.
- **AI는 숫자를 잘못 읽거나 지어낼 수 있어요.** 장부에 넣기 전에 합계를 직접 다시 계산하세요. 이 글의 연습은 실제 청구서로 실행하지 않았어요. 프롬프트와 예시 표는 이 사이트가 만든 예시예요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- PDF 청구서·명세서 묶음을 내가 고른 항목의 **표 하나**로 바꿀 수 있어요.
- 매번 같은 열로 결과가 나오고, 없는 값은 추측하지 않고 표시하게 하는 추출 프롬프트를 쓸 수 있어요.
- 올리기 전에 어떤 정보를 지울지 판단할 수 있어요.
- 몇 가지 간단한 확인으로 **결과를 검산**해서 틀린 숫자가 장부에 들어가지 않게 할 수 있어요.

종이 영수증 사진과 가계부는 [AI로 가계부·영수증 정리하기](/ko/automation/46-budget-sheet/)를 보세요. 이 글은 PDF, 청구서, 표에 집중해요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **추출** | AI가 문서를 읽고 고른 항목(청구서 번호, 날짜, 합계)을 구조화된 표로 옮기는 일. |
| **항목(필드)** | 뽑고 싶은 데이터 하나. 예: 거래처명, 지급 기한. 목록은 내가 정해요. |
| **텍스트 PDF와 스캔 PDF** | 텍스트 PDF는 글자를 선택할 수 있어요. 스캔 PDF는 페이지 사진이라 AI가 이미지를 읽어야 해서 오류가 더 쉽게 생겨요. |
| **품목(라인 아이템)** | 청구서 합계가 아니라 개별 줄(상품, 수량, 단가). |
| **대조(검산)** | 뽑은 숫자가 맞는지 확인하는 일. 예: 품목 금액의 합이 소계와 같은지. |

<Aside type="caution" title="올리기 전에">
청구서와 명세서에는 고객·거래처 이름, 주소, 사업자 번호, 계좌번호가 들어 있을 수 있어요. 먼저 회사나 고객사의 규정을 확인하고 [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)를 읽으세요. 공유해도 되는지 모르겠다면 올리지 마세요.
</Aside>

<Aside type="note" title="참고할 점 (2026-11-04 기준)">
- 이 글은 머리말의 공식 문서 5개를 바탕으로 해요. 실제 계정에서 단계를 실행해 보지는 않았으니, 메뉴 이름은 도움말 기준이에요.
- 어느 서비스가 청구서나 표를 얼마나 정확히 읽는지에 대한 공식 수치는 찾지 못했고 직접 시험하지도 않았어요. 뽑은 값은 모두 초안으로 보세요.
- Anthropic의 두 문서가 파일 크기를 다르게 적어요. 업로드 문서는 채팅 업로드를 파일당 500MB로, 파일 생성 문서는 업로드·다운로드를 파일당 30MB로 적어요. 어느 쪽이 내 경우에 적용되는지 확인하지 못했으니 파일을 작게 유지하고 앱에 표시되는 한도를 확인하세요.
- ChatGPT는 우리가 읽은 문서에 파일 형식과 크기 한도가 없어요. OpenAI 도움말 센터 본문은 이 글을 위해 읽지 않았어요.
- 문서 추출 전문 도구의 공식 도움말은 읽지 않아서 설명하지 않아요.
- 기능과 메뉴는 자주 바뀌어요. 화면에서 직접 확인하세요.
</Aside>

### 서비스별로 받는 것 (2026-11-04 확인)

| 서비스 | 공식 도움말 내용 | 확인하지 못한 것 |
| --- | --- | --- |
| **Claude** | 문서: PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON, XLSX(XLSX는 코드 실행·파일 생성을 켜야 해요). 채팅 업로드: 대화당 최대 20개, PDF는 1,000쪽까지. 100쪽 이하 PDF는 텍스트와 시각 요소 분석, 101~1,000쪽은 텍스트만. PDF가 아닌 문서는 텍스트만 추출하고 삽입된 이미지는 읽지 못해요. Claude는 내려받을 수 있는 .xlsx 파일을 만들 수 있어요. | 적용되는 파일당 크기 한도(500MB 대 30MB, 위 참고), 스캔 문서 읽기 정확도. |
| **Gemini** | 프롬프트 하나에 파일 최대 10개(제공 상황에 따라 다름), 그 밖의 파일은 개당 100MB까지, ZIP은 파일 10개·100MB까지. 사용량에 롤링 한도가 있고 Google AI 요금제에서 한도가 늘어요. 분석에 실패하면 다시 올리라고 안내해요. | 모든 PDF 레이아웃을 제대로 읽는지. |
| **ChatGPT** | 웹: 원본 파일을 첨부하고, 생성된 파일을 채팅에서 확인·내려받고, 수정할 때 쪽·시트·표를 지정하라고 안내해요. 이미지는 웹 입력창에 첨부·붙여넣기·끌어다 놓기가 돼요. | 일반 계정의 파일 형식과 크기 한도. |

## 따라 하기

먼저 공유해도 되는 청구서 두세 개나 가짜로 만든 문서로 연습하세요.

<Checklist items={[
  '이 문서를 이 AI 서비스에 올려도 되는 것을 확인했다',
  '필요한 항목을 한 줄씩 적어 두었다',
  '계좌번호와 표에 필요 없는 정보를 지우거나 가렸다',
  '각 PDF가 텍스트 PDF인지 스캔인지 알고 있다',
  '표를 쓰기 전에 합계를 직접 다시 계산할 것이다',
]} />

<Steps>

1. **열(항목)부터 정하기**

   원하는 항목을 순서대로 적으세요. 예: 파일 이름, 거래처, 청구서 번호, 발행일, 지급 기한, 통화, 소계, 세금, 합계. 값이 없을 때 어떻게 할지도 정하세요. 항목 목록이 고정돼야 청구서가 달라도 표 모양이 같아요.

2. **파일 준비하기**

   - 종이를 출력해 스캔하거나 찍은 사진보다, 보낸 쪽에서 받은 원본 PDF가 좋아요.
   - 일부 쪽만 필요하면 파일을 나누세요. Anthropic은 큰 문서를 작은 부분으로 나누라고 권해요.
   - 스캔이면 오류가 더 많을 수 있어요. 이미지는 1000x1000 픽셀 이상이 작거나 해상도 낮은 것보다 좋다는 Anthropic의 팁을 참고하세요.
   - 계좌번호처럼 필요 없는 정보는 가리세요.

3. **조금만 올리기**

   Claude는 **+** 버튼, Gemini는 **Add files**, ChatGPT는 웹 입력창의 첨부로 올려요. 폴더 전체 말고 두세 개로 시작해야 결과를 확인할 수 있어요.

4. **규칙을 붙여 표로 요청하기**

   <PromptBox>
   첨부한 PDF 청구서를 각각 읽고, 청구서 하나당 한 줄인 표 하나로 정리해 줘. 열은 이 순서로: 파일 이름, 거래처, 청구서 번호, 발행일(YYYY-MM-DD), 지급 기한(YYYY-MM-DD), 통화, 소계, 세금, 합계. 규칙: 값은 인쇄된 그대로 옮겨. 값이 없거나 읽을 수 없으면 추측하지 말고 NOT FOUND라고 써. 계산하거나 고치지 마. 표 아래에 소계와 세금의 합이 합계와 다른 청구서가 있으면 목록으로 알려 줘.
   </PromptBox>

5. **필요하면 품목까지 뽑기**

   <PromptBox>
   첨부한 청구서의 품목을 한 줄씩 표로 정리해 줘. 열은: 줄 번호, 품목 설명, 수량, 단가, 줄 금액. 값은 인쇄된 그대로 옮겨. 마지막 줄에 CHECK라는 이름으로 줄 금액의 합계를 적어서 내가 인쇄된 소계와 비교할 수 있게 해 줘. 불분명한 값은 NOT FOUND로 표시해 줘.
   </PromptBox>

6. **믿기 전에 검산하기**

   PDF를 표 옆에 열어 놓고 비교하세요. 최소한 다음을 하세요.

   - 숫자가 중요하면 일부만이 아니라 모든 합계와 날짜를 문서와 맞춰 보세요.
   - 품목 금액을 직접(또는 스프레드시트 `SUM`으로) 더해 인쇄된 소계와 비교하세요.
   - 표의 줄 수가 올린 청구서 수와 같은지 보세요.
   - AI가 건너뛰거나 합친 청구서가 없는지 보세요.

   틀린 값이 있으면 어느 줄의 어느 항목인지 알려 주고 그 쪽을 다시 읽게 하세요.

7. **표를 시트로 옮기기**

   표를 Google Sheets나 Excel에 붙여 넣거나, Claude에게 .xlsx 파일을 요청하세요. Anthropic 설명으로 Claude는 코드 실행·파일 생성이 켜져 있으면 내려받거나 Google Drive에 저장할 수 있는 Excel 파일을 만들어요. 그다음 숫자 열에 숫자 형식을 지정하고 직접 `SUM`을 넣어 AI의 합계와 비교하세요. 시트 안에서 AI를 쓰는 방법은 [엑셀·구글 시트에 AI 붙이기: Copilot·Gemini·Claude](/ko/automation/23-spreadsheet-ai/)를 보세요.

8. **기록을 남기고 필요 없는 것은 지우기**

   원본 PDF는 기준 자료로 보관하세요. 사용한 서비스의 개인정보 설정과 대화 기록도 점검하세요. [내 대화가 AI 학습에 쓰이지 않게: Claude·ChatGPT·Gemini 개인정보 설정](/ko/basics/12-privacy-settings/)를 보세요.

</Steps>

## 한눈에 보는 요약

### 오류를 줄이는 프롬프트 규칙

| 규칙 | 이유 |
| --- | --- |
| 열 목록을 정확히 주기 | 매번 같은 구조 |
| "인쇄된 그대로 옮겨" | 몰래 반올림하거나 형식을 바꾸는 것을 막아요 |
| "추측하지 말고 NOT FOUND" | 빈 곳이 눈에 보여요 |
| "계산하거나 고치지 마" | 추출과 내 검산을 분리해요 |
| CHECK 줄이나 불일치 목록 요청 | 합이 안 맞는 곳이 드러나요 |
| 파일 두세 개로 시작 | 레이아웃 문제를 일찍 발견해요 |

### 묶음마다 하는 확인

| 확인 | 방법 |
| --- | --- |
| 줄 수 | 파일 수와 같은지 |
| 합계 | 소계+세금=합계, 품목 합=소계 |
| 날짜 | PDF와 같고 한 가지 형식인지 |
| 통화 | 모든 줄이 같거나 표시되어 있는지 |
| 중복 | 같은 청구서 번호가 실수로 두 번 나오지 않는지 |

## 자주 막히는 부분

### 표의 한 칸 숫자가 틀려요

- **원인**: AI가 숫자를 잘못 읽었거나(특히 스캔), 페이지의 다른 숫자를 골랐어요.
- **해결**: PDF와 비교하고, 줄과 항목을 알려 주며 그 쪽을 다시 읽게 하세요. 필요하면 직접 고치세요.

### 줄이 빠지거나 합쳐졌어요

- **원인**: 한 번에 파일이 너무 많거나 청구서가 여러 쪽에 걸쳐 있어요.
- **해결**: 작은 묶음으로 나눠 돌리고 줄 수를 확인하세요. Gemini 도움말은 프롬프트당 파일 10개까지, Claude 도움말은 대화당 20개까지라고 해요.

### 업로드가 실패하거나 답이 세부 내용을 놓쳐요

- **원인**: 파일이 너무 크거나 길어요. Anthropic은 1,000쪽이 넘는 PDF는 올릴 수 없다고 하고, Gemini 도움말은 너무 큰 업로드는 세부 내용을 놓친 답이 나올 수 있다고 해요.
- **해결**: 파일을 나눠서 따로 처리하세요.

### 표 대신 설명만 해요

- **원인**: 프롬프트에 무엇을 돌려줄지 적지 않았어요.
- **해결**: 열을 적고 "표만 돌려줘"라고 하세요.

## 실전 팁

- **숫자는 내가 확인해요.** 검산하지 않은 표로 입금, 입력, 신고를 하지 마세요. [AI 답변 믿어도 될까: 사실 확인하는 법](/ko/basics/04-fact-checking/)을 보세요.
- **최소한만 공유하세요.** 필요 없는 열은 지우고 계좌번호는 올리기 전에 가리세요.
- **기록을 남기세요.** 날짜, 파일, 프롬프트, 합계를 확인한 사람을 적어 두세요.
- **회사·고객사 규정을 지키세요.** 고객사 문서는 계약으로 보호될 수 있어요. 애매하면 먼저 물어보세요.
- **회계·세무 조언이 아니에요.** 세금이나 법률 문제는 전문가에게 물어보세요. 관련 주의점은 [AI 결과물, 써도 될까? 저작권·윤리 기초](/ko/basics/09-ai-copyright-ethics/)를 보세요.
- **잘 된 프롬프트는 저장하세요.** 반복 작업이면 템플릿으로 만들 수 있어요. [AI로 반복 문서 템플릿 만들기](/ko/automation/50-document-templates/)를 보세요.
