<Summary>
- 자동화 도구는 **"이런 일이 생기면(트리거) → 이렇게 해라(액션)"** 규칙을 만들어 줘요. 이 편은 **Gmail에 새 메일 → Google 시트에 한 줄 추가 → 알림** 흐름을 만들어요.
- **Zapier**는 Zap, **Make**는 시나리오(scenario)라고 불러요. 둘 다 무료로 시작할 수 있지만 한도와 기능이 달라요(2026-10-26 기준).
- Zapier는 도움말에서 **제품이 영어로만 제공된다**고 안내해요. Make는 무료(Free) 플랜이 월 1,000 크레딧이라고 공식 도움말이 안내해요. Make의 한국어 지원 여부는 확인하지 못했어요.
- 처음에는 **테스트 → 한 건 확인 → 켜기** 순서로, 개인정보가 든 메일은 시트에 통째로 옮기지 마세요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 트리거·액션·시나리오 같은 자동화 용어를 이해할 수 있어요.
- 특정 라벨이 붙은 메일을 **Google 시트에 자동 기록**하는 자동화를 Zapier 또는 Make로 만들 수 있어요.
- 알림 단계를 붙이는 방법과, 무료 플랜의 한계를 확인하는 방법을 알 수 있어요.
- 두 도구와 AI 에이전트 방식(루틴 등)의 차이를 구분해 고를 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **트리거(Trigger)** | 자동화를 시작시키는 사건이에요. 예: Gmail에 새 메일 도착 |
| **액션(Action)** | 자동화가 하는 일이에요. 예: 시트에 행 추가, 메시지 보내기 |
| **Zap** | Zapier의 자동화 하나예요. 트리거 1개 + 액션들로 이뤄져요. |
| **Scenario(시나리오)** | Make의 자동화 하나예요. 모듈(module)을 이어서 만들어요. |
| **모듈(Module)** | Make에서 앱 하나의 동작 단위예요. 데이터를 만들고, 바꾸고, 지우는 일을 해요. |
| **task / 크레딧(credit)** | 사용량 단위예요. Zapier는 task, Make는 크레딧(예전 용어는 operations)을 써요. |
| **폴링(Polling)** | 도구가 주기적으로 "새 게 있나?" 확인하는 방식이에요. 즉시 반응하지 않고 확인 주기만큼 늦을 수 있어요. |

### Zapier와 Make, 무엇이 다른가요 (2026-10-26 기준)

| 항목 | Zapier | Make |
| --- | --- | --- |
| 자동화 이름 | Zap | 시나리오(scenario) |
| 화면 언어 | 도움말은 "영어로만 제공"이라고 안내 | 한국어 지원 여부는 확인하지 못함 |
| 무료 플랜 | 월 $0, 월 100 task, 2단계(Two-step) Zap, 확인 주기 15분 | 월 1,000 크레딧(Make 도움말 기준). 최소 실행 간격은 플랜별이라 화면에서 확인 |
| 사용량 계산 | 새 데이터 확인(폴링)은 task를 쓰지 않고, 동작이 성공해야 task를 소모 | 일반 앱은 동작(operation) 1번이 1크레딧(AI 기능은 토큰 등으로 더 쓸 수 있음) |
| 분기·변환 | 단계를 추가해 구성(플랜별 제한은 가격 페이지 확인) | 라우터(Router)로 분기, 모듈 사이 데이터 변환 |

<Aside type="caution" title="가격과 한도는 공식 페이지에서 확인하세요">
Zapier 무료 플랜 수치(월 100 task, 2단계 Zap, 15분 확인 주기, Professional은 다단계 Zap과 2분 확인 주기)는 2026-10-26 기준 [Zapier 가격 페이지](https://zapier.com/pricing)에서 확인한 값이에요. 이 가격 페이지의 통화 선택에 원화(KRW)는 없었고, 달러 표시가 기본이에요. Make는 operations 대신 크레딧을 청구 단위로 쓰고, 구독을 해지하면 월 1,000 크레딧의 Free 플랜으로 전환된다고 [Make 도움말](https://help.make.com/cancel-your-subscription)이 안내해요(2026-08-31 갱신 문서). 가격 페이지(make.com)는 자동 접근이 막혀 열지 못했으니 현재 요금과 플랜별 기능은 [Make 가격 페이지](https://www.make.com/en/pricing)에서 직접 확인하세요.
</Aside>

<Aside type="note" title="확인하지 못한 점">
- 두 도구의 편집기 버튼 이름은 자주 바뀌어요. Zapier의 이름(New Email, New Labeled Email, Create Spreadsheet Row)은 Zapier 공식 연동 페이지에서 확인했어요. Make의 모듈 이름(Gmail > Watch emails, Google Sheets > Add a Row)은 Make 앱 문서(apps.make.com)에서 확인했어요. 그래도 화면의 이름이 다르면 **화면 안내에 따르세요.**
- Make의 Slack 메시지 모듈은 앱 문서에 Send a Message로 나오지만 같은 문서의 다른 표에는 Create a Message도 보여요. 모듈 목록에서 검색해 고르세요.
- Make 무료 플랜의 최소 실행 간격과 한국어 화면 지원 여부는 공식 문서에서 확인하지 못했어요.
- 카카오톡 등 국내 메신저 연동 여부는 확인하지 못했어요. 각 도구의 앱 목록에서 검색해 보세요.
</Aside>

## 단계별 따라하기

### 준비: 메일 분류용 라벨과 시트 만들기

<Checklist items={[
  'Gmail에 자동화 전용 라벨을 만들고, 테스트 메일 1통에 붙였어요',
  'Google 시트에 열 이름(받은 시각, 보낸 사람, 제목, 링크)을 만들었어요',
  '(Zapier) 트리거와 액션을 설정하고 각각 테스트했어요',
  '(Make) 모듈을 연결하고 Run once로 한 번 실행했어요',
  '시트에 행이 정확히 한 줄 생긴 것을 확인했어요',
  '알림 단계를 추가하고 켰어요(Zapier 무료는 2단계 제한 확인)',
]} />

<Steps>

1. **Gmail 라벨과 시트 준비하기**

   Gmail에서 "자동화-기록" 같은 라벨을 만들어요. 모든 메일이 아니라 **라벨 붙은 메일만** 처리하게 하면 사용량과 사고를 줄여요. Google 시트 첫 줄에는 열 이름(받은 시각, 보낸 사람, 제목, 링크)을 적어요.

   <PromptBox label="AI에게 시트 설계를 물어볼 때">
   고객 문의 메일을 Google 시트에 기록하려고 해. 열 이름을 추천해 줘. 개인정보(전화번호, 주소)는 시트에 옮기지 않고, 메일로 돌아갈 수 있는 링크만 남기고 싶어. 열 5개 이내로.
   </PromptBox>

2. **방법 A. Zapier로 만들기**

   Zapier에서 새 Zap을 만들고 아래처럼 고르세요. 이름은 Zapier 공식 연동 페이지에서 확인한 것이에요.

   - 트리거 앱: **Gmail**, 이벤트: **New Email**(메일함에 새 메일이 오면) 또는 **New Labeled Email**(라벨 붙은 메일)
   - 액션 앱: **Google Sheets**, 이벤트: **Create Spreadsheet Row**(시트에 행 추가)

   각 단계에서 계정 연결(Google 로그인)을 하고, 트리거의 **Test Trigger**로 샘플 메일을 가져온 뒤, 액션 칸에 보낸 사람·제목 같은 값을 열에 맞게 끌어다 연결해요. 액션의 **Test step**을 누르면 시트에 실제로 행이 생겨요. 마지막으로 Zap을 게시(Publish)해서 켜요. 이 흐름은 Zapier의 연동 페이지와 안내를 바탕으로 했고, 버튼 이름은 화면 안내를 따르세요.

   <ScreenshotPlaceholder caption="Zapier에서 Gmail 트리거와 Google Sheets 액션을 연결한 Zap 화면" officialUrl="https://zapier.com/apps/gmail/integrations/google-sheets" />

   <Aside type="note">
   Zapier 무료 플랜은 가격 페이지 기준으로 **2단계(Two-step) Zap**만 가능해요. 새 계정은 14일 Pro 체험이 자동으로 시작되고 카드 등록은 필요 없으며, 이 체험이 끝나면 자동으로 유료 전환되지 않고 Free 플랜으로 돌아간다고 공식 도움말이 안내해요. 다만 Free 플랜에서 직접 시작하는 체험이나 Team 체험은 끝나면 유료로 자동 전환될 수 있다고 하니, 시작 전에 안내 문구를 확인하세요. 트리거 + 시트 기록까지가 한계이고, 알림을 한 단계 더 붙이는 3단계 구성은 유료 플랜이 필요할 수 있어요. 가격 페이지에서 확인하세요.
   </Aside>

3. **방법 B. Make로 만들기**

   Make에서 새 시나리오를 만들고 모듈을 이어요.

   1. **Gmail > Watch emails**: 새 메일이 오면 시작하는 트리거 모듈이에요. Google 계정 연결을 하고 라벨·폴더 조건을 정해요.
   2. **Google Sheets > Add a Row**: 시트 맨 아래에 행을 추가하는 모듈이에요. 시트와 탭을 고르고 각 열에 Gmail 모듈의 값(보낸 사람, 제목 등)을 연결해요.
   3. (선택) 알림 모듈을 추가해요. 원하는 메신저나 메일 앱을 모듈 목록에서 검색해 고르세요.

   메일 본문에서 주문번호처럼 일부 값만 뽑고 싶다면 Make 공식 튜토리얼처럼 **Text Parser**(정규식으로 값 추출)를 중간에 넣을 수 있어요. 한 번 실행해 보려면 **Run once**를 눌러요. Run once로 실행하면 스케줄 설정은 무시되고 1회만 실행돼요.

   <ScreenshotPlaceholder caption="Make 시나리오에서 Gmail, Google Sheets 모듈을 이은 화면" officialUrl="https://help.make.com/create-your-first-scenario" />

4. **한 건으로 먼저 확인하기**

   라벨 붙은 테스트 메일 1통만으로 실행해요. 시트에 행이 **정확히 한 줄** 생겼는지 보세요. 같은 메일이 두 번 들어가거나 열이 어긋나면 켜기 전에 고치세요.

5. **알림 붙이기**

   시트에 쌓이는 것만으로 부족하면 알림을 붙여요. 예를 들어 "새 문의가 들어왔어요: 제목"을 팀 메신저에 보내요. 알림 문구에는 **메일 본문 전체를 넣지 말고** 제목과 링크만 넣는 게 안전해요.

6. **켜고 모니터링하기**

   Zapier는 Zap을 켜고(게시), Make는 시나리오를 스케줄에 맞게 켜요(기본 실행 간격은 15분이고 최소 간격은 플랜마다 달라요). 첫날은 실행 기록(History/로그)을 열어 오류가 없는지 확인하세요.

</Steps>

## 자주 막히는 지점

### 새 메일을 바로 못 가져와요

- **원인**: 두 도구 모두 주기적으로 확인하는 방식(폴링)을 써요. Zapier 무료는 15분 간격(Professional 2분)이에요. Make는 기본 15분마다 실행하고 최소 간격은 플랜마다 달라요.
- **해결**: 테스트할 때는 수동 테스트 버튼(Test Trigger, Run once)을 쓰고, 실시간이 필요하면 상위 플랜의 확인 주기를 가격 페이지에서 확인하세요.

### 한도가 다 찼어요 / Zap이 꺼졌어요

- **원인**: Zapier는 성공한 동작마다 task를 쓰고, 무료는 월 100 task예요. Zapier 도움말에 따르면 한도에 닿으면 이메일 알림이 오고, 종량제(pay-per-task)가 켜져 있으면 추가 task가 따로 청구돼요. 종량제가 없거나 꺼져 있으면 새 Zap 실행이 결제 주기가 바뀔 때까지 보류돼요(2026-10-13 기준). 사용량 화면도 함께 보세요. Make는 일반 앱 동작 하나당 1크레딧을 써요.
- **해결**: 라벨 붙은 메일만 처리하도록 범위를 좁히고, 불필요한 단계를 줄이세요. 사용량 화면을 주기적으로 확인하세요.

### 시트에 같은 메일이 여러 번 들어가요

- **원인**: 트리거 조건이 너무 넓거나(받은편지함 전체), 테스트 때 만든 행이 남아 있어요.
- **해결**: 라벨 조건을 쓰고, 처리 후 라벨을 떼거나 "처리됨" 열을 두어 중복을 구분하세요.

### 열이 어긋나거나 값이 비어요

- **원인**: 액션에서 연결한 필드가 잘못됐거나 테스트에 쓴 샘플 메일에 그 값이 없어요.
- **해결**: 샘플을 다시 불러와 필드를 확인하고, 시트 열 이름을 먼저 정해 두세요.

### Google 연결(인증) 오류가 나요

- **원인**: 로그인한 계정이 다르거나 권한 동의를 놓쳤거나, 회사 관리자가 외부 앱 연결을 막았을 수 있어요.
- **해결**: 연결을 삭제하고 다시 만든 뒤, 회사 계정이면 관리자에게 문의하세요.

## 실전 팁

- **작게 시작하세요.** 단계 2개짜리 자동화를 안정적으로 돌린 뒤 늘리세요.
- **개인정보 최소화.** 고객 연락처, 주민번호 같은 정보는 시트나 알림에 옮기지 마세요. 외부 자동화 서비스를 거치는 순간 데이터가 그 서비스를 통과해요. 회사 데이터라면 사내 보안 규정을 먼저 확인하세요.
- **이름 규칙을 만드세요.** Zap/시나리오 이름에 목적과 담당자를 적으면 나중에 찾기 쉬워요.
- **실패 알림을 켜세요.** 도구마다 오류 알림 설정이 있어요. 위치는 화면 안내를 따르세요.
- **AI 단계가 필요하면** 두 도구 모두 AI 기능이 있지만 사용량을 더 쓸 수 있어요(Make는 AI 기능이 크레딧을 더 쓸 수 있다고 안내). 먼저 규칙 기반으로 충분한지 따져 보세요.
