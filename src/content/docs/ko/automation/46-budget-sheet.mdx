<Summary>
- 흐름은 **민감한 정보 가리기 → 영수증 사진이나 지출 목록을 AI에 주기 → 정한 열대로 표 채우기 → 합계 직접 검산 → 시트로 보관**이에요.
- 세 대화형 AI 모두 파일이나 이미지를 받을 수 있어요. Claude(PDF·CSV·XLSX·JPEG·PNG 등), Gemini(프롬프트당 파일 10개까지), ChatGPT(웹 입력창에 첨부한 이미지). 한도는 아래 표에 있어요(2026-11-02 확인).
- **카드번호·계좌번호·이름·주소는 올리기 전에 가리세요.** 사진에서 먼저 잘라 내거나 덮으세요. [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)를 참고하세요.
- **금융 조언이 아니에요. 기록 정리를 돕는 방법이에요.** AI는 흐릿한 영수증을 잘못 읽거나 더하기를 틀릴 수 있으니 합계는 사람이 꼭 확인하세요.
- 이 페이지를 위해 실제 영수증으로 이 실습을 해 보지는 않았어요. 프롬프트와 표 예시는 이 사이트가 만든 예시이고, 실제 결과는 달라질 수 있어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 영수증 사진 더미나 카드 내역 파일을 날짜·가게·분류·금액이 있는 **표 하나**로 바꿔요.
- 계속 고쳐 쓸 수 있는 **가계부 템플릿**(분류, 월 합계, 요약)을 스프레드시트로 받아요.
- 영수증이 AI 서비스에 닿기 전에 **민감한 정보를 가려요.**
- 잘못 읽은 숫자가 기록에 남지 않도록 **AI가 낸 합계를 확인해요.**

## 먼저 알아둘 개념

| 용어 | 여기서의 뜻 |
| --- | --- |
| **영수증 추출** | AI가 사진이나 PDF에서 가게, 날짜, 품목, 합계를 읽어 표로 옮기는 것. 이미지의 글자를 읽는 일이라 실수가 생길 수 있어요. |
| **분류(카테고리)** | 식비, 교통비, 외식 같은 이름표. 목록은 내가 정하고, AI는 거기에 맞춰 행을 나눠요. |
| **가리기(마스킹)** | 카드번호처럼 공유하고 싶지 않은 부분을 올리기 전에 덮거나 잘라 내는 것. |
| **내역 내보내기** | 은행·카드사 사이트나 앱에서 직접 내려받는 CSV나 스프레드시트 파일. 사진보다 정확하고 편한 경우가 많아요. |
| **표본 검산** | 몇 개 숫자를 직접, 또는 간단한 `SUM`으로 다시 계산해 AI 표가 맞는지 보는 것. |

<Aside type="caution" title="금융 조언이 아니에요">
이 튜토리얼은 **기록을 정리하는 방법**만 다뤄요. 저축, 투자, 대출, 세금 신고를 어떻게 하라는 내용이 아니에요. 돈 문제 판단을 AI에 물으려면 먼저 [건강·법률·돈 문제를 AI에 물을 때 주의할 점](/ko/basics/13-sensitive-questions/)을 읽고, 큰 결정은 자격 있는 전문가와 상의하세요.
</Aside>

### 서비스별로 받을 수 있는 것 (2026-11-02 확인)

| 서비스 | 공식 도움말 내용 | 확인하지 못한 것 |
| --- | --- | --- |
| **Claude** | 문서: PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON, XLSX(XLSX는 코드 실행·파일 생성 기능을 켜야 해요). 이미지: JPEG, PNG, GIF, WebP. 채팅 업로드: 파일당 500MB, 채팅당 20개까지, 이미지는 8000x8000픽셀까지. 이미지 팁: 1000x1000픽셀 이상 권장, 작거나 해상도가 낮은 사진은 피하기. | 손글씨나 구겨진 영수증의 인식 정확도, 한국어 영수증 정확도. |
| **Gemini** | 한 프롬프트에 파일 10개까지(제공 상황에 따라 다름), 대부분의 파일 형식 지원, 동영상이 아닌 파일은 개당 100MB까지. 기간별로 차오르는 한도가 있고, Google AI 요금제에서 한도가 늘어나요. 올린 스프레드시트로 차트도 만들 수 있어요. | 영수증 인식 정확도. |
| **ChatGPT** | ChatGPT 문서는 웹 입력창에 이미지를 첨부·붙여넣기·끌어다 놓을 수 있고, 무엇을 살펴보고 어떤 결과를 원하는지 함께 적으라고 안내해요. | 일반 계정의 파일 크기·개수 한도: 공식 도움말(help.openai.com)이 이 환경에서 접근 오류로 열리지 않아 쓰지 않았어요. |

<Aside type="note" title="확인하지 못한 것">
어느 서비스든 영수증 사진을 얼마나 정확히 읽는지에 대한 공식 수치는 찾지 못했고, 실제 영수증으로 시험해 보지도 않았어요. 추출된 금액은 종이 영수증과 맞춰 보기 전까지 초안으로 취급하세요.
</Aside>

## 따라 하기

처음에는 공유해도 괜찮은 영수증 3~5장이나 가린 영수증으로 연습하세요. 가상 지출 목록도 좋아요.

<Steps>

1. **먼저 민감한 정보 가리기**

   올리기 전에 사진을 하나씩 보세요. 영수증에는 카드번호(일부만 가려져 있기도, 아니기도 해요), 이름, 전화번호, 멤버십 번호, 주소가 보일 수 있어요. 이미지를 자르거나 휴대폰의 마크업·편집 도구로 덮은 뒤 복사본으로 저장하세요. 원본이 아니라 복사본을 올리세요. 은행 내역 파일에 계좌번호가 있으면 올리기 전에 스프레드시트에서 그 열을 지우세요. 이유와 학습 설정은 [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)와 [내 대화가 AI 학습에 쓰이지 않게](/ko/basics/12-privacy-settings/)에 있어요.

   대화가 기록에 남지 않게 하려면 임시 채팅이나 시크릿 채팅을 쓰세요. 이 기능의 위치는 서비스마다 달라서 각 도움말에서 확인하세요.

2. **열과 분류 정하기**

   AI가 알아서 짐작하기 전에 원하는 모양을 적어 두세요. 예를 들면 날짜, 가게, 분류, 금액, 결제 수단(현금 또는 카드만, 번호는 절대 아님), AI가 확신하지 못한 내용을 적는 비고 열이에요.

3. **영수증이나 내역 파일을 올리고 표로 요청하기**

   Claude에서는 채팅창 왼쪽 아래 **+** 버튼을 누르고 **Add files or photos**를 고르거나, 파일을 끌어다 놓거나, 클립보드의 이미지를 붙여넣으세요(공식 업로드 도움말, 2026-11-02 확인). Gemini에서는 프롬프트를 입력하고 **Add files**를 누르세요(프롬프트당 파일 10개까지). ChatGPT에서는 웹 입력창에 이미지를 첨부하거나 붙여넣거나 끌어다 놓으세요. 영어 UI 기준 이름이고, 한국어 화면의 버튼 이름은 확인하지 못했어요.

   <PromptBox>
   영수증 사진 5장을 첨부했어요(카드번호는 가렸어요). 영수증마다 날짜, 가게, 분류, 금액, 결제 수단(현금 또는 카드만), 확인 열이 있는 표를 만들어 주세요. 분류는 식료품, 외식, 교통, 의료, 생활용품, 기타 중에서만 고르세요. 읽기 어렵거나 짐작한 값은 칸에 "?"를 쓰고 이유를 확인 열에 적어 주세요. 보이지 않는 내용은 지어내지 마세요. 마지막에 분류별 합계와 전체 합계를 보여 주세요.
   </PromptBox>

   <ScreenshotPlaceholder caption="Claude 채팅창의 + 버튼으로 이미지나 파일 첨부하기" officialUrl="https://support.claude.com/en/articles/8241126-uploading-files-to-claude" officialLabel="Claude 고객센터에서 보기" />

4. **숫자 확인하기**

   표가 나왔다고 끝내지 마세요. 영수증 두세 장을 골라 날짜, 가게, 합계를 종이와 비교하세요. 그다음 금액 열을 직접 더해 보세요(스프레드시트의 `=SUM()` 등). 그 값을 AI가 준 전체 합계와 비교하고, "?"가 있는 행을 모두 살펴보세요.

   <PromptBox>
   두 번째 영수증의 합계는 23,400원인데 표에는 28,400원으로 되어 있어요. 그 영수증을 다시 보고 어느 숫자가 확실하지 않았는지 알려 주세요. 그다음 표를 고치고 분류별 합계와 전체 합계를 다시 계산한 뒤, 바꾼 칸을 모두 나열해 주세요.
   </PromptBox>

5. **계속 쓸 가계부 템플릿 부탁하기**

   <PromptBox>
   계속 쓸 수 있는 월별 가계부 스프레드시트를 만들어 주세요. 시트 1 "거래내역": 날짜, 가게, 분류, 금액, 결제 수단, 비고. 시트 2 "요약": 분류별 월 합계와 전체 지출에서 차지하는 비율을, 거래내역 시트를 읽는 수식으로 만들어 주세요. 분류마다 계획 금액을 적을 빈 "계획 금액" 열도 넣어 계획과 실제를 비교할 수 있게 해 주세요. 위 표의 데이터를 예시 행으로 채우고, 각 수식이 하는 일을 설명해 주세요.
   </PromptBox>

   Claude에서 실제 `.xlsx` 파일을 받으려면, 공식 도움말에 따르면 코드 실행·파일 생성은 Free, Pro, Max, Ultra, Team, Enterprise 요금제 모두에서 쓸 수 있어요(2026-11-02 확인). Free, Pro, Max, Ultra에서는 **Settings > Capabilities**에 있고, 토글 이름은 "Code execution and file creation"(업데이트된 설정 화면에서는 "Create and edit files")이에요. Team과 Enterprise에서는 조직 설정이에요. ChatGPT 문서는 스프레드시트를 만들고 채팅에서 내려받는 방법을 설명하고, Gemini의 Sheets 도움말은 Ask Gemini 사이드 패널에서 표와 수식을 만드는 방법을 설명해요. 이미 쓰는 서비스를 고르세요.

   <FlowSteps title="영수증에서 가계부 시트까지" officialUrl="https://support.claude.com/en/articles/8241126-uploading-files-to-claude" steps={[

     { where: 'AI 채팅', action: '복사본을 첨부하고 정한 열과 분류로 표를 요청', result: '확신 없는 곳에 "?"가 있는 표 초안' },
     { where: '스프레드시트 또는 계산기', action: '영수증 두세 장과 전체 합계를 직접 비교', result: '고쳐야 할 행이 보임' },
     { where: 'AI 채팅', action: '행을 고치고 다시 계산해 달라고 요청', result: '수정된 표' },

   ]} />

6. **스프레드시트로 옮기고 원본 보관하기**

   결과를 Excel이나 Google Sheets에 붙여넣거나 열어 보세요. Google Sheets에서는 오른쪽 위 Ask Gemini 패널이 표와 수식을 만들고 데이터를 요약해 줄 수 있고, 자격 있는 Google Workspace 또는 Google AI 요금제가 필요해요(2026-11-02 확인). Gemini 기능은 원래 Google Sheets 파일에서 가장 잘 동작하므로, `.xlsx`는 **File > Save as Google Sheets**로 바꿔서 쓰세요. 스프레드시트 안의 AI는 [엑셀·구글 시트에 AI 붙이기](/ko/automation/23-spreadsheet-ai/)를 참고하세요.

   월 마감이 끝날 때까지 종이 영수증이나 원본 사진은 보관하세요. 나중에 CSV를 읽어 보고서를 쓰는 반복 가능한 스크립트가 필요하면 [Claude Code로 CSV·엑셀 데이터 분석하고 보고서 만들기](/ko/coding/38-data-analysis-claude-code/)를 보세요.

</Steps>

| 내역 파일 | "카드 거래 CSV예요. [목록] 중에서만 분류 열을 추가하고 금액은 바꾸지 마세요." |
| 재계산 | "제 계산은 [x]인데 표는 [y]예요. 합계에 들어간 행을 보여 주세요." |
| 템플릿 | "거래내역·요약 시트가 있는 월별 가계부를 수식과 함께 만들고 수식을 설명해 주세요." |
| 다음 달을 위해 | "분류를 정할 때 쓴 규칙을 목록으로 알려 주세요. 다음 달에 다시 쓸게요." |

### 영수증 사진 vs 내역 파일

| | 영수증 사진 | 내역 파일(CSV) |
| --- | --- | --- |
| 잘 맞는 경우 | 현금, 작은 가게, 품목별 내역 | 카드·은행 지출 |
| 주된 위험 | 숫자 오독, 흐릿한 글자 | 계좌번호·이름이 파일에 남아 있음 |
| 올리기 전 | 카드번호와 이름 자르기·덮기 | 필요 없는 열 지우기 |
| 확인 | 종이 영수증과 비교 | 합계를 내역서의 합계와 비교 |

## 자주 막히는 곳

### AI가 영수증 숫자를 잘못 읽었어요

- **원인**: 작은 글씨, 그림자, 접힌 자국, 낮은 해상도의 사진은 읽기 어려워요. Claude 공식 업로드 도움말은 1000x1000픽셀 이상의 이미지를 권하고, 작거나 해상도가 낮은 사진은 피하라고 안내해요.
- **해결**: 밝은 곳에서 평평하고 똑바로 다시 찍고, AI에게 어느 값이 확실하지 않았는지 짚어 달라고 하세요.

### 달마다 분류가 달라져요

- **원인**: AI가 매번 분류를 스스로 정했어요.
- **해결**: 매번 프롬프트에 고정된 분류 목록을 넣고 같은 규칙을 쓰라고 하세요. 프롬프트를 메모에 저장해 두면 다시 쓸 수 있어요.

### 합계가 은행 내역과 안 맞아요

- **원인**: 영수증이 빠졌거나, 환불·팁이 영수증과 다르거나, 행이 중복됐을 수 있어요.
- **해결**: AI에게 중복처럼 보이는 행을 나열해 달라고 한 뒤, 내역서와 한 줄씩 직접 맞춰 보세요.

### 파일이 올라가지 않거나 한도에 걸렸다고 나와요

- **원인**: 파일이 너무 크거나 개수가 많을 수 있어요. Gemini는 파일이 있는 채팅에 기간별 한도가 있다고 안내하고, Claude는 파일당·채팅당 한도를 안내해요.
- **해결**: 영수증을 작은 묶음으로 나누거나, 서비스 도움말에서 현재 한도를 확인하세요.

### 카드번호를 올린 것 같아 걱정돼요

- **원인**: 사진에는 내가 눈치채지 못한 정보까지 찍힐 수 있어요.
- **해결**: 그 대화를 삭제하세요. 이미 처리된 내용이 완전히 사라졌는지는 알 수 없으니, 카드번호 전체가 보였다면 카드사에 재발급 여부를 문의하세요. [개인정보·회사 정보 안전하게 지키며 쓰기](/ko/basics/05-privacy-safety/)를 참고하세요.

## 실전 팁

- **월 단위로 나눠서 하세요.** 작은 묶음이 1년치 영수증보다 확인하기 쉬워요.
- **월 마감 전까지는 AI 표를 원본 옆에 두세요.**
- **짐작 대신 "?"를 쓰게 하세요.** 눈에 보이는 빈칸이 자신 있게 틀린 숫자보다 나아요.
- **내역 파일이 있으면 그걸 쓰세요.** 보통 사진을 읽는 것보다 믿을 만하고, 가릴 파일도 줄어요.
- **이 시트를 조언으로 쓰지 마세요.** 지출 요약은 지난 일을 보여 줄 뿐이에요. 저축이나 대출 결정은 본인의 몫이고, 가능하면 전문가와 함께 하세요.
