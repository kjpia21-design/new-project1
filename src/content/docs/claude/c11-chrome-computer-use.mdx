<Summary>
- **Claude in Chrome**은 Chrome 안에서 Claude가 페이지를 읽고 클릭·입력·이동을 대신 해 주는 확장 프로그램이에요. 모든 유료 플랜에서 쓰고, Chrome 사이드 패널은 베타예요(2026-10-10 기준).
- **컴퓨터 사용(Computer use)**은 커넥터나 브라우저로 안 될 때 Claude가 내 컴퓨터 화면의 앱을 직접 조작하는 기능이에요. Pro와 Max에서 베타이고, Team·Enterprise는 현재 쓸 수 없다고 안내돼요(2026-10-10 기준).
- 컴퓨터 사용은 macOS와 Windows의 Claude Desktop 앱 안(Cowork, Claude Code)에서 써요. Linux 데스크톱은 안 돼요.
- 도구 우선순위는 **커넥터 → 브라우저 → 화면 조작**이에요. 화면 조작이 가장 느리고 오류 가능성이 높아요.
- **은행·의료·정부 앱, 금융 계좌, 법률 문서에는 쓰지 마세요.** 컴퓨터 사용에는 샌드박스가 없어서 화면에 보이는 모든 정보를 Claude가 볼 수 있어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 작업에 맞게 커넥터, Claude in Chrome, 컴퓨터 사용 중 알맞은 도구를 고를 수 있어요.
- Chrome 확장을 설치하고 사이드 패널에서 첫 작업을 맡길 수 있어요.
- 권한 모드와 사이트별 허용을 이해하고 안전하게 설정할 수 있어요.
- 데스크톱 앱에서 컴퓨터 사용을 켜고, 민감 정보를 지키면서 작은 작업부터 시도할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Claude in Chrome** | Chrome 확장 프로그램이에요. 페이지 읽기, 클릭, 입력, 이동, 양식 작성, 여러 탭 관리를 해요. Claude Cowork와 Claude Code에서 쓸 수 있어요. |
| **사이드 패널** | Chrome 옆에 열리는 Claude 창이에요. 베타예요. Max·Team에서는 Cowork 세션으로 실행되고 Pro로 확대 중이라고 안내돼요. |
| **컴퓨터 사용(Computer use)** | Claude가 화면을 보고 클릭·입력·앱 열기·이동을 직접 하는 기능이에요. 컴퓨터가 켜져 있으면 자리를 비워도 계속 작업해요. |
| **Cowork** | Claude Desktop 안에서 작업을 맡기는 공간이에요. 컴퓨터 사용은 여기와 Claude Code에서 쓸 수 있어요. |
| **권한 모드** | Claude가 동작하기 전에 얼마나 승인을 받을지 정하는 설정이에요. |

### 어떤 도구를 쓸까요?

Claude는 가능하면 더 빠르고 안정적인 방법을 먼저 쓰도록 되어 있어요. 우선순위는 이래요.

| 순서 | 방법 | 설명 |
| --- | --- | --- |
| 1 | **커넥터** | Gmail, Drive 같은 서비스에 직접 연결해요. 가장 빠르고 정확해요. [C7. 커넥터로 Gmail·캘린더·Drive·Notion 연결하기](/new-project1/claude/c07-connectors/) 참고. |
| 2 | **브라우저** | 내장 브라우저 또는 Claude in Chrome으로 웹페이지를 조작해요. |
| 3 | **화면 조작** | 컴퓨터 사용으로 앱 화면을 직접 조작해요. 가장 느리고 오류 가능성이 높아요. |

<Aside type="caution" title="문서마다 다른 점 (2026-10-10 기준)">
- **지원 브라우저**: 지원센터 문서는 Chrome 전용이고 다른 Chromium 브라우저와 모바일은 지원하지 않는다고 설명해요. 반면 Claude Code 문서는 Chrome과 Edge에서 동작하고, Brave·Arc 등 다른 Chromium 브라우저도 연결을 설정한다고 적혀 있어요. 쓰려는 환경은 각 공식 문서에서 최신 내용을 확인하세요.
- **컴퓨터 사용 플랜**: 지원센터 문서는 Pro·Max 베타, Team·Enterprise 불가로 안내해요. 플랜별 제공은 자주 바뀌므로 Claude Desktop의 설정 화면에서 실제 표시를 확인하세요.
</Aside>

<Aside type="note" title="확인되지 않은 점">
Chrome 확장의 사용량 소모량은 공식 문서에서 확인하지 못했어요. Auto 방식은 추가 안전 검사 때문에 사용량이 더 들 수 있다는 안내가 있는 정도예요. 한도는 [C2. 요금제와 사용량 한도](/new-project1/claude/c02-plans-limits/)와 설정(Settings) > 사용량(Usage)에서 확인하세요.
</Aside>

<Steps>

1. **Chrome 확장 설치하기**

   Google Chrome에서 Chrome 웹 스토어로 가서 Claude 확장 프로그램을 추가해요. 설치 후 Claude 계정으로 로그인하고, 퍼즐 아이콘에서 고정(pin)한 뒤 요청하는 권한을 허용해요.

   <ScreenshotPlaceholder caption="Chrome 웹 스토어의 Claude 확장 설치와 퍼즐 아이콘 고정 화면" officialUrl="https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome" />

   Claude Desktop 앱에서 쓰려면 설정(Settings) > 커넥터(Connectors) > Claude in Chrome > 구성(Configure)에서 켜요. 대화마다 기본은 꺼져 있어요.

2. **사이드 패널에서 첫 작업 맡기기**

   지금 보고 있는 페이지로 간단한 작업부터 시작해요.

   <PromptBox>
   이 페이지에 있는 표를 읽고, 항목별로 핵심만 뽑아서 간단한 목록으로 정리해 주세요. 페이지의 내용은 바꾸지 마세요.
   </PromptBox>

3. **권한 모드 확인하기**

   입력창 드롭다운에서 권한 모드를 골라요.

   | 모드 | 동작 |
   | --- | --- |
   | **Manually approve** | 동작마다 승인을 물어요. 처음엔 이걸로 시작하세요. |
   | **Automatically approve** | 계속 진행하되 각 동작을 안전 검사해요. 안전하지 않은 동작은 자동으로 막아요. 사이드 패널의 기본값이에요. |
   | **Skip all approvals** | 자동 검사 없이 실행해요. 완전히 신뢰하는 작업에만 쓰세요. |

   모드 이름은 예전에 "Ask before acting", "Act without asking"으로 불렸어요. 화면 표기는 버전에 따라 다를 수 있어요.

4. **사이트별 권한 다루기**

   새 사이트에서 "New permissions required" 창이 뜨면 세 가지 중에서 골라요.

   - **Allow this action**: 이번 동작 하나만 허용해요. 가장 안전해요.
   - **Always allow actions on this site**: 그 사이트를 계속 허용해요. 완전히 믿는 사이트에만 쓰세요.
   - **Decline**: 막아요.

   허용한 사이트는 확장 설정(사이드 패널의 점 세 개) > Permissions 페이지의 "Your approved sites"에서 검토하고 취소할 수 있어요.

   <ScreenshotPlaceholder caption="New permissions required 창과 Your approved sites 목록" officialUrl="https://support.claude.com/en/articles/12902446-claude-in-chrome-permissions-guide" />

5. **컴퓨터 사용 켜기 (선택, Pro/Max)**

   Claude Desktop을 최신으로 업데이트한 뒤 설정(Settings) > General(Desktop app)에서 "Enable computer use"를 켜요. 그다음 Cowork 또는 Claude Code 세션에서 앱 관련 작업을 요청하면 Claude가 앱마다 접근 승인을 물어요.

6. **작은 작업으로 시험하기**

   민감한 정보가 든 파일과 앱은 먼저 닫아요. 그다음 구체적이고 위험이 낮은 작업을 요청하고, 처음에는 Claude가 하는 일을 지켜보세요.

## 빠른 참조표

### Claude in Chrome과 컴퓨터 사용 비교 (2026-10-10 기준)

| 항목 | Claude in Chrome | 컴퓨터 사용 |
| --- | --- | --- |
| 대상 | 웹 브라우저 안의 작업 | 내 컴퓨터의 앱 화면 |
| 플랜 | 모든 유료 플랜 (Pro, Max, Team, Enterprise) | Pro, Max (Team·Enterprise 불가) |
| 상태 | 사이드 패널은 베타 | 베타 |
| OS / 브라우저 | Chrome (문서마다 다른 점은 위 참고). 모바일 불가 | macOS, Windows의 Claude Desktop. Linux 데스크톱 불가. macOS 15 이상에서 백그라운드 작동 |
| 쓰는 곳 | Cowork, Claude Code, Chrome 사이드 패널 | Claude Desktop의 Cowork, Claude Code |
| 켜는 곳 | 확장 설치, Desktop에서는 Settings > Connectors | Settings > General > Enable computer use |

### Claude in Chrome이 할 수 있는 일

- 페이지 읽기, 클릭, 입력, 이동, 양식 작성
- 여러 탭 관리
- 예약 작업, 단축 명령("/"), 백그라운드 워크플로
- 콘솔·네트워크·DOM 디버깅
- Slack, Google Calendar, Gmail, Google Docs, GitHub 탐색
- 1Password 로그인 요청은 macOS 베타예요(Claude는 비밀번호를 볼 수 없어요).

### 권한과 안전

| 항목 | 내용 |
| --- | --- |
| 항상 명시적 허가가 필요한 동작 | 권한 설정 변경, 인증 승인, 웹사이트에 민감할 수 있는 정보 입력. "항상 허용" 사이트에서도 파일 다운로드와 민감 정보 입력 전에는 물어요. |
| 권한과 상관없이 하지 않는 일 | 구매, 계정 생성, 신용카드·신분증 정보 처리, 영구 삭제, 이메일이나 웹 콘텐츠 안에 적힌 지시 수행 |
| 컴퓨터 사용 기본 차단 | 투자·거래 플랫폼, 암호화폐 앱 |
| 앱 차단 목록 | 직접 추가할 수 있고, 차단 앱 요청은 자동으로 거부돼요. |
| 샌드박스 | 컴퓨터 사용에는 없어요. 화면에 보이는 모든 것을 볼 수 있어요. |
| 관리자 | Team/Enterprise 관리자는 사이트 허용/차단 목록을 설정할 수 있어요. |

### 한계

- Chrome 확장: 로컬 파일과 컴퓨터 관련 작업은 Claude Desktop이 열려 연결되어 있어야 해요. 백그라운드 작업은 Chrome이 열려 있는 동안만 돼요.
- 컴퓨터 사용: 컴퓨터가 깨어 있고 Claude Desktop이 열려 있어야 해요. 복잡한 다단계 작업은 다시 시도해야 할 수 있어요.
- 웹과 모바일에서의 컴퓨터 사용과 로컬 파일 접근은 Claude Desktop 앱에 의존해요.

### Claude Code에서 Chrome 쓰기

개발자라면 Claude Code에서도 Chrome을 연결해 로컬 웹앱을 테스트하고 콘솔 오류를 보며 디버깅할 수 있어요. Claude Code 문서 기준 요건은 Claude in Chrome 확장, Claude Code, 직접 Anthropic 플랜(Pro, Max, Team, Enterprise)이에요. 연결은 `claude --chrome`으로 시작하고, `/chrome`에서 상태 확인과 재연결을 할 수 있어요. API 키나 서드파티 제공자(Bedrock 등)만으로는 이 기능을 쓸 수 없어요. Claude Code의 Chrome 연동은 조직의 Claude in Chrome 관리자 설정을 따라서(2.1.260), 관리자가 끄면 `--chrome`, `/chrome`, 브라우저 도구를 쓸 수 없어요. 또 프로젝트의 설정 파일로는 켤 수 없고(2.1.290) `--chrome`, `/chrome`, 사용자 설정으로만 켜요(2026-10-11 기준). Claude Code 전반은 [C12. Claude Code 개요](/new-project1/claude/c12-claude-code-overview/)에서 다뤄요.

## 자주 막히는 지점

### 컴퓨터 사용 메뉴가 안 보여요

- **원인**: Team·Enterprise 플랜이거나, Linux 데스크톱이거나, Claude Desktop이 최신이 아닐 수 있어요.
- **해결**: Pro/Max인지, macOS 또는 Windows인지 확인하고 Claude Desktop을 업데이트하세요. 플랜별 제공은 바뀔 수 있으니 공식 도움말에서 최신 내용을 확인하세요.

### Claude가 클릭을 잘못하거나 같은 동작을 반복해요

- **원인**: 화면 조작은 가장 느리고 오류 가능성이 높은 방법이에요. 복잡한 다단계 작업은 재시도가 필요할 수 있어요.
- **해결**: 작업을 작게 나누고 구체적으로 지시하세요. 가능하면 커넥터나 브라우저로 처리할 수 있는지 먼저 보세요.

### 컴퓨터를 켜 두었는데 작업이 멈췄어요

- **원인**: 컴퓨터가 잠자기 상태이거나 Claude Desktop이 닫혔을 수 있어요.
- **해결**: 컴퓨터가 깨어 있고 Claude Desktop이 열려 있는지 확인하세요.

### Chrome 확장이 로컬 파일 작업을 못 해요

- **원인**: 로컬 파일과 컴퓨터 관련 작업은 Claude Desktop이 열려 연결되어 있어야 해요.
- **해결**: Claude Desktop을 열어 두고 연결을 확인하세요.

### Claude Code에서 "Browser extension is not connected"가 나와요

- **원인**: Claude Code 문서에 따르면 확장이 설치·실행되지 않았거나, 확장과 Claude Code가 서로 다른 claude.ai 계정·조직으로 로그인했을 수 있어요.
- **해결**: 같은 계정과 조직인지 확인하고 Chrome과 Claude Code를 다시 시작한 뒤 `/chrome`에서 재연결하세요.

### 사이트가 계속 권한을 물어봐요

- **원인**: 파일 다운로드나 민감 정보 입력은 "항상 허용"이어도 확인을 요구해요.
- **해결**: 정상 동작이에요. 승인 전에 무엇을 하려는지 읽고 판단하세요.

## 실전 팁

- **민감한 것은 먼저 치우세요.** 컴퓨터 사용 전에 민감한 파일과 앱을 닫으세요. Claude는 화면에 보이는 모든 것을 볼 수 있어요.
- **금융·의료·법률은 맡기지 마세요.** 은행, 의료, 정부 앱과 금융 계좌, 법률 문서, 의료 정보 작업에는 쓰지 말라는 공식 권고가 있어요.
- **Manually approve로 시작하세요.** 익숙해지고 나서 Automatically approve로 바꿔도 늦지 않아요. Skip all approvals는 완전히 신뢰하는 작업에만 쓰세요.
- **"항상 허용"은 아껴 쓰세요.** 완전히 믿는 사이트에만 주고, 가끔 승인 목록을 검토해 정리하세요.
- **웹 콘텐츠 속 지시를 조심하세요.** 웹페이지나 이메일 안에 숨은 지시에 속지 않도록, 확장은 그런 지시를 수행하지 않게 되어 있어요. 그래도 안전 장치가 완벽하지는 않으니 낯선 사이트에서는 지켜보세요.
- **초반에는 지켜보세요.** 작은 작업, 구체적인 프롬프트, 초반 관찰이 기본이에요. 언제든 중단할 수 있어요.
- **베타라는 점을 기억하세요.** 기능과 제공 범위는 바뀔 수 있어요(2026-10-10 기준).
