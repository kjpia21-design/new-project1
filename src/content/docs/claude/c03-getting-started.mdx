- Claude는 **웹(claude.ai), 데스크톱 앱(Mac/Windows), 모바일 앱(iOS/Android)** 세 가지로 쓸 수 있어요. 만 18세 이상, 지원 지역에서만 가능해요.
- 웹은 설치 없이 바로, 데스크톱은 로컬 파일·확장·컴퓨터 사용·Claude Code, 모바일은 이동 중 대화와 클라우드 작업 확인에 강해요.
- 같은 계정으로 로그인하면 어느 기기에서든 이어 쓸 수 있어요.
- 2026-09-16부터 Cowork의 기능을 **어느 대화에서나** 쓸 수 있고, 디자인·슬라이드·문서도 어느 대화에서나 만들 수 있어요. Pro·Max부터 순차 롤아웃이라 계정마다 시점이 달라요. (2026-10-11 기준)
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 웹·데스크톱·모바일 중 내 상황에 맞는 앱을 고를 수 있어요.
- 각 앱을 설치하고 로그인할 수 있어요.
- 입력창의 "+" 버튼, 모델 선택기 같은 기본 화면 요소를 찾을 수 있어요.
- Chat과 Cowork가 하나의 Claude가 된다는 것이 무엇인지 이해할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **웹(claude.ai)** | 브라우저로 접속해요. 설치가 필요 없어요. |
| **데스크톱 앱** | Mac/Windows에 설치하는 앱이에요. Linux는 베타예요. |
| **모바일 앱** | iOS/Android 앱이에요. 앱 이름은 "Claude by Anthropic"이에요. |
| **Cowork** | 다단계 에이전트 작업을 맡기는 기능이에요. 데스크톱에서는 격리된 VM에서 코드를 실행하고, 연결한 폴더만 읽고 써요. 유료 플랜이 필요해요. |
| **Code 탭** | 데스크톱·모바일 앱 안에서 Claude Code를 쓰는 곳이에요. 유료 구독이 필요해요. |

### 앱별 차이 (2026-10-19 기준)

| 구분 | 웹 | 데스크톱 | 모바일 |
| --- | --- | --- | --- |
| 설치 | 필요 없음 (claude.ai) | claude.ai/download | App Store / Google Play |
| 지원 환경 | 브라우저 | macOS 13(Ventura) 이상, Windows 10 이상, Linux 베타(Ubuntu 22.04+ / Debian 12+, x64·arm64) | iOS·iPadOS 18.0 이상, Android 8.0 Oreo 이상 |
| 채팅 | 가능 | 가능 (모든 플랜) | 가능 |
| 강점 | 어디서나 바로 | 로컬 파일, 데스크톱 확장, Quick Entry 단축키, Cowork, 컴퓨터 사용, Claude Code | 이동 중 대화, 클라우드 작업 시작·확인 |
| Claude Code·Cowork | 클라우드 세션 | 유료 플랜 필요 | Code 탭에서 클라우드 세션 시작·확인 |

- 데스크톱 확장은 설정(Settings) > 확장(Extensions)의 큐레이션 디렉터리에서 로컬 파일·캘린더·메일 등을 연결하는 기능이에요.
- Linux 베타에서는 컴퓨터 사용과 받아쓰기를 쓸 수 없어요.
- 데스크톱의 Code 탭에서는 Local/Cloud 선택, 여러 세션 병렬 실행, 시각적 diff 검토, 스케줄 작업을 쓸 수 있어요. 자세한 내용은 [C12](/claude/c12-claude-code-overview/)와 [C13](/claude/c13-cloud-sessions/)을 보세요.

### Chat과 Cowork 통합 (2026-10-11 기준)

공식 도움말은 "Cowork와 채팅은 하나의 Claude"라고 안내해요. 주요 내용은 다음과 같아요.

- 다단계 에이전트 작업(Cowork)과 채팅이 **한 대화로 통합**돼요. 릴리스 노트(2026-09-16)는 "Claude Cowork comes to every conversation"이라며 Cowork가 하던 일을 어느 대화에서나 쓸 수 있게 하는 새 경험을 롤아웃한다고 안내해요.
- 같은 날 공지로 **디자인·슬라이드·문서 만들기**도 어느 대화에서나 할 수 있어요. 유료 플랜 기능이고 베타예요. Enterprise는 소유자(owner)가 켜기 전까지 기본으로 꺼져 있어요.
- Pro/Max의 웹·데스크톱·모바일부터 **단계적으로 롤아웃**하고, Team/Enterprise는 이후예요. Enterprise는 최소 30일 전에 공지돼요.
- 통합 후에는 **되돌릴 수 없어요.**
- 로컬 파일 접근, 내장 브라우저, 컴퓨터 사용은 **Claude Desktop이 열려 있을 때만** 작동해요.
- 한 곳에서 시작한 작업이 다른 곳에도 나타나고, 모바일에서 클라우드 작업을 시작할 수 있어요.
- 통합 경험에서는 웹 검색 토글이 없고(필요할 때 자동 검색), Research는 `/deep-research` 또는 "+" 버튼으로 시작해요. 전역 지침은 설정(Settings) > Your Claude의 "Instructions for Claude"에 있어요(예전 화면 구성에서는 설정 > Account, 2026-10-26 기준).

<Aside type="note" title="롤아웃은 순차적이에요">
새 경험은 Pro와 Max부터 단계적으로 열리고 있어서, 같은 플랜이라도 계정마다 시점이 달라요. 아직 받지 못한 계정은 입력창에 Chat과 Cowork가 따로 보여요. 다른 플랜은 "곧 이어진다"고만 안내하고 날짜는 공식적으로 공개하지 않아요. Enterprise 관리자에게는 변경 최소 30일 전에 알려 준다고 해요(공식 도움말 "Claude Cowork and chat are one Claude", 2026-10-13 확인). 내 화면이 이 설명과 다르면 공식 도움말에서 최신 내용을 확인하세요. 앱별 모델 선택기에 플랜별로 어떤 모델이 나오는지, 모바일과 웹의 기능 차이를 한 번에 정리한 표는 공식 문서에 없어요.
</Aside>

<Steps>

1. **웹에서 가입·로그인하기**

   claude.ai에 접속해 가입하거나 로그인해요. 만 18세 이상, 지원 지역이어야 해요. 무료 플랜에도 사용 한도가 있지만, 구체적인 수치와 리셋 방식은 공식 문서에 나와 있지 않아요(5시간마다 리셋되는 세션 한도는 유료 플랜 기준으로 안내돼요).

   <ScreenshotPlaceholder caption="claude.ai 로그인 화면" />

2. **데스크톱 앱 설치하기 (선택)**

   claude.ai/download에서 내 운영체제에 맞는 버전을 내려받아 설치하고 로그인해요. 채팅은 모든 플랜에서 되지만 Claude Code와 Cowork는 유료 플랜이 필요해요.

3. **모바일 앱 설치하기 (선택)**

   - iOS: App Store에서 "Claude by Anthropic"을 검색해 받아요(iOS·iPadOS 18.0 이상). Enterprise에서 Microsoft Intune을 쓰는 조직이면 별도의 "Claude for Intune" 앱이 있으니 IT 팀에 먼저 확인하세요.
   - Android: Google Play에서 "Claude by Anthropic"을 검색해 설치해요(Android 8.0 Oreo 이상).
   - 앱이 안 보이면 지원되지 않는 지역·기기·OS 버전일 수 있어요.
   - 웹과 **같은 계정**으로 로그인하세요.

4. **화면 요소 익히기**

   입력창 왼쪽 아래의 "+" 버튼이나 `/`로 추가 기능과 명령을 열어요. 현재 모델은 입력창 아래(웹·데스크톱) 또는 화면 상단(모바일)에 표시되고, 눌러서 바꿀 수 있어요. effort와 확장 사고도 여기서 조절해요. 모델 고르는 법은 [C1](/claude/c01-overview/)을 보세요.

   <ScreenshotPlaceholder caption="입력창의 + 버튼과 모델 선택기" officialUrl="https://support.claude.com/en/articles/8114491-get-started-with-claude" />

5. **첫 대화 해 보기**

   공식 시작 가이드는 간단한 질문으로 시작하고, 구체적으로 요청하고, 후속 질문으로 다듬으라고 안내해요.

## 자주 막히는 지점

### 모바일 앱이 스토어에 안 보여요

- **원인**: 지원되지 않는 지역, 기기, 또는 OS 버전일 수 있어요.
- **해결**: iOS·iPadOS 18.0 이상, Android 8.0 이상인지 확인하세요.

### 데스크톱에서 Code 탭이나 Cowork를 쓸 수 없어요

- **원인**: 유료 플랜이 필요해요.
- **해결**: 플랜을 확인하세요. [C2](/claude/c02-plans-limits/)에서 비교할 수 있어요.

### 웹 검색 토글이 안 보여요

- **원인**: 통합 경험에서는 웹 검색 토글이 없고 필요할 때 자동으로 검색해요.
- **해결**: 그냥 질문하면 돼요.

### 폰에서 시작한 작업이 로컬 파일을 못 읽어요

- **원인**: 로컬 파일 접근, 내장 브라우저, 컴퓨터 사용은 Claude Desktop이 열려 있을 때만 작동해요.
- **해결**: 데스크톱 앱을 켜 두거나, 클라우드 작업으로 진행하세요.

### Linux에서 컴퓨터 사용이 안 돼요

- **원인**: Linux 데스크톱은 베타이고 컴퓨터 사용과 받아쓰기를 지원하지 않아요.
- **해결**: Mac/Windows 데스크톱을 쓰세요.

## 실전 팁

- **같은 계정으로 모두 로그인하세요.** 기기를 옮겨도 대화를 이어갈 수 있어요.
- **처음에는 웹으로 충분해요.** 로컬 파일 작업이 필요해질 때 데스크톱을 설치하세요.
- **모바일은 확인용으로.** 클라우드 작업을 시작하고 결과를 확인하는 데 편해요.
- **개인 설정은 한 번만.** 메모리와 지침은 [C9](/claude/c09-memory-settings/)에서 정리해요.
