<Summary>
- **Cowork** brings Claude Code's agentic approach to **general work instead of coding**. You describe the outcome (what the result should look like), and Claude makes a plan, carries out multiple steps on its own, and hands back documents, spreadsheets, or organized files. You don't need a terminal.
- You can use it on **paid plans (Pro, Max, Ultra, Team, Enterprise)**. For work that uses folders, the browser, or apps on your computer, the **Claude Desktop app on macOS or Windows** has to be open (as of 2026-11-02).
- On Pro, Max, and Ultra, starting 2026-10-06, **new Cowork tasks run in the cloud**. They keep going even if you close your laptop, and you can follow along from your phone or the web. However, steps that access your folders work only while the desktop app is open.
- Cowork and chat are **being merged into one Claude**. The timing varies by account, so if you still see a "Chat" / "Cowork" choice in the input box, you're on the earlier screen.
- There are three approval modes: **Manual**, **Auto**, and **Skip**. Auto is the default on Pro, Max, Ultra, and Team, and Manual is the default on Enterprise (as of 2026-11-02). Use Manual for anything involving money, sending messages, or important files, and the surest safety rule is to **not connect sensitive folders at all**.
</Summary>

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Cowork** | An agent feature where you hand over multi-step work and Claude plans and carries it out, then returns a finished result. It uses the same agent architecture as Claude Code but works without a terminal. |
| **Cloud session** | A task that runs in an isolated, temporary environment on Anthropic's servers. It's created fresh for each session and wiped when it ends. It can't reach your home or company network. |
| **Claude Desktop** | The macOS and Windows app. For a cloud session to reach your computer's folders, built-in browser, and computer use, this app has to be open. |
| **Connected folder** | A folder you've allowed Claude to access. Claude reads and writes files only inside this folder, and permanent deletion can happen inside it too. |
| **Approval mode** | A setting that decides how often Claude asks before acting. |
| **Scheduled task** | A task Claude does automatically at set times. It runs in the cloud, so it runs even when your computer is off. |

<Steps>

1. **Install Claude Desktop and log in**

   Download the app for your operating system from claude.ai/download and install it (see [C3](/claude/c03-getting-started/) for details). You need this app to use folders on your computer. Handing off just document or research work from the web or mobile, without folders, works without the app.

   <ScreenshotPlaceholder caption="The input box on the Claude Desktop home screen (Chat / Cowork choice, or the unified screen)" officialUrl="https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork" />

2. **Prepare a working folder**

   The official safety guide recommends that you **make a dedicated working folder for Claude, don't give broad access, and back up important files**. Don't connect folders that hold financial documents, passwords or credentials, or personal records. We couldn't confirm in the help articles we read this time the exact menu name and order for connecting a folder. Follow the in-app prompts, and it's noted that in the new experience you can see connected folders under "Trusted folders" in Settings.

3. **Start a task**

   In the input box, choose "Cowork" (or just type, on the unified screen) and describe the job. The official help says to write, as if asking a colleague, **the result you want, the format, and the inputs Claude should use (files, links, apps)** together.

   <PromptBox>
   Read the 12 receipt photos in the receipts folder inside my "Work" folder, and make an Excel file that organizes the date, store name, and amount. Add a monthly totals tab too. Don't move or delete the original files. Give me a separate list of any receipts that are hard to read.
   </PromptBox>

   Claude analyzes the request and makes a plan, splits it into subtasks if needed, runs code in an isolated environment, and posts the results to the session. It shows its progress and reasoning, and you can step in partway to change direction.

4. **Choose an approval mode**

   In the input box settings, decide how often Claude asks. Names may differ depending on the screen.

   | Mode | Behavior |
   | --- | --- |
   | **Manual** | Asks you to allow or deny each action. The older name is "Ask before acting." Default on Enterprise. |
   | **Auto** (default on Pro, Max, Ultra, and Team) | Proceeds without stopping, but runs a safety check on every action and blocks risky ones. If blocks keep happening, it goes back to asking one at a time. It's noted that the extra checks **use more of your usage**. |
   | **Skip** (older name: "Act without asking") | Neither asks nor checks. Use it only when you fully trust every element involved. |

   In any mode, **it always asks for permission before permanently deleting files**. Start with Manual.

5. **Watch the progress and review the results**

   If Claude opens unexpected files or sites, or goes beyond the scope of your request, stop it right away. When it finishes, preview and download the result. Spot-check the totals, dates, and names in tables yourself. Claude can make mistakes too.

6. **(Optional) Schedule a low-risk recurring task**

   Inside a Cowork task, type `/schedule` or create one from "Scheduled" in the left sidebar. Scheduled tasks run in the cloud, so they run even when your computer is off. Which tool to pick is compared in [C18](/claude/c18-automate-recurring/).

## Quick reference

### What you can use and what's required (as of 2026-11-02)

| Feature | Where | Desktop app required? |
| --- | --- | --- |
| Starting, steering, and reviewing tasks | Desktop, web, mobile | No |
| Connectors, skills, plugins | Desktop, web, mobile | Plugins that include local MCP servers: desktop only |
| Scheduled tasks | Desktop, web, mobile | No (runs in the cloud) |
| Projects | Everywhere | Projects tied to local folders: desktop only |
| Folders and files on your computer | Tasks started on desktop, and when following along from web or mobile | **Yes.** Only while the app is open |
| Browser use (built-in browser, Claude in Chrome) | Mainly desktop | **Yes** |
| Computer use | Beta on Pro, Max, and Ultra | **Yes** |

### Limitations to know (as of 2026-11-02)

- **Sessions can't be shared**: You can't share a session itself with others. Artifacts you create can be shared individually.
- **Some features are desktop-only** (live artifacts made before 2026-08-19, plugins that include local MCP servers).
- On Team and Enterprise, cloud Cowork is in beta, and admins can restrict things like approval modes.
- Known constraints of the new unified screen are noted as: "Add from GitHub" not supported, no conversation branching, and incognito chats can't create files or run code.

### Usage

Multi-step tasks use more of your usage than quick questions. If you hit your limit often, the guidance is to bundle related work into a single task, start unrelated work in a new conversation, say so if you only need a quick answer, and check Settings > Usage. Per-plan limits are in [C2](/claude/c02-plans-limits/).

## Common sticking points

### I don't see the Cowork choice in the input box

- **Cause**: Your account has received the new unified experience. In that case, any conversation can become a Cowork task. Conversely, if Cowork isn't there at all, your app may be out of date or you may be on the free plan.
- **Fix**: Update the app and check that you're on a paid plan. If you're on Enterprise, check your admin settings.

### A task stopped partway

- **Cause**: If it's a local session started on your computer before 2026-10-06, it can end when Claude Desktop is closed or the computer goes to sleep. Cloud sessions keep running in the background.
- **Fix**: Open the session from any device and check the progress.

### It can't find files in my folder

- **Cause**: A cloud session can reach files on your computer only while the desktop app is open, and only for folders you've connected. If the app is closed, the session keeps running but can't see local files.
- **Fix**: Keep the app open, and check that the folder is connected and where Claude said it would put the output.

### My usage is going down fast

- **Cause**: Multi-step tasks and Auto mode use more of your usage.
- **Fix**: Bundle tasks, split into new conversations, and check your usage in Settings.

### What happens to my earlier local-only tasks?

- After 2026-10-06, new tasks on Pro, Max, and Ultra run in the cloud, and the "Only on your computer" option is gone. Local tasks you already started stay local until they finish. To run something only on your own computer, you're directed to use Claude Code on the desktop ([C12](/claude/c12-claude-code-overview/)). The official docs also describe the procedure for downloading Cowork task data and bringing it into Claude Code.

## Practical tips

- **A folder is a permission.** Claude can read, write, and even permanently delete in the folders you connect. Make a dedicated working folder and back up important files.
- **Separate read tools from write tools.** The official safety guide explains that the size of any harm is determined almost entirely by "what Claude can read and see" and "what it can do." If you only let it read, the risk is much smaller.
- **Know about prompt injection.** Emails, web pages, and documents can contain instructions an attacker has hidden. Have it read only trusted sources, and connect only MCP servers you can trust.
- **Keep scheduled tasks simple.** They run while no one is watching, so start with reversible things like summaries and tidying. Don't schedule anything involving sensitive files, sending messages, or purchases. Check the results each time on the "Scheduled" page, and pause or delete tasks you don't use.
- **The higher the stakes, the more Manual.** Switch to Manual when you first use a new tool, plugin, or site, when sensitive files or accounts are involved, or when the work is hard to undo.
- **Do web tasks only on trusted sites.** The official docs say browser use isn't recommended on logged-in sites or sites involving money or personal information. Computer use has no sandbox, so be especially careful ([C11](/claude/c11-chrome-computer-use/)).
- **Decide the scope of memory.** Cloud sessions carry over your chat memory. To run once without memory, turn Memory off from the "+" menu before you start. You can't change it after starting ([C9](/claude/c09-memory-settings/)).
- **You can delete things.** You can delete a task at any time, and it's noted that it's removed from backend storage within 30 days.
