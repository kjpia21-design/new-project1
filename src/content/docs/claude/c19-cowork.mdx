<Summary>
- **Cowork**는 Claude Code의 에이전트 방식을 **코딩이 아닌 일반 업무**에 가져온 기능이에요. 결과물(결과 형태)을 말하면 Claude가 계획을 세우고, 여러 단계를 스스로 실행해서 문서·스프레드시트·정리된 파일로 돌려줘요. 터미널은 필요 없어요.
- **유료 플랜(Pro, Max, Ultra, Team, Enterprise)**에서 쓸 수 있어요. 내 컴퓨터의 폴더·브라우저·앱을 쓰는 작업은 **macOS 또는 Windows의 Claude Desktop 앱**이 열려 있어야 해요(2026-10-15 기준).
- Pro와 Max에서는 2026-10-06부터 **새 Cowork 작업이 클라우드에서 실행**돼요. 노트북을 닫아도 계속 돌고, 폰·웹에서 이어 볼 수 있어요. 단, 내 폴더에 접근하는 단계는 데스크톱 앱이 열려 있을 때만 돼요.
- Cowork와 채팅은 **하나의 Claude로 합쳐지는 중**이에요. 계정마다 시점이 달라서, 입력창에 "Chat"·"Cowork" 선택이 보이면 아직 이전 화면이에요.
- 승인 방식은 **Manual(기본)**과 **Auto**가 있어요. 돈·메시지 발송·중요한 파일이 걸린 일은 Manual로, 그리고 **민감한 폴더는 아예 연결하지 않는** 것이 가장 확실한 안전 수칙이에요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- Cowork가 채팅, Claude Code와 무엇이 다른지 설명하고, 내 업무에 맞는 곳에 맡길 수 있어요.
- 내 플랜과 기기에서 무엇을 쓸 수 있는지(웹·데스크톱·모바일 차이) 확인할 수 있어요.
- 작업용 폴더를 따로 만들어 권한을 최소로 주고, 승인 방식을 골라 첫 작업을 맡길 수 있어요.
- 프롬프트 인젝션 같은 위험을 이해하고, 예약 작업을 안전하게 설계할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Cowork** | 여러 단계의 업무를 맡기면 Claude가 계획하고 실행해서 완성된 결과물을 돌려주는 에이전트 기능이에요. Claude Code와 같은 에이전트 구조를 쓰지만 터미널 없이 써요. |
| **클라우드 세션** | Anthropic 서버의 격리된 임시 환경에서 도는 작업이에요. 세션마다 새로 만들어지고 끝나면 지워져요. 내 집·회사 네트워크에는 닿지 않아요. |
| **Claude Desktop** | macOS·Windows 앱이에요. 내 컴퓨터의 폴더, 내장 브라우저, 컴퓨터 사용은 이 앱이 열려 있어야 클라우드 세션이 닿을 수 있어요. |
| **연결한 폴더** | 내가 Claude에게 접근을 허용한 폴더예요. Claude는 이 폴더 안에서만 파일을 읽고 쓰고, 영구 삭제도 이 안에서 일어날 수 있어요. |
| **승인 방식** | Claude가 행동 전에 얼마나 물어볼지 정하는 설정이에요. |
| **예약 작업** | 정해진 시간에 Claude가 자동으로 하는 작업이에요. 클라우드에서 돌아서 내 컴퓨터가 꺼져 있어도 실행돼요. |

### Cowork는 무엇이 다른가요?

| 기능 | 이럴 때 | 자세히 |
| --- | --- | --- |
| **채팅** | 질문하고 답을 받는 대화 | [C3](/claude/c03-getting-started/) |
| **Cowork** | 파일·웹·앱을 다루는 여러 단계 업무를 맡기고 결과물을 받을 때 | 이 글 |
| **Claude in Chrome / 컴퓨터 사용** | 브라우저나 앱 화면을 직접 조작해야 할 때 | [C11](/claude/c11-chrome-computer-use/) |
| **Claude Code 클라우드 세션** | GitHub 저장소의 코드 작업을 맡길 때 | [C13](/claude/c13-cloud-sessions/) |
| **반복 실행** | 정해진 일정에 자동으로 돌릴 때 | [C18](/claude/c18-automate-recurring/) |

<Aside type="note" title="Cowork는 이제 그냥 Claude예요 (2026-10-15 기준)">
공식 도움말은 "Claude Cowork is now just Claude"라고 안내해요. 질문을 하면 Claude가 빠른 답변으로 할지 긴 작업으로 할지 스스로 정해요. Pro와 Max부터 단계적으로 열리고 있고, Enterprise에서는 관리자가 베타 설정을 켜야 해요. 입력창에 "Chat"과 "Cowork" 선택이 아직 보이면 이전 화면이고, 한번 새 경험으로 넘어가면 되돌릴 수 없다고 안내돼요. 이 글은 두 화면 모두에 통하게 썼어요. 내 화면이 다르면 [공식 도움말](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)을 확인하세요.
</Aside>

### 어디서 쓸 수 있나요? (2026-10-31 기준)

| 기기 | 제공 |
| --- | --- |
| Claude Desktop (macOS, Windows, Linux 베타) | 모든 유료 플랜. Linux는 베타예요. |
| 웹 (claude.ai)·모바일 (iOS, Android) | Pro, Max, Ultra, Team(Team은 베타). Enterprise는 관리자가 켠 경우 |
| Chrome 사이드 패널 | 모든 유료 플랜. Enterprise는 관리자가 Claude in Chrome과 클라우드 Cowork를 켜야 해요 |

Linux 데스크톱은 2026-10-31 기준 Cowork 시작 가이드에 "Linux (beta)"로 올라 있어요. 같은 문서가 로컬 파일·브라우저·컴퓨터 사용에는 macOS 또는 Windows의 Claude Desktop 앱이 필요하다고 안내하니, Linux에서 되는 범위는 화면 안내와 공식 도움말로 확인하세요. 컴퓨터 사용은 macOS·Windows만 된다고 [C11](/claude/c11-chrome-computer-use/)에 정리돼 있어요. 한국에서의 Cowork 제공은 Claude 자체가 한국에서 제공되는지(Anthropic 제공 국가 목록에 South Korea 포함, 2026-10-15 확인)까지만 확인했고, Anthropic 제공 국가 정책 페이지는 Cowork도 같은 규칙의 적용 대상으로 두고 Cowork만의 지역 제한은 적지 않았어요(2026-10-19 확인).

## 단계별 따라하기

<Steps>

1. **Claude Desktop을 설치하고 로그인하기**

   claude.ai/download에서 내 운영체제용 앱을 받아 설치해요(자세한 내용은 [C3](/claude/c03-getting-started/)). 내 컴퓨터의 폴더를 쓰려면 이 앱이 필요해요. 폴더 없이 웹이나 모바일에서 문서·조사 작업만 맡기는 것은 앱 없이도 돼요.

   <ScreenshotPlaceholder caption="Claude Desktop 홈의 입력창 (Chat·Cowork 선택 또는 통합 화면)" officialUrl="https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork" />

2. **작업용 폴더 준비하기**

   공식 안전 가이드는 **Claude 전용 작업 폴더를 따로 만들고, 넓은 접근을 주지 말며, 중요한 파일은 백업**하라고 권해요. 재무 문서, 비밀번호·인증 정보, 개인 기록이 든 폴더는 연결하지 마세요. 폴더를 연결하는 정확한 메뉴 이름과 순서는 이번에 읽은 도움말에서 확인하지 못했어요. 앱 안의 안내를 따르고, 연결된 폴더는 새 경험에서는 설정(Settings)의 "Trusted folders"에서 볼 수 있다고 안내돼요.

3. **작업 시작하기**

   입력창에서 "Cowork"를 고르고(통합 화면이면 바로) 일을 설명해요. 공식 도움말은 동료에게 부탁하듯 **원하는 결과, 형식, Claude가 쓸 입력(파일·링크·앱)**을 함께 적으라고 해요.

   <PromptBox>
   '작업용' 폴더의 receipts 폴더에 있는 영수증 사진 12장을 읽고, 날짜·가게 이름·금액을 정리한 엑셀 파일을 만들어 주세요. 월별 합계 탭도 넣어 주세요. 원본 파일은 이동하거나 지우지 마세요. 읽기 어려운 영수증은 따로 목록으로 알려 주세요.
   </PromptBox>

   Claude는 요청을 분석해 계획을 세우고, 필요하면 하위 작업으로 나눠 격리된 환경에서 코드를 실행한 뒤 결과를 세션에 올려요. 진행 표시와 추론 과정을 보여 주고, 중간에 끼어들어 방향을 바꿀 수 있어요.

4. **승인 방식 고르기**

   입력창의 설정에서 Claude가 얼마나 물어볼지 정해요. 이름은 화면에 따라 다를 수 있어요.

   | 방식 | 동작 |
   | --- | --- |
   | **Manual (기본)** | 행동마다 허용·거부를 물어요. 예전 이름은 "Ask before acting"이에요. |
   | **Auto** | 멈추지 않고 진행하되, 매 행동을 안전 검사하고 위험하면 막아요. 막힘이 반복되면 다시 하나씩 물어요. 추가 검사 때문에 **사용량을 더 쓴다**고 안내돼요. |
   | **Skip all approvals** | 묻지도, 검사하지도 않아요. 모든 요소를 완전히 믿을 때만 쓰세요. |

   어떤 방식에서든 **파일 영구 삭제 전에는 항상 허락을 물어요**. 처음에는 Manual로 시작하세요.

5. **진행 지켜보고 결과 검토하기**

   Claude가 예상 밖의 파일이나 사이트를 열거나, 요청 범위를 넘어서면 바로 중단하세요. 끝나면 결과물을 미리 보고 내려받아요. 표의 합계, 날짜, 이름은 직접 샘플로 대조해 보세요. Claude도 실수할 수 있어요.

6. **(선택) 낮은 위험의 반복 작업 예약하기**

   Cowork 작업 안에서 `/schedule`을 입력하거나 왼쪽 사이드바의 "Scheduled"에서 만들어요. 예약 작업은 클라우드에서 돌아 내 컴퓨터가 꺼져 있어도 실행돼요. 어떤 도구를 고를지는 [C18](/claude/c18-automate-recurring/)에서 비교해요.

### 알아둘 한계 (2026-10-15 기준)

- **세션 공유 불가**: 세션 자체는 다른 사람과 공유할 수 없어요. 만든 아티팩트는 개별로 공유할 수 있어요.
- **데스크톱 전용 기능**이 일부 있어요(2026-08-19 이전에 만든 라이브 아티팩트, 로컬 MCP 서버가 든 플러그인).
- Team·Enterprise에서는 클라우드 Cowork가 베타이고, 관리자가 승인 방식 등을 제한할 수 있어요.
- 새 통합 화면의 알려진 제약으로 "Add from GitHub" 미지원, 대화 분기 불가, 시크릿 채팅은 파일 생성·코드 실행 불가가 안내돼요.

### 사용량

여러 단계를 거치는 작업은 빠른 질문보다 사용량을 더 써요. 한도를 자주 만나면 관련 일을 한 작업으로 묶고, 관련 없는 일은 새 대화로 시작하고, 빠른 답만 필요하면 그렇게 말하고, 설정(Settings) > 사용량(Usage)에서 확인하라고 안내돼요. 플랜별 한도는 [C2](/claude/c02-plans-limits/)에 있어요.

## 자주 막히는 지점

### 입력창에 Cowork 선택이 안 보여요

- **원인**: 새 통합 경험을 받은 계정이에요. 이 경우에는 어느 대화에서나 Cowork 작업이 돼요. 반대로 Cowork가 아예 없으면 앱이 최신이 아니거나 무료 플랜일 수 있어요.
- **해결**: 앱을 업데이트하고, 유료 플랜인지 확인하세요. Enterprise라면 관리자 설정을 확인하세요.

### 작업이 중간에 멈췄어요

- **원인**: 2026-10-06 이전에 내 컴퓨터에서 시작한 로컬 세션이라면 Claude Desktop이 닫히거나 컴퓨터가 잠들면 끝날 수 있어요. 클라우드 세션은 백그라운드에서 계속 돌아요.
- **해결**: 어느 기기에서든 세션을 열어 진행 상황을 확인하세요.

### 내 폴더의 파일을 못 찾아요

- **원인**: 클라우드 세션은 데스크톱 앱이 열려 있고, 내가 연결한 폴더에 대해서만 내 컴퓨터 파일에 닿을 수 있어요. 앱이 닫혀 있으면 세션은 계속 돌지만 로컬 파일은 못 봐요.
- **해결**: 앱을 열어 두고, 폴더가 연결돼 있는지, Claude가 알려 준 출력 위치가 어디인지 확인하세요.

### 사용량이 빨리 줄어요

- **원인**: 멀티 스텝 작업과 Auto 방식은 사용량을 더 써요.
- **해결**: 작업을 묶고 새 대화로 나누며, 설정에서 사용량을 확인하세요.

### 이전에 쓰던 로컬 전용 작업은 어떻게 되나요?

- 2026-10-06 이후 Pro·Max의 새 작업은 클라우드에서 돌고, "Only on your computer" 옵션은 없어졌어요. 이미 시작한 로컬 작업은 끝낼 때까지 로컬에 남아요. 내 컴퓨터에서만 돌리려면 데스크톱의 Claude Code를 쓰라고 안내돼요([C12](/claude/c12-claude-code-overview/)). Cowork 작업 데이터를 내려받아 Claude Code로 가져가는 절차도 공식 문서에 있어요.

## 실전 팁

- **폴더가 곧 권한이에요.** Claude는 연결한 폴더를 읽고, 쓰고, 영구 삭제할 수도 있어요. 작업용 폴더를 따로 만들고 중요한 파일은 백업하세요.
- **읽기 도구와 쓰기 도구를 구분하세요.** 공식 안전 가이드는 피해의 크기가 "Claude가 무엇을 읽고 볼 수 있는가"와 "무엇을 할 수 있는가"로 거의 정해진다고 설명해요. 읽기만 시키면 위험이 훨씬 작아요.
- **프롬프트 인젝션을 알아 두세요.** 이메일·웹페이지·문서 안에 공격자가 숨긴 지시가 있을 수 있어요. 신뢰하는 출처만 읽게 하고, 믿을 수 있는 MCP만 연결하세요.
- **예약 작업은 단순하게.** 사람이 보지 않는 동안 도니까, 요약·정리처럼 되돌릴 수 있는 일부터 하세요. 민감한 파일, 메시지 발송, 구매는 예약하지 마세요. 매번 "Scheduled" 페이지에서 실행 결과를 확인하고, 안 쓰는 작업은 일시 중지하거나 삭제하세요.
- **걸린 게 클수록 Manual.** 새 도구·플러그인·사이트를 처음 쓸 때, 민감한 파일·계정이 걸릴 때, 되돌리기 어려운 일일 때는 Manual로 바꾸세요.
- **웹 작업은 신뢰하는 사이트에서만.** 로그인한 사이트나 돈·개인정보가 걸린 사이트에서 브라우저 사용은 권하지 않는다고 공식 문서가 밝혀요. 컴퓨터 사용은 샌드박스가 없으니 특히 조심하세요([C11](/claude/c11-chrome-computer-use/)).
- **기억 범위를 정하세요.** 클라우드 세션은 채팅의 메모리를 이어 써요. 메모리 없이 한 번만 돌리려면 시작 전에 "+" 메뉴에서 Memory를 끄세요. 시작 후에는 바꿀 수 없어요([C9](/claude/c09-memory-settings/)).
- **지울 수 있어요.** 작업은 언제든 삭제할 수 있고, 백엔드 저장소에서는 30일 안에 지워진다고 안내돼요.

<Aside type="caution" title="확인하지 못한 항목 (2026-10-31 기준)">
폴더를 연결하는 정확한 메뉴 이름과 순서, 그리고 Linux 베타에서 정확히 어떤 기능이 되는지는 이번에 읽은 공식 도움말에서 확인하지 못했어요. 화면 안내와 공식 도움말을 우선하세요.
</Aside>
