<Summary>
- **Claude Code is not on the Free plan.** The feature table on the official pricing page shows Claude Code as "No" for Free and "Yes" for Pro, Max, Ultra, Team and Enterprise (as of 2026-11-28).
- **Individuals**: Pro ($17 a month billed annually, or $20 monthly), Max ($100) or Ultra ($200). Usage is shared between Claude and Claude Code. **Teams**: every Team seat includes Claude Code; premium seats have more usage.
- **No subscription**: you can instead sign in with a Claude Console account, where Claude Code is **billed by API tokens**.
- **Non-developers**: the official pages do not say who it is "for". The docs do offer a desktop app with a Code tab and a browser version, so a terminal is not the only way in.
- Prices and limits change often. Every figure here is **as of 2026-11-28** and links to its official page.
</Summary>

## Individual plans (as of 2026-11-28)

Claude Code is included in Pro, Max and Ultra, and not in Free. This table keeps only the plans that include it. For the Free plan, the full comparison and usage-limit details, see [C2](/claude/c02-plans-limits/).

| Plan | Price on the pricing page | Usage limits (pricing page) |
| --- | --- | --- |
| Pro | $17 a month with annual discount ($200 billed up front), $20 if billed monthly | More usage than Free, every 5 hours and every week |
| Max | $100 a month | 5x Pro usage every 5 hours and every week |
| Ultra | $200 a month | No 5-hour limit for verified accounts, 10x Pro usage every week |

Source for every cell: [claude.com/pricing](https://claude.com/pricing). Prices shown there do not include applicable tax, and the page says prices and plans are subject to change.

- **One subscription, two tools.** The Help Center says Pro, Max and Ultra give you Claude on web, desktop and mobile and Claude Code in your terminal with one subscription.
- **Shared limits.** Usage in Claude and in Claude Code counts against the same limits. IDE use (VS Code, Cursor and other VS Code forks, JetBrains) counts toward them too.
- **Fable models.** Per the pricing page, Fable is paid with usage credits on Pro, and included up to half of your weekly limit on Max and Ultra. See [C2](/claude/c02-plans-limits/) for the details.
- **Exact Claude Code allowances are not published.** The pages we read give no number of messages or tokens for Claude Code per plan. Check your own usage screen.

## Team and Enterprise

- **Team**: the Help Center says Claude Code is included with every Team plan seat, and premium seats offer more usage for heavier workloads. The pricing page lists standard seats at $20 per seat a month billed annually ($25 monthly) and premium seats at $100 ($125 monthly) as of 2026-11-28.
- **Enterprise**: Claude Code is included with the single Enterprise seat on new and self-serve plans, where usage is billed at API rates with no per-seat usage limits. Older Enterprise plans may use Chat + Claude Code or Premium seats. The pricing page lists Enterprise at US$20 per seat a month billed annually with a 20-seat minimum, plus usage at API rates.
- **Health data**: the Help Center says Claude Code on a HIPAA-ready Enterprise plan is covered by the agreement only after a specific configuration is applied. Ask your admin before using it with protected health information.
- For the admin side, see [C29. Team and Enterprise admin basics](/claude/c29-team-admin-basics/).

## Paying by the token: Console and API

If you do not have a subscription, or your organization prefers usage-based billing, Claude Code can sign in with a Claude Console account.

- The Claude Code docs say Claude Code charges by API token consumption, and subscribers' usage is included in their plan.
- The same page says that across enterprise deployments the average cost is around $13 per developer per active day and $150-250 per developer per month, with costs below $30 per active day for 90% of users. These are averages for enterprises, not a quote for you. The page advises starting with a small pilot to find your own baseline.
- **Watch out for one setting.** The Help Center warns that if an `ANTHROPIC_API_KEY` environment variable is set, Claude Code uses that key instead of your subscription, so you are charged API usage instead of using your plan.
- **Monthly API credits do not cover it.** The Max, Ultra and Team API credits cannot be used in Claude Code or the Claude apps.
- Current API prices per million tokens are on the [pricing page](https://claude.com/pricing). For how agent work uses up allowances, see [Agent costs and usage limits](/agents/09-agent-usage-limits/).

## When you hit the limit

The Help Center lists these options for individual plans. For Pro, upgrade to Max, turn on usage credits, switch to a Console account with API credits, or wait for the reset. For Max, the same list with Ultra as the upgrade. For Ultra, usage credits, a Console account, or waiting.

- Pro and Max have a five-hour session limit and a weekly limit. Ultra has a weekly limit, with no five-hour limit for verified accounts.
- Claude Code may keep working briefly to finish a step in progress ("Usage limit reached · wrapping up"). The page says this is small, counts toward the weekly limit, and is rolling out gradually.
- The `/status` command shows your remaining allocation, per the Help Center. If you are billed through usage credits or the API, the cost grows with use, so decline the option when it is offered if you want to stay within your plan.

## Can non-developers use Claude Code?

The official pages do not describe a target audience, so here is only what they state.

- The docs say Claude Code runs on the terminal, IDE extensions, a desktop app and the web. The desktop app has a **Code** tab and does not need the command-line install, and it requires a paid subscription. The web version runs in your browser with no local setup.
- The docs also include a guide on how to open a terminal for people who have not used one.
- Whether it suits you depends on your task, which these pages cannot tell you. For a hands-on first project, see [Getting started with Claude Code](/coding/06-claude-code-start/).

## Common sticking points

### I signed in but I am being charged API usage

- **Cause**: An `ANTHROPIC_API_KEY` environment variable takes priority over your subscription.
- **Fix**: Remove the variable, then sign in again with your Claude account, as the Help Center describes.

### I do not see the subscription login option

- **Cause**: An older Claude Code version or an existing login.
- **Fix**: Use `/logout`, run `claude update`, restart the terminal and run `claude` again.
