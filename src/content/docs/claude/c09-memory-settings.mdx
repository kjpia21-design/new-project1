<Summary>
- 메모리는 대화 중에 **주제(topic) 단위로 자동 저장**돼요. "이거 기억해줘"라고 직접 요청할 수도 있어요.
- Free/Pro/Max는 **기본 켜짐**이에요. Team/Enterprise는 조직 Owner가 켜야 해요. (2026-10-10 기준)
- 설정(Settings) > 메모리(Memory)에서 켜고 끄고, 저장된 주제를 보고 고치고 지울 수 있어요.
- 기록을 남기기 싫으면 **시크릿(incognito) 채팅**을 쓰세요.
- Claude Code의 메모리(CLAUDE.md, auto memory)는 별개예요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 메모리가 무엇을 저장하고 무엇을 저장하지 않는지 설명할 수 있어요.
- 메모리를 켜고, 끄고, 일시정지하고, 초기화할 수 있어요.
- 저장된 내용을 확인하고 수정·삭제할 수 있어요.
- 기록을 남기지 않는 채팅과 이전 대화 검색을 쓸 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **메모리(memory)** | 대화에서 알게 된 나에 대한 정보를 주제 단위로 저장해 다음 대화에 활용하는 기능이에요. 대화가 끝난 뒤 요약하는 방식이 아니라 대화 중에 저장돼요. |
| **채팅 검색(chat search)** | "지난번에 X에 대해 뭐라고 했지?"처럼 물으면 과거 대화를 검색해 출처를 인용해 주는 기능이에요. 유료 플랜(Pro/Max/Team/Enterprise)에서 쓸 수 있어요. |
| **시크릿(incognito) 채팅** | 기록과 메모리에 저장되지 않고 이후 검색도 안 되는 채팅이에요. |
| **프로젝트 메모리** | 프로젝트마다 별도의 메모리 공간과 요약이 있어서 다른 프로젝트·일반 채팅과 분리돼요. |

### 무엇을 저장하고 무엇을 저장하지 않나요?

- 건강·정치·종교 같은 **민감 주제**는 옵트인하지 않으면 저장하지 않아요.
- **정부 신분증 번호와 금융 계좌번호**는 저장하지 않아요.

### 플랜별 기본값

- **Free/Pro/Max**: 기본 켜짐.
- **Team/Enterprise**: 조직 Owner가 활성화해야 하고, 멤버별로도 꺼진 상태에서 시작해요. Owner는 개별 멤버의 메모리를 보거나 편집할 수 없어요. 조직 차원에서 끄면 모든 사람의 메모리가 영구 삭제돼요.
- HIPAA·공공 부문·맞춤 데이터 보존 계약 조직에는 제공되지 않아요.

<Aside type="note" title="확인되지 않은 점">
공식 메모리 도움말(2026-10-10)에는 메모리 용량이나 주제 개수의 한도가 적혀 있지 않아요. 한도 숫자가 필요하면 설정(Settings) > 메모리(Memory) 화면이나 고객지원에 확인하세요. 구형 "설정(Settings) > 기능(Capabilities) > 메모리(Memory)" 화면이 일부 계정에 남아 있을 수 있어요(일부 Team/Enterprise 조직은 레거시 버전을 씀). 내 화면이 다르면 공식 도움말에서 최신 내용을 확인하세요.
</Aside>

## 단계별 따라하기

  '채팅에서 기억해 달라고 요청해 봤어요',
  '저장된 주제를 열어 보고 수정 또는 삭제해 봤어요',
  '시크릿 채팅 위치를 확인했어요',
  '채팅 검색을 써 봤어요',
]} />

<Steps>

1. **메모리 켜짐 상태 확인하기**

   설정(Settings) > 메모리(Memory)에서 "Generate memory from chats"가 켜져 있는지 확인해요.

   <ScreenshotPlaceholder caption="설정(Settings) > 메모리(Memory) 화면" officialUrl="https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context" />

2. **기억해 달라고 요청하기**

   <PromptBox>
   내 직업은 데이터 분석가라는 걸 기억해줘. 앞으로 보고서를 쓸 때는 결론을 먼저 말하고 근거를 뒤에 붙이는 형식으로 도와줘.
   </PromptBox>

3. **저장된 내용 보기·수정·삭제하기**

   설정(Settings) > 메모리(Memory)의 주제(Topics)를 열어서 연필 아이콘으로 편집하거나 삭제(Delete)해요. 채팅에서 "그건 잊어줘"라고 말해도 돼요.

4. **일시정지와 초기화 구분하기**

   - **일시정지(Pause)**: 기존 메모리는 유지하되 사용도, 추가도 멈춰요.
   - **초기화(Reset)**: 프로젝트 메모리를 포함해 전부 영구 삭제해요. **되돌릴 수 없어요.**

5. **기록을 남기지 않고 쓰기**

   - 한 채팅에서만 메모리를 끄려면 첫 메시지를 보내기 전에 "+" 메뉴에서 메모리를 꺼요. 채팅을 시작한 뒤에는 바꿀 수 없어요.
   - 새 채팅 화면 오른쪽 위의 유령 아이콘을 누르면 시크릿 채팅이 돼요.

6. **지난 대화 검색하기 (유료 플랜)**

   <PromptBox>
   지난번에 내가 신제품 가격 전략에 대해 뭐라고 했는지 찾아서 요약해줘.
   </PromptBox>

   이 기능은 설정(Settings) > 메모리(Memory)의 "Search and reference chats"로 끌 수 있어요.

7. **다른 AI의 메모리 가져오기 (선택)**

   Free/Pro/Max/Team에서 웹과 Claude Desktop으로 쓸 수 있어요.

   1. 지금 쓰는 다른 AI 서비스에 저장된 메모리와 맥락을 코드 블록 하나로 정리해 달라고 요청해요(공식 도움말에 안내 문구가 있어요). 민감한 정보는 미리 지우세요.
   2. 설정(Settings) > 메모리(Memory)에서 "Start import"를 누르고 텍스트를 붙여넣은 뒤 "Add to memory"를 눌러요.
   3. 개별 항목으로 저장되며, "See what Claude learned about you" 버튼이나 질문으로 확인해요.

   가져오기는 실험적 기능이라서 모든 내용이 반영되지 않을 수 있고, Claude는 업무 관련 주제에 집중하기 때문에 업무와 무관한 개인 정보는 남지 않을 수 있어요.

</Steps>

## 빠른 참조표

| 하고 싶은 일 | 방법 |
| --- | --- |
| 메모리 켜기/끄기 | 설정(Settings) > 메모리(Memory) > Generate memory from chats |
| 잠시 멈추기 | Pause (기존 메모리 유지) |
| 전부 삭제 | Reset (프로젝트 메모리 포함, 되돌릴 수 없음) |
| 저장 내용 수정 | 메모리(Memory) > 주제(Topics) > 편집/Delete, 또는 채팅에서 "잊어줘" |
| 한 채팅만 메모리 끄기 | 첫 메시지 전에 "+" > Memory 끄기 |
| 기록 안 남기기 | 새 채팅 오른쪽 위 유령 아이콘(시크릿) |
| 지난 대화 검색 끄기 | 메모리(Memory) > Search and reference chats |
| 메모리 가져오기 | 메모리(Memory) > Start import |
| 메모리 내보내기 | 설정(Settings) > 기능(Capabilities)의 "View and edit your memory"(공식 도움말 기준), 또는 Claude에게 메모리를 그대로 써 달라고 요청 |
| 전체 대화 데이터 내보내기 | 설정(Settings) > 개인정보(Privacy) > Export data (링크는 24시간 후 만료) |

## 자주 막히는 지점

### 대화를 지웠는데 메모리는 남아 있어요

- **원인**: 메모리는 대화 보존 정책을 따르지만, 대화를 삭제해도 그 대화로 생긴 메모리는 별도로 삭제해야 해요.
- **해결**: 설정(Settings) > 메모리(Memory)에서 해당 주제를 삭제하세요.

### 이미 시작한 채팅에서 메모리를 끌 수 없어요

- **원인**: 채팅별 메모리 끄기는 첫 메시지 전에만 바꿀 수 있어요.
- **해결**: 새 채팅을 열어 시작 전에 끄거나 시크릿 채팅을 쓰세요.

### 팀 계정인데 메모리가 안 켜져요

- **원인**: Team/Enterprise는 조직 Owner가 먼저 활성화해야 하고, 멤버별로도 꺼진 상태에서 시작해요.
- **해결**: 관리자에게 문의하세요.

### 채팅 검색이 안 돼요

- **원인**: 유료 플랜 기능이거나, "Search and reference chats"가 꺼져 있을 수 있어요.
- **해결**: 플랜과 설정을 확인하세요.

### Cowork에서 메모리가 반영되지 않아요

- **원인**: Cowork는 클라우드에서 실행될 때만 채팅과 메모리를 공유해요. 로컬 Cowork 세션은 메모리를 쓰지 않아요.
- **해결**: 클라우드 실행인지 확인하세요.

## 실전 팁

- **Reset 전에는 내보내기부터.** 초기화하면 되돌릴 수 없으니 필요한 내용은 먼저 Claude에게 그대로 써 달라고 해서 저장해 두세요.
- **민감한 대화는 시크릿 채팅으로.** 메모리와 검색에 남지 않아요.
- **정기적으로 주제 목록을 훑어보세요.** 틀린 내용이 쌓이면 답도 어긋나요.
- **Claude Code의 메모리는 따로 있어요.** CLAUDE.md(내가 작성)와 auto memory(Claude가 작성)가 있고, 자세한 내용은 [C14](/new-project1/claude/c14-claude-code-features/)에서 다뤄요.
- **전역 지침**: 통합 경험에서는 설정(Settings) > 일반(General)의 "Instructions for Claude"에 항상 적용할 지침을 쓸 수 있어요([C3](/new-project1/claude/c03-getting-started/) 참고).
