<Summary>
- **웹 검색**은 한두 번의 검색으로 답할 수 있는 사실 확인용이에요. 모든 응답에 인용(citation)이 붙어요.
- **Research**는 여러 번 검색하며 단계적으로 조사해서 인용이 달린 보고서를 주는 기능이에요. 유료 플랜(Pro, Max, Team, Enterprise)의 웹·데스크톱·모바일에서 쓰고, 웹 검색이 켜져 있어야 해요.
- 공식 도움말은 Research를 "5회 이상의 도구 호출, 1~3분이 걸리는 포괄적 조사"에 쓰라고 안내해요.
- 두 기능 모두 사용량 한도에 합산돼요. 특히 Research는 한도를 더 빨리 쓸 수 있어요.
- 인용 링크를 눌러 출처를 직접 확인하는 습관이 가장 중요해요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 질문의 크기에 맞춰 일반 대화, 웹 검색, Research 중 알맞은 방법을 고를 수 있어요.
- Research를 켜고, 조사 범위를 좁힌 질문으로 보고서를 받을 수 있어요.
- 인용 링크로 출처를 검증하고, 부족한 부분을 후속 질문으로 보완할 수 있어요.
- 사용량을 아끼면서 리서치를 돌리는 요령을 알 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **웹 검색(Web search)** | 실시간 웹 콘텐츠를 근거로 답하는 기능이에요. URL을 주면 그 페이지 전체를 가져올 수도 있어요. |
| **인용(Citation)** | 답변이 어떤 웹 출처에서 나왔는지 보여 주는 링크예요. 웹 검색 응답에는 모두 포함돼요. |
| **Research** | Claude가 앞선 결과를 바탕으로 다음에 조사할 것을 스스로 정해 여러 번 검색하는 기능이에요. 웹과 연결된 Gmail, Google Calendar, Google Docs를 함께 활용해요. |
| **확장된 사고(Extended thinking)** | 최신 웹 정보 없이 깊이 추론해야 하는 작업(수학, 디버깅 등)에 쓰는 기능이에요. 웹 검색과 별개예요. |

### 어떤 방법을 고를까요?

| 질문 종류 | 알맞은 방법 | 예시 |
| --- | --- | --- |
| 한두 번의 검색으로 답이 나오는 사실형 질문 | 웹 검색 | "오늘 서울 날씨는?", "어제 경기 결과는?" |
| 최신 정보 없이 깊이 따져야 하는 문제 | 확장된 사고 | 수학 문제, 코드 디버깅 |
| 여러 출처를 모아 비교·정리해야 하는 포괄적 조사 | Research | 경쟁사 비교, 정책 변화 정리 |

공식 도움말은 웹 검색을 "한두 번의 도구 호출로 답할 수 있는 단순한 사실형 질문"에, Research를 "5회 이상의 도구 호출과 1~3분이 걸리는 포괄적 조사"에 쓰라고 설명해요. Research와 확장된 사고를 함께 쓰면 더 길고 종합적인 보고서를 받을 수 있다고 안내해요.

### 지원 모델

웹 검색은 Haiku 5.5, Sonnet 5.5, Opus 5.5, Fable 5.1을 포함한 여러 모델에서 쓸 수 있어요(2026-10-10 기준). 모델 비교는 [C1. Claude 한눈에 보기](/new-project1/claude/c01-overview/)를 참고하세요.

<Aside type="note" title="통합 Claude 경험에서는 화면이 달라요">
새 통합 Claude 경험에서는 웹 검색 토글이 따로 없고, 도움이 된다고 판단하면 Claude가 자동으로 검색해요. Research는 `/deep-research`를 입력하거나 "+" 버튼으로 시작해요(2026-10-10 기준). 화면 구성은 계정과 앱 버전에 따라 다를 수 있어요.
</Aside>

<Aside type="note" title="확인되지 않은 점">
Research의 정확한 소요 시간 상한, 횟수 상한, 플랜별 별도 한도는 공식 문서에서 확인하지 못했어요. 설정(Settings) > 사용량(Usage) 화면과 공식 도움말에서 최신 내용을 확인하세요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '웹 검색이 켜져 있는지 확인했어요',
  'Research를 켜고 구체적인 질문을 보냈어요',
  '인용 링크를 눌러 핵심 주장의 출처를 확인했어요',
  '(선택) Gmail·Drive 같은 내 자료도 함께 찾아 달라고 요청했어요',
  '후속 질문으로 부족한 부분을 보완했어요',
]} />

<Steps>

1. **웹 검색 확인하기**

   입력창의 "+"를 눌러 웹 검색(Web search)에 체크가 되어 있는지 확인해요. Research는 웹 검색이 켜져 있어야 작동해요. 통합 경험에서는 토글이 없을 수 있어요. Team/Enterprise 계정이라면 조직 Owner가 조직 설정(Organization settings) > Capabilities에서 먼저 켜야 해요.

   <ScreenshotPlaceholder caption="입력창 '+' 메뉴에서 웹 검색과 Research를 고르는 화면" />

2. **Research 켜기**

   "+" > Research를 선택하면 파란색으로 표시돼요. 다시 누르면 꺼져요. 통합 경험에서는 `/deep-research`로 시작해도 돼요. 유료 플랜의 웹·데스크톱·모바일에서 쓸 수 있어요.

3. **범위를 좁힌 질문 보내기**

   주제, 기준, 원하는 결과 형태를 함께 적으면 조사 방향이 선명해져요.

   <PromptBox>
   2026년 국내 전기차 보조금 변화를 정부 발표와 언론 보도 기준으로 정리해 주세요. 달라진 점을 표로 정리하고, 정부 발표와 언론 보도가 다른 부분이 있으면 따로 표시해 주세요. 마지막에 확인이 안 된 부분도 알려 주세요.
   </PromptBox>

   Research는 인용이 포함된 답을 "몇 분" 안에 줘요. 진행하는 동안 기다리거나 다른 작업을 해도 돼요.

4. **인용 링크로 출처 확인하기**

   보고서에서 중요한 숫자나 주장 몇 개를 골라 인용 링크를 눌러 보세요. 원문이 실제로 그렇게 말하는지 직접 확인하는 단계예요. 보고서를 외부에 쓸 거라면 이 단계를 건너뛰지 마세요.

5. **내 자료까지 함께 찾기 (선택)**

   Gmail, Google Calendar, Google Docs를 연결해 두었다면 내 자료도 함께 조사하게 할 수 있어요. 커넥터 연결은 [C7. 커넥터로 Gmail·캘린더·Drive·Notion 연결하기](/new-project1/claude/c07-connectors/)를 참고하세요.

   <PromptBox>
   내 Drive와 Gmail에서도 이 주제와 관련된 자료를 찾아서, 웹에서 찾은 내용과 함께 정리해 주세요. 내 자료에서 가져온 내용과 웹에서 가져온 내용을 구분해서 표시해 주세요.
   </PromptBox>

6. **후속 질문으로 다듬기**

   부족한 부분을 짚어 다시 물어요. 처음부터 Research를 다시 돌리기보다 일반 대화로 이어가면 사용량을 아낄 수 있어요.

   <PromptBox>
   위 보고서에서 출처가 하나뿐인 주장을 골라 주세요. 그 주장을 뒷받침하는 다른 출처가 있는지 추가로 검색해서 알려 주세요.
   </PromptBox>

</Steps>

## 빠른 참조표

### 웹 검색과 Research 비교

| 항목 | 웹 검색 | Research |
| --- | --- | --- |
| 용도 | 사실형 질문 | 포괄적 조사 |
| 규모 | 한두 번의 도구 호출 | 5회 이상, 1~3분(공식 도움말 기준) |
| 켜는 법 | "+" > Web search (통합 경험에서는 자동) | "+" > Research 또는 `/deep-research` |
| 내 자료 활용 | URL을 주면 페이지 전체를 가져와요 | Gmail, Google Calendar, Google Docs를 웹과 함께 활용 |
| 결과 | 인용이 포함된 답 | 인용이 포함된 보고서 |
| 필요 조건 | 계정 설정 (Team/Enterprise는 Owner가 먼저 켜야 함) | 유료 플랜 + 웹 검색 켜짐 |
| 사용량 | 한도에 합산 | 한도에 합산, 더 빨리 소모될 수 있음 |

### 사용량과 관리자 설정

| 항목 | 내용 |
| --- | --- |
| 한도 합산 | 웹 검색과 가져오기 모두 한도에 합산돼요. 긴 글을 가져오면 컨텍스트를 많이 써요. |
| Free 계정 | 한도가 5시간마다 리셋돼요. |
| 초과 사용 | usage credits가 Research에도 적용돼요. Research 세션은 토큰을 빠르게 소모해요. |
| 이미지 검색 | 검색 결과 이미지를 출처 링크와 함께 보여 줘요. Bing 기반이에요. |
| 위치 | 대략적인 위치를 IP로 추정할 수 있어요. |
| 커넥터 도구 | 고급 리서치는 커넥터 도구를 추가 승인 없이 호출해요. 로컬 MCP 서버는 쓸 수 없어요. 쓰기 가능한 도구는 미리 끄라는 권고가 있어요. |

한도 구조 전반은 [C2. 요금제와 사용량 한도](/new-project1/claude/c02-plans-limits/)에서 다뤄요.

## 자주 막히는 지점

### Research 메뉴가 안 보여요

- **원인**: 무료 플랜이거나, 웹 검색이 꺼져 있거나, Team/Enterprise에서 Owner가 기능을 켜지 않았을 수 있어요.
- **해결**: 유료 플랜인지, 웹 검색이 켜져 있는지 확인하세요. 조직 계정이면 관리자에게 Organization settings > Capabilities를 확인해 달라고 요청하세요. 통합 경험에서는 `/deep-research`를 입력해 보세요.

### 보고서에 출처가 부족하거나 틀린 것 같아요

- **원인**: 인용이 있어도 요약 과정에서 원문과 다르게 옮겨질 수 있어요.
- **해결**: 인용 링크를 눌러 원문을 직접 확인하세요. 후속 질문으로 "이 주장의 원문 문장을 그대로 보여 줘"라고 요청해도 좋아요.

### 한도가 평소보다 빨리 줄어요

- **원인**: Research는 여러 출처를 가져오기 때문에 일반 대화보다 한도를 더 빨리 소모할 수 있어요.
- **해결**: 사실형 질문은 웹 검색으로 충분한지 먼저 따져 보세요. 필요 없는 대화에서는 웹 검색을 끄세요.

### 내 Gmail·Drive 자료가 반영되지 않아요

- **원인**: 연결이 안 되어 있거나, 질문에서 내 자료를 찾으라고 지시하지 않았을 수 있어요.
- **해결**: 커넥터 연결을 확인하고, "내 Drive/Gmail에서도 관련 자료를 찾아줘"라고 명확히 요청하세요.

### 로컬 MCP 서버를 쓰는 도구가 리서치에서 안 돼요

- **원인**: 고급 리서치는 로컬 MCP 서버를 쓸 수 없어요.
- **해결**: 원격 커넥터를 쓰세요. [C7. 커넥터로 Gmail·캘린더·Drive·Notion 연결하기](/new-project1/claude/c07-connectors/)를 참고하세요.

## 실전 팁

- **질문에 기준을 넣으세요.** "정부 발표와 언론 보도 기준", "2025년 이후 자료만"처럼 범위를 정하면 결과가 훨씬 쓸 만해요. 프롬프트 요령은 [C4. 프롬프트 잘 쓰는 법](/new-project1/claude/c04-prompting/)에서 다뤄요.
- **표 형식을 요청하세요.** 비교·정리형 조사는 표로 달라고 하면 빈틈이 한눈에 보여요.
- **확인 안 된 부분을 따로 적게 하세요.** "확인이 안 된 부분도 알려 주세요"를 붙이면 단정하는 문장이 줄어요.
- **쓰기 가능한 커넥터는 미리 끄세요.** 리서치는 커넥터 도구를 추가 승인 없이 호출해요. 읽기만 필요하면 쓰기 도구를 꺼 두세요.
- **사실형 질문은 웹 검색으로.** 한두 번 검색이면 되는 질문에 Research를 쓰면 한도만 더 써요.
- **보고서는 초안으로 보세요.** 중요한 결정에 쓰기 전에는 핵심 출처를 직접 열어 확인하세요.
