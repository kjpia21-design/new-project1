<Summary>
- 유료 플랜(Pro·Max·Team·Enterprise)에는 **5시간마다 리셋되는 세션 한도**와 **주 1회 리셋되는 주간 한도**가 있어요.
- Claude 앱(웹·데스크톱·모바일)과 Claude Code는 **같은 한도를 함께 써요.**
- 메시지 몇 개, 토큰 몇 개 같은 **절대 수치는 공식적으로 공개하지 않아요.** 내 사용량은 설정(Settings) > 사용량(Usage)에서 확인해요.
- 한도를 다 쓰면 멈추는 대신 **추가 사용량(usage credits)** 으로 종량제로 이어 쓸 수 있어요. 직접 켜야 해요.
- 가격과 한도는 자주 바뀌니 이 문서는 **2026-10-10 기준**으로 읽어 주세요. (가격은 미국 기준)
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 내게 맞는 요금제를 고를 수 있어요.
- 세션 한도, 주간 한도, 추가 사용량이 어떻게 이어지는지 설명할 수 있어요.
- 내 사용량과 다음 리셋 시점을 직접 확인할 수 있어요.
- 한도에 걸렸을 때 기다릴지, 모델을 바꿀지, 추가 사용량을 켤지 판단할 수 있어요.

## 먼저 알아둘 개념

<PlanFlowDiagram />

| 용어 | 뜻 |
| --- | --- |
| **세션 한도(session limit)** | 5시간마다 리셋되는 한도예요. 유료 플랜에 적용돼요. |
| **주간 한도(weekly limit)** | 주 1회 리셋되는 한도예요. 모든 모델에 적용되고, 리셋 시각은 계정마다 정해진 고정 시각이에요. 다음 리셋은 설정(Settings) > 사용량(Usage)에서 확인해요. |
| **추가 사용량(usage credits)** | 한도를 다 쓴 뒤 막히는 대신, 표준 API 요율의 **종량제**로 이어서 쓰게 해 주는 기능이에요. 선불로 충전해요. 공식 문서에서는 "extra usage"라고도 불러요. |
| **좌석(seat)** | Team·Enterprise에서 구성원 한 명에게 주는 자리예요. 좌석 종류(스탠더드·프리미엄)에 따라 사용량이 달라요. |

### 사용량은 무엇에 따라 달라질까요?

대화 길이와 복잡도, 사용한 기능, 선택한 모델, 선택한 effort, 그리고 요금제에 따라 달라져요. 같은 한도라도 긴 대화나 큰 모델을 쓰면 더 빨리 줄어요.

### 한도는 어디까지 공유될까요?

- Claude(웹·앱), Claude Code, 데스크톱 앱은 **같은 한도를 공유**해요. VS Code·Cursor·JetBrains에서 Claude Code를 쓴 사용량도 합산돼요.
- Team 한도는 팀 전체가 아니라 **구성원별**이에요.
- 클라우드 세션도 별도 VM 요금 없이 같은 플랜 사용량에 합산돼요. 자세한 내용은 [C13. 클라우드 세션](/claude/c13-cloud-sessions/)에서 다뤄요.

### 절대 수치는 공개하지 않아요

<Aside type="note" title="몇 개까지 쓸 수 있나요?">
세션당 메시지 몇 개, 토큰 몇 개 같은 구체적인 수치는 공식 문서에 나와 있지 않아요. 공식 도움말은 사용량이 대화의 길이와 복잡도, 쓰는 기능, 모델, 선택한 effort 수준에 따라 달라진다고만 설명하고 숫자는 밝히지 않아요(2026-10-13 확인). 공식 문서에서 확인할 수 없는 수치는 근거가 없다고 보세요. 확실한 건 설정(Settings) > 사용량(Usage) 화면에 표시되는 내 사용량뿐이에요. 요금제 비교에서도 "Free 대비 5시간 세션당 최소 5배" 같은 **상대적인 배수**만 안내돼요.
</Aside>

### Fable 모델의 한도는 조금 달라요

Fable 모델(모델 소개는 [C1](/claude/c01-overview/))의 한도는 공식 문서 두 곳의 설명이 서로 달라서, **둘 다 소개하고 실제 화면을 확인하라**고 안내드려요.

- **Claude Code용 Pro/Max 안내 문서**: "Max 플랜은 Fable에 대한 별도의 주간 한도도 있다"고 설명해요.
- **"Claude Fable models on your plan" 문서**: Fable 5와 5.1은 Free를 뺀 모든 유료 플랜에서 쓸 수 있어요. Max, Team 프리미엄 좌석, Enterprise 프리미엄 좌석은 플랜에 포함돼 **주간 한도의 최대 50%까지 추가 비용 없이** Fable에 쓸 수 있어요. 이 50%는 추가 용량이 아니라 같은 주간 한도 안의 상한이고, Fable은 다른 모델보다 한도를 더 빨리 소모해요. Pro, Team 스탠더드, Enterprise 스탠더드 좌석은 Fable이 플랜 한도에 포함되지 않고 usage credits(종량)로만 쓸 수 있어요.

어느 설명이 최신인지는 단정하기 어려워요. **설정(Settings) > 사용량(Usage) 화면에서 실제로 표시되는 항목을 확인하세요.** 또 Claude Code에서 Fable을 쓰려면 Fable 5는 v2.1.170 이상, Fable 5.1은 v2.1.255 이상이 필요해요. (Claude Code Model configuration 문서는 Fable 5.1에 v2.1.257 이상이라고 적고 있어요. 2026-10-12 기준 두 문서의 숫자가 달라서, 안 보이면 최신 버전으로 업데이트하세요.)

### "클라우드 세션 크레딧"이라는 항목을 봤다면

<Aside type="caution" title="계정에 따라 보일 수 있는 항목">
공식 문서는 클라우드 세션을 "별도 VM 요금 없이 플랜 사용량에 합산"된다고 설명해요. 그런데 일부 계정의 설정(Settings) > 사용량(Usage) 화면에는 **"클라우드 세션 크레딧"** 항목이 표시되는데, 화면의 설명은 "클라우드 세션에 자동으로 적용되고, 모두 쓰거나 만료되면 플랜의 일반 사용량이 적용된다"는 내용이에요.

이 항목은 **2026-10-13 기준 공식 문서에 설명이 없어요.** 사용량 한도 문서, Claude Code용 Pro/Max 문서, 클라우드 세션 문서 어디에도 나오지 않아요. 그래서 위 usage credits(추가 사용량)와 같은 것인지, 누구에게 어떤 조건으로 주어지는지는 공식적으로 알려지지 않았어요. 내 화면에 보이면 화면 설명을 기준으로 이해하시고, 안 보여도 이상한 게 아니에요.
</Aside>

## 단계별 따라하기

  '내 현재 요금제와 사용량 화면을 확인했어요',

  'Claude Code에서 /usage 또는 /status를 실행해 봤어요',
  '추가 사용량(usage credits)을 켤지 말지 정했어요',
  '(켠다면) 월 지출 한도를 정했어요',
  '한도에 걸렸을 때의 대처 순서를 알아 뒀어요',
]} />

<Steps>

1. **내 사용량 확인하기**

   claude.ai에 로그인해 설정(Settings) > 사용량(Usage)으로 들어가요. 현재 세션 한도와 주간 한도의 사용 정도, 다음 리셋 시점을 볼 수 있어요.

   <ScreenshotPlaceholder caption="설정(Settings) > 사용량(Usage) 화면의 세션·주간 한도 표시" officialUrl="https://support.claude.com/en/articles/12429409-extra-usage-for-paid-claude-plans" />

   Claude Code를 쓴다면 터미널에서도 확인할 수 있어요.

   ```sh
   /usage
   /status
   ```

2. **내게 맞는 요금제 고르기**

   아래 [빠른 참조표](#빠른-참조표)에서 요금제를 비교해요. 처음에는 Free로 시작해서 한도에 자주 걸리면 Pro, 그래도 부족하면 Max를 보는 순서가 무난해요. 여러 명이 함께 쓴다면 Team을 살펴보세요.

3. **추가 사용량(usage credits) 켜기 (선택)**

   한도가 끝나도 작업을 이어 가고 싶을 때만 켜세요. 대상은 Pro, Max 5x, Max 20x(그리고 Team, 좌석제 Enterprise)예요.

   1. 설정(Settings) > 사용량(Usage) > 사용량 크레딧(Usage credits)에서 켜기(Enable)를 눌러요.
   2. 결제 수단을 등록해요.
   3. **월 지출 한도**를 정해요. 한도를 두지 않는 것도 선택할 수 있지만, 처음에는 상한을 두는 편이 안전해요.
   4. 크레딧을 선불로 충전(Add funds)해요.

   자동 충전(auto-reload)과 사용량 알림도 설정할 수 있어요. 모바일 앱으로 구독했다면 활성화와 구매는 **웹에서만** 가능해요.

   <ScreenshotPlaceholder caption="사용량 크레딧(Usage credits) 켜기와 월 지출 한도 설정 화면" officialUrl="https://support.claude.com/en/articles/12429409-extra-usage-for-paid-claude-plans" />

   Claude Code에서는 `/usage-credits` 명령으로 설정해요.

   <Aside type="tip" title="언제 이어서 쓰이나요?">
   Pro는 5시간 한도와 주간 한도를 다 쓴 뒤에, Max는 5시간·주간·Fable 주간 한도를 다 쓴 뒤에 적용돼요. 리서치(Research) 모드와 프로젝트 콘텐츠도 한도를 넘으면 크레딧을 소모해요.
   </Aside>

4. **한도에 걸렸을 때 대처하기**

   메시지 종류에 따라 해결법이 달라요.

   - `You've hit your Opus limit`, `Sonnet limit`처럼 **모델 계열별** 메시지 → Claude Code에서 `/model`로 다른 계열로 바꾸면 계속할 수 있어요.
   - `session limit`, `weekly limit` 메시지 → **모든 모델 공통**이라 모델을 바꿔도 풀리지 않아요.

   모든 모델 공통 한도라면 선택지는 이 정도예요.

   - 리셋까지 기다리기 (다음 리셋은 설정(Settings) > 사용량(Usage)에서 확인)
   - 추가 사용량(usage credits)으로 이어 쓰기
   - 한 단계 위로 업그레이드하기: Pro → Max 5x → Max 20x
   - Console에서 API 크레딧을 구매해 쓰기

5. **사용량을 아끼는 습관 들이기**

   아래 [실전 팁](#실전-팁)을 참고해 `/clear`, 작은 모델, 낮은 effort를 적절히 쓰세요.

</Steps>

내 업무에 어떤 요금제가 맞을지 Claude에게 정리를 맡겨 볼 수도 있어요.

<PromptBox>
저는 Claude를 주로 [문서 요약 / 글쓰기 / 코딩 등 내 업무]에 하루 [몇 시간] 정도 쓰려고 합니다. 이 작업을 가벼운 작업과 무거운 작업(긴 문서, 긴 대화, 코드 작업)으로 나누고, 무거운 작업은 사용량을 아끼려면 어떻게 쓰면 좋을지 알려 주세요. 요금제 가격이나 한도 수치는 추측하지 말고, 제가 공식 페이지에서 확인해야 할 항목만 목록으로 알려 주세요.
</PromptBox>

| **Team** (2~150명, 최소 2명) | 스탠더드 좌석: 연간 결제 월 $20, 월 결제 월 $25<br />프리미엄 좌석: 연간 결제 월 $100, 월 결제 월 $125<br />Pro 대비 세션당 스탠더드 1.25배, 프리미엄 6.25배 (구성원별 한도) | Cowork, Projects, 중앙 청구, SSO, 관리자 커넥터 통제, 기본적으로 콘텐츠로 모델 학습 안 함, 월 풀링 API 크레딧(최대 $500/월) | Claude Code 포함<br />클라우드 세션 가능 |
| **Enterprise** | 좌석당 연간 결제 월 $20 + 사용량은 API 요율로 청구<br />고정 배수 없음(사용량 기반) | 지출 한도, 역할 기반 접근, SCIM, 감사 로그, Compliance API, 맞춤 데이터 보존, IP 허용 목록, HIPAA 대응 | 좌석 종류에 따라 Claude Code 사용(프리미엄 또는 Chat + Claude Code 좌석)<br />같은 좌석 종류에서 클라우드 세션 가능 |

- Enterprise는 셀프서비스 또는 영업 경유로 시작해요. 사용량 기반 Enterprise(셀프서브 포함)에는 좌석별 사용 한도가 없고 API 요율로 과금돼요. 구형 Enterprise에는 Chat + Claude Code 좌석과 Premium 좌석이 있어요.
- Max와 Team에 포함된 월 API 크레딧은 usage credits로도, Claude Code나 Claude 앱에서도 **쓸 수 없어요.** 받는 방법은 아래 "월 API 크레딧 받는 법"을 보세요.

### 월 API 크레딧 받는 법 (Max, Team, 2026-10-11 기준)

2026-10-07부터 Max와 Team 플랜에 월 API 크레딧이 포함돼요. 자동으로 들어오지 않고, **Claude Console 조직을 플랜에 연결**해야 받아요.

1. claude.ai에서 설정(Settings) > 결제(Billing)(Max) 또는 조직 설정(Organization settings) > 결제(Billing)(Team)로 가요.
2. API 크레딧(API credits) 섹션에서 크레딧을 받을 Console 조직을 고르고 약관에 동의하며 연결해요. Console 조직이 없으면 platform.claude.com에서 먼저 만들거나 연결 과정에서 만들 수 있어요.
3. 크레딧은 Console의 설정(Settings) > 결제(Billing)의 프로모션 크레딧(Promotional credits)에 금액과 만료일이 표시돼요.

| 플랜 | 월 크레딧 |
| --- | --- |
| Max 5x | $100 |
| Max 20x | $200 |
| Team 스탠더드 좌석 | 좌석당 $20 |
| Team 프리미엄 좌석 | 좌석당 $100 |

- Team은 모든 좌석의 크레딧이 한 잔액으로 합쳐지고 월 $500가 상한이에요.
- 필요한 권한: Max는 구독자 본인, Team은 Primary Owner 또는 Owner이고, Console 조직에서는 Owner, Admin, Billing 중 하나예요.
- 신규 구독자는 7일 뒤부터 받을 수 있어요. Free, Pro, Enterprise는 대상이 아니에요.
- 플랜 하나는 Console 조직 하나에만 연결되고 직접 바꿀 수 없어요(지원팀 문의). 연결한 조직에서 쓸 계획인 곳을 고르세요.
- 이 크레딧은 Claude API, Managed Agents, Agent SDK, Playground에 쓸 수 있고 Claude Code, 앱의 추가 사용량, AWS·Bedrock·Google Cloud·Foundry에는 못 써요. 청구 주기마다 새로 들어오고 남은 크레딧은 이월되지 않아요. 크레딧은 Claude나 Claude Code의 사용량 한도를 바꾸지 않아요.
- 대상인데 설정에 안 보이면 지원팀에 문의하세요.
- 가격 페이지는 "프리미엄은 스탠더드의 5배"로 적고 있어요. 스탠더드가 Pro의 1.25배이니 프리미엄은 6.25배로, 두 설명은 일치해요.

| --- | --- | --- | --- |

| Fable 관련 한도 | 위 "Fable 모델의 한도" 참고 | 플랜·좌석에 따라 다름 | 설정(Settings) > 사용량(Usage) 화면의 실제 표시 |
| 추가 사용량(usage credits) | 해당 없음 (선불 잔액) | Pro, Max 5x/20x, Team, 좌석제 Enterprise | 설정(Settings) > 사용량(Usage), Claude Code `/usage-credits` |

## 자주 막히는 지점

### 모델을 바꿨는데도 계속 막혀요

- **원인**: `session limit` 또는 `weekly limit` 메시지는 모든 모델에 공통이라서 모델을 바꿔도 소용없어요.
- **해결**: 리셋 시점까지 기다리거나, 추가 사용량(usage credits)을 켜거나, 업그레이드를 고려하세요. 메시지가 `Opus limit`처럼 특정 모델 계열을 가리킨다면 `/model`로 다른 계열로 바꾸면 돼요.

### Claude Code만 썼는데 앱에서도 한도가 줄었어요

- **원인**: Claude 앱, Claude Code, 데스크톱 앱은 같은 한도를 공유해요. VS Code·Cursor·JetBrains에서 쓴 것도 합산돼요.
- **해결**: 설정(Settings) > 사용량(Usage)에서 전체 사용량을 확인하세요. 병렬로 작업을 여러 개 돌리면 그만큼 더 빨리 줄어요.

### Fable 모델을 고르려는데 크레딧을 요구해요

- **원인**: Pro, Team 스탠더드, Enterprise 스탠더드 좌석은 Fable이 플랜 한도에 포함되지 않고 usage credits(종량)로만 쓸 수 있다고 안내돼요.
- **해결**: 요금제와 좌석 종류를 확인하고, 설정(Settings) > 사용량(Usage)에서 실제 표시를 확인하세요. Claude Code라면 버전도 확인하세요(Fable 5는 v2.1.170 이상, Fable 5.1은 v2.1.255 이상).

### 앱에서 추가 사용량을 켤 수 없어요

- **원인**: 모바일 앱으로 구독한 경우에는 활성화와 구매를 웹에서만 할 수 있어요.
- **해결**: 웹(claude.ai)의 설정(Settings) > 사용량(Usage)에서 진행하세요.

### 크레딧을 샀는데 Max에 포함된 API 크레딧이 안 줄어요

- **원인**: 구독에 포함된 월 API 크레딧(Max, Team)은 usage credits와 별개이고, Claude Code나 Claude 앱에는 쓸 수 없어요. usage credits는 구독과 별도로 청구돼요.
- **해결**: 두 가지를 따로 관리하세요. 크레딧은 대체로 만료되지 않아요. 다만 일본은 2026-09-10부터 구매 후 6개월이 지나면 만료되는 것으로 안내돼요.

### 팀원이 많이 써서 내 한도도 줄었나 걱정돼요

- **원인**: Team 한도는 팀 전체가 아니라 구성원별이에요.
- **해결**: 내 한도는 내 사용량에 따라 줄어요. 설정(Settings) > 사용량(Usage)에서 내 화면을 확인하세요.

## 실전 팁

- **관련 없는 작업 사이에는 `/clear`를 쓰세요.** 긴 대화 기록을 계속 끌고 가지 않게 돼요.
- **작업에 맞는 작은 모델을 고르세요.** 간단한 작업까지 큰 모델을 쓸 필요는 없어요. 모델별 특징은 [C1. Claude 한눈에 보기](/claude/c01-overview/)에서 살펴보세요.
- **effort를 낮추세요.** 간단한 작업에는 effort를 낮추는 것을 고려해 보세요.
- **병렬 작업은 한도를 더 써요.** 클라우드 세션을 여러 개 동시에 돌리거나 루틴을 자주 실행하면 그만큼 한도가 줄어요.
- **크레딧은 상한부터 정하세요.** usage credits를 켤 때는 월 지출 한도와 사용량 알림을 먼저 설정해 두면 안심이에요.
- **가격은 공식 페이지에서 다시 확인하세요.** 이 문서의 가격은 2026-10-10 기준 미국 가격이에요.
