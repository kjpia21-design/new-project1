<Summary>
- Artifacts are **showpiece results** (designs, slides, documents, dashboards, small interactive tools) that Claude makes. They open beside the conversation. Since 2026-09-16 you can create designs, slides, and documents in any conversation (for Enterprise it has been described as beta and off by default until an owner turns it on, but the Artifacts help article says it is on by default for Enterprise from 2026-10-15. The help wording is the same as of 2026-10-19).
- Ask in any chat, or start from a template (Docs, Slides, Design) on the Artifacts tab. Code execution and file creation must be turned on in Settings.
- New artifacts **start private**, and you share them with the **Share** menu. Only older artifacts made before 2026-09-16 still have the **Publish** method.
- **Unpublishing is permanent.** You can't republish, and stored data is deleted.
- AI-powered apps are used by viewers who **log in with their own Claude account**. There's no cost to the creator, and usage counts against the viewer's plan limit.
</Summary>

## What you'll be able to do

- Ask in chat to make a small app or document, then refine it with edit requests and direct editing.
- Export results as files such as Word, PDF, and PowerPoint.
- Understand the difference between Share and the older Publish, and share with the right scope.
- Understand how artifacts that use AI, storage, and connectors work, and what sharing restrictions apply.

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Artifact** | A result Claude makes beside the conversation when the content is substantial, self-contained (usually more than 15 lines), and likely to be edited or reused. |
| **Template** | A starting framework on the Artifacts tab. Docs, Slides, and Design are on all plans; Dashboards and Motion are in beta and vary by plan. |
| **Share** | How new artifacts are shared. Permissions are Can view / Commenter / Can edit. |
| **Publish** | The method for older artifacts made in chat before 2026-09-16. You can keep publishing and sharing them, but you can't create new ones this way. |
| **AI-powered app** | An app where the artifact calls Claude directly. Viewers log in with their own accounts to use it. |
| **Storage** | The space where an artifact stores data. There are two kinds: private and shared. |

### Share vs. Publish at a glance

| | Share (new method) | Publish (older method) |
| --- | --- | --- |
| Applies to | All newly made artifacts | Artifacts made in chats before 2026-09-16 |
| Start | Starts private | Private until published |
| How | Share menu, choose access level | Free/Pro/Max: Publish (creates a public link); Team/Enterprise: Share & copy link |
| Undo | Change the sharing settings | **Unpublishing is permanent; no republishing** |

<Aside type="note" title="On-screen wording varies by account">
The sharing/publishing terminology is in transition, so the UI wording may differ by account. Descriptions differ in places between help center articles, so this tutorial favors the latest article. Artifacts that call Claude (AI apps) are charged against each user's own plan limit (not the creator's), and a separate numeric cap on calls isn't published officially. Artifact storage is 20MB per artifact, text only (official help "What are artifacts and how do I use them?", confirmed 2026-10-13). Go by what's shown on your screen first.
</Aside>

<Steps>

1. **Turn on the feature**

   In Settings > Capabilities, check that "Cloud code execution and file creation" (in the new layout, "Create and edit files") is on. For Team/Enterprise, it's Organization settings > Capabilities (as of 2026-10-26). If it's off, you can't create artifacts.

2. **Ask Claude to make one**

   Just ask in any chat (including Claude Code). Or start from a template (Docs, Slides, Design) on the Artifacts tab. The result opens to the right of the conversation.

   <PromptBox>
   Make me a currency converter app. When I enter an amount in Korean won (KRW), show it converted to US dollars, yen, and euros, and make the exchange rates input fields so I can edit them myself.
   </PromptBox>

   <ScreenshotPlaceholder caption="An artifact (currency converter) open to the right of the chat" officialUrl="https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them" />

3. **Edit it**

   - Ask Claude for changes. ("Make the button bigger," "Show yen per 100 yen.")
   - Template-style artifacts can be edited directly.
   - In documents, select text and click **Edit with Claude**.
   - If an error appears, click **Try fixing with Claude**. Success isn't guaranteed.
   - Editing an earlier message creates a separate version of the conversation.

4. **Export**

   The files you can export depend on the type.

   | Type | Export |
   | --- | --- |
   | Docs | Word, PDF, Markdown, Google Docs |
   | Slides | PowerPoint, PDF, Google Slides |
   | Design | zip, PDF, PowerPoint, HTML |
   | Animation | MP4 |

5. **Share**

   Use the Share button to set the access level. On all plans you can share by link (Anyone with the link), and on Pro/Max/Ultra/Team/Enterprise you can also invite specific people by email (beta) (Free isn't eligible for email invites, as of 2026-10-26). Team/Enterprise stays inside the organization by default, and link sharing requires an Owner to turn on External sharing. Link recipients usually need to log in to Claude.

   <ScreenshotPlaceholder caption="Choosing an access level (Can view / Commenter / Can edit) in the Share menu" officialUrl="https://support.claude.com/en/articles/9547008-publish-and-share-artifacts" />

   <Aside type="caution" title="Unpublishing can't be undone">
   If you unpublish an artifact you published the older way, public access is cut off and **you can't publish the same artifact again.** The private and shared storage data the artifact used is permanently deleted too. To share again, you have to make a new artifact. Export anything you need before unpublishing.
   </Aside>

6. **Build an app that runs AI (optional)**

   You can make an artifact call Claude directly. Viewers log in with their own Claude account, and no API key is needed. There's no cost to the creator, and usage counts against each viewer's plan limit. New artifacts ask for permission the first time they're used.

   <PromptBox>
   Build an app where I type a sentence to send to a client and it polishes it into a polite business email style. Have Claude inside the app do the polishing.
   </PromptBox>

   <Aside type="note" title="AI apps and link sharing">
   Artifacts that use connectors or Claude can't be shared with "Anyone with the link." Viewers need a Claude account to use the AI features.
   </Aside>

</Steps>

## Quick reference

### How sharing works by plan (as of 2026-10-10)

| Plan | New artifacts (Share) | Older artifacts |
| --- | --- | --- |
| Free | Share by link | Publish |
| Pro / Max | Link sharing, email invites (beta) | Publish |
| Team | Sharing within the organization, email invites (beta). External links require an Owner to turn on External sharing | Share & copy link |
| Enterprise | Same as Team + group sharing | Share & copy link |

### Permissions and limits

| Item | Details |
| --- | --- |
| Permissions | Can view / Commenter / Can edit |
| Email invites (beta) | Up to 50 invitees outside the organization per artifact; pending invites expire after 30 days |
| Email invites not allowed | Claude Docs, artifacts that connect to outside sites, artifacts with uploaded files that are being scanned or failed the scan |
| Link sharing not allowed | Artifacts that use connectors/Claude. Claude Docs on Team/Enterprise |
| Mobile | View and edit; sharing settings only on web/desktop |

### Storage and connectors (Pro/Max/Ultra/Team/Enterprise, as of 2026-10-10)

| Item | Details |
| --- | --- |
| Storage | Web and desktop. Private and shared. Shared storage is visible to all viewers |
| Capacity | 20MB per artifact, text only |
| Connectors | Can read and write Asana, Google Calendar, Slack, and others, plus custom connectors. Asks for approval first and can be turned off per tool; viewers use their own connections |
| Organization controls | Team/Enterprise Owners can turn it off organization-wide |

## Common sticking points

### The artifact isn't created

- **Cause**: Code execution and file creation may be off, or the content may be short enough that Claude judged a chat reply sufficient.
- **Fix**: Check Settings and clearly ask "make this as an artifact."

### An error shows on screen

- **Cause**: The generated code may have a problem.
- **Fix**: Click **Try fixing with Claude**, or tell the chat what the error says. Success isn't guaranteed, so if it doesn't work, simplify the requirements and ask again.

### I don't see the link sharing option

- **Cause**: Artifacts that use connectors or Claude, and Claude Docs on Team/Enterprise, can't be shared by link. On Team/Enterprise an Owner has to turn on External sharing for external links.
- **Fix**: Use email invites or sharing within the organization, or ask an Owner.

### I shared it but the other person can't open it

- **Cause**: Link recipients usually need to log in to Claude. AI features require the other person to have a Claude account.
- **Fix**: Check that they're logged in, and consider email invites.

### I unpublished it and can't put it back up

- **Cause**: Unpublishing is permanent.
- **Fix**: Make a new artifact and share it again. The stored data was deleted too.

## Practical tips

- **Check the storage type before sharing.** Shared storage is visible to all viewers. Be especially careful with apps that collect sensitive information.
- **Don't ask for everything at once; refine in rounds.** Making it small and then asking for edits gives better results.
- **Export before unpublishing.** It can't be undone.
- **Let people know AI apps use the viewer's limit.** There's no cost to the creator, but the viewer's usage goes down. The limit structure is in [C2. Plans and usage limits](/claude/c02-plans-limits/).
- **Claude Code works too.** You can publish a session's results as an artifact at a private URL that updates as the session goes on (this is based on a help-center search summary, so check the official docs for the latest behavior).
