<Summary>
- 아티팩트는 Claude가 만든 **보여줄 만한 결과물**(디자인, 슬라이드, 문서, 대시보드, 작은 인터랙티브 도구)이에요. 대화 옆에 열려요.
- 아무 채팅에서 요청하거나 Artifacts 탭의 템플릿(Docs, Slides, Design)으로 시작해요. 설정에서 코드 실행과 파일 생성이 켜져 있어야 해요.
- 새 아티팩트는 **비공개로 시작**하고 **공유(Share)** 메뉴로 공유해요. 2026-09-16 이전에 만든 예전 아티팩트만 **게시(Publish)** 방식이 남아 있어요.
- **게시 취소(unpublish)는 영구적**이에요. 다시 게시할 수 없고 저장된 데이터도 삭제돼요.
- AI 내장 앱은 열람자가 **자기 Claude 계정**으로 로그인해 써요. 만든 사람에게 비용이 없고 열람자의 플랜 한도에 합산돼요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 채팅에서 요청해 작은 앱이나 문서를 만들고, 수정 요청과 직접 편집으로 다듬을 수 있어요.
- 결과물을 Word, PDF, PowerPoint 같은 파일로 내보낼 수 있어요.
- 공유(Share)와 예전 게시(Publish)의 차이를 알고, 올바른 범위로 공유할 수 있어요.
- AI·저장소·커넥터를 쓰는 아티팩트의 동작 방식과 공유 제한을 이해할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **아티팩트(Artifact)** | 내용이 중요하고 독립적이며(대개 15줄 초과) 수정·재사용될 가능성이 클 때 Claude가 대화 옆에 만들어 주는 결과물이에요. |
| **템플릿** | Artifacts 탭에서 시작하는 틀이에요. Docs, Slides, Design은 모든 플랜에서, Dashboards·Motion은 베타로 플랜에 따라 달라요. |
| **공유(Share)** | 새 아티팩트의 공유 방식이에요. 권한은 Can view / Commenter / Can edit이에요. |
| **게시(Publish)** | 2026-09-16 이전에 채팅에서 만든 예전 아티팩트의 방식이에요. 계속 게시·공유할 수 있지만 새로 만들 수는 없어요. |
| **AI 내장 앱** | 아티팩트가 Claude를 직접 호출하는 앱이에요. 열람자가 자기 계정으로 로그인해 써요. |
| **저장소** | 아티팩트가 데이터를 저장하는 공간이에요. 개인(private)과 공유(shared) 두 가지예요. |

### 공유(Share)와 게시(Publish) 한눈에 비교

| | 공유 (새 방식) | 게시 (예전 방식) |
| --- | --- | --- |
| 대상 | 새로 만드는 모든 아티팩트 | 2026-09-16 이전 채팅에서 만든 아티팩트 |
| 시작 | 비공개로 시작 | 게시 전에는 비공개 |
| 방법 | Share 메뉴, 접근 수준 선택 | Free/Pro/Max는 Publish(공개 링크 생성), Team/Enterprise는 Share & copy link |
| 취소 | 공유 설정 변경 | **취소(unpublish)는 영구적, 재게시 불가** |

<Aside type="note" title="확인되지 않은 점">
공유/게시 용어가 전환 중이라 UI 문구가 계정마다 다를 수 있어요. 지원센터 문서 사이에 서술이 일부 달라서 이 튜토리얼은 최신 문서를 우선했어요. AI 앱의 호출 횟수 상한 같은 세부 한도는 확인하지 못했어요. 화면에 보이는 안내를 우선하세요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '설정에서 코드 실행과 파일 생성을 켰어요',
  '채팅에서 요청해 아티팩트를 만들었어요',
  '수정 요청으로 아티팩트를 다듬었어요',
  '필요한 형식으로 내보냈어요',
  '공유 범위를 확인하고 공유했어요',
  '(선택) AI 기능이 있는 앱을 만들어 봤어요',
]} />

<Steps>

1. **기능 켜기**

   설정(Settings)에서 클라우드 코드 실행과 파일 생성이 켜져 있는지 확인해요. 꺼져 있으면 아티팩트를 만들 수 없어요.

2. **만들어 달라고 요청하기**

   아무 채팅에서 요청하면 돼요(Claude Code 포함). 또는 Artifacts 탭의 템플릿(Docs, Slides, Design)에서 시작해요. 결과는 대화 오른쪽에 열려요.

   <PromptBox>
   환율 계산기 앱을 만들어 줘. 원화 금액을 입력하면 달러·엔·유로로 바꿔 보여 주고, 환율은 내가 직접 고칠 수 있게 입력칸으로 만들어 줘.
   </PromptBox>

   <ScreenshotPlaceholder caption="채팅 오른쪽에 아티팩트(환율 계산기)가 열린 화면" />

3. **수정하기**

   - Claude에게 변경을 요청해요. ("버튼을 더 크게", "엔화는 100엔 기준으로")
   - 템플릿형 아티팩트는 직접 편집할 수 있어요.
   - 문서에서는 텍스트를 선택하고 **Edit with Claude**를 눌러요.
   - 오류가 나면 **Try fixing with Claude**를 눌러요. 성공이 보장되지는 않아요.
   - 이전 메시지를 수정하면 별도 버전의 대화가 생겨요.

4. **내보내기**

   형식별로 내보낼 수 있는 파일이 달라요.

   | 종류 | 내보내기 |
   | --- | --- |
   | Docs | Word, PDF, Markdown, Google Docs |
   | Slides | PowerPoint, PDF, Google Slides |
   | Design | zip, PDF, PowerPoint, HTML |
   | 애니메이션 | MP4 |

5. **공유하기**

   공유(Share) 버튼으로 접근 수준을 정해요. Free/Pro/Max는 링크(Anyone with the link)로 공유하거나 이메일로 특정인을 초대(베타)할 수 있어요. Team/Enterprise는 기본적으로 조직 안에 머물고, 링크 공유는 Owner가 External sharing을 켜야 해요. 링크 수신자는 대개 Claude 로그인이 필요해요.

   <ScreenshotPlaceholder caption="공유(Share) 메뉴에서 접근 수준(Can view / Commenter / Can edit)을 고르는 화면" />

   <Aside type="caution" title="게시 취소는 되돌릴 수 없어요">
   예전 방식으로 게시한 아티팩트를 게시 취소(unpublish)하면 공개 접근이 끊기고, **같은 아티팩트를 다시 게시할 수 없어요.** 아티팩트가 쓰던 개인·공유 저장 데이터도 영구 삭제돼요. 다시 공유하려면 새 아티팩트를 만들어야 해요. 취소 전에 필요한 내용은 내보내 두세요.
   </Aside>

6. **AI가 동작하는 앱 만들기 (선택)**

   아티팩트가 Claude를 직접 호출하게 만들 수 있어요. 열람자는 자기 Claude 계정으로 로그인하고, API 키는 필요 없어요. 만든 사람에게는 비용이 들지 않고, 사용량은 각 열람자의 플랜 한도에 합산돼요. 새 아티팩트는 첫 사용 때 권한을 물어요.

   <PromptBox>
   내가 거래처에 보낼 문장을 입력하면 정중한 비즈니스 이메일 문체로 다듬어 주는 앱을 만들어 줘. 안에서 Claude가 문장을 다듬도록 해 줘.
   </PromptBox>

   <Aside type="note" title="AI 앱과 링크 공유">
   커넥터나 Claude를 쓰는 아티팩트는 "Anyone with the link"로 공유할 수 없어요. 열람자가 Claude 계정이 있어야 AI 기능을 쓸 수 있어요.
   </Aside>

</Steps>

## 빠른 참조표

### 플랜별 공유 방식 (2026-10-10 기준)

| 플랜 | 새 아티팩트(Share) | 예전 아티팩트 |
| --- | --- | --- |
| Free | 링크로 공유 | Publish |
| Pro / Max | 링크 공유, 이메일 초대(베타) | Publish |
| Team | 조직 내 공유, 이메일 초대(베타). 외부 링크는 Owner가 External sharing을 켜야 함 | Share & copy link |
| Enterprise | Team과 같음 + 그룹 공유 | Share & copy link |

### 권한과 제한

| 항목 | 내용 |
| --- | --- |
| 권한 | Can view / Commenter / Can edit |
| 이메일 초대(베타) | 아티팩트당 조직 외부 초대 최대 50명, 대기 초대는 30일 후 만료 |
| 이메일 초대 불가 | Claude Docs, 외부 사이트에 연결하는 아티팩트, 검사 중이거나 검사를 통과하지 못한 업로드 파일이 있는 아티팩트 |
| 링크 공유 불가 | 커넥터/Claude를 쓰는 아티팩트. Team/Enterprise의 Claude Docs |
| 모바일 | 보기·편집 가능, 공유 설정은 웹/데스크톱에서만 |

### 저장소와 커넥터 (Pro/Max/Team/Enterprise, 2026-10-10 기준)

| 항목 | 내용 |
| --- | --- |
| 저장소 | 웹·데스크톱. 개인(private)과 공유(shared). 공유 저장은 열람자 모두에게 보임 |
| 용량 | 아티팩트당 20MB, 텍스트만 |
| 커넥터 | Asana, Google Calendar, Slack 등과 커스텀 커넥터를 읽고 쓸 수 있음. 처음에 승인을 묻고 도구별로 끌 수 있으며, 열람자는 자기 연결을 씀 |
| 조직 제어 | Team/Enterprise Owner가 조직 단위로 끌 수 있음 |

## 자주 막히는 지점

### 아티팩트가 안 만들어져요

- **원인**: 코드 실행과 파일 생성이 꺼져 있거나, 내용이 짧아 채팅 답변으로 충분하다고 판단했을 수 있어요.
- **해결**: 설정(Settings)을 확인하고 "아티팩트로 만들어 줘"라고 분명히 요청하세요.

### 화면에 오류가 떠요

- **원인**: 생성된 코드에 문제가 있을 수 있어요.
- **해결**: **Try fixing with Claude**를 누르거나, 오류 내용을 채팅에 알려 주세요. 성공이 보장되지는 않으니 안 되면 요구사항을 단순하게 바꿔 다시 요청하세요.

### 링크 공유 옵션이 안 보여요

- **원인**: 커넥터나 Claude를 쓰는 아티팩트, Team/Enterprise의 Claude Docs는 링크 공유가 안 돼요. Team/Enterprise는 Owner가 External sharing을 켜야 외부 링크가 가능해요.
- **해결**: 이메일 초대나 조직 내 공유를 쓰거나 Owner에게 문의하세요.

### 공유하려 했는데 상대가 못 열어요

- **원인**: 링크 수신자는 대개 Claude 로그인이 필요해요. AI 기능은 상대의 Claude 계정이 있어야 해요.
- **해결**: 상대가 로그인했는지 확인하고, 이메일 초대 방식을 고려하세요.

### 게시를 취소했는데 다시 올릴 수 없어요

- **원인**: 게시 취소는 영구적이에요.
- **해결**: 새 아티팩트를 만들어 다시 공유하세요. 저장 데이터도 삭제되었어요.

## 실전 팁

- **공유 전에 저장소 종류를 확인하세요.** 공유(shared) 저장은 열람자 모두에게 보여요. 민감한 정보를 입력받는 앱이라면 특히 조심하세요.
- **내용은 한 번에 다 요구하지 말고 반복해서 다듬으세요.** 작게 만들고 수정을 요청하는 편이 결과가 좋아요.
- **게시 취소 전에 내보내 두세요.** 되돌릴 수 없어요.
- **AI 앱은 열람자 한도를 쓴다는 점을 알리세요.** 만든 사람에게는 비용이 없지만 열람자의 사용량이 줄어요. 한도 구조는 [C2. 요금제와 사용량 한도](/new-project1/claude/c02-plans-limits/)에 있어요.
- **Claude Code도 쓸 수 있어요.** 세션 결과를 비공개 URL의 아티팩트로 게시해 세션이 진행되며 갱신되게 할 수 있어요(지원센터 검색 요약 기준이라 최신 동작은 공식 문서에서 확인하세요).
