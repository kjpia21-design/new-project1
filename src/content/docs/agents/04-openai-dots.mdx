## 이 튜토리얼로 할 수 있게 되는 것

- Dots가 무엇이고 채팅·ChatGPT Work·Codex와 어떻게 다른지 설명할 수 있어요.
- 내 계정에서 Dots를 쓸 수 있는지 확인하고, 첫 dot을 만들 수 있어요.
- 앱(플러그인), Slack/Teams, 내 컴퓨터를 필요한 만큼만 연결할 수 있어요.
- 작업을 맡기고, 예약하고, 멈추고, 삭제하는 방법을 알 수 있어요.

이 글은 OpenAI 개발자 문서(영어)를 기준으로 정리했어요. openai.com과 도움말센터는 자동 접근이 막혀 열어 보지 못했어요. 확인한 것과 확인하지 못한 것은 아래에 구분해서 적었어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **Dots** | 제품(기능) 이름이에요. |
| **dot** | 내가 만드는 에이전트 한 명이에요. 이름, 모양, 색, 눈, 안경, 액세서리를 정할 수 있고, 핸들은 `@이름-dot` 형태로 시작해요. |
| **클라우드 컴퓨터** | dot이 가진 자기만의 컴퓨터와 브라우저예요. 내 기기가 꺼져 있어도 작업이 이어져요. |
| **플러그인** | Gmail, Google Drive, GitHub 같은 앱 연결이에요. 연결하고 허용한 것만 쓸 수 있어요. |
| **Activity / Scheduled** | 데스크톱 앱에서 dot 프로필에 있는 화면이에요. Activity는 위임한 작업, Scheduled는 반복 작업을 보여 줘요. |
| **사용자 규칙(Custom rules)** | 특정 행동을 "묻지 않고 / 내가 말할 때 / 묻고 / 나에게 넘김" 중 어떻게 처리할지 정하는 설정이에요. |

### 무엇이고, 무엇이 다른가요?

공식 문서의 설명을 줄이면 이래요. 답이나 초안이 필요하면 **채팅**, 한 번 맡길 일(조사·분석·파일 만들기)은 **ChatGPT Work**, 코드 작업은 **Codex**, 그리고 **계속 신경 써야 하는 일**은 **dot**에게 맡기는 쪽이에요. dot은 대화 사이에도 진행을 추적하고, 스스로 다음 할 일을 정하고, ChatGPT·Slack·Teams로 먼저 연락하고, 필요하면 Work나 Codex에 작업을 나눠 맡겨요.

### 누가, 언제 만들었나요?

OpenAI가 만들었고, 2026-09-29 DevDay에서 공개됐다고 여러 매체가 보도했어요(언론 보도 기준). 공식 문서에는 날짜가 없고 "점진적으로 롤아웃 중"이라고만 나와요. 기업 관리자 문서에는 "Use dots (Beta)"로 표시돼 있어요. 기반 모델은 공식 문서상 GPT-6 Astra예요.

### 할 수 있는 일

- **책임 맡기기**: "이 행사 준비를 계속 챙겨 줘"처럼 오래 가는 일을 맡기면 결정할 일, 마감, 답을 기다리는 일을 추적해요.
- **스스로 깨어나 이어가기**: 모든 후속 일정을 지정하지 않아도 dot이 언제 쉬었다 다시 일할지 정해요. 시간이 중요하면 시간대와 기간을 넣어 예약할 수 있어요.
- **병렬 작업**: 백그라운드 에이전트로 여러 일을 동시에 하고, 그동안에도 대화할 수 있어요.
- **통화**: 대화 화면의 전화 버튼으로 음성 통화를 해요. 통화 중에도 글을 입력할 수 있어요. dot이 먼저 거는 전화는 출시 후 예정이고, 문자는 "곧 지원"이라고 돼 있어요.
- **능동적 리서치**: 연결된 앱을 읽기 전용으로 살펴서 도울 만한 일을 찾아요. 이 과정에서는 메시지 보내기, 내용 수정, 브라우저·컴퓨터 제어를 못 해요.
- **Work·Codex에 위임**: 내 컴퓨터의 로컬 작업을 만들거나, 미리 만들어 둔 Codex 클라우드 환경에서 코딩 작업을 시킬 수 있어요.

## 한국에서 쓸 수 있나요?

<Aside type="caution" title="이 부분은 확정이 아니라 '확인 가능한 범위'예요">
출처마다 표현이 달라서 정리했어요.

| 출처 | 내용 |
| --- | --- |
| OpenAI 개발자 문서 (공식) | Pro는 만 18세 이상, **EEA·영국·스위스 제외**. Business Premium·Enterprise는 전 세계 순차 제공. 한국을 따로 언급하지 않아요. |
| 국내 언론 보도 | 한국에서 순차 제공 중이라고 전해요 (언론 보도 기준). |
| 영어권 매체 요약 | 제외 지역 외에는 "해당 시장"이라고만 하고 한국은 언급하지 않아요. |

**정리하면** 한국은 공식 제외 목록에 없어서 대상 플랜이면 쓸 수 있을 가능성이 있어요. 하지만 "한국 제공 확정"이라고 적은 공식 문장은 확인하지 못했고, 롤아웃이 점진적이라 대상 플랜이어도 바로 안 보일 수 있어요. 한국 App Store의 ChatGPT 앱 등록 페이지도 최근 버전 노트가 "버그 수정 및 작은 개선"뿐이라 Dots 근거가 되지 못했어요.
</Aside>

**한국어는요?** ChatGPT 앱은 한국 App Store에 한국어로 등록돼 있고 지원 언어에 한국어가 들어 있어요. 하지만 **Dots 자체**의 한국어 지원(대화 품질, 음성 통화, 화면 문구)은 공식 문서에서 확인하지 못했어요. 국내 보도가 인용한 사용 후기에는 한국어 음성이 아직 어색하다는 평이 있었어요. 직접 써 보고 판단하세요.

VPN 등으로 지원 지역을 속여 가입하는 방법은 안내하지 않아요. 이용약관 위반이 될 수 있고, 결제·계정 문제가 생기면 보호받기 어려울 수 있어요. 한국에서 내 계정에 보이면 쓰고, 안 보이면 롤아웃을 기다리세요.

### 요금은 어떻게 되나요?

Dots만의 별도 요금은 공식 문서에 없어요. 아래 플랜에 포함돼요.

| 플랜 | 접근 |
| --- | --- |
| Pro 100 / 200 / 500 | 만 18세 이상, EEA·영국·스위스 제외 |
| Business Premium | 전 세계 순차 제공 |
| Enterprise | 전 세계 순차 제공, **기본 꺼짐**. 워크스페이스 관리자가 켜야 해요 |

- Pro 가격은 OpenAI 공식 가격 안내에서 월 **$100·$200·$500**(USD)이에요. 원화 가격은 확인하지 못했어요.
- **dot과 나누는 대화는 ChatGPT 사용 한도에 포함되지 않아요.** 하지만 dot이 시작하거나 관리하는 **Work·Codex 작업은 해당 제품의 한도에 포함**돼요.
- 플랜에 더 깊은 작업을 위한 허용량이 포함되고, 출시 후 첫 달은 한도가 확장돼요.
- Plus나 무료 플랜은 문서의 접근 목록에 없어요. "안 된다"고 직접 적힌 문구는 못 봤어요.

<Steps>

1. **내 계정에 Dots가 있는지 확인하기**

   ChatGPT 모바일 앱(최신 버전으로 업데이트), 데스크톱 앱, 또는 데스크톱 브라우저에서 Dots 메뉴를 찾아요. **모바일 웹 브라우저는 지원하지 않아요.** 안 보이면 계정이 대상이 아니거나 롤아웃이 아직 오지 않은 거예요. Enterprise는 관리자가 켜 줘야 해요.

   <ScreenshotPlaceholder caption="ChatGPT 앱에서 Dots를 여는 화면" />

2. **dot 만들기**

   앱의 안내를 따라 만들어요. 이름과 모양(색, 눈, 안경, 액세서리)은 나중에 바꿀 수 있어서 기본값으로 넘어가도 돼요. 이름을 정하면 핸들이 `@이름-dot` 식으로 바뀌어요. 폰에서 시작해도, 데스크톱에서 시작해도 같은 dot을 이어서 쓸 수 있어요.

3. **앱(플러그인) 연결하기**

   메일, 캘린더, 파일 같은 앱을 플러그인으로 연결해요. 건너뛰고 나중에 해도 돼요. 연결한 앱의 **권한은 기존 ChatGPT 앱 권한을 그대로** 따라서, 예를 들어 메일은 "읽기만 허용, 보내기는 불허"처럼 나눌 수 있어요.

   <Aside type="caution" title="처음에는 최소한만 연결하세요">
   Slack 같은 메시지 채널을 연결해도 메일이나 내 컴퓨터가 자동으로 연결되지는 않아요. 반대로 말하면 각각을 따로 열어야 한다는 뜻이에요. 필요할 때 하나씩 추가하세요.
   </Aside>

4. **첫 대화로 책임 맡기기**

   dot이 먼저 자기소개를 하고 연결된 정보로 도울 일을 제안해요. 공식 문서의 예시처럼 "계속 챙겨야 하는 일"로 시작해 보세요.

   <PromptBox>
   이번 팀 워크숍 준비를 계속 챙겨 줘요. 내가 공유한 계획서와 장소 업체 메일을 읽고, 결정할 일과 마감, 답을 기다리는 일의 목록을 만들어 주세요. 예산이나 이번 주 안에 답해야 하는 것을 먼저 챙겨 주세요. 답장은 초안만 만들고 보내지 마세요.
   </PromptBox>

   결과를 확인하고 빠진 내용을 고쳐 달라고 한 다음에 범위를 넓히세요. dot도 실수할 수 있어요.

5. **알림과 일정 정하기**

   일상적인 진행 알림은 ChatGPT에, 결정이 필요한 일은 Slack으로 받는 식으로 나눌 수 있어요. 정해진 시각에 해야 하면 **시간대와 기간(또는 종료일)** 을 넣고 "일정을 확인해 달라"고 해 두세요.

   <PromptBox>
   앞으로 4주 동안 평일 오전 9시(한국 시간)에 워크숍 계획 채널을 확인해 주세요. 마감이 위험하거나 내 결정이 필요하면 ChatGPT로 메시지를 주세요. 일상적인 변경은 체크리스트에만 기록하세요. 저장한 일정을 마지막에 알려 주세요.
   </PromptBox>

   Slack 같은 곳에 dot을 추가하는 것만으로는 감시가 시작되지 않아요. 어떤 채널에서 무엇을 볼지 말해 줘야 해요.

6. **Slack·Teams에서 부르기 (선택)**

   dot 프로필에서 **Add**를 눌러 연락 방법을 연결해요. Slack에서는 DM을 보내거나, 채널에 추가해 멘션할 수 있어요. 기본적으로 dot은 **나에게만** 답해요. 다른 사람에게도 응답하게 하려면 지침을 줘야 하고, 이때도 기존 권한과 안전장치가 적용돼요. 기업에서는 관리자가 먼저 "Add dots to Slack" 권한을 줘야 해요.

7. **내 컴퓨터 연결하기 (선택)**

   기본적으로 dot은 클라우드 컴퓨터만으로 일해요. 내 파일, 코드, 로그인된 브라우저가 필요하면 **데스크톱 앱**에서 dot 프로필 > Computers > Your computer > **Allow access**를 눌러요. 한 번에 **한 대**만 연결되고, 사용하는 동안 컴퓨터가 온라인이고 ChatGPT 앱이 열려 있어야 해요. 연결을 끊으려면 Revoke access를 눌러요.

   <Aside type="caution" title="이 권한은 신중하게">
   내 컴퓨터를 연결하면 로컬 파일과 앱으로 작업할 수 있게 돼요. Codex나 Work Sync 연결과는 별개의 권한이에요. 공용 컴퓨터나 회사 지급 기기는 연결하지 마세요.
   </Aside>

8. **웹사이트 로그인이 필요할 때**

   dot의 클라우드 브라우저는 **내 브라우저의 로그인과 별개**예요. 로그인이 필요하면 dot이 요청을 보내고, 열어서 **비공개 입력 창**에 입력하면 자격 증명이 대화 밖의 브라우저로 전달돼요. 직접 하고 싶으면 "Take over to sign in"을 눌러 대신 로그인한 뒤 Done을 누르세요. 저장된 로그인을 쓸 때는 매번 확인을 거쳐요. 일부 사이트는 클라우드 브라우저를 막아서, 이럴 때는 연결한 내 컴퓨터로 해 보라고 시킬 수 있어요.

9. **진행 상황 보고 멈추기**

   데스크톱 앱에서 dot 프로필의 **Activity**로 위임한 작업의 진행, 파일, 결과를 보고, **Scheduled**로 반복 작업을 확인해요. 클라우드 컴퓨터에서 직접 보거나 조작해야 하면 **Take over**를, 다시 맡기려면 **Return control**을 누르세요. 멈추는 법은 아래 "빠른 참조표"에 정리했어요.

</Steps>

## 빠른 참조표

### 어디서 쓰나요

| 항목 | 내용 |
| --- | --- |
| 만들기·대화 | ChatGPT 모바일 앱(최신), 데스크톱 앱, 데스크톱 브라우저. **모바일 웹 불가** |
| 연락 채널 | ChatGPT(메시지·통화), Slack, Microsoft Teams. 문자는 "곧 지원" |
| 컴퓨터 연결·Activity | 데스크톱 앱 중심 |

### 연결은 서로 별개예요

| 연결 | 가능해지는 것 |
| --- | --- |
| 메시지 채널 | 그곳에서 dot과 대화하고 업데이트를 받기 |
| 앱(플러그인) | 그 서비스의 정보와 도구를 허용 범위 안에서 쓰기 |
| 내 컴퓨터 | 그 컴퓨터가 켜져 있는 동안 로컬 파일, 앱, 작업 쓰기 |

### 멈추는 방법 4가지

| 하고 싶은 일 | 방법 |
| --- | --- |
| 지금 하던 주 작업 멈추기 | **Pause** (위임 작업과 예약은 그대로 둬요). 다시 하려면 Resume |
| 위임한 작업 멈추기 | Activity에서 그 작업을 열어 중지 |
| 반복 작업 끝내기 | Scheduled에서 해당 작업을 비활성화 또는 삭제 |
| dot 없애기 | Delete (되돌릴 수 없어요) |

통화를 끊어도 맡긴 일은 계속될 수 있어요. 멈춰도 이미 한 행동은 되돌려지지 않아요.

### 사용자 규칙 4가지

설정 > 개인 설정(Personalization) > 권한(Permissions) > Custom rules에서 만들어요.

| 규칙 | 동작 |
| --- | --- |
| Take action without asking | 묻지 않고 실행 |
| Take action when you say so | 내가 분명히 시킬 때만 실행. 아니면 실행 직전에 물어봄 |
| Ask before taking action | 실행 전에 승인 요청 |
| Hand off to you | 나에게 넘김 |

예를 들어 고객에게 보내는 메시지는 "Ask before taking action", 공유 프로젝트 파일 삭제는 "Hand off to you"로 정할 수 있어요. 글쓰기 스타일 같은 취향은 규칙이 아니라 대화로 알려 주라고 문서가 안내해요.

### 기업 관리자가 정하는 것

Enterprise에서는 관리자가 역할별로 Dots 사용, Slack 추가, 로컬 컴퓨터 접근(별도 동의), 사용자 규칙 사용, 클라우드 브라우저·네트워크·컴퓨터 사용, 비밀번호 관리자 사용을 제어해요. 자세한 설정은 관리자용 문서를 보세요.

## 결제·권한·개인정보 주의점

- **초안 작성은 발송 허락이 아니에요.** 공식 문서도 "초안을 써 달라"는 요청이 보내기 권한을 주지 않는다고 설명해요. 반대로 범위를 분명히 한 지침(누가, 무엇을, 언제까지)은 이후 같은 범위의 행동에 쓰일 수 있으니 범위를 좁게 쓰세요.
- **자동 검토가 있어요.** 계정에 영향을 주거나 정보를 공유하는 행동 전에 지침, 권한, 사용자 규칙, 내장 안전 요건을 확인해 진행·승인 요청·내가 직접 할 일(예: 비밀번호 변경) 중 하나로 정해요. 다만 사용자 규칙은 dot이 따르려 노력하는 지침일 뿐이고 실수할 수 있다고 문서가 밝혀요.
- **결제 기능은 확인하지 못했어요.** 공식 Dots 문서에서 결제나 구매 전용 기능은 찾지 못했어요. 없다고 단정하지는 않아요. 결제가 걸린 일은 직접 하거나 "Ask before" 또는 "Hand off to you"로 두세요. 비밀번호 저장도 선택 사항이니 꼭 필요할 때만 쓰세요.
- **연결은 최소로.** 메일은 읽기만 허용하는 식으로 앱 권한을 나누고, 쓰지 않는 플러그인은 해제하세요.
- **내 컴퓨터 연결은 선택이에요.** 한 대만, 필요한 때만 쓰고 Revoke access를 기억해 두세요.
- **채널 사이 정보 이동.** dot은 채널을 옮겨도 같은 dot이라 메모를 공유해요. 대신 비공개 대화에서 들은 내용을 다른 사람에게 말하기 전에는 내 허락을 확인한다고 해요. 팀 채널에 추가할 때는 어디까지 말해도 되는지 먼저 알려 주세요.
- **데이터.** ChatGPT 데이터 제어가 dot과의 적격 대화와 작업에 적용돼요. OpenAI는 능동적 리서치와 비공개 노트로는 모델을 직접 학습시키지 않는다고 밝혀요. 자세한 설정은 ChatGPT의 데이터 제어 안내를 확인하세요.
- **결과를 믿기 전에 확인.** 문서는 dot이 실수할 수 있다고 직접 경고하고, 실행이 끝났다고 원하는 결과가 달성된 것은 아니라고 해요. 중요한 결과는 출처와 함께 검토하세요.
- 에이전트에게 권한을 줄 때의 일반 점검표는 [5. 개인 AI 에이전트 안전하게 쓰는 법](/new-project1/agents/05-agent-safety/)에 따로 정리해 뒀어요.

## 자주 막히는 지점

### Dots 메뉴가 안 보여요

- **원인**: 플랜이 대상이 아니거나(Plus·무료 등), 지역 제외(EEA·영국·스위스), 만 18세 미만, 롤아웃이 아직 안 왔거나, Enterprise에서 관리자가 켜지 않은 경우예요.
- **해결**: 앱을 최신 버전으로 업데이트하고, 모바일 웹이 아닌 앱 또는 데스크톱 브라우저로 접속하세요. 대상 플랜인데도 안 보이면 며칠 기다려 보세요. Enterprise는 관리자에게 Use dots 권한을 요청하세요.

### 내 컴퓨터의 파일을 못 써요

- **원인**: 컴퓨터가 오프라인이거나 ChatGPT 앱이 닫혀 있거나, 연결 자체를 하지 않았을 수 있어요. 기업에서는 관리자의 로컬 컴퓨터 접근 허용이 별도로 필요해요.
- **해결**: 데스크톱 앱을 열어 둔 채 dot 프로필의 Computers에서 상태를 확인하세요. Offline 표시는 연결이 끊긴 게 아니라 일시적으로 쓸 수 없다는 뜻이에요.

### 어떤 사이트에서 클라우드 브라우저가 막혀요

- **원인**: 일부 웹사이트는 클라우드 브라우저를 차단하거나 추가 인증을 요구해요.
- **해결**: Take over로 직접 로그인하거나, 연결한 내 컴퓨터로 시도해 보라고 요청하세요. 단, 클라우드 브라우저의 로그인 세션이 내 컴퓨터로 옮겨지지는 않아요.

### 대화를 끝냈는데 일이 계속돼요

- **원인**: 통화나 대화를 끝내도 맡긴 작업은 이어질 수 있어요.
- **해결**: Pause로 주 작업을, Activity에서 위임 작업을, Scheduled에서 반복 작업을 각각 멈추세요.

### 메일이나 앱을 못 읽어요

- **원인**: 플러그인이 연결되지 않았거나 연결이 만료됐을 수 있어요. Slack만 연결했다면 메일은 연결되지 않은 거예요.
- **해결**: dot이 보내는 재연결 요청을 열어 다시 연결하세요.

## 실전 팁

- **작게 시작하세요.** 한 가지 책임, 몇 개의 자료로 시작해 결과를 보고 범위를 넓히세요.
- **"보내지 말고 초안만"을 습관으로.** 메일, 메시지, 문서 공유는 확인 뒤에 보내게 하세요.
- **알림 기준을 말해 주세요.** "마감이 위험할 때만 알려 줘"처럼 알림 가치가 있는 변화를 정해 주면 알림이 덜 시끄러워요.
- **예약은 시간대와 기간을 적고 확인받으세요.** "한국 시간 평일 9시, 4주"처럼요. 저장된 내용을 dot에게 되읽어 달라고 하세요.
- **출시 첫 달 한도.** 공식 문서상 출시 후 첫 달은 깊은 작업 허용량이 확장돼요. 이후 한도가 달라질 수 있으니 사용량을 지켜보세요.
- **첫 결과는 반드시 검토하세요.** 같은 책임을 처음 맡길 때는 출처와 누락을 직접 확인하세요.

## 다른 에이전트와 다른 점

- **ChatGPT 안에 있어요.** 별도 앱이 아니라 ChatGPT 계정, 메모리, 플러그인, Work, Codex와 연결돼요.
- **같은 dot을 여러 곳에서.** ChatGPT, 통화, Slack, Teams에서 같은 dot과 메모를 공유해요.
- **자체 컴퓨터 + 내 컴퓨터(선택).** 클라우드 컴퓨터가 기본이고, 로컬 연결은 한 대만 선택적으로 할 수 있어요.
- **Work·Codex에 위임.** 코드는 Codex로, 파일 만들기는 Work로 나눠 일을 시킬 수 있어요.
- 다른 제품과의 나란히 비교는 [1. 개인 AI 에이전트 한눈에 비교](/new-project1/agents/01-agents-compared/)에서 해요.
