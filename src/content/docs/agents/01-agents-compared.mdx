## Concepts to know first

### What is a personal AI agent?

A chat AI is a tool that **answers when you ask**. A personal AI agent is a tool that **breaks a goal into steps and carries them out once you hand it off**. Compare the two in the table below.

| | Chat AI | Personal AI agent |
| --- | --- | --- |
| How it works | One answer per question | Takes a goal, makes a plan, and runs multiple steps |
| What it can reach | Inside the chat window | Email, calendar, websites, files, and sometimes even payments |
| Timing | Only when you talk to it | Keeps working after you close the app, or runs on a schedule |
| Speaking first | Almost never | Notifies you first when it needs a result or a decision |
| Risk | Can give a wrong answer | Can take a wrong **action** (sending email, buying, deleting, etc.) |

The last row is the important one. The more convenient an agent is, the more **permissions** you have to give it, and the bigger the consequences of a mistake. We cover how to use agents safely in [Part 5, Using Personal AI Agents Safely](/agents/05-agent-safety/).

### Terms used in this comparison

| Term | Meaning |
| --- | --- |
| **Always-on** | It keeps working in the cloud even when your computer or app is off. |
| **Connector / plugin** | A connection that lets the agent access services like email, calendar, and collaboration tools. |
| **Computer use** | Operating sites or apps that have no connection tool, by clicking and typing on the screen like a person. |
| **Approval** | A step where the agent asks a person "Is it okay to do this?" before a sensitive action. |

## One line per product

- **Meta Muse**: An agent aimed at everyday users. You tell it a goal by message, and it operates a browser on a dedicated cloud VM, even making purchases and bookings. You can't use it in Korea yet. See [Getting to Know Meta Muse](/agents/02-meta-muse/) for details.
- **Grok Bot**: "AI teammates" you hand work to by message, as several named Bots. All Bots share one cloud computer, and your account and billing are tied to Cursor. See [Getting Started with Grok Bot](/agents/03-grok-bot/).
- **ChatGPT Dots**: An always-on agent inside ChatGPT. Give it a responsibility and it tracks progress on its own and contacts you first when needed. See [Getting Started with ChatGPT Dots](/agents/04-openai-dots/).
- **Claude**: Less a single "agent product" like the three above and more a **bundle of features**. You pick what you need: Cowork for multi-step tasks, the Chrome extension for browser control, computer use for screen control, and routines for automatic cloud runs. They're covered in [C3. Getting started](/claude/c03-getting-started/), [C7. Connectors](/claude/c07-connectors/), [C11. Chrome and computer use](/claude/c11-chrome-computer-use/), and [C13. Cloud sessions and routines](/claude/c13-cloud-sessions/).

## Which one is right for me

These are recommendations by situation for users in Korea. Every recommendation relies on the [Official] items in the tables above, and we've marked the parts where you need to verify sign-up availability yourself.

| My situation | Recommendation | Why and what to watch for |
| --- | --- | --- |
| I want to start now, with certainty, in Korea | **Claude** | Korea is on the supported countries list. You can start by connecting email and calendar through connectors and getting approval for every write action. Many features need a paid plan (Pro $20/month). |
| I want to automate code or GitHub repository work | **Claude (cloud sessions, routines)** | It keeps running even with your computer off. Routines run autonomously without approval, so keep the scope narrow. See [C13](/claude/c13-cloud-sessions/). |
| I want to hand off browser tasks | **Claude in Chrome** | It doesn't make purchases or create accounts, and asks before sensitive input. See [C11](/claude/c11-chrome-computer-use/). |
| I want "AI teammates" I can hand multiple jobs to by message | **Grok Bot** | The app is on the Korean stores. Before signing up, check whether you can pay for a Cursor or SuperGrok subscription from Korea. Usage is capped weekly, and overage may be billed pay-as-you-go. |
| I'm already on ChatGPT Pro | **Dots** | It's included at no extra charge. Check whether it shows up in your ChatGPT app (gradual rollout). Plus and Free aren't mentioned in the docs. |
| I'm most curious about an agent that handles purchases and bookings | **Muse (waiting for launch)** | You can't use it in Korea. Wait for an official Korea launch announcement. |

## Common sticking points

### Dots doesn't show up in my app

- **Cause**: The official docs say it's a "gradual rollout," so it may not appear right away even if your plan qualifies. You need Pro or above (or Business Premium or Enterprise), and for Enterprise it's off by default, so an admin has to turn it on.
- **Fix**: Update the ChatGPT app to the latest version, check your plan, and wait a bit. It isn't supported on mobile web.

### I want to sign up for Muse

- **Cause**: Korea isn't an officially supported region.
- **Fix**: Wait for the official Korea launch announcement. In the meantime, we suggest getting familiar with the concepts through the other products in this comparison or [Getting to Know Meta Muse](/agents/02-meta-muse/).

### My Grok Bot usage suddenly ran short

- **Cause**: Weekly usage resets every week. The X Subscription shares the same weekly usage with Grok and Cursor (as of 2026-10-26), and once it runs out, prepaid credits or (for existing Cursor plans) pay-as-you-go usage may be billed.
- **Fix**: Check your usage settings and billing settings first. More details are in [Getting Started with Grok Bot](/agents/03-grok-bot/).

## Practical tips

- **Read first, write later.** After a few days of read tasks like summarizing and organizing, consider permissions for sending email, deleting, and payments.
- **One job per product.** Connecting several services all at once makes it hard to trace what happened.
- **Look at what the price "includes."** Dots counts against ChatGPT Pro, Grok Bot against your Cursor or SuperGrok account, and Claude against the usage of plans like Pro and Max. The more you run agents, the faster your limit shrinks.
- **Official docs are mostly in English.** We couldn't find Korean versions of the official docs for Dots, Grok Bot, or Muse. Even if you use a translator, check the original for important terms and permission screens.
