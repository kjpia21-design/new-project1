## 이 튜토리얼로 할 수 있게 되는 것

- 개인 AI 에이전트가 채팅 AI와 무엇이 다른지 한 문장으로 설명할 수 있어요.
- Muse, Grok Bot, Dots, Claude의 차이를 한국 사용자 입장에서 비교할 수 있어요.
- "나에게 맞는 선택" 가이드로 지금 시작할 제품과 기다릴 제품을 정할 수 있어요.

## 먼저 알아둘 개념

### 개인 AI 에이전트란?

채팅 AI는 **내가 물어보면 답하는** 도구예요. 개인 AI 에이전트는 **내가 목표를 맡기면 스스로 단계를 나눠 실행하는** 도구예요. 아래 표에서 차이를 비교해 보세요.

| 구분 | 채팅 AI | 개인 AI 에이전트 |
| --- | --- | --- |
| 일하는 방식 | 질문 하나에 답 하나 | 목표를 받아 계획을 세우고 여러 단계를 실행 |
| 손이 닿는 범위 | 대화창 안 | 메일, 캘린더, 웹사이트, 파일, 때로는 결제까지 |
| 시간 | 내가 말할 때만 | 앱을 닫아도 계속 작업하거나 일정에 맞춰 실행 |
| 먼저 말 걸기 | 거의 없음 | 결과나 결정이 필요하면 먼저 알림 |
| 위험 | 틀린 답을 줄 수 있음 | 틀린 **행동**을 할 수 있음 (메일 발송, 구매, 삭제 등) |

마지막 줄이 중요해요. 에이전트는 편리한 만큼 **권한을 줘야** 하고, 권한을 주면 실수의 결과도 커져요. 안전하게 쓰는 방법은 [5편 개인 AI 에이전트 안전하게 쓰는 법](/agents/05-agent-safety/)에서 다뤄요.

### 이 비교에서 쓰는 용어

| 용어 | 뜻 |
| --- | --- |
| **상시 작동** | 내 컴퓨터나 앱을 꺼도 클라우드에서 계속 일하는 것이에요. |
| **커넥터 / 플러그인** | 에이전트가 메일, 캘린더, 협업 도구 같은 서비스에 접근하게 해 주는 연결이에요. |
| **컴퓨터 사용** | 연결 도구가 없는 사이트나 앱을 사람처럼 화면에서 클릭하고 입력해서 조작하는 방식이에요. |
| **승인** | 민감한 행동 전에 에이전트가 사람에게 "해도 될까요?"라고 묻는 단계예요. |

### 확인 수준 표시 읽는 법

이 표의 모든 칸 끝에 확인 수준을 붙였어요.

| 표시 | 뜻 |
| --- | --- |
| **[공식]** | 회사 공식 페이지나 공식 앱 스토어 등록 페이지를 직접 열어 확인했어요. |
| **[부분]** | 공식 페이지를 일부만 읽었거나, 검색 결과 요약, 언론 보도에 일부 기대고 있어요. 바뀌었을 수 있어요. |
| **[미확인]** | 공식 출처에서 확인하지 못했어요. "없다"는 뜻이 아니에요. |

<Aside type="note" title="기준일이 중요해요">
이 표는 2026-10-10 기준이에요(Grok Bot 요금 칸은 2026-10-13에 Cursor 공식 문서로 다시 확인했어요). Grok Bot은 베타로 시작했고, Dots는 점진적으로 롤아웃 중이고, Muse는 제한적 테스트 중이라고 공식 페이지가 밝히고 있어요. 새로운 소식이 나오면 각 제품 편의 출처 링크에서 최신 내용을 확인하세요.
</Aside>

| **한국 제공** | **아니요.** 공식 제공 지역은 미국과 캐나다. 한국은 어느 공식 페이지에도 없고 출시 일정 발표도 없어요 [공식] | **앱은 가능.** 한국 App Store와 Google Play에 등록돼 있어요. 한국 App Store에서 Cursor Pro·Pro+·Ultra 앱 내 구입이 원화로 표시돼요. SuperGrok·X Premium+ 구독이 한국에서 되는지는 [미확인]. @bot 태그는 일부 지역 제외지만 한국은 제외 목록에 없어요 [공식] | **제외 지역이 아님.** Pro 기준 제외는 EEA·영국·스위스이고 한국은 목록에 없어요. 다만 "한국 제공 확정" 공식 문장은 못 찾았고, 롤아웃이 점진적이라 계정마다 달라요. 국내 보도는 순차 제공으로 전해요 [부분] | **예.** Anthropic 제공 국가·지역 목록에 South Korea가 있어요. <Aside type="caution" title="Muse 우회 가입은 안내하지 않아요">
Muse 약관은 관련 법률상 서비스를 받을 수 없는 경우 사용할 수 없다고 하고, 계정 정지·종료 권한도 명시해요. VPN으로 가입하면 약관 위반 가능성, 계정 정지, 결제·본인 확인 문제가 생길 수 있어요. 이 사이트는 방법을 알려 드리지 않고, 한국 출시를 기다리는 쪽을 권해요.
</Aside>

### 에이전트로서의 능력

| 항목 | Meta Muse | Grok Bot | ChatGPT Dots | Claude |
| --- | --- | --- | --- | --- |
| 상시 작동 | 예. 앱을 닫아도 클라우드 VM에서 일정·이벤트에 따라 작업 [공식] | 예. 지속되는 클라우드 컴퓨터에서 앱을 닫아도 작동, 루틴 실행 [공식] | 예. 클라우드에서 계속 동작하고 스스로 깨어나 이어서 일해요 [공식] | **부분적.** 클라우드 세션과 루틴은 내 컴퓨터가 꺼져 있어도 돌지만 GitHub 저장소 작업 중심이에요. 컴퓨터 사용은 컴퓨터가 깨어 있고 데스크톱 앱이 열려 있어야 해요 [공식] |
| 외부 서비스 연동 | 이메일, 캘린더, 인스타그램, Shopify, Slack, Notion, GitHub 등 + 커스텀 커넥터 [공식] | Marketplace 플러그인 + 커넥터 없는 사이트는 컴퓨터 사용으로 직접 조작 [공식] | Gmail, Google Drive, GitHub 등 플러그인, Slack, Teams, 내 컴퓨터(선택, 한 대) [공식] | 커넥터(Gmail, Calendar, Drive, Notion, 커스텀 MCP 등), Claude in Chrome, 컴퓨터 사용 [공식] |
| 결제 기능 | 예. Stripe Link 일회용 카드(적격 구매 보호), 구매 전 사람 승인 [공식] | 전용 결제 수단·지출 상한은 문서에서 확인 안 됨. 구매는 가능하나 결제 확인은 사용자가 직접 입력 [공식] | 공식 문서에서 결제·구매 기능은 확인 못 함 (없다고 단정하지 않아요) [미확인] | 구매 기능 없음. Claude in Chrome은 권한과 상관없이 구매·계정 생성·카드 정보 처리를 하지 않아요 [공식] |
| 승인 방식 | 이메일 발송·구매 등 민감 작업은 사람 승인. 활동 로그 제공 [공식] | 승인 카드(Allow once, Always allow, Deny)와 Auto Review [공식] | 사용자 규칙 4단계(묻지 않고 실행 ~ 나에게 넘기기)와 자동 검토 [공식] | 커넥터는 전송·삭제 전 승인. Chrome은 Manual·Auto·Skip 모드. 루틴은 승인 없이 자율 실행 [공식] |

<Aside type="tip" title="Claude만 '일부러 보수적'인 부분이 있어요">
Claude는 Muse나 Dots처럼 구매까지 맡기는 방향이 아니라, 커넥터 → 브라우저 → 화면 조작 순서로 가장 안전한 도구를 먼저 쓰고 구매·계정 생성은 하지 않는 쪽이에요. 편의성은 낮지만 한국에서 지금 쓸 수 있고 권한 범위를 좁히기 쉬워요.
</Aside>

## 제품별로 한 줄씩

- **Meta Muse**: 메시지로 목표를 말하면 전용 클라우드 VM에서 브라우저를 조작해 구매·예약까지 하는, 일반 사용자 지향 에이전트예요. 한국에서는 아직 못 써요. 자세한 내용은 [Meta Muse 알아보기](/agents/02-meta-muse/)에서 봐요.
- **Grok Bot**: 이름 붙인 Bot 여러 개에게 메시지로 일을 맡기는 "AI 팀원"이에요. 모든 Bot이 클라우드 컴퓨터 하나를 공유하고, 계정과 청구가 Cursor에 묶여 있어요. [Grok Bot 시작하기](/agents/03-grok-bot/)에서 봐요.
- **ChatGPT Dots**: ChatGPT 안에서 책임을 맡기면 스스로 진행 상황을 추적하고 필요할 때 먼저 연락하는 상시 에이전트예요. [ChatGPT Dots 시작하기](/agents/04-openai-dots/)에서 봐요.
- **Claude**: 위 셋처럼 하나의 "에이전트 제품"이라기보다 **기능 묶음**이에요. 다단계 작업을 맡기는 Cowork, 브라우저를 조작하는 Chrome 확장, 화면을 조작하는 컴퓨터 사용, 클라우드에서 자동 실행하는 루틴을 필요에 따라 골라 써요. 각각 [C3. 시작하기](/claude/c03-getting-started/), [C7. 커넥터](/claude/c07-connectors/), [C11. Chrome과 컴퓨터 사용](/claude/c11-chrome-computer-use/), [C13. 클라우드 세션과 루틴](/claude/c13-cloud-sessions/)에서 다뤄요.

## 자주 막히는 지점

### Dots가 앱에 안 보여요

- **원인**: 공식 문서가 "점진적 롤아웃"이라고 밝히고 있어서, 요금제가 해당돼도 바로 안 보일 수 있어요. Pro 이상(또는 Business Premium, Enterprise)이어야 하고 Enterprise는 기본 꺼짐이라 관리자가 켜야 해요.
- **해결**: ChatGPT 앱을 최신 버전으로 업데이트하고 요금제를 확인한 뒤 기다려 보세요. 모바일 웹에서는 지원되지 않아요.

### Muse에 가입하고 싶어요

- **원인**: 한국은 공식 제공 지역이 아니에요.
- **해결**: 한국 출시 공식 발표를 기다려 주세요. 그 사이에는 이 비교의 다른 제품이나 [Meta Muse 알아보기](/agents/02-meta-muse/)로 개념을 익혀 두는 걸 권해요.

### Grok Bot 사용량이 갑자기 부족해요

- **원인**: 주간 사용량은 매주 초기화돼요. The X Subscription은 Grok·Cursor와 같은 주간 사용량을 공유하고(2026-10-26 기준), 소진되면 선불 크레딧 또는 (기존 Cursor 플랜은) 종량제 사용량이 청구될 수 있어요.
- **해결**: 사용량 설정과 청구 설정을 먼저 확인하세요. 자세한 내용은 [Grok Bot 시작하기](/agents/03-grok-bot/)에 있어요.

## 실전 팁

- **읽기부터, 쓰기는 나중에.** 요약·정리 같은 읽기 작업으로 며칠 써 본 뒤에 메일 발송, 삭제, 결제 권한을 검토하세요.
- **제품 하나에 한 가지 일만.** 처음부터 여러 서비스를 한꺼번에 연결하면 무슨 일이 일어났는지 추적하기 어려워요.
- **요금은 "무엇에 포함되는가"를 보세요.** Dots는 ChatGPT Pro, Grok Bot은 Cursor·SuperGrok 계정, Claude는 Pro·Max 같은 플랜의 사용량에 합산돼요. 에이전트를 많이 돌릴수록 한도가 줄어요.
- **공식 문서는 영어가 많아요.** Dots, Grok Bot, Muse의 공식 문서는 한국어판을 확인하지 못했어요. 중요한 약관과 권한 화면은 번역기를 쓰더라도 원문을 한 번 확인하세요.
