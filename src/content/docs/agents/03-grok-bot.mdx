## 먼저 알아둘 개념

### 무엇이고, 누가 만들었나요?

Grok Bot은 xAI가 만든 앱이에요. 공지에서는 "내 일을 맡길 수 있는 AI 팀원"이라고 소개하고, 사내 프로토타입으로 시작해 외부에 공개했다고 밝혀요. 사이트 푸터에는 회사 이름이 SpaceXAI LLC로 표기돼 있어요. 앱 스토어에서는 제공자가 X Corp.로 나와요.

한 가지 알아둘 점이 있어요. **실제 로그인, 사용량 계량, 개인정보 설정은 Cursor 계정을 통해 이뤄져요.** 앱에서 "Sign In with Cursor"로 로그인하고, 사용량도 Cursor 계정에서 세요.

### 채팅 AI, @grok과 뭐가 다른가요?

| 구분 | 일반 채팅 AI (Grok 챗봇 등) | Grok Bot |
| --- | --- | --- |
| 일하는 곳 | 대화창 안 | Bot 전용 **클라우드 컴퓨터** (브라우저, 파일, 터미널) |
| 결과물 | 답변, 초안 | 내 앱에서 **실제로 끝낸 일** (공식 설명) |
| 내가 앱을 닫으면 | 멈춤 | **계속 작동** |
| 진행 방식 | 한 대화씩 | 여러 Bot 병렬, Bot끼리 업무 전달 |
| 기억 | 대화 중심 | 이름 붙인 Bot이 선호와 지난 작업 요약을 유지 |

X에서 글에 `@grok`을 달아 묻는 것은 별개 서비스예요. Grok Bot에 X에서 일을 맡기려면 `@bot`을 태그해요([아래](#x에서-bot으로-일-맡기기)).

### 핵심 용어

| 용어 | 뜻 |
| --- | --- |
| **Bot** | 이름, 맡은 일, 일하는 방식을 가진 AI 팀원이에요. 여러 개 만들 수 있어요. |
| **Agent Computer** | Bot이 쓰는 클라우드 컴퓨터예요. **내 모든 Bot이 한 대를 같이 써요.** |
| **커넥터(플러그인)** | Marketplace에서 설치하는 연결이에요. 있으면 사이트를 클릭하는 것보다 안정적이에요. |
| **컴퓨터 사용** | 커넥터가 없는 사이트를 Bot이 직접 조작하는 방식이에요. |
| **스킬** | "이 일은 이렇게 한다"를 저장한 재사용 지침이에요. |
| **루틴** | 어떤 Bot이 언제 어떤 일을 할지 정한 반복 작업이에요. |
| **Auto Review** | 도구 호출과 컴퓨터 동작을 실행 전에 모델이 점검하는 기능이에요. |
| **인수(Takeover)** | 로그인, 2단계 인증, CAPTCHA, 결제 확인을 내가 직접 컴퓨터에서 처리하는 것이에요. |

### 누가 쓸 수 있고, 얼마인가요?

별도 "Grok Bot 요금제"는 없어요. 아래 중 하나로 접근 권한이 생겨요(Cursor 도움말 기준).

| 내가 가진 것 | Grok Bot |
| --- | --- |
| Cursor Pro, Pro+, Ultra (개인 유료) | 포함. 위로 갈수록 주간 사용량이 커져요 |
| Cursor Teams (self-serve) | 모든 구성원 포함 |
| SuperGrok, SuperGrok Plus, SuperGrok Heavy | Cursor 계정에 **연결**해서 사용 |
| X Premium+ | Cursor 계정에 **연결**해서 사용 |
| self-serve Grok Business 좌석 | "Sign in with Grok"으로 로그인 |
| SuperGrok Lite | **포함되지 않음** |
| Cursor Enterprise, Grok Enterprise | 담당자에게 문의 (대기자 명단/영업 문의) |

알아둘 규칙들이에요.

- Grok Bot에는 **전용 주간 사용량**이 있어요. 일반 Grok·Cursor 사용량과 따로 계산돼서 Bot에 맡긴 일이 기존 한도를 깎지 않아요.
- 주간 사용량을 다 쓰면 **종량제(on-demand)** 사용량이 Cursor로 청구될 수 있어요. 한도를 미리 확인하세요.
- Cursor 플랜과 SuperGrok 연결은 **합산되지 않아요.** 둘 다 있으면 사용량이 더 많은 쪽이 적용돼요.
- SuperGrok이나 X Premium+ 연결은 **한 번 하면 해제하거나 다른 Cursor 계정으로 옮길 수 없어요.** 연결하기 전에 올바른 Cursor 계정으로 로그인했는지 꼭 확인하세요.
- 무료 체험은 일수가 아니라 **크레딧** 방식이에요(7일 창도 적용). 크게 맡기면 한 번에 다 쓸 수 있어요.
- 금액은 공식 가격 페이지 기준으로 Cursor Pro가 월 $20, Cursor Teams가 사용자당 월 $40이에요. Pro+·Ultra·SuperGrok 금액과 구체적인 사용량 수치는 이번에 공식 출처로 확인하지 못해서 싣지 않아요.

### 한국에서 쓸 수 있나요? 한국어는요?

| 항목 | 확인된 내용 |
| --- | --- |
| 한국 앱 스토어 | **한국 App Store에 등록**돼 있어요. 무료 + 앱 내 구입, iOS 18.0 이상 |
| 한국 Google Play | **한국어 설명으로 등록**돼 있어요 |
| 데스크톱 | 공식 사이트에서 macOS·Windows·Linux 설치 파일을 내려받아요 |
| 지역 제한 문구 | 설치와 로그인에 관한 국가 제한 문구는 공식 문서에서 찾지 못했어요 |
| 앱 화면 언어 | **한국어 지원.** App Store 지원 언어 11개에 한국어가 포함돼요. 데스크톱 문서도 한국어를 언어 목록에 적어요 |
| Bot의 한국어 작업 품질 | **공식 확인이 없어요.** 한국어로 시켜도 되는지, 한국 사이트를 얼마나 잘 다루는지는 직접 시험해 봐야 해요 |
| 한국에서의 청구·통화 | 이번에 확인하지 못했어요 |

따라서 이 글은 한국에서 **공식 스토어와 공식 로그인 방식으로** 시작하는 경우만 안내해요. 공식 경로가 아닌 우회 가입은 안내하지 않아요.

<Aside type="caution" title="X의 @bot 태그는 지역 제한이 있어요">
X 계정으로 @bot을 부르는 기능은 영국, EU, 호주 등에서는 아직 안 돼요. 한국은 제외 목록에 없지만, 기준은 **X 계정에 등록된 국가**이고 VPN이나 현재 위치는 영향이 없어요.
</Aside>

  '로컬 컴퓨터 실행을 "Ask every time" 이하로 두었어요',
  '필요한 앱에 직접 로그인하고 Auto Review 규칙을 정했어요',
  '(선택) 잘 되는 일을 스킬과 루틴으로 저장했어요',

<Steps>

1. **계정과 데이터 설정 확인하기**

   위 표에서 내 플랜이 포함되는지 보세요. Grok Bot은 클라우드 데이터 저장이 필요해서, Cursor 계정이 **Legacy Privacy Mode**이면 시작되지 않아요. 이 경우 Cursor의 개인정보 설정에서 지원되는 데이터 설정으로 바꿔야 해요.

2. **앱 설치하기**

   - **데스크톱**: 공식 다운로드 페이지(x.ai/bot)에서 내 운영체제용 파일을 받아요. macOS는 Apple 칩/Intel, Windows는 x64/Arm64, Linux는 deb, rpm, AppImage 중에서 골라요.
   - **iPhone/iPad**: App Store에서 "Grok Bot"(제공자 X Corp.)을 설치해요. iOS 18 이상이 필요해요.
   - **Android**: Google Play에서 "Grok Bot"을 설치해요. 공식 문서 기준 Android 9 이상이에요.

   <ScreenshotPlaceholder caption="한국 App Store의 Grok Bot 등록 화면 (제공자 X Corp., 무료·앱 내 구입)" />

   <Aside type="note" title="2026-08-26 공지와 지금 문서가 달라요">
   8월 공지의 다운로드 버튼은 macOS만 보여요. 2026-10-07에 갱신된 공식 문서는 Windows·Linux와 Android도 지원한다고 적어요. 이 글은 더 최근 문서를 따르지만, 설치 화면에서 내 기기용 파일이 안 보이면 공식 페이지를 다시 확인하세요.
   </Aside>

3. **로그인하고 접근 권한 연결하기**

   앱에서 Cursor 계정으로 로그인해요(조직이 SSO를 쓰면 조직 로그인으로). SuperGrok 구독으로 쓴다면 앱이 안내할 때 Grok 계정을 연결해요. 앞에서 말했듯 연결은 되돌릴 수 없으니 **올바른 Cursor 계정인지** 먼저 확인하세요.

   처음 실행하면 Bot, 공유 컴퓨터, 루틴을 소개하고 쓰는 도구를 물어봐요. 이 답은 추천을 정하는 데만 쓰이고 도구를 연결하지는 않아요. 컴퓨터 준비는 몇 분 걸릴 수 있어요.

   <ScreenshotPlaceholder caption="처음 실행 후 'Meet a future teammate'에서 첫 Bot을 고르는 화면" />

4. **첫 Bot 만들기**

   추천 팀원을 고르거나 직접 만들어요. 이름, **주된 일 하나**, 일하는 방식을 적으면 돼요. 한 Bot에 여러 역할을 몰아주기보다 역할별로 나누는 편이 맥락이 잘 쌓여요(공식 권고).

   <PromptBox>
   이름: 모아
   일: 주간 업무 정리
   설명: 내가 올린 문서와 메모를 읽고 날짜, 결정 사항, 열린 질문을 따로 정리해 줘요. 원본 파일은 바꾸지 말고, 출처(쪽수나 항목)를 같이 적어 주세요. 메일 발송이나 외부 게시처럼 바깥에 영향을 주는 일은 반드시 먼저 물어보세요.
   </PromptBox>

5. **안전한 첫 일 맡기기**

   좋은 요청에는 결과물, 참고할 곳, 하지 말 것, 돌려받을 형태, 멈출 지점이 들어가요. 로그인이나 커넥터가 필요 없는 문서 요약부터 해보세요.

   <PromptBox>
   첨부한 문서를 다섯 줄로 요약해 주세요. 날짜, 결정, 열린 질문은 따로 모아 주세요. 각 항목의 출처 쪽수나 절을 적고, 원본 파일은 건드리지 마세요.
   </PromptBox>

   키보드 받아쓰기(`Cmd/Ctrl+D`)나 음성 채팅으로도 맡길 수 있어요. 한국어 음성 인식이 잘 되는지는 공식 확인이 없으니 직접 시험해 보세요.

6. **필요한 앱에는 직접 로그인하기**

   Bot이 로그인이 필요한 곳에 닿으면 컴퓨터 인수를 요청해요. 대화에서 **Agent Computer**를 열고, 인수 버튼을 눌러, 비밀번호·패스키·2단계 코드·CAPTCHA를 **내가 직접** 입력한 다음 제어권을 돌려주세요. 비밀번호나 일회용 코드를 일반 채팅에 보내지 마세요.

   로그인한 브라우저 세션은 공유 컴퓨터에 남아서 다른 Bot도 쓸 수 있어요. 지원되는 서비스는 사이드바 Marketplace에서 플러그인을 설치하고 브라우저에서 인증하는 방법도 있어요. 채팅에서 `@`로 커넥터를, `/`로 스킬을 불러요.

   <ScreenshotPlaceholder caption="Agent Computer 화면에서 로그인을 직접 처리하는 인수 화면" />

7. **결과 확인하고 다듬기**

### X에서 Bot으로 일 맡기기

X 글이나 답글에 `@bot`을 태그하면 내 대표 Bot이 그 글을 작업으로 받아요. 작업과 결과는 Grok Bot 앱의 대화에 남고, @bot은 X에 짧은 확인 답글만 달아요.

- Grok 계정에 X 계정이 연결돼 있고, Bot이 하나 이상 있어야 해요.
- 영상·GIF가 있는 글, @grok도 같이 태그한 글에는 응답하지 않아요.
- 태그로 시작한 작업도 **Grok Bot 사용량을 써요.**

| 승인 만료 | 루틴·트리거·다른 Bot에서 시작된 승인은 약 10분 뒤 만료 |

### 승인 카드의 선택지

| 선택 | 의미 |
| --- | --- |
| **Allow once** | 이번 한 번만 허용해요 |
| **Always allow** | 비슷한 동작을 계속 허용하는 규칙을 저장해요 |
| **Deny** | 막아요 |

규칙 종류는 두 가지예요. **Ask first**는 항상 멈추고, **Allow automatically**는 자동 점검에서 다른 문제가 없을 때만 통과시켜요. 둘이 겹치면 **Ask first가 이겨요.**

### 로컬 컴퓨터 실행 설정

| 값 | 의미 |
| --- | --- |
| **Ask every time** | 기본값. 매번 물어요 |
| **Always allow** | 항상 허용 (권장하지 않아요) |
| **Never allow** | 내 컴퓨터에서는 명령 실행 금지 |

이 설정은 클라우드 컴퓨터 사용과는 별개예요. 내 파일이 필요한 이유가 없으면 **Never allow**를 권해요.

## 결제·권한·개인정보에서 조심할 점

Grok Bot은 내 앱에 로그인해서 실제 작업을 해요. 편리한 만큼 실수의 비용도 커요. 일반 원칙은 [개인 AI 에이전트 안전하게 쓰는 법](/new-project1/agents/05-agent-safety/)에서 더 다뤄요.

<Aside type="caution" title="모든 Bot이 한 컴퓨터를 같이 써요">
파일, 브라우저 로그인, 명령줄 자격 증명이 모든 Bot에게 공유돼요. 공식 문서도 "Bot을 보안 경계로 쓰지 말라"고 해요. "이 Bot은 메일만"이라고 정해도 같은 컴퓨터에 로그인된 다른 서비스에 다른 Bot이 접근할 수 있다고 가정하세요. Bot을 삭제해도 공유 컴퓨터의 파일과 로그인 세션은 남아요.
</Aside>

### 결제와 구매

- 공식 공지에는 웹사이트를 만들고 **도메인을 구매해 배포**하는 사례가 있어요. 구매가 가능한 일이라는 뜻이에요.
- 반면 이번에 확인한 문서에서 **Bot 전용 결제 수단이나 지출 상한을 정하는 기능은 찾지 못했어요.** 있다고 가정하지 마세요.
- 결제 확인은 Bot이 컴퓨터 제어권을 넘기는 **인수** 단계에서 내가 직접 처리하도록 설계돼 있어요. 카드 번호를 채팅에 보내지 마세요.
- 구매, 금융 이체, 삭제, 권한 변경, 운영 환경 변경, 약관 동의는 요청 안에 **"먼저 물어보라"**고 명시하세요. 이것이 공식 권고예요.
- 승인은 앞으로 할 동작을 통제할 뿐 **이미 끝난 일을 되돌리지 못해요.** 확인 화면의 대상·범위·금액을 읽고 이해되지 않으면 승인하지 마세요.
- 고객 환불 같은 금전 작업은 정책 범위를 문장으로 못 박고, 처음에는 초안만 만들게 하세요.

### 권한

- 처음에는 읽기 전용, 초안 작성부터 시작하세요. 보내기, 게시, 구매, 삭제는 승인 뒤에만 하게 하세요.
- **Auto Review**는 모델이 점검하는 기능이라 완벽하지 않아요. 문서도 최소 권한과 명시적 승인을 대체하지 못한다고 말해요. "브라우저에서는 모두 허용" 같은 넓은 규칙은 피하고 좁게 쓰세요(예: "외부 메일 발송 전에는 항상 먼저 묻기").
- 루틴이나 다른 Bot이 시작한 승인은 10분쯤 뒤 만료되고 실행되지 않아요. 놓쳤다면 Bot에게 다시 시도시키세요.
- 쓰지 않는 서비스는 로그아웃하고, 연결 앱은 원 서비스에서 권한을 취소하세요.
- 서비스 쪽에 범위가 제한된 계정(서비스 계정)을 만들 수 있다면 그 계정을 쓰세요. Bot은 로그인한 사람의 권한만큼 일해요.

### 개인정보와 데이터

- Grok Bot은 **클라우드 데이터 저장이 필수**예요. 학습 거부 선택은 Cursor 계정과 개인정보 설정을 따라요.
- Bot의 컴퓨터는 현재 **미국**에서 실행돼요. 한국 사용자의 데이터가 해외 서버에서 처리된다는 뜻이에요. 회사 자료를 다루기 전에 소속 조직의 정책을 확인하세요.
- Bot **공유 링크**는 Bot의 설정만 공개하고 내 컴퓨터나 로그인은 공유하지 않지만, 설정에 비밀이나 내부 주소를 넣으면 노출돼요. 고객 정보도 넣지 마세요.
- Enterprise 전용 통제(네트워크 정책, 감사 로그 등)는 self-serve 플랜에는 없어요.
- 이 글에서는 SOC 2 같은 인증 상태를 확인하지 못했어요. 업무용으로 도입한다면 Cursor의 보안 문서와 계약 조건을 직접 검토하세요.

### 사용량과 비용

- 루틴이나 병렬 Bot을 많이 돌리면 주간 사용량이 빨리 줄고, 종량제가 켜져 있으면 추가 청구가 생겨요.
- 무료 체험은 크레딧 방식이라 큰 작업 하나로 소진될 수 있어요. 작게 시작해서 사용량 화면을 보며 늘리세요.
- 오래 자리를 비우면 앱이 루틴을 계속 돌릴지 물을 수 있고, 답이 없으면 루틴이 멈출 수 있어요.

## 자주 막히는 지점

### 시작이 안 되고 Legacy Privacy Mode 오류가 나와요

- **원인**: Grok Bot은 클라우드 데이터 저장이 필요한데, Legacy Privacy Mode는 이를 허용하지 않아요.
- **해결**: Cursor 계정의 데이터 설정을 지원되는 값으로 바꾸세요. 조직 계정이면 관리자에게 문의하세요.

### 로그인은 됐는데 접근 권한이 없다고 해요

- **원인**: 플랜이 포함 대상이 아니거나(SuperGrok Lite 등), SuperGrok 연결을 안 했거나, 다른 Cursor 계정으로 로그인했어요.
- **해결**: 위 플랜 표를 확인하세요. SuperGrok 연결이 필요하면 앱의 접근 화면에서 Grok 계정을 연결하고 상태를 새로 고치세요.

### 컴퓨터가 "준비 중"에서 오래 걸려요

- **원인**: 처음 설정과 이미지 업데이트는 몇 분 걸릴 수 있어요.
- **해결**: 앱을 열어 두고 기다려요. 멈춘 듯하면 재시도, 앱 재시작, 업데이트 확인, 설정의 컴퓨터 업데이트 순서로 가장 덜 파괴적인 방법부터 쓰세요. **Reset**은 마지막 수단이에요. 마지막 저장 이후 작업을 잃을 수 있어요.

### Bot이 멈춘 것 같아요

- **원인**: 로그인, CAPTCHA, 승인, 비밀 입력을 기다리는 중일 수 있어요.
- **해결**: 대화의 질문과 승인 카드를 보고, Agent Computer에서 화면을 확인하세요. 방향이 틀렸다면 짧게 고쳐 말하고, 중단하려면 "지금 멈춰"라고 보내세요. 사용량이 소진됐는지도 확인하세요.

### 사이트가 계속 로그인을 요구해요

- **원인**: 사이트가 세션을 일찍 만료시키거나 자동화를 막아요.
- **해결**: 직접 인수해 로그인한 뒤, 로그인된 화면이 뜬 것을 확인하고 제어권을 돌려주세요. 인증을 우회시키려 하지 마세요. Bot도 그런 단계는 사람에게 넘기도록 설계돼 있어요.

### 루틴이 실행되지 않았어요

- **원인**: 꺼져 있거나, 일정·시간대가 틀렸거나, 소유 Bot이 삭제됐거나, 플러그인 인증이 풀렸거나, 사용량이 소진됐을 수 있어요.
- **해결**: 루틴 화면에서 위 항목과 실행 기록을 확인하세요. **Test run은 실제 작업을 해요.** 안전한 입력으로만 시험하세요.

### X에서 @bot이 답이 없어요

- **원인**: 지역 제한, 영상/GIF가 있는 글, @grok 동시 태그, 내부 검수 미통과, Grok Bot 미연결, 주간 사용량 소진 중 하나예요.
- **해결**: X 계정의 국가 등록을 확인하고, 글을 단순하게 바꿔 다시 태그해 보세요.

## 실전 팁

- **Bot을 역할별로 나누세요.** 하나에 몰면 맥락이 흐려져요. 다만 컴퓨터는 공유된다는 점을 잊지 마세요.
- **한 번 해보고, 스킬로, 그다음 루틴으로.** 처음부터 자동화하지 않아요.
- **"하지 말 것"을 적으세요.** 첫 요청에 "발송하지 말고 초안만"을 넣으면 사고가 크게 줄어요.
- **루틴에는 데이터 없음 규칙을 넣으세요.** 원본이 없으면 예전 자료를 쓰지 말고 실패를 알리게 하세요.
- **루틴 시각은 정각을 피하세요.** 9시 07분처럼 어긋나게 잡아요.
- **한국어 작업은 작게 시험하세요.** 한국어 품질은 공식 확인이 없으니, 한국어 사이트와 한국어 문서로 먼저 짧게 확인해 보세요.
- **정기적으로 점검하세요.** 설치한 커넥터, 로그인된 사이트, 켜 둔 루틴을 정리해요.
