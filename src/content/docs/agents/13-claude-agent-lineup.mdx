<Summary>
- Claude has several agent-style features, and they differ mainly in **where they work**: your documents and files (Cowork), your browser (Claude in Chrome), your computer screen (computer use), a video call (Meetings), a Slack channel (Claude Tag), or your own application (Managed Agents).
- Plans differ a lot. Cowork and Claude in Chrome are on all paid plans. Computer use is on Pro, Max and Ultra, and entered beta on Team and Enterprise on 2026-11-20. **Claude Meetings** and **Claude Tag** are beta on Team and Enterprise only. **Managed Agents** is an API product for developers.
- A short rule for choosing: use the lightest tool that reaches the place the work lives. The computer use help puts connectors first, then the browser, then screen control, which it calls the slowest and most error-prone.
- Statuses change quickly. Every row below carries a date, and the table is a snapshot from official pages read on **2026-11-22**, not a promise.
- Each row links to a full tutorial. The new Meetings, Team and Enterprise computer use, and self-hosted pages are linked from the table.
</Summary>

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Agent** | A model that uses tools in a loop to work toward a goal. See [Agents 1](/agents/01-agents-compared/). |
| **Beta** | The label the official pages use for features still being rolled out. Behavior and availability can change. |
| **Owner / admin** | On Team and Enterprise plans, the person who turns organization features on or off. |
| **Connector** | A built-in link from Claude to another service such as Gmail or Slack. |

## How to choose

Start from where the work lives, then check your plan.

| The work is in... | Try first | Because |
| --- | --- | --- |
| Files, documents, a research task you can leave running | Cowork | It is built for multi-step tasks that end in finished files |
| A website | Claude in Chrome | It acts inside the browser tab |
| A desktop app with no connector or web version | Computer use | It is the fallback when connectors and the browser cannot reach the work |
| A video call | Meetings | It joins the call and keeps notes and artifacts on a meeting page |
| A Slack thread | Claude Tag | The task and the result stay in the thread |
| Your own product or backend | Managed Agents | It is an API, so your code controls when sessions start |

The computer use help states the same order of preference: a connector if one exists, then the browser, then screen control, which is slowest and most error-prone.

### Things the official pages say to watch

- **Meetings:** the help says to make sure everyone on the call is okay with being transcribed before adding Claude. It is not available to some organizations, including ZDR, HIPAA-ready configuration or CMEK. It saves a transcript, summary and screen descriptions, not audio.
- **Computer use on Team and Enterprise:** the admin help says there is no sandbox between Claude and a user's applications, and that content on the screen could cause unintended actions. Screenshots are saved with the chat and can include personal or confidential information.
- **Claude Tag:** work in a channel is visible to the channel. See [C28](/claude/c28-claude-tag/) for billing and data details.
- **Managed Agents:** the overview marks it not eligible for ZDR or HIPAA.

## Common sticking points

### The feature is not in my account

- **Cause:** rollouts are gradual, and some features need an owner to switch them on.
- **Fix:** ask your organization owner, and check the linked help page for your plan.

### I cannot tell which tool to use

- **Cause:** several features can touch the same task, such as a web page.
- **Fix:** follow the order connector, browser, screen control from the computer use help.

### A feature is blocked for my organization

- **Cause:** Meetings and computer use list ZDR, HIPAA-ready configuration and CMEK among the settings that keep them from being turned on.
- **Fix:** this is an organization setting, so contact your admin. Do not look for ways around it.

## Practical tips

- **Start with the tool nearest the work.** Do not give a screen-control tool a job a connector can do.
- **Treat beta as beta.** Keep a manual fallback for important tasks.
- **Check consent for anything that listens.** Recording and transcription rules vary by place, and this page is not legal advice.
- **Keep sensitive apps out of reach.** The official safety pages advise against using screen control with banking, medical or government apps.
- **Re-check dates.** This table will age; the linked release notes are the place to look.
