개인 AI 에이전트는 질문에 답하는 데서 그치지 않고, 내 메일·일정·앱 같은 서비스에 연결해서 **내 대신 일을 해 주는 AI**예요. 사람이 매번 말을 걸지 않아도 정해 둔 일을 이어서 하거나, 알림이 오면 먼저 움직이기도 해요.

일반 채팅 AI는 "물어보면 답하는" 도구에 가깝고, 에이전트는 "맡기면 실행하는" 도구에 가까워요. 그만큼 편리하지만, 결제나 계정 권한 같은 중요한 일을 맡기게 되니 **어디까지 허용할지 정하는 것**이 중요해요.

이 섹션에서는 요즘 화제인 세 가지, Meta의 Muse, xAI의 Grok Bot, OpenAI의 ChatGPT Dots를 다뤄요. 각 편에서 **한국에서 쓸 수 있는지**와 **한국어를 지원하는지**를 먼저 확인하고, 공식 출처 기준으로만 설명해요. 한국에서 공식 제공되지 않는 서비스를 우회해서 가입하는 방법은 안내하지 않아요.
