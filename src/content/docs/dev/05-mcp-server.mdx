<Summary>
- MCP 서버는 Claude가 부를 수 있는 **도구(함수)를 내놓는 프로그램**이에요. 공식 Python SDK(`mcp`)로 함수에 `@mcp.tool()`만 붙이면 만들어져요.
- 내 컴퓨터에서만 쓰면 **stdio**, 여러 사람이나 Claude 앱에서 쓰려면 **Streamable HTTP**(공용 HTTPS 주소)로 띄워요.
- Claude Code에는 `claude mcp add`로, Claude 앱에는 **커스텀 커넥터**(원격 서버 URL)로 연결해요. 로컬 stdio 서버는 Claude 앱 채팅(claude.ai)에서는 못 써요.
- 서버가 돌려주는 글은 모델이 읽는 입력이에요. **읽기 전용 도구부터, 입력 검증, 비밀 값은 환경변수로, 인증 없는 공개는 금지**가 기본이에요.
- 예제는 공식 문서 기준이며 2026-10-11에 문법을 검증했어요. 서버 동작도 로컬에서 직접 호출해 확인했어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 공식 SDK로 재고 조회 도구 2개를 가진 MCP 서버를 만들고, 호출 테스트까지 할 수 있어요.
- 같은 서버를 Claude Code에 `claude mcp add`로 붙이고 `/mcp`로 상태를 확인할 수 있어요.
- HTTP로 띄운 서버를 Claude 앱의 커스텀 커넥터로 연결하는 절차와 조건을 알 수 있어요.
- MCP 서버를 만들 때 지켜야 할 보안 원칙(권한 최소화, 프롬프트 인젝션, 비밀 값)을 적용할 수 있어요.

<Aside type="note" title="이 편에서 Claude API 호출은 하지 않아요">
서버는 모델을 부르지 않고 도구만 제공해요. 그래서 이 편의 예제 코드에는 API 키가 필요 없어요. 모델이 도구를 부르는 쪽(클라이언트)이 비용을 쓰는 곳이에요. 도구를 직접 정의해서 API로 부르는 방법은 [1. 도구 사용으로 업무 봇 만들기](/new-project1/dev/01-tool-use/)를 보세요.
</Aside>

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **MCP** | Model Context Protocol. AI 앱과 외부 도구·데이터를 잇는 개방형 표준이에요. 쉬운 소개는 [20. 커넥터(MCP)](/new-project1/automation/20-connectors-mcp/)를 보세요. |
| **MCP 서버** | 도구(tools), 자원(resources), 프롬프트를 내놓는 프로그램이에요. 이 편은 **도구**만 다뤄요. |
| **호스트와 클라이언트** | Claude Code나 Claude 앱 같은 AI 앱이 호스트이고, 그 안의 클라이언트가 서버와 1:1로 연결해요. |
| **stdio** | 호스트가 서버를 자기 컴퓨터에서 **자식 프로세스로 실행**하고 표준 입출력으로 대화하는 방식이에요. |
| **Streamable HTTP** | 서버가 URL(기본 경로 `/mcp`)로 떠 있고 여러 클라이언트가 접속하는 방식이에요. 원격 서버에 쓰는 방식이에요. |
| **커스텀 커넥터** | Claude 앱에서 원격 MCP 서버의 URL을 직접 넣어 연결하는 기능이에요. [C7](/new-project1/claude/c07-connectors/)에서 개념을 다뤘어요. |

### 어디에 연결할 수 있나요?

| 연결 대상 | 서버 방식 | 서버가 있는 곳 |
| --- | --- | --- |
| Claude Code (터미널) | stdio 또는 HTTP | 내 컴퓨터 또는 원격 |
| Claude Desktop의 로컬 설정 (`claude_desktop_config.json`) | stdio | 내 컴퓨터 (Cowork와 claude.ai에서는 안 쓰여요) |
| Claude 앱 커스텀 커넥터 (claude.ai, Desktop, Cowork) | HTTP | **Anthropic 클라우드에서 닿는 공용 인터넷** |

<Aside type="caution" title="SDK 버전이 바뀌었어요">
공식 Python SDK는 현재 v2 계열이에요(이 글을 쓰며 설치한 버전은 2.3.0). 서버 클래스가 `MCPServer`이고 `from mcp.server import MCPServer`로 가져와요. 예전 튜토리얼의 `FastMCP` 예제와 다를 수 있으니, 검색해서 찾은 코드가 안 돌면 SDK 버전부터 확인하세요. TypeScript도 v2(`@modelcontextprotocol/server`)가 main이고, v1(`@modelcontextprotocol/sdk`)은 별도 브랜치에서 유지돼요.
</Aside>

1. **작업 폴더와 SDK 설치**

   Python 3.10 이상이 필요해요. 가상환경을 만들고 공식 SDK를 설치해요. `cli` 확장은 개발용 `mcp dev` 명령을 같이 깔아 줘요.

   ```bash
   mkdir inventory-mcp && cd inventory-mcp
   python3 -m venv .venv
   source .venv/bin/activate
   pip install "mcp[cli]"
   ```

   `uv`를 쓴다면 `uv add "mcp[cli]"`도 같은 결과예요.

2. **서버 만들기: 읽기 전용 도구 2개**

   `server.py`를 만들어요. 재고 조회 서버예요. 실제로는 DB나 사내 API를 읽겠지만, 예제는 메모리의 가짜 데이터를 써요.

   ```python
   """재고 조회 MCP 서버 (읽기 전용 예제)."""
   import sys

   from mcp.server import MCPServer
   from mcp.server.mcpserver.exceptions import ToolError
   from mcp.types import ToolAnnotations

   mcp = MCPServer("inventory")

   # 실제로는 DB나 사내 API를 읽겠지만, 예제는 메모리 데이터를 써요.
   STOCK = {
       "KB-100": {"name": "무선 키보드", "qty": 42, "location": "A-1"},
       "MS-200": {"name": "무선 마우스", "qty": 0, "location": "A-2"},
       "MN-300": {"name": "27인치 모니터", "qty": 7, "location": "B-1"},
   }


   @mcp.tool(annotations=ToolAnnotations(readOnlyHint=True))
   def get_stock(sku: str) -> str:
       """SKU 코드(예: KB-100)로 재고 수량과 보관 위치를 조회한다."""
       print(f"get_stock called: {sku!r}", file=sys.stderr)  # 로그는 stderr로
       item = STOCK.get(sku.strip().upper())
       if item is None:
           raise ToolError(f"알 수 없는 SKU예요: {sku}")
       return f"{item['name']}: {item['qty']}개 (위치 {item['location']})"


   @mcp.tool(annotations=ToolAnnotations(readOnlyHint=True))
   def search_items(keyword: str, max_results: int = 5) -> list[dict]:
       """상품 이름에 keyword가 들어간 항목을 찾아 SKU와 수량을 돌려준다."""
       max_results = max(1, min(max_results, 20))  # 상한을 코드에서 강제
       hits = [
           {"sku": sku, "name": v["name"], "qty": v["qty"]}
           for sku, v in STOCK.items()
           if keyword in v["name"]
       ]
       return hits[:max_results]


   if __name__ == "__main__":
       mcp.run()  # 기본값은 stdio
   ```

   코드에서 눈여겨볼 점이에요.

   - **타입 힌트가 곧 스키마예요.** `sku: str`, `max_results: int = 5`로 JSON 스키마가 만들어지고 입력 검증도 SDK가 해 줘요. docstring이 모델에게 보이는 도구 설명이에요. 설명을 구체적으로 쓸수록 Claude가 알맞게 불러요.
   - **`readOnlyHint=True`는 힌트일 뿐이에요.** 클라이언트에게 "읽기만 하는 도구"라고 알려 주지만, MCP 명세는 믿을 수 있는 서버가 아니면 이런 주석을 신뢰하지 말라고 해요. 안전은 코드로 지켜야 해요.
   - **예상한 실패는 `ToolError`로 올려요.** `ToolError`의 메시지는 모델에게 그대로 전달돼서 Claude가 다른 SKU로 다시 시도할 수 있어요. 일반 예외(`ValueError` 등)는 모델에게 "Error executing tool …"만 전달되고 원문은 서버 로그에만 남아요. 직접 실행해서 둘의 차이를 확인했어요.
   - **로그는 stderr로 써요.** stdio 서버에서 표준 출력(stdout)은 프로토콜 통로예요. `print()`를 stdout으로 쓰면 통신이 깨져요.

   문법을 확인해요.

   ```bash
   python3 -m py_compile server.py && echo 문법 OK
   ```

3. **연결하기 전에 직접 호출해 보기**

   Claude에 붙이기 전에 서버 자체를 먼저 확인하면 문제를 나눠서 볼 수 있어요. SDK의 인메모리 클라이언트로 `test_server.py`를 만들어요.

   ```python
   import asyncio

   from mcp import Client

   from server import mcp


   async def main() -> None:
       async with Client(mcp) as client:
           tools = await client.list_tools()
           print([t.name for t in tools.tools])

           ok = await client.call_tool("get_stock", {"sku": "kb-100"})
           print(ok.content[0].text)

           found = await client.call_tool("search_items", {"keyword": "무선"})
           print(found.structured_content)

           bad = await client.call_tool("get_stock", {"sku": "zz"})
           print(bad.is_error, bad.content[0].text)


   asyncio.run(main())
   ```

   ```bash
   python test_server.py
   ```

   도구 목록, `무선 키보드: 42개 (위치 A-1)`, 검색 결과, 그리고 마지막 줄에 `True Error executing tool get_stock: 알 수 없는 SKU예요: zz`가 보이면 정상이에요. 브라우저 화면으로 도구를 눌러 보고 싶다면 `mcp dev server.py`로 MCP Inspector를 열 수 있어요(공식 README 안내).

4. **Claude Code에 연결하기 (stdio)**

   `claude mcp add`는 `--`를 기준으로 앞은 Claude Code의 옵션, 뒤는 서버를 실행하는 명령이에요. 서버 실행 경로는 **절대 경로**로 쓰세요.

   ```bash
   claude mcp add inventory -- "$PWD/.venv/bin/python" "$PWD/server.py"
   claude mcp list
   ```

   `inventory: … - Connected`가 보이면 성공이에요. 세션을 열고 `/mcp`로 상태를 보거나, 바로 물어보세요.

   <PromptBox>
   inventory 서버로 KB-100 재고를 알려 주고, 이름에 "무선"이 들어간 상품 중 재고가 0인 걸 골라 줘.
   </PromptBox>

   Claude가 도구를 부르기 전에 승인을 물어요. 서버 도구는 `mcp__inventory__get_stock`처럼 `mcp__서버이름__도구이름` 형태로 권한 규칙과 훅에서 가리켜요.

   <ScreenshotPlaceholder caption="/mcp 화면에서 inventory 서버가 Connected로 보이는 모습" officialUrl="https://code.claude.com/docs/en/mcp" officialLabel="Claude Code 문서에서 보기" />

   범위(scope)는 이렇게 골라요. 자세한 설명은 [C14](/new-project1/claude/c14-claude-code-features/)에 있어요.

   | 범위 | 옵션 | 저장 위치 | 쓰임 |
   | --- | --- | --- | --- |
   | local (기본) | `--scope local` | `~/.claude.json` | 나만, 이 프로젝트에서 |
   | project | `--scope project` | 프로젝트의 `.mcp.json` | 팀과 git으로 공유 |
   | user | `--scope user` | `~/.claude.json` | 내 모든 프로젝트 |

   <Aside type="note" title="project 범위는 승인이 필요해요">
   `--scope project`로 추가하면 `.mcp.json`이 만들어져요. 직접 실행해 보니 `claude mcp list`에는 `Pending approval (run claude to approve)`로 표시됐어요. 대화형 세션은 처음 쓸 때 승인을 묻고, `claude -p` 같은 헤드리스 실행은 묻지 않고 로드해요(공식 문서). 팀 저장소의 `.mcp.json`에는 **누가 올렸는지 확인된 서버만** 두세요.
   </Aside>

   비밀 값이 필요한 서버라면 `--env KEY=값`으로 넘기거나 `.mcp.json`에서 `${VAR}` 환경변수 확장을 쓰세요. 값 자체를 파일에 적어 커밋하지 마세요.

   ```json
   {
     "mcpServers": {
       "inventory": {
         "type": "stdio",
         "command": "${CLAUDE_PROJECT_DIR:-.}/.venv/bin/python",
         "args": ["${CLAUDE_PROJECT_DIR:-.}/server.py"],
         "env": { "INVENTORY_API_TOKEN": "${INVENTORY_API_TOKEN}" }
       }
     }
   }
   ```

   <Aside type="note">
   위 `.mcp.json`은 공식 문서의 형식(`type`, `command`, `args`, `env`, `${VAR:-기본값}`)을 따랐어요. 예제의 `INVENTORY_API_TOKEN`은 설명용 이름이고, 이 서버는 실제로 쓰지 않아요.
   </Aside>

5. **HTTP로 띄우기 (원격 서버와 Claude 앱용)**

   같은 서버를 URL로 접속하는 방식으로 띄워요. 파일을 하나 더 만들어요.

   ```python
   from server import mcp

   mcp.run(transport="streamable-http", host="127.0.0.1", port=8000)
   ```

   이렇게 `serve_http.py`로 저장해 `python serve_http.py`로 실행하면 `http://127.0.0.1:8000/mcp`에서 접속할 수 있어요. 직접 실행해서 Claude Code로 확인했어요.

   ```bash
   claude mcp add --transport http inventory-http http://127.0.0.1:8000/mcp
   claude mcp list
   ```

   `Connected`가 나오면 돼요. 서버를 끄면 `Failed to connect`로 바뀌어요.

   <Aside type="caution" title="이 예제 서버를 그대로 인터넷에 열지 마세요">
   `127.0.0.1`은 내 컴퓨터에서만 닿아요. 예제 서버에는 **인증이 없어요**. 공용 주소로 열면 주소를 아는 누구나 도구를 부를 수 있어요. 진짜 데이터가 걸린 서버라면 OAuth나 토큰 검증 같은 인증을 먼저 붙이세요. Python SDK의 `MCPServer`는 생성자에 인증 설정(`auth`, `token_verifier`)을 받지만, 구체적인 사용법은 이 글에서 검증하지 않았으니 SDK 공식 문서를 따르세요. `host`를 `0.0.0.0`으로 바꿔 외부에 열기 전에는 SDK의 전송 보안(호스트 헤더 검증) 설정도 확인해야 해요.
   </Aside>

6. **Claude 앱에 커스텀 커넥터로 연결하기**

   Claude 앱의 커스텀 커넥터는 내 기기가 아니라 **Anthropic의 클라우드에서** 서버로 접속해요. 그래서 조건이 있어요.

   - 서버가 **공용 인터넷에서 HTTPS로** 닿아야 해요. `127.0.0.1`, 사내망, VPN 뒤의 서버는 안 돼요.
   - 사설 서버를 방화벽 뒤에 두려면 Anthropic IP 대역을 허용해야 해요(대역 목록은 platform.claude.com/docs/en/api/ip-addresses).
   - 서버 주소는 `https://도메인/mcp`처럼 MCP 경로까지 써요.

   조건이 갖춰졌다면 Pro/Max 개인 계정은 이렇게 해요(2026-10-11 지원센터 문서 기준, 화면 표기는 바뀔 수 있어요).

   1. 사용자 지정(Customize) > 커넥터(Connectors)에서 **+ Add** > **Add custom connector**
   2. 이름과 서버 URL을 넣고 **Continue**
   3. 인증 설정을 확인해요. **Sign in now**, **Sign in when needed**, **No sign in** 중에서 골라요. OAuth나 요청 헤더(고정 자격 증명)도 쓸 수 있어요.
   4. **Add**를 누르고, 대화창의 **+** > **Connectors**에서 켜요.

   Team/Enterprise는 Owner(또는 Primary Owner)가 조직 설정(Organization settings) > 커넥터(Connectors)에서 Add > Custom > Web으로 추가하고, 구성원은 Customize > Connectors에서 **Connect**를 눌러요. 수정은 제거했다가 다시 추가하는 방식이에요. Free 플랜은 커스텀 커넥터가 1개까지예요.

7. **같은 서버를 TypeScript로 만든다면 (참고)**

   TypeScript SDK v2로는 이런 모양이에요. Node.js 20 이상이 필요하고, `npm pkg set type=module`로 ESM을 켜야 해요.

   ```bash
   npm init -y && npm pkg set type=module
   npm install @modelcontextprotocol/server zod tsx
   ```

   ```typescript
   import { McpServer } from '@modelcontextprotocol/server';
   import { serveStdio } from '@modelcontextprotocol/server/stdio';
   import * as z from 'zod/v4';

   const STOCK: Record<string, { name: string; qty: number; location: string }> = {
       'KB-100': { name: '무선 키보드', qty: 42, location: 'A-1' },
       'MS-200': { name: '무선 마우스', qty: 0, location: 'A-2' }
   };

   function createServer(): McpServer {
       const server = new McpServer({ name: 'inventory', version: '1.0.0' });

       server.registerTool(
           'get_stock',
           {
               description: 'SKU 코드(예: KB-100)로 재고 수량과 보관 위치를 조회한다.',
               inputSchema: z.object({ sku: z.string().max(20).describe('SKU 코드') }),
               annotations: { readOnlyHint: true }
           },
           async ({ sku }) => {
               const item = STOCK[sku.trim().toUpperCase()];
               if (!item) {
                   return { content: [{ type: 'text', text: `알 수 없는 SKU예요: ${sku}` }], isError: true };
               }
               return { content: [{ type: 'text', text: `${item.name}: ${item.qty}개 (위치 ${item.location})` }] };
           }
       );
       return server;
   }

   void serveStdio(createServer);
   console.error('inventory MCP server running on stdio'); // 로그는 stderr로
   ```

   `npx tsx server.ts`로 실행하고, Claude Code에는 `claude mcp add inventory -- npx tsx /절대/경로/server.ts`로 붙여요. 이 코드는 `tsx`로 직접 띄워 `initialize`와 도구 호출 응답을 확인했어요.

</Steps>

### `claude mcp` 명령

| 하고 싶은 일 | 명령 |
| --- | --- |
| 로컬 stdio 서버 추가 | `claude mcp add <이름> -- <명령> [인자...]` |
| 환경변수와 함께 추가 | `claude mcp add --env KEY=값 --transport stdio <이름> -- <명령>` |
| 원격 HTTP 서버 추가 | `claude mcp add --transport http <이름> <URL>` |
| 헤더(토큰) 붙이기 | `--header "Authorization: Bearer ..."` (토큰을 셸 기록에 남기지 않도록 주의) |
| 목록과 상태 | `claude mcp list` |
| 서버 상세 | `claude mcp get <이름>` |
| 제거 | `claude mcp remove <이름>` (저장된 OAuth 토큰도 삭제) |
| 세션 안에서 상태·인증·재연결 | `/mcp` |
| JSON으로 추가 | `claude mcp add-json <이름> '<json>'` |

SSE 전송은 deprecated예요. 새 서버는 HTTP를 쓰세요.

### 서버 보안 체크리스트

| 항목 | 이렇게 해요 |
| --- | --- |
| 권한 최소화 | 읽기 전용 도구부터 시작해요. 쓰기·삭제 도구는 꼭 필요할 때만, 적은 범위로 넣어요. 서버가 쓰는 DB 계정·토큰도 읽기 전용으로 만들어요. |
| 입력 검증 | 타입·길이·범위를 코드에서 제한해요(예: `max_results` 상한). 모델이 만든 입력은 신뢰할 수 없는 입력이에요. 파일 경로나 SQL, 셸 명령을 만들 때 그대로 이어 붙이지 마세요. |
| 프롬프트 인젝션 | 도구가 돌려주는 글(메일, 웹, 티켓 본문)에 "이전 지시를 무시해" 같은 숨은 지시가 있을 수 있어요. 외부 글을 가져오는 도구는 쓰기 도구와 같은 서버에 두지 마세요. |
| 비밀 값 | 코드나 `.mcp.json`에 직접 쓰지 말고 환경변수로 받아요. 도구 결과와 로그에 토큰·개인정보를 싣지 마세요. |
| 출력 크기 | 한 번에 돌려주는 양을 제한해요. 큰 결과는 토큰(비용)과 컨텍스트를 같이 키워요. |
| 인증 | HTTP로 공개하는 서버는 인증을 붙여요. 공유 토큰은 모두에게 같은 권한을 줘요. MCP 공식 보안 문서(2026-10-12 기준)에 따르면 서버는 **자기에게 발급된 토큰만** 받아야 하고, 받은 토큰을 다른 API에 그대로 넘기는 token passthrough는 스펙이 금지해요. OAuth 스코프는 처음엔 읽기 같은 최소 범위로 시작해요. |
| 로컬 HTTP 서버 | 같은 PC의 다른 프로세스가 접근할 수 있어요. 공식 보안 문서는 로컬용 서버에 `stdio`를 쓰거나, HTTP라면 인증 토큰이나 접근이 제한된 IPC를 쓰라고 해요. |
| 힌트에 의존 금지 | `readOnlyHint` 같은 주석은 힌트예요. 실제 권한은 서버 코드와 자격 증명으로 막아요. |
| 로그 | stdio 서버는 stderr에만 써요. 민감한 값은 로그에 남기지 않아요. |

## 자주 막히는 지점

### `ImportError: cannot import name 'FastMCP'` 또는 `MCPServer`를 찾을 수 없어요

- **원인**: 예전 튜토리얼은 `FastMCP`를 쓰고, 현재 SDK v2는 `MCPServer`를 써요. 설치된 `mcp` 버전이 글과 달라서 생겨요.
- **해결**: `pip show mcp`로 버전을 보고, 이 글의 코드는 v2 기준임을 기억하세요. 가상환경을 활성화한 상태에서 `pip install "mcp[cli]"`로 다시 설치해 보세요.

### `claude mcp list`에 `Failed to connect`가 떠요

- **원인**: stdio는 서버 실행 명령이 틀렸거나(상대 경로, 가상환경 밖의 `python`) 서버가 시작 중에 죽은 경우가 많아요. HTTP는 서버가 안 떠 있거나 주소·포트가 달라요.
- **해결**: 같은 명령을 터미널에서 직접 실행해 오류를 보세요. 절대 경로로 다시 `claude mcp remove` 후 `claude mcp add` 하세요. HTTP는 `ECONNREFUSED`면 서버부터 켜세요.

### stdio 서버가 연결 직후 멈추거나 깨진 응답이 와요

- **원인**: 서버가 표준 출력(stdout)에 `print()` 로그를 찍으면 프로토콜 메시지가 섞여요.
- **해결**: 모든 로그를 `sys.stderr`(TypeScript는 `console.error`)로 바꾸세요.

### Claude가 내 도구를 안 불러요

- **원인**: 도구 이름과 설명이 모호하거나, 서버가 연결되어 있지 않거나, 승인 단계에서 거절했을 수 있어요.
- **해결**: `/mcp`에서 연결 상태를 확인하고, docstring을 "무엇을 하는지 + 입력 예시" 형태로 구체적으로 고치세요. 요청에 서버 이름을 넣어 보세요(예: "inventory 서버로 …").

### 커스텀 커넥터를 추가했는데 연결이 안 돼요

- **원인**: 서버가 공용 인터넷에서 닿지 않거나(로컬·사내망·VPN), 인증 방식이 서버와 맞지 않아요. 연결은 내 기기가 아니라 Anthropic 클라우드에서 나가요.
- **해결**: 외부 네트워크에서 `https://도메인/mcp`가 열리는지 확인하고, 사설 서버라면 Anthropic IP 대역을 허용하세요. 인증 설정은 서버가 요구하는 방식(OAuth, 헤더, 없음)과 맞추세요. 커넥터 수정은 제거 후 재추가예요.

### `.mcp.json` 서버가 `Pending approval`로 멈춰 있어요

- **원인**: 프로젝트 범위 서버는 처음 쓸 때 승인이 필요해요. 신뢰하지 않은 폴더에서는 저장소가 스스로 승인할 수 없어요.
- **해결**: 대화형 `claude`를 열어 승인하세요. 승인 선택을 초기화하려면 `claude mcp reset-project-choices`를 써요.

## 실전 팁

- **도구는 적게, 설명은 구체적으로.** 도구가 많으면 Claude가 고르기 어렵고 컨텍스트도 더 써요. 도구 하나가 한 가지 일을 하게 만드세요.
- **오류 메시지는 모델이 읽어요.** `ToolError`에 "무엇이 잘못됐고 어떻게 다시 시도할지"를 적으세요. 내부 경로나 SQL 같은 서버 내부 정보는 빼세요.
- **먼저 로컬 stdio로 만들고, 필요할 때 HTTP로 옮기세요.** 같은 도구 코드에서 `mcp.run()`의 전송 방식만 바꾸면 돼요.
- **직접 만들기 전에 있는 것부터 보세요.** 이미 공식 커넥터나 공개 서버가 있는 서비스라면 새로 만드는 비용이 더 클 수 있어요. 다만 서드파티 서버는 Anthropic이 검증하지 않으니 코드와 권한을 읽어 보고 쓰세요.
- **팀에 나눠 줄 때는 플러그인에 넣으세요.** 플러그인은 스킬과 MCP 서버(`.mcp.json`)를 한 묶음으로 배포해요. [6. 스킬·플러그인 패키지로 만들어 팀에 배포하기](/new-project1/dev/06-plugins-skills-team/)를 보세요.
