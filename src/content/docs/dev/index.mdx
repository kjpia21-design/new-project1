Claude를 앱에서 쓰는 단계를 넘어, **코드와 API로 직접 다루고 싶은 분**을 위한 섹션이에요. 업무 봇 만들기, 에이전트 직접 만들기, MCP 서버 연결, CI 자동화, 결과 품질 관리까지 실행 가능한 코드를 중심으로 10편으로 정리해요.

## 누구를 위한 섹션인가요?

- 개발자이거나, 코드를 읽고 터미널을 쓰는 데 거부감이 없는 파워 유저
- Claude Code와 API를 이미 한 번 써 본 분

기초 설명은 반복하지 않아요. 이 섹션은 **[Claude Code 핵심 기능(C14)](/new-project1/claude/c14-claude-code-features/), [모델 분담(C15)](/new-project1/claude/c15-model-division/), [API 시작하기(C16)](/new-project1/claude/c16-api/)를 읽은 독자**를 기준으로 쓰여요. 모르는 용어가 나오면 해당 편으로 돌아가세요.

## 준비물

- Claude API 키 (환경변수로만 관리해요. 코드에 직접 쓰지 않아요)
- Python 3.10 이상
- Node.js (TypeScript·JavaScript 예제와 MCP 서버, Claude Code에 필요해요)
- 터미널과 Git

:::caution[비용에 주의하세요]
반복 호출, 에이전트 루프, 배치, 컴퓨터 사용 예제는 비용이 빠르게 커질 수 있어요. 각 편의 사용량 상한 안내를 따르고, 콘솔에서 지출 한도를 먼저 설정해 두세요.
:::

## 추천 학습 순서

1. **API 기본기**: 도구 사용(01) → 비용 최적화(02)
2. **에이전트**: Agent SDK(03) → Managed Agents(04)
3. **확장과 배포**: MCP 서버(05) → 스킬·플러그인(06)
4. **자동화와 품질**: 헤드리스·CI(07) → 평가(08)
5. **응용**: 사내 문서 Q&A(09) → 컴퓨터·브라우저 도구(10)

아직 공개되지 않은 편은 "준비 중"으로 표시돼요.
