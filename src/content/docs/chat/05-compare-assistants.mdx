<Summary>
- 가장 믿을 만한 비교는 **내 업무 샘플을 세 서비스에 똑같이 넣어 보는 것**이에요. 순위표는 금방 낡아요.
- 이 튜토리얼은 **공식 페이지에서 직접 확인한 사실만** 써요. Claude 쪽은 확인했고, **ChatGPT·Gemini의 가격·한도·기능은 이번 조사에서 공식 페이지에 접속하지 못해 확인하지 못했어요.** 그래서 숫자를 쓰지 않고 확인할 항목과 위치를 안내해요.
- 고르는 기준은 **업무 적합도 · 보안·학습 정책 · 이미 쓰는 업무 환경 · 가격**이에요.
- 가격과 한도는 자주 바뀌어요. 결제 전 반드시 공식 가격 페이지를 보세요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 내 업무에 맞는 비교 기준과 점수표를 만들 수 있어요.
- 같은 프롬프트로 세 서비스를 공정하게 비교 테스트할 수 있어요.
- 가격·한도·개인정보 정책에서 공식 페이지로 확인할 항목을 알 수 있어요.
- 팀에 도입을 제안할 때 쓸 판단 근거를 정리할 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **요금제 계층** | 무료, 개인 유료, 팀, 기업처럼 나뉜 구독 단계예요. 이름과 기능은 서비스마다 달라요. |
| **사용량 한도** | 일정 시간이나 기간 안에 쓸 수 있는 양의 상한이에요. 정확한 수치가 비공개인 경우도 많아요. |
| **모델 학습 정책** | 내 대화가 서비스 개선에 쓰이는지, 끌 수 있는지에 대한 규정이에요. |
| **컨텍스트 윈도우** | 한 번에 볼 수 있는 글의 양이에요. |

<Aside type="caution" title="이 튜토리얼의 한계 (2026-10-10 기준)">
Claude는 공식 가격 페이지와 도움말을 열람해 확인했어요. ChatGPT(OpenAI)와 Gemini(Google)는 이번 조사 환경에서 공식 사이트 접속이 막혀 가격, 플랜별 기능, 사용 한도, 학습 정책을 확인하지 못했어요. 제3자 블로그나 비교 사이트는 근거로 쓰지 않았고, 검색 결과에서도 같은 요금제의 가격 설명이 서로 달라 직접 확인이 필요하다는 점만 확인했어요. 아래 표의 해당 칸은 "공식 페이지에서 확인하세요"로 비워 뒀어요.
</Aside>

## 단계별 따라하기

<Checklist items={[

  '점수 기준(정확성, 형식, 말투, 속도)을 정했어요',
  '세 서비스에 똑같은 프롬프트를 넣었어요',
  '결과를 가린 채 점수를 매겼어요',
  '공식 가격 페이지에서 비용과 한도를 확인했어요',
  '보안·학습 정책을 확인하고 최종 선택했어요',
]} />

<Steps>

1. **비교할 업무 정하기**

   하루 일과에서 AI에 가장 자주 시킬 일 2~3개를 고르세요. 예를 들어 회의록 요약([2편](/new-project1/chat/02-summarize-documents/)), 표 데이터 분석([3편](/new-project1/chat/03-data-analysis/)), 보고서 초안([4편](/new-project1/chat/04-write-reports/))이 있어요. 개인정보와 기밀은 가린 샘플로 하세요.

2. **점수 기준 만들기**

   <PromptBox label="점수표 만들기 요청 (아무 서비스에나 붙여넣기)">
   내가 AI 서비스를 업무용으로 비교하려고 해. 업무는 [회의록 요약, 매출 CSV 분석, 제안서 초안]이야. 결과물을 평가할 점수표를 만들어줘. 항목은 정확성, 지시 준수, 형식, 말투, 수정에 드는 시간이고 각 1~5점으로, 항목별 판단 기준을 한 줄씩 적어줘.
   </PromptBox>

3. **같은 프롬프트로 테스트하기**

   [1편](/new-project1/chat/01-prompt-basics/)의 6칸 틀로 프롬프트를 한 번 만들고, 세 서비스에 글자 하나 바꾸지 않고 붙여넣으세요. 모델 선택기나 기능(웹 검색, 파일 분석)이 서비스마다 다르면 어떤 설정이었는지 메모하세요.

   - 유료와 무료를 섞어 비교하면 공정하지 않아요. 같은 가격대끼리 비교하세요.
   - 같은 서비스에서도 모델이나 설정에 따라 결과가 달라질 수 있어요.

   <ScreenshotPlaceholder caption="같은 프롬프트로 세 서비스를 비교하는 화면 구성" />

4. **결과 평가하기**

   어느 서비스 결과인지 가리고 점수를 매기면 선입견이 줄어요. 동료에게도 평가를 부탁하세요. 정확성은 원본 자료와 대조해 확인하세요.

5. **비용과 한도 확인하기**

   세 서비스의 공식 가격 페이지에서 아래를 확인하세요. 웹 검색 결과 요약이나 블로그 표는 낡았거나 서로 다를 수 있어요.

   - 내 업무량에 맞는 플랜의 월 가격과 연 결제 할인
   - 사용량 한도가 어떤 단위로 걸리는지, 한도를 넘으면 어떻게 되는지
   - 내가 쓸 기능(파일 분석, 웹 검색, 파일 생성, 앱 연동)이 그 플랜에 포함되는지
   - 한국 원화 가격, 부가세, 결제 수단, 한국어 지원 여부
   - 팀·기업 플랜이 필요한지

6. **보안·학습 정책 확인하기**

   회사 데이터를 다룬다면 이 단계가 가격보다 중요해요.

   - 내 대화가 모델 학습에 쓰이는지, 끌 수 있는지
   - 개인 계정과 팀·기업 계정의 정책 차이
   - 관리자 기능(권한, 감사 로그), 데이터 보관 설정
   - 회사 보안 지침이 허용하는 서비스 목록

</Steps>

## "이럴 땐 이것" 추천은 어떻게 만드나요

이 사이트는 **공식 문서로 뒷받침되는 추천만** 싣는다는 원칙을 가지고 있어요. 이번 조사에서는 세 서비스의 공식 문서를 모두 비교할 수 없었기 때문에 서비스 이름을 붙인 업무별 순위는 싣지 않아요. 대신 상황별 판단 규칙을 드려요.

| 상황 | 판단 규칙 |
| --- | --- |
| 회사가 이미 쓰는 업무 도구가 있다 | 그 도구와 연동되는 서비스를 먼저 테스트하세요. 연동 범위는 각 서비스의 공식 도움말에서 확인하세요 |
| 고객 정보·내부 문서를 다룬다 | 조직용 플랜의 학습 정책을 공식 문서로 확인하고, 보안 담당자의 승인을 받으세요 |
| 긴 문서를 자주 다룬다 | 업로드·컨텍스트 한도를 비교하세요. Claude는 채팅당 파일 20개, PDF 1000쪽, 모델별 최대 1M 토큰이에요 |
| 엑셀·워드 파일을 결과물로 받아야 한다 | 파일 형식 출력 지원을 직접 시험하세요. Claude는 .xlsx .docx .pptx PDF를 만들 수 있어요 |
| 사용량이 많다 | 한도 단위와 초과 시 동작을 공식 문서로 확인하세요. Claude는 5시간 세션 한도와 주간 한도가 있어요([C2](/new-project1/claude/c02-plans-limits/)) |
| 잘 모르겠다 | 위 3단계 테스트로 결정하세요 |

## 자주 막히는 지점

### 블로그마다 가격이 달라요

- **원인**: 가격과 플랜 이름이 자주 바뀌고 지역별로 달라요. 오래된 글도 많아요.
- **해결**: 공식 가격 페이지의 현재 값만 믿으세요. 이 사이트 표에도 기준일(2026-10-10)을 붙였어요.

### 한 번 테스트했더니 서비스마다 결과가 들쭉날쭉해요

- **원인**: 같은 서비스에서도 실행마다 결과가 조금씩 달라질 수 있어요.
- **해결**: 업무 샘플 2~3개를 각각 한 번 이상 돌려 보고 평균적인 인상으로 판단하세요.

### 무료와 유료를 비교하게 돼요

- **원인**: 서비스마다 무료·유료의 모델과 기능이 달라요.
- **해결**: 같은 가격대끼리 비교하고, 어떤 플랜으로 테스트했는지 기록하세요.

### 회사에서 쓰는 도구가 정해져 있어요

- **원인**: 보안 정책으로 허용 서비스가 제한되기도 해요.
- **해결**: 개인 계정으로 업무 데이터를 올리지 말고, 허용 목록과 조직 계정 여부를 먼저 확인하세요.

## 실전 팁

- **한 도구에 묶이지 마세요.** 프롬프트 틀([1편](/new-project1/chat/01-prompt-basics/))은 도구가 달라도 같이 쓰여요. 템플릿을 모아 두면 갈아타기 쉬워요.
- **분기마다 다시 테스트하세요.** 모델과 요금제가 자주 바뀌어요.
- **무료로 먼저 써 본 뒤 결제하세요.** 결제 전 환불 규정도 공식 페이지에서 확인하세요. Claude 가격 페이지는 EEA와 영국 고객에게 14일 철회 기간이 있다고 안내해요.
- **Claude를 고른다면** 모델 선택은 [C1](/new-project1/claude/c01-overview/), 요금제와 한도는 [C2](/new-project1/claude/c02-plans-limits/)에서 자세히 볼 수 있어요.
