<Summary>
- 요약만 시키지 말고 **결정사항 · 할 일(담당자·기한) · 미결 사항**으로 구조를 정해 주세요.
- 담당자나 기한이 문서에 없으면 **지어내지 말고 "확인 필요"** 라고 적게 하세요.
- 결과는 **근거 문장 인용**을 함께 받아 원문과 대조하세요.
- Claude 기준 채팅 업로드는 파일당 500MB, 채팅당 20개, PDF는 1000쪽까지예요 (2026-10-10 기준). Gemini 앱은 프롬프트 하나에 파일 최대 10개, 동영상 외 파일은 100MB까지예요(Gemini 도움말 기준). ChatGPT 앱의 파일 수·크기 한도는 OpenAI가 공개한 문서(learn.chatgpt.com, developers.openai.com)에서 찾지 못해 숫자를 적지 않았어요. 화면에 나오는 안내를 따르세요.
- 긴 대화는 새 대화로 나누면 사용량도 아낄 수 있어요.
</Summary>

## 이 튜토리얼로 할 수 있게 되는 것

- 회의록을 팀장 보고용 요약과 할 일 표로 바꿀 수 있어요.
- 수십 쪽짜리 문서에서 필요한 결정과 위험 요소만 뽑을 수 있어요.
- 요약이 원문과 맞는지 근거 문장으로 검증할 수 있어요.
- 요약을 후속 메일이나 공지로 바로 이어 쓸 수 있어요.

## 먼저 알아둘 개념

| 용어 | 뜻 |
| --- | --- |
| **컨텍스트 윈도우** | AI가 한 번에 볼 수 있는 글의 양이에요. 대화, 올린 자료, 답변이 모두 이 안에 들어가요. |
| **구조화 요약** | 줄글 요약 대신 항목(결정, 할 일, 위험)을 정해서 뽑는 방식이에요. |
| **근거 인용** | 요약의 각 항목이 원문 어디에서 나왔는지 문장을 함께 받는 것이에요. |
| **프로젝트** | 같은 자료와 지침을 여러 대화에서 반복 쓰는 Claude의 작업 공간이에요. |

Claude의 컨텍스트 윈도우는 모델마다 달라요. 공식 도움말은 유료 플랜의 최신 모델이 최대 1M 토큰, 그 외는 500K 또는 200K 토큰을 지원한다고 설명해요 (2026-10-10 기준). 응답용으로 일부가 예약되어 실제 쓸 수 있는 양은 조금 적어요.

<Aside type="note" title="업로드된 파일과 한도">
공식 도움말은 업로드한 파일이 컨텍스트나 사용량에 어떻게 계산되는지 설명하지 않아요. 파일이 커질수록 사용량을 더 쓴다고 가정하고 아껴 쓰는 편이 안전해요.
</Aside>

## 단계별 따라하기

<Checklist items={[
  '민감한 이름·연락처·금액을 가렸어요',
  '문서를 붙여넣거나 업로드했어요',
  '구조(결정/할 일/미결)를 정해 요약을 받았어요',
  '근거 문장으로 원문과 대조했어요',
  '후속 메일 초안까지 만들었어요',
]} />

<Steps>

1. **자료 준비하고 올리기**

   회의 메모는 채팅창에 바로 붙여넣어도 돼요. 문서는 첨부(Claude는 입력창 왼쪽 아래 "+")로 올려요.

   Claude가 받는 형식은 PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON, XLSX, 이미지(JPEG·PNG·GIF·WebP)예요. 한도는 채팅당 파일 20개, 파일당 500MB, PDF 1000쪽이에요. PDF가 100쪽 이하면 글과 시각 요소를 함께 분석하고, 101~1000쪽이면 글만 분석해요. 1000쪽을 넘으면 "Uploaded file is too large" 오류로 거부돼요. DOCX 같은 문서는 글만 추출되어 안에 든 이미지는 못 읽어요.

   <ScreenshotPlaceholder caption="파일을 첨부한 채팅 입력창" officialUrl="https://support.claude.com/en/articles/8241126-upload-files-to-claude" />

   <Aside type="caution" title="올리기 전에">
   고객 이름, 연락처, 계약 금액처럼 외부에 나가면 안 되는 정보는 지우거나 가명으로 바꾸세요. 회사 보안 지침도 먼저 확인하세요.
   </Aside>

2. **구조를 정해서 요약 요청하기**

   긴 자료는 위에, 요청은 아래에 두세요. 공식 가이드가 안내하는 방식이에요.

   <PromptBox>
   [회의 메모 붙여넣기]

   위 회의 메모를 팀장 보고용으로 정리해줘. 아래 형식을 지켜줘.
   1) 한 줄 결론
   2) 결정사항 (번호 목록)
   3) 할 일: 표로, 열은 할 일 / 담당자 / 기한 / 근거 문장
   4) 미결 사항과 다음 회의에서 정할 것
   메모에 담당자나 기한이 없으면 지어내지 말고 "확인 필요"라고 적어줘.
   </PromptBox>

3. **근거를 대조하기**

   요약이 그럴듯해도 원문과 다를 수 있어요. 표의 "근거 문장"이 원문에 실제로 있는지 몇 개만 직접 찾아보세요. 의심이 가면 이렇게 요청해요.

   <PromptBox>
   방금 표의 항목 중 원문에 직접 근거가 없고 네가 추론한 것이 있으면 따로 표시해줘. 추론한 항목은 이유도 한 줄 적어줘.
   </PromptBox>

4. **긴 문서에서 필요한 것만 뽑기**

   여러 문서를 한꺼번에 줄 때는 문서마다 이름을 붙여 구분하게 하면 헷갈림이 줄어요. 공식 가이드는 `<document>` 태그로 문서를 나누는 구조를 안내해요.

   <PromptBox>
   <documents>
   <document index="1">
   <source>1차 계약서 초안</source>
   <document_content>[내용]</document_content>
   </document>
   <document index="2">
   <source>2차 수정본</source>
   <document_content>[내용]</document_content>
   </document>
   </documents>

   두 문서에서 달라진 조항을 표로 정리해줘. 열은 조항 / 1차 / 2차 / 달라진 이유로 하고, 각 칸에는 원문 문장을 짧게 인용해줘.
   </PromptBox>

   <Aside type="caution" title="법률·재무 문서">
   계약서 같은 문서는 AI 요약을 참고용으로만 쓰고, 중요한 판단은 원문과 담당자 확인을 거치세요.
   </Aside>

5. **후속 문서로 이어 쓰기**

   정리한 표를 그대로 두고 다음 산출물을 만들어요.

   <PromptBox>
   위 할 일 표를 바탕으로 참석자에게 보낼 회의 후속 메일을 써줘. 할 일은 담당자별로 묶고, "확인 필요"로 남은 항목은 마지막에 회신을 요청해줘. 300자 이내로.
   </PromptBox>

   원하면 결과를 파일로 받을 수도 있어요. Claude는 코드 실행·파일 생성 기능을 켜면 .docx, .xlsx, .pptx, PDF를 만들 수 있고 파일당 30MB까지예요. 켜는 곳은 [3편](/chat/03-data-analysis/)에 정리했어요.

</Steps>

## 빠른 참조표

| 항목 | Claude 기준 (2026-10-10) | Gemini (2026-10-10) | ChatGPT (2026-10-10) |
| --- | --- | --- | --- |
| 채팅당 업로드 | 파일 20개, 파일당 500MB | 프롬프트당 파일 10개, 동영상 외 파일당 100MB, 동영상은 2GB | 앱 한도는 공개 문서에서 찾지 못함. 참고로 API 입력은 파일당 50MB, 요청 전체 합계 50MB(앱 한도와 다를 수 있음) |
| PDF | 1000쪽까지, 100쪽 초과는 글만 분석 | 쪽수 한도는 확인하지 못함 | 앱 기준 쪽수 한도는 찾지 못함 |
| 프로젝트 파일 | 파일당 30MB, 개수 제한 없음(내용은 컨텍스트 안에 들어가야 함) | 확인하지 못함 | 프로젝트의 Sources에 파일을 올려 여러 대화가 함께 쓰고, 프로젝트 지침도 모든 대화에 적용돼요. 개수·크기 한도는 찾지 못함 |
| 컨텍스트 | 모델별 200K~1M 토큰 | 플랜 없음 32K, AI Plus 128K, AI Pro·Ultra 1M 토큰(약 1,500쪽) | 앱 기준 수치는 찾지 못함 |
| 긴 대화 | 코드 실행이 켜져 있으면 한계 근처에서 이전 메시지를 자동 요약 | 확인하지 못함 | 찾지 못함 |

ChatGPT 열은 OpenAI의 ChatGPT 문서(learn.chatgpt.com)와 API 문서를 근거로 해요. 이 문서들은 파일을 올려 요약·분석을 맡기는 흐름과 프로젝트 구조를 설명하지만 앱의 업로드 수치는 싣지 않아요. 숫자가 중요하면 업로드할 때 나오는 안내나 OpenAI 도움말을 직접 보세요.

## 자주 막히는 지점

### 요약이 너무 짧거나 핵심을 놓쳐요

- **원인**: 독자와 목적을 알려 주지 않았을 수 있어요.
- **해결**: "팀장 보고용", "신입에게 설명용"처럼 독자를 정하고 꼭 들어갈 항목을 지정하세요.

### 없는 담당자나 기한이 생겨요

- **원인**: 빈칸을 AI가 그럴듯하게 채웠을 수 있어요.
- **해결**: "없으면 지어내지 말고 확인 필요"를 요청에 넣고, 근거 문장 열을 추가하세요.

### 긴 PDF 뒷부분 내용이 반영되지 않은 것 같아요

- **원인**: 대화가 길어졌거나 PDF가 100쪽을 넘어 글만 분석된 경우일 수 있어요. 표나 그림은 글로 추출되지 않으면 놓칠 수 있어요.
- **해결**: 장 단위로 나눠 올리거나, 필요한 부분을 따로 붙여넣으세요.

### 업로드가 거부돼요

- **원인**: 지원하지 않는 형식이거나 한도 초과일 수 있어요. 음성 파일은 지원 형식 목록에 없어요.
- **해결**: 지원 형식으로 변환하세요. XLSX는 코드 실행·파일 생성을 켜야 올릴 수 있어요. 녹음은 먼저 글로 옮기세요([녹음을 텍스트로 받아 정리하기](/media/14-transcribe-recordings/)에서 다뤄요).

### 대화가 길어지며 답이 느려지거나 한도가 빨리 줄어요

- **원인**: 긴 대화는 사용량을 더 써요.
- **해결**: 주제가 바뀌면 새 대화를 시작하세요.

## 실전 팁

- **회의 직후 10분 안에 정리하세요.** 기억이 남아 있어 "확인 필요" 항목을 바로 채울 수 있어요.
- **같은 양식이 반복되면 프로젝트에 저장하세요.** Claude 프로젝트는 지침에 요약 양식을 넣고 대화마다 재사용해요. 유료 플랜은 지식이 많을 때 필요한 부분만 불러오는 방식으로 용량이 늘어나요. 공식 도움말은 프로젝트 지침을 짧게 유지하고 안 쓰는 파일은 지우라고 안내해요 ([C5](/claude/c05-projects/)).
- **주제가 바뀌면 새 대화로 옮기세요.** 길어진 대화는 사용량을 더 많이 쓰고 앞 내용이 요약될 수 있어요.
- **최종 확인은 사람이 하세요.** 요약은 초안이에요. 보고 전에 숫자, 날짜, 담당자를 한 번 더 보세요.
