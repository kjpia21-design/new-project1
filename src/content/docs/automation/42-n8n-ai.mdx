<Summary>
- **n8n** is a workflow automation tool with AI nodes. You can use **n8n Cloud** (n8n hosts it; 14-day free trial) or **self-host** it (the free Community edition has almost the full feature set, but you run the server).
- In n8n you chain **nodes**: a trigger starts the workflow, an AI node (for example a Basic LLM Chain with an Anthropic Chat Model) thinks, and an app node (for example Gmail) acts. You choose which model provider to plug in.
- This tutorial builds **new labeled Gmail message → Claude writes a reply → saved as a Gmail draft, not sent**.
- Compared with [Zapier/Make](/automation/18-zapier-make/), n8n gives you more control and a self-hosting option, but expects you to think in nodes and data. Prices below are what we confirmed as of 2026-10-31.
</Summary>

## What you'll be able to do

- Decide between n8n Cloud and self-hosting for your situation.
- Explain the difference between a Basic LLM Chain and an AI Agent in n8n.
- Connect Claude to a workflow with an Anthropic Chat Model node.
- Build a small workflow that drafts (but never sends) replies, and test it safely.

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Workflow** | One automation in n8n: nodes connected on a canvas. |
| **Node** | One step. Trigger nodes start a workflow; other nodes do the work. |
| **Credential** | A saved login or API key a node uses to reach a service. |
| **Basic LLM Chain** | An AI node that sends a prompt you define to a model and returns the answer. It has fixed steps. |
| **AI Agent** | An AI node that has a chat model plus one or more tools, and decides which tool to call. The official page says at least one tool must be connected. |
| **Sub-node** | A node plugged into an AI node, such as the Anthropic Chat Model that supplies the model. |
| **Publish** | Turning a workflow on so its trigger runs by itself (the Schedule Trigger page says to save and publish). |

### n8n Cloud or self-hosted (as of 2026-10-31)

| Item | n8n Cloud | Self-hosted |
| --- | --- | --- |
| Who runs it | n8n hosts, updates and scales it | You provide and maintain the server |
| Getting started | Sign up for a 14-day free trial | Install with Docker Compose, Docker, npm and others |
| Cost | Plans: Starter, Pro, Enterprise | Community edition is free; Business and Enterprise are paid |
| Skills needed | None for setup | Servers, containers and security (n8n says mistakes can cause data loss and downtime) |
| Features | Per plan | Community lacks some features such as SSO, Projects and Git version control |

<Steps>

1. **Choose where to run n8n**

   If you just want to try it, start the 14-day free trial on n8n Cloud. If you self-host, n8n recommends Docker Compose for installing with Docker (the plain Docker page is marked outdated). By default it listens on port 5678, so you open `http://localhost:5678` in a browser. The official docs recommend self-hosting for experienced users; if you do not manage servers, they recommend Cloud.

   <ScreenshotPlaceholder caption="n8n docs page for choosing Cloud or self-hosted" officialUrl="https://docs.n8n.io/choose-n8n/" />

2. **Get a model connection ready**

   An Anthropic credential uses an API key. In the Anthropic Console, open **Settings > API Keys**, select **+ Create Key**, copy it and paste it as the API Key in the n8n credential. On n8n Cloud Starter or Pro you can instead select **Use Gateway credits** in the node's credential field, which bills a prepaid balance and needs no Anthropic account. Gateway credits are not available on Cloud Enterprise or self-hosted n8n. Treat the key like a password and never paste it into a chat or a shared doc.

3. **Add the trigger: Gmail Trigger**

   Create a new workflow and add **Gmail Trigger** with the event **Message Received**. Sign in with a Google credential, then set the filters. Use **Label Names or IDs** to react only to your practice label. The node checks at the **Poll Time** you choose (it does not react instantly), reads unread emails by default, and fetches up to 10 emails per poll by default.

4. **Add the AI step: Basic LLM Chain with Anthropic Chat Model**

   Add a **Basic LLM Chain** and connect an **Anthropic Chat Model** sub-node to it. In the chain, set the prompt to **Define below** and drop in the email fields from the trigger. Use a **System** message under Chat Messages to set tone and rules.

   <PromptBox label="System message for the chain">
   You write reply drafts for a small business owner. Be polite and brief, in at most 5 sentences. Use only facts that appear in the email. If the sender asks about price, delivery dates or anything you cannot know, write "[owner to confirm]" instead of guessing. Do not promise anything.
   </PromptBox>

   <Aside type="note">
   If you need the AI to look things up or call apps by itself, use an **AI Agent** instead. For a fixed "read this, write that" task a Basic LLM Chain is simpler and easier to predict.
   </Aside>

5. **Save the result as a draft, not a sent email**

   Add a **Gmail** node, set Resource to **Draft** and Operation to **Create**. Fill in **Subject**, **Message** (the chain's output) and **To Email**, and choose the email type. Because the output is a draft, you always read it before anything leaves your account.

   <FlowSteps title="The workflow you are building" officialUrl="https://docs.n8n.io/build-your-first-workflow.md" steps={[
     { where: 'Gmail Trigger', action: 'A new email with your practice label arrives', result: 'Subject, sender and body are passed on' },
     { where: 'Basic LLM Chain + Anthropic Chat Model', action: 'Claude writes a short reply from your prompt', result: 'A text reply' },
     { where: 'Gmail (Draft > Create)', action: 'The reply is saved as a draft', result: 'Nothing is sent' },
   ]} />

6. **Test, then publish**

   Run the workflow manually with your test email and open the node outputs to see what each step received. Read the draft in Gmail. When it looks right, publish the workflow so the trigger runs on its own. Check the executions list the next day for errors.

</Steps>

| --- | --- |
| Start on a schedule | Schedule Trigger (publish the workflow) |

### n8n vs Zapier/Make

| Question | Better fit |
| --- | --- |

## Common sticking points

### The workflow does not start by itself

- **Cause**: It is only saved, not published, or the trigger polls on an interval and you did not wait.
- **Fix**: Publish the workflow, and use the manual test to check the logic first.

### The AI node says it needs a tool

- **Cause**: You added an AI Agent, which requires at least one connected tool.
- **Fix**: Connect a tool, or use a Basic LLM Chain for a plain prompt-and-answer step.

### The Anthropic credential fails

- **Cause**: The key was copied wrongly, deleted, or the account has no usable balance.
- **Fix**: Create a new key in the Anthropic Console and paste it again. On Cloud Starter/Pro, try Gateway credits instead.

### Gateway credits are missing

- **Cause**: They exist only on n8n Cloud Starter and Pro, and trials cannot top up until you upgrade.
- **Fix**: Use your own API key, or upgrade the Cloud plan.

### The same email is processed twice, or too many at once

- **Cause**: The filter is too wide, or old unread emails match the label.
- **Fix**: Narrow the label or search filter, and remove the label after you handle a message.

## Practical tips

- **Draft, do not send.** Anything an AI writes in your name should wait for a human. For agent tools that act (send, delete, change records), n8n offers human approval before the tool runs.
- **Keep personal data out of prompts.** The email body goes to the model provider. Start with practice mail, and check your company's rules first ([5. Privacy and safety](/basics/05-privacy-safety/)).
- **Start with one node of AI.** Get trigger, AI and action working with a single email, then add steps.
- **Watch cost.** API calls are billed by the provider (or by your Gateway credits), and Cloud plans have execution limits.
- **Self-hosting is a job.** Updates, backups and security are yours. n8n releases a new minor version most weeks.
