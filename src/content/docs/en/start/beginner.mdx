If you're new to AI or it still feels unfamiliar, just follow the steps below from the top, one after another. We avoid difficult jargon, so start without any pressure.

If you run into a word you don't know, you can look it up right away in the [AI glossary](/en/start/glossary/).

## Recommended learning path

1. [AI First Steps](/en/basics/), tutorials 01 → 11
2. [C1. Claude at a glance](/en/claude/c01-overview/)
3. [C3. Getting started with the Claude app](/en/claude/c03-getting-started/)
4. [C4. How to write good prompts](/en/claude/c04-prompting/)
5. [1. Writing practical prompts](/en/chat/01-prompt-basics/)

If you'd like to go further, these are good too.

- [Can I use this AI output? Copyright and ethics basics](/en/basics/09-ai-copyright-ethics/): Worth reading after AI First Steps, before you use AI output.
- [Build your first web app with Claude Code, no coding required](/en/coding/27-first-app-with-claude-code/): A hands-on tutorial where you follow along by describing what you want in plain words, even with no coding experience.
- [A tour of Korean AI services](/en/chat/29-korean-ai-services/): A look at AI services in Korea, such as Naver and Kakao.

First, the 11 AI First Steps tutorials teach you how to sign up, ask questions, fact-check, and use AI safely. Then move on to the 3 Claude basics and the practical prompt tutorial, and you can start using AI at work right away.
