If you run into an unfamiliar word while reading about AI, look it up here. Each term comes with a **plain explanation**, an **analogy**, and a **tutorial link** for when you want to learn more. Terms are in alphabetical order.

If you're new to AI, start with [AI First Steps](/en/basics/).

<div class="glossary">

## A

### Agent

- **Plain explanation**: An AI that, once given a goal, plans on its own and uses tools to see the job through.
- **Analogy**: Not a support rep who only answers questions, but an assistant who actually gets the work done for you.
- **Learn more**: [Trending AI agents compared](/en/agents/01-agents-compared/) · [Using agents safely](/en/agents/05-agent-safety/)

### API

- **Plain explanation**: A doorway opened up so programs can call AI directly.
- **Analogy**: Like a restaurant's dedicated window for delivery orders.
- **Learn more**: [Getting started with the API](/en/claude/c16-api/)

### Artifacts

- **Plain explanation**: Web pages, documents, and small tools you can open right next to the conversation and share.
- **Analogy**: Like a picture frame beside the chat that displays the work product.
- **Learn more**: [Create and share with Artifacts](/en/claude/c06-artifacts/)

## B

### Batch

- **Plain explanation**: A way to hand over non-urgent requests all at once and get the results later.
- **Analogy**: Like gathering your laundry and dropping it off in one go for a lower price.
- **Learn more**: [Cutting API costs](/en/dev/02-cost-optimization/)

## C

### Citations

- **Plain explanation**: A feature where AI also tells you the location in the source text that its answer is based on.
- **Analogy**: Like footnotes in a paper, showing where something came from.
- **Learn more**: [Document Q&A and citations](/en/dev/09-rag-files-citations/) · [How to fact-check](/en/basics/04-fact-checking/)

### Claude Code

- **Plain explanation**: Claude's agent tool that does coding for you in the terminal and in the cloud.
- **Analogy**: An AI teammate who codes right alongside you.
- **Learn more**: [Claude Code overview](/en/claude/c12-claude-code-overview/) · [Getting started with Claude Code](/en/coding/06-claude-code-start/)

### CLAUDE.md

- **Plain explanation**: A file of project rules that Claude Code reads every time it starts work.
- **Analogy**: A team rulebook you hand to a new teammate.
- **Learn more**: [Claude Code features](/en/claude/c14-claude-code-features/) · [Agent SDK](/en/dev/03-agent-sdk/)

### Cloud session

- **Plain explanation**: A way of running AI work on a cloud server instead of on your own computer.
- **Analogy**: You can shut your laptop and head home, and it keeps working in the server room.
- **Learn more**: [Cloud sessions](/en/claude/c13-cloud-sessions/) · [Cloud and GitHub](/en/coding/08-cloud-github/)

### Computer use

- **Plain explanation**: A feature where AI looks at the screen and operates apps directly with the mouse and keyboard.
- **Analogy**: It's as if someone sat at your desk and clicked for you.
- **Learn more**: [Chrome and computer use](/en/claude/c11-chrome-computer-use/) · [Computer and browser tools API](/en/dev/10-computer-browser-tools/)

### Connector

- **Plain explanation**: A pathway that links Claude to your own services, such as Gmail, Calendar, Drive, and Notion.
- **Analogy**: Like plugging devices into a power strip one by one.
- **Learn more**: [Connecting with connectors](/en/claude/c07-connectors/) · [Connectors and MCP](/en/automation/20-connectors-mcp/)

## D

### Deep Research

- **Plain explanation**: A feature where AI finds and reads many sources on its own and produces a long report with citations.
- **Analogy**: Like handing a junior researcher an assignment with "look into this for me."
- **Learn more**: [Claude's research feature](/en/claude/c10-research/) · [AI assistants compared](/en/chat/05-compare-assistants/)

## E

### Embeddings

- **Plain explanation**: A technique that turns the meaning of text into a set of numbers so that texts with similar meaning can be found.
- **Analogy**: Like a library shelving books on the same topic together even when their titles differ.
- **Learn more**: [Evals](/en/dev/08-evals/) · [Using Cursor](/en/coding/09-cursor/)

### Evals

- **Plain explanation**: A method of repeatedly scoring AI output with the same set of test questions to see whether it's good enough to use.
- **Analogy**: Like running quality inspection on a new product before launch.
- **Learn more**: [Manage quality with evals](/en/dev/08-evals/)

### Extended thinking

- **Plain explanation**: A mode where AI thinks longer before answering.
- **Analogy**: Like working through the steps on an exam instead of guessing right away.
- **Learn more**: [Getting started with Claude](/en/claude/c03-getting-started/) · [Getting started with the API](/en/claude/c16-api/)

## F

### Files API

- **Plain explanation**: A feature where you upload a document once and reuse it across multiple requests.
- **Analogy**: Like submitting your paperwork once so you don't have to hand it in every time.
- **Learn more**: [Document Q&A and citations](/en/dev/09-rag-files-citations/)

## G

### Guardrails

- **Plain explanation**: Safety rules set in advance to block AI from doing things it shouldn't.
- **Analogy**: Like a guardrail at the edge of a road, it catches you when you start to drift off.
- **Learn more**: [Using agents safely](/en/agents/05-agent-safety/)

## H

### Hallucination

- **Plain explanation**: When AI plausibly makes up content that isn't true.
- **Analogy**: Like someone who speaks confidently as if they know, but mixes in wrong information.
- **Learn more**: [How to fact-check](/en/basics/04-fact-checking/)

### Headless

- **Plain explanation**: Running AI from a command or inside a program, with no screen.
- **Analogy**: An unmanned factory that runs on its own without anyone watching in person.
- **Learn more**: [Headless mode and GitHub Actions](/en/dev/07-headless-ci/)

### Hooks

- **Plain explanation**: Rules you set up to run automatically at specific moments, such as before or after a tool runs.
- **Analogy**: Like a sensor on a door that reacts automatically the moment it opens.
- **Learn more**: [Agent SDK](/en/dev/03-agent-sdk/) · [Headless mode and CI automation](/en/dev/07-headless-ci/)

## M

### Managed Agents

- **Plain explanation**: A service that lets you run agents reliably on a server instead of your own computer.
- **Analogy**: Like renting a shared kitchen that's already equipped, instead of cooking at home.
- **Learn more**: [Managed Agents](/en/dev/04-managed-agents/)

### MCP

- **Plain explanation**: A common standard that lets AI connect to many tools and services in the same way.
- **Analogy**: Like a USB-C port that any device plugs into.
- **Learn more**: [Connectors and MCP](/en/automation/20-connectors-mcp/) · [Build an MCP server](/en/dev/05-mcp-server/)

### Memory

- **Plain explanation**: A feature where AI remembers information and preferences about you that it learned in earlier conversations.
- **Analogy**: Like the owner of your regular shop remembering your tastes.
- **Learn more**: [Memory and settings](/en/claude/c09-memory-settings/)

### Model

- **Plain explanation**: The core "brain" of the AI that produces answers. There are several kinds, depending on size and purpose.
- **Analogy**: Like how one car company makes compact cars, sedans, and trucks.
- **Learn more**: [Dividing work among models](/en/claude/c15-model-division/) · [Claude overview](/en/claude/c01-overview/)

## O

### OAuth

- **Plain explanation**: A sign-in method that lets another service access your account without you handing over your password.
- **Analogy**: Like giving a one-time key card instead of your hotel room key.
- **Learn more**: [Build an MCP server](/en/dev/05-mcp-server/) · [Connecting with connectors](/en/claude/c07-connectors/)

## P

### Personal and sensitive information

- **Plain explanation**: Information you shouldn't casually enter into AI, such as names, contact details, and company secrets.
- **Analogy**: If you wouldn't say it loudly in an elevator, it's safer not to tell AI either.
- **Learn more**: [Protecting personal and company information](/en/basics/05-privacy-safety/)

### Plugin

- **Plain explanation**: An extension package that installs skills, commands, connections, and more as one bundle.
- **Analogy**: Like installing an app on your smartphone to add features.
- **Learn more**: [Distribute skills and plugins to your team](/en/dev/06-plugins-skills-team/)

### Projects

- **Plain explanation**: Claude's workspace where you keep related materials and instructions in one place and chat within it.
- **Analogy**: Like a drawer or folder organized by subject.
- **Learn more**: [Manage materials and instructions with Projects](/en/claude/c05-projects/)

### Prompt

- **Plain explanation**: The question or request you write to AI.
- **Analogy**: Like ordering at a restaurant. The more specific you are, the closer the food is to what you wanted.
- **Learn more**: [Asking good questions](/en/basics/03-asking-well/) · [Prompt basics](/en/chat/01-prompt-basics/)

### Prompt caching

- **Plain explanation**: A feature that saves the long, repeated front part of your requests and reuses it, saving cost and time.
- **Analogy**: Like pulling out a note instead of giving the same explanation from scratch every time.
- **Learn more**: [Cutting API costs](/en/dev/02-cost-optimization/) · [Document Q&A and citations](/en/dev/09-rag-files-citations/)

## R

### RAG

- **Plain explanation**: A method where only the document pieces related to a question are found and shown to the AI alongside it so it can answer.
- **Analogy**: Like an open-book exam where you only flip to the pages you need.
- **Learn more**: [Document Q&A and citations](/en/dev/09-rag-files-citations/)

### Rate limit

- **Plain explanation**: The cap on how many requests or how much usage you can send within a set time.
- **Analogy**: Like a limit on how many people can enter a buffet at once, so it doesn't get overcrowded.
- **Learn more**: [Getting started with the API](/en/claude/c16-api/) · [Cutting API costs](/en/dev/02-cost-optimization/)

## S

### Sandbox

- **Plain explanation**: A mechanism that confines the work AI runs inside a safe, isolated space.
- **Analogy**: Like letting a child play only inside the sandbox.
- **Learn more**: [Using agents safely](/en/agents/05-agent-safety/) · [Agent SDK](/en/dev/03-agent-sdk/)

### SDK

- **Plain explanation**: A ready-made set of development tools that makes it easy to add AI features to your own program.
- **Analogy**: Like a furniture assembly kit with the parts prepared.
- **Learn more**: [Agent SDK](/en/dev/03-agent-sdk/)

### Skills

- **Plain explanation**: A bundle of instructions that teaches Claude how to do a specific task. You call it up when needed.
- **Analogy**: Like a work manual you hand to a new hire.
- **Learn more**: [Using and creating skills](/en/claude/c08-skills/) · [Distribute skills and plugins to your team](/en/dev/06-plugins-skills-team/)

### Streaming

- **Plain explanation**: A way of sending the answer out bit by bit as it's produced, instead of after it's all done.
- **Analogy**: Like receiving it as a flowing stream of water rather than one delivered package.
- **Learn more**: [Document Q&A and citations](/en/dev/09-rag-files-citations/)

### Subagent

- **Plain explanation**: A helper agent that takes on part of a big job. Each works separately and reports back only the result.
- **Analogy**: Like a team lead splitting up work and handing pieces to team members.
- **Learn more**: [Agent SDK](/en/dev/03-agent-sdk/) · [Headless mode and CI automation](/en/dev/07-headless-ci/)

### Subscription (plan)

- **Plain explanation**: A way of paying a monthly fee to get more features and usage.
- **Analogy**: Like a monthly streaming subscription, where what you can use depends on the tier.
- **Learn more**: [Free vs. paid](/en/basics/08-free-vs-paid/) · [Plans and usage limits](/en/claude/c02-plans-limits/)

### System prompt

- **Plain explanation**: Instructions that tell AI its role and rules before the conversation starts.
- **Analogy**: Like the "here's what your role is" briefing you get on your first day of work.
- **Learn more**: [Tool use](/en/dev/01-tool-use/) · [Agent SDK](/en/dev/03-agent-sdk/)

## T

### Token

- **Plain explanation**: The smallest unit AI uses when reading and writing text. It's the basis for usage and cost.
- **Analogy**: Like a taxi meter, the number goes up the longer the text is.
- **Learn more**: [Free vs. paid](/en/basics/08-free-vs-paid/) · [Cutting API costs](/en/dev/02-cost-optimization/)

### Tool use

- **Plain explanation**: A feature where AI doesn't just answer but directly calls tools such as search, calculation, or your own programs.
- **Analogy**: Like an employee who used to only take questions now getting a calculator and a phone too.
- **Learn more**: [Build a work bot with tool use](/en/dev/01-tool-use/)

### Trigger (automation)

- **Plain explanation**: A signal that starts a task, such as "when an email arrives" or "at 7 AM."
- **Analogy**: Like a porch sensor light that turns on when someone approaches.
- **Learn more**: [Automating a morning briefing](/en/automation/17-morning-briefing/) · [Zapier and Make](/en/automation/18-zapier-make/)

### Two-factor authentication

- **Plain explanation**: A sign-in method that adds one more check, such as a text message or app approval, on top of your password.
- **Analogy**: Like a door that needs a key in addition to the front-door passcode.
- **Learn more**: [Using agents safely](/en/agents/05-agent-safety/)

## U

### Usage limit

- **Plain explanation**: The cap on how much AI you can use within a set period.
- **Analogy**: Similar to a phone carrier's monthly data allowance.
- **Learn more**: [From signing up to your first question](/en/basics/02-sign-up-first-question/) · [Plans and usage limits](/en/claude/c02-plans-limits/)

## V

### Voice recognition (speech-to-text)

- **Plain explanation**: A feature that turns spoken words into text.
- **Analogy**: Like having AI stand in for a meeting stenographer.
- **Learn more**: [Transcribing recordings](/en/media/14-transcribe-recordings/) · [Using AI on your phone](/en/basics/07-ai-on-phone/)

## W

### Workflow (multi-step task)

- **Plain explanation**: A flow of work that links several steps and handles them in a set order.
- **Analogy**: Like a recipe, where steps 1, 2, and 3 come in a fixed order.
- **Learn more**: [Automate with Zapier and Make](/en/automation/18-zapier-make/)
