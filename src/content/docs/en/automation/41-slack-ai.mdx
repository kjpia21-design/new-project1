<Summary>
- There are two ways to add AI to Slack: **Slack's own AI** (summaries, search answers, recaps, Slackbot) and **Claude Tag** (a feature where you call @Claude in a channel to hand off work).
- Slack AI is described as using **only conversations you can see**. Features vary by plan: summaries are described as available across paid plans, while search answers, recaps, translation, and Slackbot are described as Business+ and above (as of 2026-10-31).
- Claude's Slack integration **became Claude Tag as of 2026-08-03.** It's a beta feature on Claude Team and Enterprise plans, and is described as unavailable on personal plans (Free, Pro, Max).
- Claude Tag's channel work is **billed to the organization based on usage**. Only Owners can configure it.
- Either way, **click through to the sources to check the original** for results, and for channels with confidential content, check your company policy first on whether to hand them to AI.
</Summary>

## What you'll be able to do

- Know how to **summarize** long channels and threads and get **search answers** in natural language.
- Judge **which AI features you can see** based on your plan and admin settings.
- Write prompts that hand work to Slackbot, and understand the idea of **recurring tasks (Tasks)**.
- Know what Claude Tag is and **who sets it up and who gets billed**, and list what to check before adopting it.

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Slack AI** | The bundle of AI features built into Slack. It includes conversation summaries, search answers, recaps, file summaries, translation, huddle notes, and Slackbot. |
| **Slackbot** | What Slack introduces as a "personal work agent." It answers questions and creates things like document drafts based on the Slack information you can see. |
| **Recap** | A feature that summarizes what you missed in selected channels every morning. |
| **Claude Tag** | Claude's Slack feature where you tag @Claude in a channel to hand off work. Described as a beta on Team and Enterprise plans. |
| **Owner** | The role in a Claude organization that can configure Claude Tag's access and channels. The Admin role is described as unable to configure it. |

## Slack's own AI

### Features by plan (as of 2026-10-31)

This unpacks the table in Slack's help. Some entries were confirmed only from the text alignment of columns in the table, so be sure to check whether they actually show up in your workspace.

| Feature | Which plans it's described for |
| --- | --- |
| Conversation (channel/DM) and thread summaries, huddle notes, automatic search filters | Pro, Business+, Enterprise+ |
| Search answers, recaps, file summaries, translation, workflow automation, canvas content generation | Business+, Enterprise+ |
| Slackbot | Business+, Enterprise+ (on Pro and others it may be a limited preview) |
| Enterprise search | Enterprise+ |

- Older Business+ plans, and Enterprise Grid without the Slack AI add-on, are described as having only Pro features.
- This article doesn't cover prices. Slack's official help says to check pricing on Slack's pricing page or with the sales team.
- We couldn't confirm in the official documentation the quality when summarizing Korean-language conversations or the range of supported languages. Judge by trying it yourself.

<Aside type="caution" title="Admins can turn it off">
Workspace owners and admins can restrict or turn off AI features. If a feature doesn't show up, check admin settings as well as your plan.
</Aside>

### Common features and where to find them

| What you want to do | Location (desktop) |
| --- | --- |
| Summarize a channel or DM | The three-dot icon above the conversation > **Summarize channel** or **Summarize conversation** |
| Summarize a thread | **Summarize** above the thread |
| Search answers | Type a question in the search bar and press Enter. An AI answer with sources appears above the results |
| See what you missed in one place | **Recap** in the sidebar. Choose which channels to include under **Manage Recap** |
| Summarize a file | Automatic summary when a .pdf, .docx, .pptx, or .xlsx file is uploaded. To turn off: Profile > Preferences > **AI** |
| Translate a message | Set your translation language under Profile > Preferences > Language & region, then use the message's three dots > **Translate message** |
| Slackbot | **Slackbot** at the top right or in the sidebar |

For summaries, you choose from unread messages, the last 7 days, or (on desktop) a custom period. Summaries and answers come with **More details** or citations to see the sources.

### Handing work to Slackbot

Slackbot's help tells you to write prompts **short and precise** and to include context such as the channels and file links to reference. It also says to start a new conversation when the topic changes.

<PromptBox>
In the #project-launch channel, organize the last 7 days into what's been decided and what's still undecided. For each item, attach a link to the message it's based on, and gather any questions I need to answer in a separate list.
</PromptBox>

<PromptBox>
Draft an agenda for today's 3 p.m. team meeting. Use this week's conversations in the #team-weekly channel and the previous meeting notes at the canvas link below as references. Keep it to no more than 5 agenda items, with one discussion question for each.

[link to previous meeting notes canvas]
</PromptBox>

<PromptBox>
Read the discussion in this thread and put what was agreed, what disagreements remain, and the next steps with owners into a table. Don't make up owners or dates that aren't in the thread. Write "TBD" instead.
</PromptBox>

- If Slackbot tries to edit a canvas, it's described as adding content only when you click **Confirm**, and changing nothing if you click **Cancel**. If it's heading the wrong way mid-task, you can halt it with **Stop**.
- You can create recurring tasks with **Tasks** (for example, a weekly agenda draft). Each task is described as running at most 3 times per day.
- Turning on **Deep research** is described as gathering multiple sources such as channels, files, and the web to produce a longer report.
- The number of messages and the features available differ by plan, and the limits are in a separate help page (Slackbot limits and credit usage). We couldn't open it to check for this article.

### How Slack AI handles data (per Slack's help)

- AI features use **only data you can access at that moment**. Private channels and DMs you aren't part of are described as not appearing in summaries, search answers, or Slackbot responses.
- Customer data is described as never leaving infrastructure that Slack controls, and not being used to train LLMs.
- Conversation summaries and search answers are described as transient responses that aren't stored, while recap data is kept for 90 days. Channel summaries created by workflows follow your organization's retention settings.

## Claude Tag: hand off work to @Claude in a channel

### What it is and who uses it

According to Claude's help, Claude Tag has **three touchpoints** in Slack.

- **Channel tag**: Call @Claude in a channel to hand off work, and follow the progress together in the thread.
- **DM**: Chat one-on-one with @Claude.
- **AI assistant panel**: Open it by clicking the Claude icon in Slack's AI assistant header.

| Item | What's described (as of 2026-10-31) |
| --- | --- |
| Plans | **Team, Enterprise**. Beta. Not available on personal plans such as Free, Pro, Max, or Ultra. |
| Identity and cost of channel work | Claude works under the organization's identity, within the tools and access scope an admin set for that channel. Costs are billed to the **organization**. |
| DMs and panel | Works with features you've turned on in your own Claude account (web search, connected tools, etc.). |
| Claude seats | Each Slack user doesn't need a Claude seat. Channel work is usage-based, with no extra per-seat fee. |
| Who can configure | Only the **Primary Owner or an Owner**. The Admin role can't. |
| Initial access scope | It starts with no access to external systems, and admins connect the services needed. |
| Execution environment | Runs in a temporary sandbox, not on your computer. |

### Cost and access control (for admins to check)

- Cost is **usage-based**. You can set organization-wide limits and per-channel limits, and admins are described as being notified at 75% and 95% of a limit. Work that would exceed the limit is rejected rather than silently cut off.
- **Who can use it** is set under Member Access: the entire Slack workspace, only Claude organization members, or by role (Enterprise).
- Access scope is configured at three levels, organization, workspace, and private channel, and sensitive connections can be kept separately in private channels.
- **Channels with guests** default to Restrict, so Claude doesn't respond.
- **Memory**: Claude Tag remembers context per channel and workspace, and Owners can view, edit, and delete it.
- **Activity log**: Owners can see scheduled and one-time tasks and network calls under Organization settings > Claude Tag > Activity.
- Conversations started in Slack are kept separate from your Claude conversation history and follow Slack's retention policy. If you disconnect the integration or delete the app, the Claude-side conversations are described as deleted within 30 days.

### Example prompts for calling it in a channel

<PromptBox>
@Claude Read this week's customer inquiry threads in this channel and count them by inquiry type. If any problems repeat, mark them separately, and attach links to the threads you based it on. Don't guess; use only what's in the threads.
</PromptBox>

<PromptBox>
@Claude Organize what was agreed in the thread above into a draft decision record. Split it into decisions, reasons, owners, and deadlines, and write "TBD" for information that isn't in the thread. Show it to me first before posting the document.
</PromptBox>

The official documentation introduces Claude Tag as used for things like checking monitoring, triaging inquiries, finding answers in documents, answering data questions, organizing threads into documents or tickets, and drafting bug fixes. For work that needs external services, such as document search or data questions, **an admin has to have set up the relevant connection**.

<Steps>

1. **Check which features show up in your workspace**

   See whether **Summarize channel** is in the three-dot menu above a channel, and whether **Recap** and **Slackbot** are in the sidebar. If you don't see them, it may be because of your plan or admin settings.

2. **Summarize a channel or thread and check the sources**

   Set the scope to unread messages or the last 7 days and create a summary. Click **More details** to check which messages it's based on. Also skim the original to see whether any important messages were left out of the summary.

3. **Ask in the search bar**

   Ask in everyday language, like "Who posted the marketing meeting slides last week?" Hover over a citation above the answer to preview the original, and before sharing with someone else, read the content once and then click **Share anyway**.

4. **Hand organizing to Slackbot and compare**

   Try the prompts above in a practice channel. Check whether the owners, dates, and numbers are actually in the original.

5. **Set up Recap (optional)**

   Open **Recap**, choose the channels to include, and turn it on to get a summary every morning. You can also choose whether to mute the channels being summarized. Use it knowing the retention period (90 days).

6. **Check before adopting Claude Tag (for organizations where it applies)**

   Ask your Owner the following: which channels it will be turned on in, who can use it, what the limit is, how guest channels are handled, and what tools are connected. We recommend starting in a practice channel and widening it as you watch cost and results.

</Steps>

## Privacy and confidentiality cautions

Slack mixes in customer information, HR talk, and contract details. More detailed principles are in [Using AI while keeping personal and company information safe](/en/basics/05-privacy-safety/).

- **Company policy comes first.** Before turning on AI features, check the approved scope with your information security team or admin.
- Slack AI uses only conversations you can see, but **if you share a summary with others**, what you could see is passed on to them. Before sharing, check that nothing from private channels got mixed in.
- Claude Tag's **channel work happens in threads everyone can see**. Make sensitive requests somewhere other than a public channel.
- Don't put national ID numbers (in Korea, resident registration numbers), bank or card numbers, or passwords into Slack conversations or AI.
- For summaries and judgments on topics like performance reviews, discipline, and legal disputes, have a person make the final decision.

## Common sticking points

### I don't see Summarize or Slackbot

- **Cause**: It may not be included in your plan, or an admin may have restricted access. Guests are described as possibly having different features.
- **Fix**: Ask your workspace admin about the AI feature access settings.

### The summary left something out

- **Cause**: It may not have been in the selected period, or the AI may not have judged it important.
- **Fix**: Widen the period and check the sources with More details. For important decisions, read the original yourself.

### I want to connect Slack with a personal Claude account (Free, Pro, Max)

- **Cause**: Claude Tag is for Team and Enterprise plans and is described as unavailable on personal plans.
- **Fix**: We couldn't confirm a separate official route for connecting personal plans to Slack this time. One approach is to copy the conversation and paste it into a Claude chat to have it summarized, but **mask personal and confidential information before pasting.**

### @Claude doesn't respond in the channel

- **Cause**: Claude may not have been added to that channel, access may be restricted by the Member Access setting, or it may be the default (Restrict) for a channel with guests. You may also have reached your limit.
- **Fix**: Ask the Owner to check the channel configuration and limit. If it's a limit issue, you're told you can ask an admin to add more from within Slack.

### I don't know how much it will cost

- **Cause**: It's usage-based, not per-seat.
- **Fix**: Run a trial with a small limit, check per-channel usage details, and then adjust.

## Practical tips

- **Specify the period and scope.** Setting a scope like "last 7 days" or "this thread only" gives useful summaries.
- **Ask for source links.** Having it attach links to the messages it's based on makes checking easy.
- **Use 'TBD' for unknowns.** Write in the prompt that it shouldn't make up owners or dates.
- **Start small.** Try recurring tasks (Tasks) and Claude Tag in a practice channel first.
- **Read before sharing.** Read an AI answer once before posting it in a channel.
