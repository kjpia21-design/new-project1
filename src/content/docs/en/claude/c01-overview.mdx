<Summary>
- There are four current models: **Fable 5.1, Opus 5.5, Sonnet 5.5, and Haiku 5.5** (as of 2026-10-10).
- The official docs say: "If you're not sure, **start with Opus 5.5** for most workloads."
- The Claude Code default (`default`) is also Opus 5.5. **Fable is not the default on any plan, so you have to pick it yourself.**
- Haiku suits high-volume, low-latency work, Sonnet balances speed and quality, and Fable fits the hardest long-horizon reasoning.
- API prices differ by model. The table below is **as of 2026-10-10**.
</Summary>

## What you'll be able to do

- Explain the differences between the four Claude models using one table.
- Pick the model that fits your work.
- Switch models in the Claude app and in Claude Code.
- Look up API model IDs and prices again when you need them.

## Concepts to know first

| Term | Meaning |
| --- | --- |
| **Model** | The kind of "brain" Claude uses. Bigger, smarter models are slower and pricier; smaller ones are fast and cheap. |
| **effort** | How deeply the model thinks. In Claude Code the levels are low / medium / high / xhigh / max. |
| **Context window** | How much text the model can handle at once. All four models have 1 million (1M) tokens. |
| **Model ID** | The name that points to a model in the API or config files. Example: `claude-opus-5-5` |
| **Alias** | A short name used in Claude Code. Examples: `opus`, `sonnet`, `haiku`, `fable`, `default` |

### The four models side by side (as of 2026-10-10)

| Model | Use it for | Speed | API price (per 1M tokens, input / output) | Model ID |
| --- | --- | --- | --- | --- |
| **Fable 5.1** | Hard reasoning, long-horizon agent work | Slow | $10 / $50 | `claude-fable-5-1` |
| **Opus 5.5** | Long-running agentic coding and knowledge work. **The officially recommended starting point** | Medium | $4 / $20 | `claude-opus-5-5` |
| **Sonnet 5.5** | The best combination of speed and intelligence | Fast | $2 / $10 | `claude-sonnet-5-5` |
| **Haiku 5.5** | High-volume, low-latency work like classification, extraction, and routing | Fastest | From $0.10 / from $0.50 | `claude-haiku-5-5` |

- These prices are for the API. The Batch API is 50% off. For Haiku 5.5, the per-token price is higher when the prompt exceeds 100K tokens (per the Claude Code Model configuration doc, as of 2026-10-12). Check the official pricing page for exact tiered rates.
- All four models have a 1M-token context window and a 128K-token maximum output (synchronous Messages API), and a reliable knowledge cutoff of June 2026.
- Default effort is `high` for Fable 5.1, `medium` for Opus 5.5, `high` for Sonnet 5.5, and `medium` for Haiku 5.5.
- Retirement commitments: Fable 5.1 will not retire before 2027-09-01, Opus 5.5 not before 2027-09-22, Sonnet 5.5 not before 2027-09-28, and Haiku 5.5 not before 2027-10-07. Keep this in mind if you're building a long-lived service.
- Earlier generations (Fable 5, Opus 5, Opus 4.x, Sonnet 5, Sonnet 4.6, Haiku 4.5) are still available. However, **Sonnet 4.5 (`claude-sonnet-4-5-20250929`) was announced as deprecated on 2026-09-30 and retires on the Claude API on 2026-11-30.** If you're using it, move to Sonnet 5.5 (as of 2026-10-11, per the official release notes and Model deprecations doc). Opus 4.1 has already retired. The models overview also mentions a model called Claude Mythos 5.1, but it isn't in the current model table, so this guide doesn't cover it.

<Aside type="caution" title="Fable is not the default">
The Claude Code docs say that "Fable models are not the default on any plan or provider and must be selected explicitly." Claude Code's `default` is **Opus 5.5** on Pro/Max/Ultra/Team/Enterprise/Anthropic API. How Fable limits apply depends on your plan and seat, so see [C2. Plans and usage limits](/en/claude/c02-plans-limits/) for details.
</Aside>

<Aside type="note" title="Go by what your own screen shows in the model picker">
The official docs have no table of which models appear in the Claude app's model picker for each plan (as of 2026-10-13). Go by the list of models you see on your own screen.
</Aside>

<Steps>

1. **Learn the basic rules for choosing**

   - Start with **Opus 5.5**.
   - For high-volume, low-latency work, step down to **Haiku 5.5**.
   - When speed and balance matter, use **Sonnet 5.5**.
   - For hard long-horizon reasoning, or when Opus 5.5 at a high effort level still isn't good enough in your evaluations, use **Fable 5.1**.

2. **Switch models in the Claude app**

   The current model is shown below the input box (web and desktop) or at the top of the screen (mobile). Tap the model picker to change it. You can also adjust effort and extended thinking.

   <ScreenshotPlaceholder caption="The model picker below the input box" officialUrl="https://support.claude.com/en/articles/8114491-get-started-with-claude" />

3. **Switch models in Claude Code**

   During a session, type `/model`, then press Enter in the picker (saves it as your default) or `s` (this session only). To set it at startup, do this:

   ```sh
   claude --model opus
   ```

   You can also set it with the `ANTHROPIC_MODEL` environment variable or the `model` field in your settings file.

4. **Send the same question to two models**

   <PromptBox>
   Handle the request below. First give me the three most important conclusions in three lines, then lay out the supporting reasoning.

   [Paste your work material or question here]
   </PromptBox>

   Send the same wording and change only the model, then compare quality, speed, and how much of your limit it uses. That gives you a yardstick that fits you.

</Steps>

## Quick reference

### Choosing a model by situation

| Situation | Recommendation | Why |
| --- | --- | --- |
| Not sure, or just starting | Opus 5.5 | The officially recommended starting point |
| Long coding tasks, knowledge work | Opus 5.5 | Described as built for long-running agentic work |
| Quick drafts, everyday work, response speed matters | Sonnet 5.5 | A balance of speed and intelligence |
| Thousands of classification, extraction, or routing jobs | Haiku 5.5 | The fastest and cheapest |
| The hardest reasoning, very long agent tasks | Fable 5.1 | The most powerful, but slow and expensive |

### Claude Code aliases and commands

| Item | Description |
| --- | --- |
| `default`, `best`, `fable`, `sonnet`, `opus`, `haiku` | Model aliases |
| `sonnet[1m]`, `opus[1m]` | 1M-context aliases |
| `opusplan` | One of the aliases. How it works is covered in [C15](/en/claude/c15-model-division/) |
| `/model` | Change the model during a session |
| `claude --model opus` | Set the model at startup |

- The `opus`, `sonnet`, and `haiku` aliases resolve to the latest version on the Anthropic API.
- Effort `max` has diminishing returns and a risk of overthinking, so testing it beforehand is recommended.

## Common sticking points

### Fable doesn't show in the picker, or it asks for credits

- **Cause**: Fable isn't the default, and whether it's included depends on your plan and seat.
- **Fix**: See the Fable limits explanation in [C2](/en/claude/c02-plans-limits/), and check what's actually shown on the Settings > Usage screen.

### I can't select Fable in Claude Code

- **Cause**: Your Claude Code version may be too old.
- **Fix**: Fable 5 needs v2.1.170 or later and Fable 5.1 needs v2.1.255 or later (per the help center article "Claude Fable models on your plan"). However, the Claude Code Model configuration doc says Fable 5.1 needs v2.1.257 or later (as of 2026-10-12). The two docs disagree, so if you can't select it, update to the latest version. The same doc also says Opus 5.5 needs v2.1.280, Sonnet 5.5 needs v2.1.284, and Haiku 5.5 needs v2.1.293 or later.

### I thought a bigger model is always better, but my limit shrinks fast

- **Cause**: Bigger models and higher effort use up your allowance faster.
- **Fix**: Run simple jobs on Sonnet or Haiku at a lower effort.

### The model ID doesn't work in the API

- **Cause**: The model ID is misspelled, or the format differs by provider. Bedrock adds an `anthropic.` prefix (example: `anthropic.claude-opus-5-5`).
- **Fix**: Use the IDs in the table above exactly as written. API usage is covered in [C16. API](/en/claude/c16-api/).

## Practical tips

- **Start with Opus 5.5, and move down or up only when you need to.** This matches the official recommended order.
- **Model choice and effort are as important a dial as the prompt.** For writing prompts, see [C4](/en/claude/c04-prompting/).
- **You can also split the work: a bigger model for planning, a smaller one for implementation.** This is covered in [C15. Dividing work among models](/en/claude/c15-model-division/).
- **Prices change.** This table is as of 2026-10-10, so check the official models overview page again before you rely on it.
