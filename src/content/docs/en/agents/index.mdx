A personal AI agent doesn't stop at answering questions. It connects to services like your email, calendar, and apps and **gets things done on your behalf**. It can keep working on a task you've set up without you prompting it each time, and it can even act first when a notification comes in.

A regular chat AI is more like a tool that "answers when you ask," while an agent is a tool that "does the work when you hand it off." That's convenient, but since you're handing over important things like payments and account permissions, **deciding how far to let it go** matters a lot.

This section covers three agents that are getting a lot of attention right now: Meta's Muse, xAI's Grok Bot, and OpenAI's ChatGPT Dots. Each guide first checks **whether you can use it in Korea** and **whether it supports Korean** (useful if you're in Korea or use it in Korean), and explains things based only on official sources. We don't cover workarounds for signing up for services that aren't officially offered in your country.
