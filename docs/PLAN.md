# 최신 AI 트렌드 따라 잡기 — 계획안

> 상태: 확정 (v1.0) · 마지막 수정: 2026-10-10
>
> 사이트 이름: **최신 AI 트렌드 따라 잡기**

## 1. 목표

최신 AI 도구를 **설명**하고 **단계별로 따라 할 수 있는 튜토리얼**을 제공하는 한국어 웹사이트.

- 사용자 수준을 **입문 / 실무 / 고급** 세 단계로 나누고, 각자 자기 수준에 맞는 콘텐츠를 골라 볼 수 있게 한다.
- **1단계는 실무 활용자**(업무에 AI를 쓰려는 직장인·전문직)를 중심으로 만든다.
- 내용이 낡지 않도록 **주기적으로 자동 점검**한다.

## 3. 사이트 구조

```
홈
├─ 나에게 맞는 시작점 (입문 / 실무 / 고급 선택)
├─ 분야별 둘러보기
│   ├─ 대화형 AI 기본기
│   ├─ 코딩·에이전트
│   ├─ 이미지·영상·음성
│   └─ 업무 자동화·생산성
├─ 도구 카드 (도구별 한 장 요약: 무엇·누구에게·가격·장단점·관련 튜토리얼)
├─ 튜토리얼 (단계별 따라하기)
├─ 최근 업데이트 (자동 점검으로 바뀐 내용)
└─ 검색
```

### 튜토리얼 한 편의 구성
1. 이 튜토리얼로 할 수 있게 되는 것 (완성 결과 미리보기)
2. 준비물 (계정, 요금제, 소요 시간, 난이도)
3. 단계별 따라하기 — 각 단계마다 체크박스, 복사 가능한 프롬프트, 스크린샷 자리
4. 자주 막히는 지점과 해결법
5. 응용 아이디어 / 다음에 볼 튜토리얼
6. 출처 링크, **마지막 확인일**

## 5. 기술 구성 (제안)

- **Astro + Starlight**: 문서·튜토리얼 사이트에 특화된 정적 사이트 도구. 사이드바, 검색, 한국어, 다크 모드, 모바일 화면 기본 지원.
- **콘텐츠는 마크다운 파일**: 튜토리얼 한 편 = 파일 하나. 상단 정보(frontmatter)에 수준·분야·도구·마지막 확인일·출처를 기록해 필터와 "최근 업데이트"에 사용.
- **배포**: GitHub Actions가 `main`에 반영될 때마다 자동으로 빌드해 GitHub Pages에 게시. 저장소가 공개라 무료.
- **수준별 보기**: 상단에서 입문/실무/고급을 고르면 해당 수준 콘텐츠만 보이도록 필터.

## 6. 자동 점검 방식 (제안)

- 매주 1회 루틴이 새 클라우드 세션을 열어:
  1. 각 튜토리얼에 나온 도구의 공식 문서·변경 이력을 확인
  2. 바뀐 점(메뉴명, 가격, 기능)이 있으면 수정안을 만들어 **PR로 올림**
  3. 사용자님이 PR을 보고 합치면 사이트에 반영
- 바로 반영하지 않고 PR을 거치므로 잘못된 수정이 그대로 공개되지 않음.
- 비용: 점검 1회마다 클라우드 세션 크레딧이 소모됨. 처음에는 주 1회로 시작해 비용을 보고 조정.

## 7. 작업 분담

| 역할 | 담당 | 하는 일 |
| --- | --- | --- |
| 설계·기획 | Opus 5.5 (이 세션) | 요구사항 정리, 구조·디자인 설계, 단계별 작업 명세 작성, 결과 검토, 사용자와 소통 |
| 코딩·실행 | Sonnet 5.5 (하위 에이전트) | 명세에 따라 코드 작성, 빌드·테스트 실행, 커밋 |

진행 방식:
1. Opus가 단계별 **작업 명세**(만들 것, 파일 구조, 완료 기준)를 작성
2. Sonnet 에이전트가 명세대로 구현하고 빌드·테스트까지 실행
3. Opus가 결과를 검토하고, 고칠 점은 다시 Sonnet에게 지시
4. 검토를 통과하면 커밋·푸시하고 사용자에게 결과 보고

튜토리얼 본문 작성(3단계)은 웹 조사와 내용 판단이 함께 필요하므로, 초안은 Sonnet이 쓰고 사실 확인과 최종 검토는 Opus가 맡는다.

## 8. 진행 단계

| 단계 | 내용 |
| --- | --- |
| 0 | 계획 확정 (지금) |
| 1 | 사이트 뼈대: 구조, 디자인, 수준·분야 필터, 배포 설정 |
| 2 | 튜토리얼 템플릿 확정 + 샘플 2편 작성 → 형태 검토 |

| 5 | 공개 → 이후 입문·고급 콘텐츠 확장 |
