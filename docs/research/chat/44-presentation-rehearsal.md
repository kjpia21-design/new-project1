# 44. AI와 발표·스피치 연습하기 — 2026-11-02 기준 (S3)

## 확인한 공식 페이지 (curl, 한 페이지씩)
- Claude 음성 모드: https://support.claude.com/en/articles/11101966-using-voice-mode
  - 베타. Free·Pro·Max·Ultra·Team·Enterprise, 모바일·데스크톱·웹, 휴대폰에서 가장 잘 맞게 만들었다고 안내.
  - 시작: 웹/데스크톱은 입력창 오른쪽 아래 음파 기호, 모바일은 입력창의 음파 기호. 핸즈프리(기본)와 푸시투토크. Claude가 끼어들면 다시 말하면 멈추고 들음.
  - 활용 예: "Preparation: Practice for interviews or important conversations through natural dialogue."
  - 음성 대화는 일반 사용량 한도에 포함. 텍스트 기록이 채팅 기록에 저장됨. 배터리 사용 더 많음(문제 해결 항목).
  - 영어 외 언어는 베타. 설정 > 기능(Capabilities) > 음성(Voice) > 말하는 언어(Spoken language), 없으면 설정 > 일반 > 음성 > 언어. Claude Fable은 음성 모드 불가. Cowork·Claude Code는 받아쓰기만.
  - 복잡한 질문은 나눠서 묻기, 자연스럽게 말하기 팁.
- Gemini Live: https://support.google.com/gemini/answer/15274899
  - Android 폰·태블릿의 Gemini 모바일 앱. 웹 앱 불가. 시작: 앱 아래 Live 또는 왼쪽 스와이프, "Hey Google, let's talk Live".
  - "Practice aloud: Rehearse for important moments in a more natural and conversational way."
  - Hold(마이크 끔)·Mute·End(대화 기록 확인), 텍스트 모드 전환. 카메라·화면 공유. Gems 불가. 타인 녹음/포함 전 허락 안내. 플랜 요건: Gemini 앱 접근 가능한 Google 계정(유료 플랜 언급 없음).
- ChatGPT Voice: https://learn.chatgpt.com/docs/features/voice (.md) — ChatGPT 데스크톱 앱, Plus·Pro·Business·Edu·Enterprise. 시작은 Start voice chat / Start new voice chat. 끼어들기 가능. Codex on iOS(데스크톱 호스트 페어링)로도 사용. 작업 지시·조율 중심 설명, 발표 연습 용도 언급 없음.

## 확인하지 못한 것
- 어느 서비스가 발표 시간·속도·군더더기 말·발음·전달력을 측정/평가하는지(문서에 없음 → 본문에 "확인하지 못함", 타이머 사용 권고).
- 긴 연속 발표를 얼마나 잘 인식하는지, Gemini Live·ChatGPT Voice의 영어 외 언어 지원, ChatGPT Voice의 휴대폰 직접 사용·무료 플랜·대화 기록 저장.
- AI 피드백의 정확도·효과 수치(공식 근거 없음 → 수치 쓰지 않음).

## 본문 반영
- 대본 다듬기·예상 질문·피드백 프롬프트는 공식 확인 사실이 아닌 "써 보는 방법". 음성 기능 설명은 위 확인 범위만. basics/07, chat/31, media/25와 연결.
