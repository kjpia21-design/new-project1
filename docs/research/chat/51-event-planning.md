# 51. AI로 행사·모임 계획하기 — 2026-11-05 기준 (D4)

## 확인한 공식 페이지 (curl 기본 옵션, 한 페이지씩; -L만)
- ChatGPT 프롬프트 https://learn.chatgpt.com/docs/prompting.md (200; 색인 https://learn.chatgpt.com/llms.txt 도 200, 행사 계획 전용 문서 없음)
  - 목표·맥락·출력·경계. 경계 예: 확정 날짜·예산 수치 유지, 예산 안에서 추천, 메시지는 초안으로만(보내지 않기). 계획 대비 실제 지출 표 예시. "Make a practical plan"(저녁 다섯 끼, 재료 재사용, 장보기 목록 통합), "Compare options" 예시. 중요한 작업은 마지막 점검(확인 못 한 정보 표시) 후 직접 검토. 최신 정보는 웹 검색, 확인은 출처 요청.
- Gemini 창의적 학습 https://support.google.com/gemini/answer/15216790 (200)
  - "Brainstorm ideas", 팁: 항상 응답 평가·팩트체크(AI는 실수 가능), 구체적으로 질문. (행사 계획 전용 페이지 아님)
- Claude 웹 검색 https://support.claude.com/en/articles/10684626-enable-and-use-web-search (200, "Updated over a month ago" 표시)
  - 실시간 웹 검색, 모든 응답에 인용. Team/Enterprise는 소유자가 조직 설정에서 먼저 켬. 새 Claude 환경에는 토글 없이 도움이 될 때 검색.

## 확인하지 못한 것
- Claude의 브레인스토밍·계획·표 작성, 초안 작성 관련 공식 문구(읽은 페이지에는 없음).
- Gemini의 계획·표·예산 관련 공식 문구, 웹 검색(최신 정보) 문구.
- 어느 서비스든 장소 시간·가격·예약 가능 정보의 최신성·완전성, 예약·초대장 발송·RSVP 취합·결제 대행 기능(시험 안 함).
- 이메일·캘린더 연결 가능 여부는 플랜·설정에 따라 달라 단정하지 않음.
- 지역별 허가·보험·식품 위생·주류 규정(확인하지 않음).
- 서비스별로 프롬프트 7개를 얼마나 잘 따르는지(실행 시험 안 함).
