# 04. 보고서·제안서 초안 쓰고 다듬기

## 핵심 사실
- 목적·독자·형식 명시, 이유 덧붙이기, 예시 주기, 후속 질문으로 다듬기. (출처: C04 노트의 공식 가이드, Get started with Claude)
- 프로젝트 지침/지식에 회사 문체·양식을 저장해 반복 사용. (출처: https://support.claude.com/en/articles/9517075-what-are-projects)
- 웹 검색 응답에는 인용 포함, Research는 다단계 조사로 인용 포함 답변. (출처: C10 노트: https://support.claude.com/en/articles/10684626-enable-and-use-web-search , https://support.claude.com/en/articles/11088861-use-research-on-claude)
- 파일 출력 .docx/.pptx/PDF 생성 가능, 파일당 30MB. (출처: https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)
- 아티팩트 Docs 템플릿은 Word/PDF/Markdown/Google Docs로 내보내기. (출처: C06 노트)

## 따라하기 절차
개요 먼저 → 항목별 초안 → 근거·수치 대조 → 톤 변경 → 반박 시뮬레이션 → docx 내보내기. (필자 구성)

## 확인 못 함
- 환각: 수치·인용은 사용자가 검증해야 한다는 일반 원칙(공식 문구는 개별 확인 못 함).
- ChatGPT·Gemini 문서 기능: 열람 불가.
