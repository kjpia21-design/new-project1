## 확인 못 함 (전부)
- ChatGPT: help.openai.com, openai.com, chatgpt.com, developers.openai.com 모두 CONNECT 403(조직 정책)으로 접속 불가. 가격·기능·한도·학습 정책 미확인.
- Gemini: support.google.com, gemini.google, gemini.google.com, ai.google.dev, blog.google 모두 접속 불가. 동일.
- WebSearch는 제3자 사이트만 반환(공식 아님) → 근거로 쓰지 않음. 검색 결과가 서로 다른 가격(예: Pro 이중 가격대)을 보여 줘 오히려 직접 확인 필요성만 확인.
