## 확인한 공식 페이지 (curl 기본 옵션, 한 페이지씩; -L만)
- Claude 대학 안내 https://support.claude.com/en/articles/11139144-use-claude-for-education-at-your-university (200)
  - 학생용 활용: Writing support = outline papers and essays, provide feedback on drafts, help with citations and bibliographies, suggest ways to improve clarity and structure. Important: 대학의 학업 윤리 정책을 따를 것, 혼자 해야 하는 과제를 끝내는 데 쓰면 안 됨. 대학이 기능을 바꾸거나 자체 정책을 적용했을 수 있음(대학 IT에 문의).
- Gemini 창의적 학습 https://support.google.com/gemini/answer/15216790 (200)
  - Important: 학교의 생성형 AI 사용 정책을 확인하고 따를 것. 아이디어 내기·글이 막힐 때 돕기. "You're the creator": 제안은 출발점, 내 목소리와 생각을 더할 것. 응답은 항상 평가·팩트체크(AI는 실수 가능).
- Claude 파일 업로드 https://support.claude.com/en/articles/8241126-upload-files-to-claude (200, 2026-07-23 표기)
  - 문서 PDF·DOCX·CSV·TXT·HTML·ODT·RTF·EPUB·JSON·XLSX(코드 실행·파일 생성 켜야). 채팅 업로드 파일당 500MB, 채팅당 20개, PDF 1000쪽.
- 보조: https://support.claude.com/sitemap.xml (영어 문서 목록에서 글쓰기 스타일 문서 없음 확인), https://learn.chatgpt.com/llms.txt (글 피드백·학교 정책 관련 항목 없음)
- 참고로만 읽음(본문 미사용): https://support.google.com/gemini/answer/14903178 (Gemini 파일 업로드)

## 확인하지 못한 것
- ChatGPT의 글 피드백·학교/학업 정책 안내(learn.chatgpt.com/llms.txt에 해당 항목 없음; https://learn.chatgpt.com/use-cases/llms.txt 는 404). help.openai.com은 시도하지 않음(이전 노트에서 403).
- Claude 글쓰기 스타일 기능(도움말 sitemap에 없음).
- 특정 학교·회사·공모전의 AI 규칙(주최 측이 정함, 공식 서비스 페이지에 없음). AI 작성 여부 판별·보증 기능.
- 각 서비스가 "코멘트만" 지시를 얼마나 잘 따르는지(시험하지 않음).
