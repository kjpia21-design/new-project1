# 31. AI로 외국어 공부하기 — 2026-10-15 기준 (K2)

## 확인한 공식 페이지 (curl, 한 페이지씩)
- Claude 음성 모드: https://support.claude.com/en/articles/11101966-using-voice-mode
  - 베타. Free·Pro·Max·Team·Enterprise 모두, 모바일(iOS·Android)·데스크톱·웹. 휴대폰에서 가장 잘 맞게 만들었다고 안내.
  - 웹/데스크톱: 입력창 오른쪽 아래 음파 기호. 모바일: 입력창의 음파 기호(마이크 옆). 핸즈프리(기본)와 푸시투토크 모드.
  - 음성 대화는 일반 사용량 한도에 포함. 대화 텍스트 기록은 채팅 기록에 저장됨.
  - 영어 외 언어 지원은 베타. 음성 언어: 설정(Settings) > 일반(General) > 음성(Voice) > 언어(Language). 앱 표시 언어를 바꿔도 음성 언어는 안 바뀜. 대화 중 언어를 바꿔 달라고 말해도 됨. 한국어가 목록에 있는지는 문서에 없음.
  - 활용 예에 Learning, Preparation(면접 연습)이 있음. Claude Fable은 음성 모드에서 사용 불가. Cowork·Claude Code에서는 받아쓰기만 가능.
- Gemini Live: https://support.google.com/gemini/answer/15274899
  - Android 폰·태블릿 + Gemini 모바일 앱. Gemini 웹 앱에서는 Live 불가. 시작: 앱 아래 Live 또는 왼쪽 스와이프, "Hey Google, let's talk Live".
  - "Practice aloud: 중요한 순간을 더 자연스럽게 예행연습" 문구. 카메라·화면 공유 가능. 종료 시 대화 기록(transcript) 확인, Live ↔ 텍스트 전환 가능. 일시 정지(Hold)·음소거 있음.
  - Gems는 Live에서 사용 불가. Live 지원 언어 목록·플랜 요건은 이 페이지에 없음. 타인을 녹음·포함하기 전에 허락을 구하라는 안내.
- Gemini 앱 언어 목록: https://support.google.com/gemini/answer/14579026 — Korean 포함(앱 언어 목록). Live 언어 지원과는 별개.
- ChatGPT Voice: https://learn.chatgpt.com/docs/features/voice (.md로 확인) — ChatGPT 데스크톱 앱, Plus·Pro·Business·Edu·Enterprise. 시작은 Start voice chat. 작업(Codex·Work) 조율 중심 설명. 휴대폰 앱의 회화 연습 용도와 무료 플랜 여부는 확인하지 못함.

## 확인하지 못한 것
- 각 서비스의 음성 한국어·영어 발음 품질, 발음 교정 정확도(공식 문서에 평가 없음).
- ChatGPT 휴대폰 음성, Gemini Live의 지원 언어 목록·유료 요건.
- AI 첨삭의 정확도 수치(공식 근거 없음 → "틀릴 수 있다"는 일반 주의로만 서술하고 수치 쓰지 않음).

## 본문 반영
- 학습 방법은 공식 확인 사실이 아닌 "써 보는 방법"으로 프롬프트 예시로만 제시. 앱 기능 설명은 위 확인 범위만.

## 재점검 (2026-10-19)
- Claude 음성 모드(전 플랜, 베타, Settings > General > Voice > Language), Gemini Live(Android 앱 도움말, 웹 불가), ChatGPT Voice(Plus·Pro·Business·Edu·Enterprise, 데스크톱 앱 중심) 모두 본문과 일치. 변경 없음.
