## 확인한 사실
- Claude in Chrome: 모든 유료 플랜, 사이드 패널 베타(Max/Team Cowork 세션, Pro 순차). 모드 Manual/Auto/Skip. 구매·계정 생성·거래·영구 삭제 불가. South Korea 제공 국가 목록 포함.
- ChatGPT: Browser는 웹·데스크톱 앱. 내장 브라우저는 별도 프로필, Settings > Browser. 확장: Chrome/Edge/Brave/Opera/Vivaldi, Settings > Computer Use, 사이트 권한 Allow once/Allow for this site/Allow for all sites/Decline. Work 클라우드 브라우저: 사이트 로그인은 웹·모바일 Plus/Pro, Enterprise/Edu 불가, 클라우드 브라우징은 Free·Go 제외 유료 플랜 모든 지역, Settings > Cloud browser(Always ask/Auto approve/Always allow). 구매·제출 등 확인 요청, 내장 브라우저는 파일 업로드 자동화 불가.
- Gemini: 작업(Tasks)은 AI Pro/Ultra, 개인 계정, 18세 이상, Keep Activity, Personal Intelligence 필요. EEA·나이지리아·스위스·영국 제외. 모바일 앱·Mac 앱·웹. Chrome auto browse는 데스크톱만, 로컬 Chrome 또는 원격 브라우저. Gemini 웹앱 지원 국가·언어 목록에 South Korea·Korean 포함.

## 확인하지 못한 것
- ChatGPT 내장 브라우저·확장의 플랜 조건, 가격. (help.openai.com 등 차단 사이트는 열지 않음)
- ChatGPT·Gemini 브라우저 기능의 한국어 지원 수준과 한국 제공 확정 문장(Work는 "all regions"만).
- Gemini 작업 기능의 한국 제공을 명시한 문장(제외 지역 목록에 한국 없음, 일반 지원 국가 목록에는 있음).
- Chrome auto browse 별도 도움말(미열람).
- 요금 수치(의도적으로 제외).
