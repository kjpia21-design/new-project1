## Confirmed
- Cowork: paid plans (Pro, Max, Ultra, Team, Enterprise); desktop on all paid plans (beta); web/mobile on Pro/Max/Ultra/Team (Team beta), Enterprise when owner enables. Example use cases (Downloads organizing, receipts to expense report, batch rename, research/transcript synthesis, spreadsheets with formulas). Explicit permission before permanent deletion. Scheduled tasks run in the cloud. Multi-step tasks use more usage. No session sharing (artifacts can be shared). Approval modes: Manual / Auto / Skip ("Manually approve", "Automatically approve", "Skip all approvals").
- Cowork safety: dedicated folder, backups, avoid sensitive financial docs; scheduled tasks: start simple, avoid sensitive data and consequential actions (messages, purchases), review each run, pause unused; Manually approve when mistakes are hard to undo; user remains responsible for messages, purchases, scheduled-task actions.
- Dots: describe result and sources; update/decision preferences; recurring-task fields; completed run is not confirmation; drafting replies does not permit sending; custom rules (Ask before taking action, Hand off to you; "sending messages to customers" given as example); pause does not cancel schedules; stopping does not undo.
- Gemini tasks: personal Google Account, 18+, Google AI Pro or Ultra, Keep Activity on, Personal Intelligence opt-in; not in EEA, Nigeria, Switzerland, UK; mobile app, Mac app, web only; do not enter sign-in/payment/sensitive info in thread; avoid sensitive schedules; file types PDF/DOCX/XLSX/PPTX etc.
