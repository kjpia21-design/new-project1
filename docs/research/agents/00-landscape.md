## 1. Muse (Meta)

**후보와 판단**
- (유력) Meta Muse: 개인용 에이전트 앱. Muse Spark 모델 기반.
- (비유력) "Muse Spark"는 같은 회사의 모델명(2026-04 공개로 보도)이므로 에이전트와 구분 필요. [검색요약/보도]
- (참고) 도메인 muse.ai는 Meta 공식 보도자료에서 Muse 에이전트 웹 주소로 쓰였다. 과거의 동명 서비스(예: 영상 호스팅 muse.ai, 뇌파 헤드밴드 등)와 혼동 가능하나, 2026 가을의 화제성은 Meta Muse가 압도적. 동명 타 제품의 현재 상태는 이번에 조사하지 않음.

**사실 정리**
- 공식명/회사: Muse / Meta. [공식-열람]
- 발표/출시: 2026-09-08 (미국). [공식-열람: 보도자료 게시일 2026-09-08, 수정 2026-09-30]
- 기능: 목표를 말하면 계획을 세우고 스스로 진행. 브라우저 열기, 양식 작성, 협상, 이메일 발송, 여행 예약 등. 앱을 닫아도 계속 작업하고, 이메일 발송/구매 같은 민감 작업은 승인 요청. 기억 기능(예: 인스타 릴스 레시피를 장보기 목록으로). Stripe Link로 결제(일회용 카드, 구매자 보호). Shop Pay, 1Password 지원 예정. [공식-열람]
- 구조: 사용자별 전용 클라우드 VM("Muse Secure VM") + 별도 "Sentinel" 에이전트가 외부 통신을 승인. 연말에 암호화된 "Muse Confidential VM" 예정. 학습 데이터 활용 거부(opt-out) 가능. [공식-열람]
- 플랫폼: iOS, Android, 웹(muse.ai), WhatsApp 대화 지원, AI 글라스 "곧 지원". [공식-열람]
- 후속: 9월 23일 Connect에서 비디오 아바타, macOS 앱 제어, 에이전트 전용 이메일, 스마트 글라스 접근 추가 / 9월 29일 소상공인 확대(Shopify, Dropbox, Slack) / 10월 7일경 iPad 앱. [보도: TechCrunch 제목·검색요약, 원문 미열람]
- 화제성: Sensor Tower 기준 미국 다운로드 250만+(9/23), 앱스토어 상위권 [검색요약: CNBC 10/07 보도 등]. 국내에서도 뉴스핌 "뮤즈 돌풍" 연재(2026-10-07), ZDNet Korea 칼럼(2026-09-26) 등 [검색 결과 제목 수준].
- 가격: 공식 보도자료는 "대부분 무료, 더 쓰려면 구독 플랜"이라고만 함 [공식-열람]. 월 $20(Power)/$100(Maximum)은 단일 매체 [보도-검색요약], 주간 1억 토큰 무료 제공은 메트로신문 [보도-열람]. 공식 가격표는 미확인.
- 한국 제공/한국어: **공식 제공 지역은 미국**으로 명시 [공식-열람: "rolling out in the US"]. 한국은 미포함, 국내 출시 일정 미정이며 VPN 우회 가입이 확산 중 [보도-열람 메트로신문; 검색요약 에펨코리아/newsspace]. 한국어 지원 여부는 확인하지 못함.
- 논란: 개인정보/권한 논란(애틀랜타 뉴스 퍼스트 10/09 등). 한 기자가 거부한 메시지 DB가 동기화됐다는 주장은 커뮤니티 글 기반이라 미검증. [검색요약]

## 2. Grok Bot (SpaceXAI / xAI)

**후보와 판단**
- (유력) Grok Bot: 상시 구동 에이전트 앱. 사용자 질문의 "grok bot"과 일치. xAI 사이트에서 "SpaceXAI" 브랜딩으로 표기됨 (SpaceX와의 결합 및 Cursor 연계는 보도 기준). [공식-열람: 사이트 푸터/네비게이션]
- (혼동 후보) X에서 멘션하는 챗봇 "@grok" 및 일반 Grok 챗봇. Grok Bot과는 별개 제품. [검색요약: layer3labs 글]
- 한국어 커뮤니티 글에서 "그록 봇 부러움 종료"처럼 Grok Bot이 이미 쓰이는 것을 확인 (제목 수준).

**사실 정리**
- 출시: 2026-08-11 베타. [공식-열람: x.ai 공지 본문 "launched Grok Bot in beta on August 11"]
- 확대: 공지 날짜 2026-08-26 (검색요약은 8/21이라 했으나 공식 페이지 표기는 Aug 26). 현재 SuperGrok, SuperGrok Plus, SuperGrok Heavy, Cursor Pro/Pro+/Ultra, Cursor Teams 플랜에 포함. Bot 전용 사용량이 별도로 제공됨. [공식-열람]
- 기능: 문자 스레드 UI로 메시지, 여러 Bot 동시 운용(그룹 채팅에서 서로 업무 전달), 각 Bot이 상시 켜진 클라우드 컴퓨터(브라우저, 터미널)를 갖고 사용자 앱에 로그인해 실제 도구에서 작업, 사용자가 한 번 시연하면 루틴으로 반복. 예: 영업 prospecting, 웹사이트 제작 및 도메인 구매/배포, 이메일/구독 정리, 고객 지원 환불, 미팅 대리 참석. [공식-열람]
- 플랫폼: 공식 페이지에 macOS 다운로드, iOS/Android 링크가 보임. Windows/Linux/Android는 보도마다 엇갈림. [공식-열람(부분); 검색요약]
- 가격: 별도 가격 없이 기존 구독에 포함. 메트로신문은 슈퍼그록 월 $30, 커서 프로 월 $20로 보도, 초과분은 Cursor 청구 [보도-열람]. 8월 초 베타는 SuperGrok Heavy(약 $300/월) 등 고가 플랜 한정이었음 [검색요약].
- 한국: 메트로신문은 "한국 앱스토어에 배포, 유료 계정 연결로 이용" [보도-열람]. 한국어 지원 여부는 미확인. 출시 한 달 만에 이용자 40만+라는 수치는 AI 검색 요약에서만 나옴(출처 불명, 사용 비권장).
- 주의: 일부 블로그가 규제 인증(SOC2 등) 미공시, 모든 Bot이 한 컴퓨터를 공유한다는 문서 내용을 지적함 [검색요약, 2차 자료].

**공식 URL**
- https://x.ai/news/grok-bot-more-plans [공식-열람]
- 제품 페이지/문서(x.ai 내 Grok Bot, Documentation): 네비게이션 링크만 확인, 직접 열람 안 함
- 앱스토어 리스팅: 미확인

## 3. Dot / Dots (OpenAI)

**후보와 판단**
- (유력) OpenAI Dots: 제품군 이름은 "Dots", 사용자가 만드는 개별 에이전트가 "dot". 한국 언론은 "닷츠(dots)", "닷". 사용자의 "dot"은 이 제품일 가능성이 높음. [보도-열람 메트로신문]
- (비유력) 동명의 자체 호스팅 프로젝트 "OpenDots" (OpenAI와 무관) [검색요약, X 게시물].
- (비유력/미확인) 기억상 "Dot"이라는 개인 AI 동반자 앱(New Computer사)이 존재했으나 현재 상태는 이번에 확인하지 못함. 배제 근거는 없으므로 사이트 운영자가 사용자 의도를 확인하는 것이 안전.

**사실 정리**
- 공개: 2026-09-29, DevDay 2026, 샌프란시스코. [보도-열람 메트로신문; 검색요약 다수(TechCrunch, VentureBeat, Technology.org)]
- 기능: ChatGPT 안에서 상시 작동하는 에이전트. 각 dot이 전용 클라우드 컴퓨터와 브라우저 보유, 앱 연동(검색요약: 4,000개 이상 앱), 사용자가 작업하지 않을 때 연결 앱을 살피는 읽기 전용 "능동적 리서치", 진행 상황/질문을 먼저 메시지로 전달, 허용/차단/승인 규칙 설정, 피드백으로 선호 학습. 팀 협업 공간 "ChatGPT Space"도 함께 보도(VentureBeat 제목). [보도/검색요약]
- 모델: GPT-6 Astra 기반이라는 보도가 있으나 보도마다 모델명 설명이 엇갈림 [검색요약, 신뢰 낮음].
- 요금: ChatGPT Pro(월 $100부터), Business Premium, Enterprise 포함 [보도-열람 메트로신문]. 추가 요금 없음 [검색요약]. dot과의 대화는 ChatGPT 한도에서 차감되지 않으나 dot이 실행하는 Codex/ChatGPT Work 작업에는 기존 한도 적용 [보도-열람].
- 한국: 메트로신문은 "한국에서 순차 제공 중, 최초 생성은 데스크톱 앱 또는 웹에서"라고 보도 [보도-열람]. 반면 일부 영어 매체는 EEA/스위스/영국 제외, 한국 언급 없음이라고 함 [검색요약]. 한국어 음성은 아직 어색하다는 유튜버 후기 인용 [보도-열람].
- 공식 페이지: OpenAI 도움말/공지는 curl 403으로 열람 못함. 한국어 공지 URL은 검색 결과에서 인용된 것 [검색요약].

**공식 URL**
- https://openai.com/ko-KR/index/introducing-dots/ [검색요약에서 인용된 URL, 열람 실패(403)]
- OpenAI 도움말센터 Dots 지원 지역 문서: URL 미확인

## 5. 사이트 운영자가 확인/결정할 사항

1. **dot의 정체**: OpenAI Dots(닷츠)로 보지만, 사용자가 다른 "Dot"(예: 동명의 AI 동반자 앱)을 뜻했을 가능성이 완전히 배제되지는 않았다. 원 질문자에게 확인 권장.
2. **Muse 한국 가용성**: Meta 공식은 미국 한정. 한국 사용자는 VPN 우회 중이므로, 사이트에서 "한국 미출시"로 명시하고 우회 이용을 권장하지 않는 편이 안전하다. 일부 외신 요약은 "미국과 캐나다"라고 하나 공식 문서에서는 확인되지 않음.
3. **Dots 한국 제공**: 국내 보도(순차 제공)와 영어권 보도(제외 지역에 한국 언급 없음)가 다르며 OpenAI 공식 페이지를 열람하지 못했다. 게시 전 OpenAI 도움말센터에서 재확인 필요.
4. **가격 수치**: Muse 월 $20/$100, Grok Bot 포함 플랜 가격, Dots 월 $100부터는 모두 공식 가격표가 아닌 보도 기준. 가격을 게시하려면 공식 가격 페이지 확인 필요.
5. **한국어 지원**: 세 제품 모두 공식 근거로 확인된 한국어 지원 문구는 없다. 유일한 단서는 Dots 한국어 음성이 어색하다는 유튜버 후기.
6. **수치 인용 주의**: Grok Bot 이용자 40만 명, Sensor Tower 250만 다운로드 등은 2차 출처 또는 단일 출처이므로 게시 시 출처 병기 또는 제외.
7. **확대 날짜**: Grok Bot 플랜 확대일은 검색 요약 8/21과 공식 페이지 표기 8/26이 달랐다. 공식 페이지를 따랐다.
