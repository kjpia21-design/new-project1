## 사이트 영향

- claude-news 두 언어판에 2건 추가, 마지막 업데이트 날짜 2026-11-17로 변경.
- 튜토리얼: 수정 없음. coding 40(설정과 권한)은 `bypassPermissions`를 "프롬프트를 건너뜀", 표에서는 "어떤 모드도 자동 승인하지 않는 짧은 목록 제외"로 설명함. 2.1.326은 "일부 도구 호출"이라고만 적어 어떤 호출인지 특정되지 않으므로 문장을 고치지 않음. 다음 월요일 전체 점검 때 권한 모드 문서(https://code.claude.com/docs/en/permission-modes)를 다시 읽고 판단.

## 확인 못 한 것

- 2.1.326에서 bypass permissions 모드에서도 묻게 된 "일부 도구 호출"의 구체적인 목록(변경 이력에 없음).
- 2.1.326의 버그 수정 233건은 읽지 않음(보안 관련 키워드 검색에서는 해당 줄 없음).
