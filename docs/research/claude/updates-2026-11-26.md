## 사이트 영향

- claude-news 두 언어판에 1건 추가(11-25 Claude Code 2.1.332), 마지막 업데이트 날짜 2026-11-26으로 변경.
- 튜토리얼 수정 없음. C15(모델 분업)는 이미 "Bedrock·Foundry 등 다른 제공자에서는 버전이 다를 수 있고 별칭은 바뀐다"고 적고 있고, C18(반복 작업 자동화)은 이미 "cloud scheduled tasks"라는 새 이름을 적고 있어 어긋나는 문장이 없음. 음성 받아쓰기 시간(15초/2분)을 적은 튜토리얼도 없음.
- 열려 있는 롤링 PR #61(`claude/site-update-2026-11-25`)에 이어서 반영.

## 확인 못 한 것

- 변경 이력 페이지(code.claude.com)는 앞부분만 읽어 버전별 날짜만 확인. 본문은 CHANGELOG.md 원문 기준.
- 2.1.332의 self-hosted runner, OpenTelemetry, Code Mode 세부 수정은 실무 사용자 대상이 아니어서 사이트에 싣지 않음.
- 이전 노트의 미확인 항목(아티팩트 앱 설치 도움말 뒷부분, 파일 전송 지원 커넥터 목록, 예약 작업 문서의 30일 반영 시점, easel 제공 범위, EFS 대상 모델 목록 등)은 그대로 미확인.
