# C20·C21 조사 노트 (Claude Design, Claude for Excel·PowerPoint)

확인일 2026-10-31. 공식 페이지를 한 번에 하나씩 curl로 받아 읽었다.

## C20 Claude Design
출처: https://support.claude.com/en/articles/14604416-get-started-with-claude-design
- Claude Design = 대화+캔버스로 디자인·인터랙티브 프로토타입·원페이저 제작. 아티팩트 템플릿의 하나. 어느 대화, Artifacts 탭, Claude Code(`/design`), iOS·Android 앱(공유 설정은 웹/데스크톱)에서 사용.
- 플랜: Free, Pro, Max, Ultra, Team, Enterprise, 기본 켜짐. Enterprise는 2026-10-15 기본 켜짐(그 전엔 Organization settings > Artifacts에서 소유자가 켬).
- 독립 버전 claude.ai/design은 2026-12-14 종료. 기존 프로젝트는 그때까지 유지, 이전 기능은 유료 플랜부터 순차 제공. 디자인 시스템은 종료 전 이전 안내.
- 디자인 시스템: 새 프로젝트는 조직 시스템 자동 상속. GitHub 저장소·디자인 파일·업로드·`/design-sync`로 가져옴. Enterprise 관리자는 게시/기본 설정/삭제 권한 제한 가능.
- 프롬프트 요소: 목표·배치·내용·대상. 수정: 채팅(큰 변경)/인라인 코멘트(부분)/캔버스 직접 편집(빠른 시각 수정).
- 내보내기: .zip, PDF, PPTX, Google Slides, 독립 HTML, 외부 도구 전송(Canva, Gamma, HubSpot, Miro, Netlify, Replit, v0, Vercel, Wix 등), 로컬 코딩 에이전트/Claude Code 웹으로 인계. 공유: 기본 비공개, 보기·댓글·편집.
- 사용량: Claude 전체와 같은 한도 공유(예전 전용 주간 한도 없어짐). 한도 도달 시 리셋까지 불가, usage credits 켜면 계속.
- 알려진 한계: 코멘트 간헐 누락(채팅에 붙여 넣기), 큰 저장소 지연(`/design-sync`), chat upstream error(새 채팅 탭), 모바일 공유 설정 불가, 동시 편집 불안정, 버전 기록 없음, 레이어 목록 삭제 동작 주의, 키보드만으로 새 요소 추가 불가. 키보드 단축키 표 있음.

### 확인하지 못한 것
- Design에서 쓰는 모델, 한국어/한글 글꼴 지원 범위, 플랜별 사용량 수치, "Move from standalone" 문서의 세부 절차(이번에 읽지 않음).

## C21 Claude for Excel·PowerPoint (Claude for M365)
출처(모두 claude.com/docs/office-agents/...): overview(페이지 이름 "Claude for M365 overview"), excel.md, powerpoint.md, work-across-apps.md, connectors-and-skills.md, performance.md. llms.txt 목록에서 Word·Outlook·dictation·third-party·enterprise-readiness·opentelemetry·data-storage 페이지 존재 확인(Word/Outlook/dictation 본문은 읽지 않음, 개요 설명만 인용).
- 애드인: Excel, PowerPoint, Word, Outlook. Pro/Max/Team/Enterprise에서 GA. 설치: Microsoft AppSource "Claude for Microsoft 365" > Get it now > 앱에서 활성화 > Claude 계정 로그인. 활성화 위치: Mac Tools>Add-ins, Windows Home>Add-ins.
- 지원: 웹, Windows(M365, 빌드 16.0.13127.20296+), Mac(Excel 16.46+ 빌드 21011600+, PowerPoint 16.46+). 미지원: 2016/2019 영구·볼륨, iPad, Android, SharedRuntime 미만 빌드.
- Excel 기능: 셀 인용 답변, 수식 관계 유지한 값 변경, 오류 원인 추적, 모델 생성/템플릿 채우기, 멀티탭, 정렬·필터·피벗·조건부 서식·유효성 드롭다운. 미지원: 데이터 테이블, 매크로/VBA. 덮어쓰기 전 경고.
- PowerPoint 기능: 템플릿(슬라이드 마스터) 기반 생성, 부분 수정, 전체 덱 생성, 글머리표→도식/네이티브 차트. 최종 고객 납품물·민감 데이터·디자인 판단 대체 비권장.
- Instructions는 앱별. 커넥터는 + > Connectors(S&P Global, LSEG, Daloopa 등). 스킬은 설정에서 켠 것이 적용, `/`로 호출(예 /deck-check).
- 앱 간 작업: "Let Claude work across files" 설정, Pro/Max 기본 켜짐·Team/Enterprise 기본 꺼짐, 기기별, 제3자 플랫폼 연결에서는 미지원.
- 한도: 코드 실행 단계 90초, 그 외 5분(웹 2분), Word 편집 30초, Excel 한 번 읽기 2,000셀 등. 데이터: 30일 내 백엔드 삭제, 채팅 기록은 브라우저 IndexedDB, 사용자 지정 보존 설정 상속 안 함, Enterprise 감사 로그 미포함(Compliance API 켜면 포함).
- 경고: 2026년 9~10월 M365 업데이트 후 Windows에서 채팅 기록·스킬 누락 문제(해결 중). 프롬프트 인젝션 경고.

### 확인하지 못한 것
- 한국어 지원 범위/한국 제공 문구, 플랜별 사용량 수치, 모델 목록(계정마다 다름), Word·Outlook 세부 사용법.
