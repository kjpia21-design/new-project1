## Verified facts
- Pricing feature table: Claude Code No on Free; Yes on Pro, Max, Ultra, Team, Enterprise.
- Free $0; Pro $17/mo annual ($200 up front), $20 monthly; Max $100; Ultra $200; Team standard $20 annual/$25 monthly, premium $100/$125; Enterprise US$20/seat/mo annual, 20-seat minimum, usage at API rates. Prices exclude tax.
- Pro/Max/Ultra help: one subscription for Claude and Claude Code; limits shared; IDEs covered; Pro/Max 5-hour + weekly limits; Ultra weekly, verified accounts no 5-hour; wrap-up allowance (gradual rollout); options on hitting limits; ANTHROPIC_API_KEY overrides subscription; Max/Ultra/Team monthly API credits cannot be used in Claude Code; /status shows allocation.
- Team/Enterprise help: Claude Code in every Team seat, premium seats more usage; new/self-serve Enterprise seat includes it with usage-based billing at API rates; older Enterprise seat types; HIPAA caveat; desktop Code tab recommended.
- Docs: Claude Code charges by API token consumption; enterprise average about $13 per developer per active day, $150-250 per month, 90% under $30 per active day. Overview: most surfaces require a Claude subscription or Console account; desktop app requires paid subscription; web needs no local setup.
