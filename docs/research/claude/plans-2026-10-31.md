## Verified facts
- Free $0. Pro $17/mo billed annually ($200 up front), $20 monthly. More usage than Free every 5 hours and every week. Fable only via usage credits.
- Max $100/mo (monthly): 5x Pro usage every 5 hours and every week; Fable included up to half the weekly limit; $100/mo API credits.
- Ultra $200/mo (monthly): everything in Max; no 5-hour limit for verified accounts; 10x Pro weekly usage; $200/mo API credits.
- "Max 5x / Max 20x" no longer appear. Max and Ultra both have a separate weekly Fable limit (Claude Code help). Fable help page: up to 50% of weekly limits on Max, Ultra, premium Team/Enterprise seats.
- API credits do not cover Claude Code or extra usage in the apps.
- Team: standard $20 annual / $25 monthly; premium $100 / $125 (unchanged).
- Cowork: Desktop for macOS, Windows, and Linux (beta) on all paid plans; web and mobile on Pro, Max, Ultra, Team (beta on Team); Chrome side panel on all paid plans. Local files, browser, and computer use need the macOS or Windows desktop app.
