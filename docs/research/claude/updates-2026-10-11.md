### (b) 낡았거나 어긋난 부분

- **c14 (권한 모드 표, 263행)**: "`auto` | 분류기가 백그라운드에서 안전 검사". 바뀐 점: 직접 Anthropic API, Claude API, Enterprise, Bedrock/Vertex/Foundry에서 서버 측 분류기가 기본이고(2.1.278, 2.1.282), 서드파티 제공자나 텔레메트리 OFF 세션은 권한 모드를 정하지 않으면 auto로 시작해요(2.1.283). `/permissions`에 Auto mode 탭, `/status`에 Auto mode server 행이 생겼어요. "분류기(서버 측이 기본일 수 있음)" 정도로 보완 권장.
- **c03 (40행, 설명 부분)**: "Cowork와 채팅이 하나의 Claude로 통합되는 중이에요. 계정마다 시점이 달라요." 9/16 공지로 Cowork가 모든 대화에서 쓸 수 있게 롤아웃되고, 디자인·슬라이드·문서 생성도 어느 대화에서나 가능해졌어요. "Pro·Max 순차 롤아웃 중, Enterprise는 문서 생성 베타·기본 꺼짐"으로 구체화 권장.
- **c06 (32행)**: 아티팩트를 "대화 옆에 열리는 결과물"로만 설명. 9/16부터 디자인·슬라이드·문서를 어느 대화에서나 만들 수 있다는 점과 연결하는 한 줄이 필요해요. 또 203행 "Claude Code도 쓸 수 있어요 ... 지원센터 검색 요약 기준" 은 2.1.275(루틴이 편집 가능한 아티팩트를 확인 없이 갱신)와 2.1.288 이후 Cowork의 Artifact 도구 제한 등 공식 근거로 확인된 내용으로 갱신 가능해요.
- **c08 (180행)**: "Claude Code v2.1.273 이상에서 세션 시작 때 동기화". 현재는 약 40분 간격으로 확인(2.1.293), `syncClaudeAiSkills`로 끌 수 있고, 클라우드 세션에서는 이름이 `anthropic-skills:<name>`, 같은 이름공간 로컬 스킬은 로드되지 않아요(2.1.282). 보완 필요. 210행 번들 스킬 목록에 `/skill-doctor`, `/doctor prompt-audit` 추가 가능.
- **c11 (Chrome)**: Chrome이 조직 관리자 설정을 따르고(2.1.260), 프로젝트 설정으로는 켤 수 없고 `--chrome`, `/chrome`, 사용자 설정으로만 켜요(2.1.290). 본문의 "Claude Code에서 켜는 법" 설명에 "프로젝트의 .claude/settings.json으로는 못 켠다" 추가 권장(본문 해당 문장 미확인, 확인 필요).
- **c13 (루틴/클라우드)**: 루틴이 편집 가능한 아티팩트를 갱신하고(2.1.275), 클라우드/원격 세션에서 fast mode(2.1.271)와 `gh api` 내장(2.1.288)이 생겼어요. 본문에 없어서 "빠진 정보" 수준이에요.
- **c16 (API)**: 가격·모델 ID는 정확하지만, 같은 문서의 "Haiku 5.5 $0.10부터 / $0.50부터"는 그대로 맞아요. 반면 다음은 빠져 있어요: Opus 5.5는 thinking을 끌 수 없고 `tool_choice` `any`/`tool`이 오류, Haiku 5.5에서 `budget_tokens`와 샘플링 파라미터가 400 오류, Fable 5.1/Mythos 5.1은 30일 보관이 필요해 ZDR 불가. 첫 호출 예제를 모델만 바꿔 돌리는 독자가 오류를 만날 수 있어서 우선순위 높아요. 또 Workbench가 Playground가 된 점, Python SDK 1.0(`anthropic` 0.x에서 1.x), Files API와 Agent Skills GA도 반영 필요.
- **c01 (66행)**: 이전 세대 목록에 Sonnet 4.5를 쓰는 독자를 위해 "Sonnet 4.5는 2026-11-30 퇴역 예정" 추가 권장(현재 본문에 Sonnet 4.5 언급 없음). Opus 4.1은 이미 8/5 퇴역.
- **c02 (103행 주변 "클라우드 세션 크레딧" Aside)**: "2026-10-10 기준 공식 문서에 설명이 아직 없어요"는 이번 점검에서도 릴리스 노트에서 해당 항목을 찾지 못해 유효해요(수정 불필요, 재확인만).
- **agents/01, agents/05**: Claude 관련 서술(Chrome, Cowork, 커넥터)은 이번 변경과 충돌하는 문장을 찾지 못했어요. 9/16 Cowork 확대와 스킬·플러그인 보안 스캔(8/6)을 안전 점검표에 한 줄 추가 가능한 정도예요.
