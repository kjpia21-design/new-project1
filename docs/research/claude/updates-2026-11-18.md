## 사이트 영향

- claude-news 두 언어판에 3건 추가, 마지막 업데이트 날짜 2026-11-18로 변경.
- C22(데스크톱 앱): "자동 업데이트를 설명하는 문서는 찾지 못했다"는 문장을 릴리스 채널 설명으로 교체(영·한). 출처는 이미 frontmatter에 있는 Install Claude Desktop 문서. lastVerified 2026-11-18.
- 그 밖의 튜토리얼: 수정 없음. dev 05·coding 41의 `claude mcp add-json <name> '<json>'` 표기는 여전히 유효(stdin 방식은 추가 옵션). dev 07·coding 42의 `/install-github-app` 설명도 그대로 맞음(확인 단계만 추가).

## 확인 못 한 것

- 한국어 UI에서 Release channel 메뉴의 표기(공식 문서에 없음).
- Linked billing 문서의 뒷부분(약 2만 4천 자)은 읽지 않음.
- auto 모드의 분류기 요청 대체 동작이 없어지는 릴리스 버전·날짜(변경 이력에 없음).
- 2.1.326에서 bypass permissions 모드에서도 묻게 된 "일부 도구 호출"의 목록은 여전히 미확인(다음 월요일 점검 때 권한 모드 문서 재확인).
