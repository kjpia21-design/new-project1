## 사이트 영향

- claude-news 두 언어판에 1건(두 버전을 한 항목으로) 추가, 마지막 업데이트 날짜 2026-11-20으로 변경.
- C14(Claude Code 핵심 기능): 훅 실패 시 `"onFailure": "block"`을 넣을 수 있는 훅 종류에 `mcp_tool`(v2.1.328 이상) 추가(영·한). Hooks reference(https://code.claude.com/docs/en/hooks)를 읽어 확인하고 sources에 추가. lastVerified 2026-11-20.
- coding 42(AI 코드 리뷰): 수정 없음. 변경 이력은 대상 없는 `/code-review`가 "대부분의 모델에서" 기본 브랜치와 비교한다고 하지만, 공식 문서(https://code.claude.com/docs/en/code-review-local)는 아직 "업스트림보다 앞선 커밋 + 커밋하지 않은 변경"이라고 적고 있어 튜토리얼 문장과 일치. 문서가 바뀌면 월요일 점검 때 반영.

- 한국어 UI에서 Release channel 메뉴의 표기(공식 문서에 없음).
