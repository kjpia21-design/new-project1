# Basics 23: Free AI tools (2026-11-23)

Read with plain curl (default options, -L), one page at a time; text extracted locally. All "as of 2026-11-23".
- https://claude.com/pricing (200): Free $0, "Limited usage every 5 hours and every week"; chat on web/desktop/mobile; search the web, create files, run code; memory; connectors; Artifacts; Claude Design, Slides, Docs. Pro text says it adds Claude Code (so Claude Code is not listed for Free). FAQ: usage depends on conversation length, model, features; no fixed message count.
- https://gemini.google/subscriptions/ (200): Free $0/month with a Google Account: Gemini app with auto model selection, image generation and editing, Deep Research, Gemini Live, Canvas, Skills, Google Flow (limited access incl. Nano Banana Pro), Gemini Notebook, 15 GB storage.
- https://support.google.com/gemini/answer/16275805 (200): without an AI plan = standard limits, 32k-token context; limits may change without notice; Deep Research etc. may be unavailable at busy times for users without a plan; a table of per-feature availability uses icons, so per-feature free/paid marks were NOT readable.
- https://learn.chatgpt.com/docs/pricing (200): page is about ChatGPT Work and Codex; Free $0/month, "GPT-6 Luna at Standard speed in the desktop app, subject to rollout"; "Image generation isn't available on the Free plan" (in the Codex context). Regular chat limits for Free not given.
- https://learn.chatgpt.com/docs/features/voice.md (200): ChatGPT Voice in the desktop app for Plus, Pro, Business, Edu, Enterprise (Free not listed).
- https://learn.chatgpt.com/docs/image-generation.md (200): "Image availability and usage limits in ChatGPT web depend on your plan and workspace settings." No free-tier statement for web chat.
- https://www.deepl.com/en/pro (200): plan comparison table: Free version text translation 50,000 characters/month, 1 file translation/month (up to 5 MB), 1 glossary with 5 entries; Individual 300,000 characters/month, 3 files. "No data training" row uses icons, so free-version value not readable.
- https://docs.github.com/en/copilot/get-started/plans (200): Copilot Free: free, limited access, an allowance of GitHub AI Credits, limited agents, auto model selection only; individuals without org access only. Copilot Student free for verified students. Copilot Pro $10/month.
- https://kanana.kakao.com/ (200): Kanana in KakaoTalk; usable after sign-up on KakaoTalk with supported on-device-AI devices (iPhone 14 Pro and later, Galaxy S22 and later, some foldables). No price stated. Page says original chat text is processed on-device only.
- https://papago.naver.com/ (200, mostly JS shell): tabs Text, Image, Document, Voice, Website; "Plus-only feature" marker; no price/limit text.
- https://support.google.com/translate/answer/6142478 (200): how to translate text in the Android app; no price or limit text.
