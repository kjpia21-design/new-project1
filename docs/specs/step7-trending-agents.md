## 공통 규칙

- 구조·문체·정확성 규칙은 `docs/specs/step2-samples.md` ~ `step6`를 따른다. 9개 섹션 구조, 한눈에 요약, 출처 자동 표시도 그대로다.
- **공식 출처 우선**: 회사 발표 페이지, 공식 도움말, 공식 앱 스토어 등록 페이지를 쓴다. 참고할 만한 곳:
  - Meta: about.fb.com, Muse 공식 사이트
  - xAI: x.ai/news, docs.x.ai
  - OpenAI: developers.openai.com, ChatGPT 앱 스토어 등록 페이지
- **뉴스 기사는 보조로만** 쓸 수 있다. 쓸 때는 본문에 "언론 보도 기준"이라고 밝히고, 숫자(다운로드 수, 사용자 수, 투자액)는 공식 출처가 없으면 쓰지 않는다.
- **한국에서 쓸 수 있는지**, **한국어를 지원하는지**를 각 편에서 반드시 명확히 다룬다.
  - 공식적으로 제공되지 않는 곳에서 VPN 등으로 우회 가입하는 방법은 **안내하지 않는다**. 약관 위반 가능성을 짚는다.
  - 한국에서 쓸 수 없는 제품(Muse)은 "무엇인지, 무엇을 할 수 있는지, 한국 출시 전 알아둘 점" 중심으로 쓴다.
- 결제·계정 권한을 주는 기능(예: Muse의 결제 연동)은 위험과 주의점을 반드시 포함한다.
- 페이지 읽기 방식: WebFetch가 호스트를 찾지 못하면 `curl -sL -m 20 -A "Mozilla/5.0" <url>`을 한 번에 한 페이지씩 쓴다. 대량 다운로드는 금지하고, 권한 시스템이 거부하면 우회하지 말고 보고한다.
- 편마다 조사 노트를 `docs/research/agents/NN-<slug>.md`에 남긴다. 형식은 기존 노트와 같다.
- git 커밋·푸시는 하지 않는다. 끝나면 `npm run build`를 실행한다.

## X1 — 사이트 구조 (설정과 컴포넌트)

1. `src/content.config.ts`: `category` enum에 `'agents'`를 추가한다.
2. `astro.config.mjs` 사이드바: "Claude 완전 정복" 다음에 **"화제의 AI 에이전트"** 그룹을 넣는다. autogenerate `agents`를 쓰고, 다른 분야 그룹과 같은 형식으로 만든다.
3. 분야 라벨과 아이콘을 쓰는 모든 곳에 `agents`를 추가한다: TutorialGrid, TutorialMeta, CategoryCards, `/tutorials/` 필터, start 페이지 등.
   - 아이콘은 기존 인라인 SVG 스타일을 따르고, 브랜드 로고는 쓰지 않는다.
   - `grep -rn "automation" src/` 결과를 기준으로 빠진 곳이 없게 한다.
4. 홈: "Claude 완전 정복" 배너 아래에 **"새로 나온 화제의 AI 에이전트"** 배너나 카드를 추가한다. 기존 디자인 언어(코랄 계열 카드)를 따른다.
5. `agents/index.mdx`: 섹션 소개(개인 AI 에이전트란 무엇인지 2~3문단)와 편 목록.
6. 나머지 다섯 편은 다른 에이전트가 쓴다. 빌드가 깨지지 않도록 **status: draft인 최소 placeholder 파일**을 먼저 만들어 둔다. frontmatter는 위 표대로 채운다.
   - 다른 에이전트가 이 파일을 덮어쓴다. X1은 placeholder를 만든 뒤에는 이 파일들을 다시 수정하지 않는다.
7. 라이트·다크, 375·1280px에서 홈과 `/tutorials/?category=agents`를 확인하고, 스크린샷을 `docs/screenshots/step7/`에 저장한다.

## X2·X3·X4 — 제품별 편

각 편에 반드시 들어갈 것:
- 무엇인가
- 누가 만들었고 언제 나왔나
- 할 수 있는 일
- 플랫폼
- 요금제(포함 플랜)
- 한국 제공 여부와 한국어 지원
- 시작하는 법: 한국에서 쓸 수 있는 경우만, 공식 절차 기준
- 결제·권한·개인정보 주의점
- 다른 에이전트와 다른 점

각 편의 조사 노트에는 X5가 비교표를 만들 수 있도록 **"비교표용 요약"** 절을 둔다. 항목은 다음과 같다.
- 출시일
- 플랫폼
- 요금
- 한국 제공
- 한국어
- 상시 작동 여부
- 외부 서비스 연동
- 결제 기능
- 확인 수준

## X5 — 비교 편과 안전 편 (X2~X4가 끝난 뒤 실행)

- **01**: 개인 AI 에이전트의 개념을 설명하고(채팅 AI와 어떻게 다른지), Muse·Grok Bot·Dots·Claude(Cowork, 루틴 등 기존 C편 근거)를 비교표로 정리한다. 이어서 "나에게 맞는 선택" 가이드를 넣는다. 수치는 X2~X4 노트와 기존 C편에서 확인된 것만 쓴다.
- **05**: 에이전트에게 결제·이메일·계정 권한을 줄 때의 위험과 점검표를 쓴다.
  - 예: 결제 상한, 승인 단계, 연결 서비스 최소화, 로그 확인, 공유 기기 주의, 개인정보.
  - 각 제품의 공식 안전 기능은 X2~X4 노트 근거로만 쓴다.
  - 일반 원칙은 기존 C11(Chrome·컴퓨터 사용), C13(루틴)의 공식 근거와 연결한다.
