# 작업 명세 — 5단계: 공식 원문 대조와 빈칸 채우기

작성: 기획 담당 · 구현: 코딩 에이전트

## 배경

4단계에서는 네트워크 정책 때문에 Anthropic 외 공식 사이트를 열 수 없었다. 그래서 일부 튜토리얼을 "검색 요약"을 근거로 썼고, 해당 페이지에 "확인 중인 튜토리얼이에요" 안내를 붙였다.

이제 다음 사이트는 열린다(2026-10-10 확인).
- support.google.com, gemini.google
- notion.com
- zapier.com, help.make.com
- cursor.com
- docs.github.com
- elevenlabs.io

다음 사이트는 여전히 403이다. 사이트 쪽에서 자동 접근을 막는 것으로 보인다.
- help.openai.com, openai.com, chatgpt.com
- canva.com, help.canva.com

이 사이트들도 WebFetch로 한 번은 다시 시도한다. 그래도 안 되면 기존 검색 요약 근거를 유지하고, 본문에서 단정하지 않는 원칙을 지킨다.

## 할 일 (담당 편마다)

1. **원문 대조**: 조사 노트 `docs/research/<분야>/`에서 "검색 요약"으로 표시된 항목을 WebFetch로 원문을 열어 확인한다.
   - 맞으면 노트 표시를 "원문 확인"으로 바꾼다.
   - 다르면 노트와 본문을 원문대로 고친다.
   - 원문에서 찾을 수 없으면 본문에서 그 내용을 삭제하거나 단정하지 않게 바꾼다.
2. **빈칸 채우기**: "공식 페이지에서 확인하세요"로 남겨 둔 가격, 무료 한도, 메뉴 이름, 한국어 지원 여부 가운데 이제 원문으로 확인 가능한 것은 채운다.
   - 가격과 한도에는 "2026-10-10 기준"을 붙인다.
   - 지역(미국/한국) 차이가 있으면 밝힌다.
3. **안내 제거 기준**: 편의 핵심 사실(따라하기 절차, 주요 메뉴, 가격·한도 표)이 모두 원문으로 확인되면 "확인 중인 튜토리얼이에요" Aside를 지운다.
   - 핵심 사실 가운데 하나라도 원문 확인이 안 되면 Aside를 남긴다.
   - 남길 때는 Aside 문구를 무엇이 미확인인지 구체적으로 바꾼다(예: "Canva 공식 도움말 원문은 아직 확인하지 못했어요").
4. **frontmatter**: `sources`를 실제로 대조한 원문 URL로 갱신한다(검색 요약 표시 제거 등). `lastVerified: 2026-10-10`은 유지한다.

## 규칙

- 구조, 문체, 정확성 규칙은 `docs/specs/step2-samples.md`, `step3`, `step4`를 그대로 따른다.
- 수정할 수 있는 파일은 담당 편의 `.mdx`와 해당 조사 노트뿐이다.
- 내용을 크게 다시 쓰지 말고 **사실 교정과 빈칸 채우기**에 집중한다.
- git 커밋·푸시 금지. 끝나면 `npm run build`를 돌린다.
