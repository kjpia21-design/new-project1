# 작업 명세 — 37단계: 레이아웃·구조 2단계 (P2 구조 개편)

작성: 기획 담당 · 구현: 코딩 에이전트 3명 (M1~M3)

배경: 1단계(`step36-layout-p1.md`, PR #62)로 메뉴·이름·홈 칩 벽·튜토리얼 윗부분을 정리했다. 2단계에서는 사이트 주인이 다시 찾아왔을 때 "어디까지 봤고 다음에 뭘 볼지"가 한눈에 보이게 한다. 시안은 `home.html`과 `tutorial.html`(scratchpad의 `ia/mockups`)에 있다. 시안 숫자는 가짜 데이터다.

## 공통 규칙
- URL과 슬러그를 바꾸지 않는다. 영어와 한국어 두 언어를 똑같이 반영한다. 문구는 `t()`나 컴포넌트 안의 언어 분기를 쓴다.
- 정적 사이트로 유지한다. 새 추적 도구는 넣지 않는다. 새 localStorage 키도 만들지 않는다. 기존 `atc:progress:v1`과 `atc:last`만 읽는다.
- `Head.astro`, `claude-news.mdx`, `weekly.mdx` 본문은 건드리지 않는다. `weekly.mdx`는 읽기만 한다.
- JS가 꺼져 있어도 쓸 만한 화면이 나와야 한다. JS가 꺼지면 첫 방문 화면이 나온다.
- 빌드: `npx astro build --outDir /tmp/build-<담당>`. 공유 캐시 충돌이나 다른 에이전트가 작업 중인 파일 때문에 오류가 나면 잠시 후 재시도한다.
- git 커밋·푸시는 하지 않는다. `playwright install`은 실행하지 않는다.
- **파일 담당이 겹치지 않게 한다.**
  - `Footer.astro`(진행 상태 스크립트)는 **M1만** 고친다.
  - `src/styles/custom.css`는 **M2만** 고친다. 다른 담당은 컴포넌트 안의 `<style>`을 쓴다.
  - `astro.config.mjs`는 **M3만** 고친다.

## 진행 상태 공통 규약 (M1이 구현하고 M3가 사용)
Footer 스크립트에 다음 동작을 추가한다.
- `data-atc-count="slug1 slug2 ..."` 속성(ko/ 없는 슬러그, 공백 구분)이 있는 요소를 찾는다.
- 완료한 수를 그 요소 안의 `.atc-count-done` 텍스트에 넣는다.
- 비율(0~100)을 CSS 변수 `--atc-pct`로 설정한다.
- 1개 이상 완료했으면 `data-atc-started` 속성을 붙인다.
- `data-atc-next` 속성이 있는 요소 안의 `a.atc-next`는 목록 순서에서 아직 안 본 첫 글로 `href`와 텍스트를 바꾼다. 영어와 한국어 URL 접두사를 맞춘다. 제목은 빌드 때 `data-atc-titles` JSON으로 넘겨도 된다.

## M1 — 대시보드 홈 + 주제 타일 진행률
- `HomeDashboard.astro`를 새로 만든다. 홈 두 언어(`index.mdx`, `ko/index.mdx`)의 큰 히어로 자리에 놓는다.
  - **다시 온 사람**(atc:progress에 기록이 있거나 atc:last가 있음):
    - 작은 제목 줄: "내 학습 현황 · 전체 N편 중 M편 완료" 아래 "이어서 볼까요?". N은 빌드 때 튜토리얼 수에서 계산한다. 숫자를 하드코딩하지 않는다.
    - 큰 검색 상자: 누르면 기존 Pagefind 검색 모달을 연다. Starlight의 검색 버튼을 클릭시키는 방식으로 한다.
    - 빠른 칩 5개: Claude Code, 프롬프트 모음, 회의록 요약, AI 용어 사전, 무료로 쓰기. 실제 존재하는 페이지로 연결한다.
    - 카드 3개를 한 줄에 둔다.
      1. **읽던 글 이어 보기**: 주 카드. 채워진 버튼은 여기 하나만 둔다. 시리즈 진행 막대를 넣는다.
      2. **내 학습 경로**: `src/data/paths.ts`와 `src/lib/paths.ts`를 쓴다. 진행 중인 경로가 있으면 진행률과 다음 단계를 보여 준다. 없으면 경로 3개로 가는 링크를 둔다.
      3. **이번 주 바뀐 것**: 빌드 때 `weekly.mdx`(언어별)에서 첫 항목 3개의 제목을 뽑아 링크한다. 파싱이 어려우면 최근 확인·수정한 튜토리얼 3개(lastVerified 기준)로 대신하고, 보고서에 적는다.
  - **처음 온 사람**: 지금 히어로 문구를 짧게 줄이고, 수준별 학습 경로 카드 3개(입문/실무/고급)를 보여 준다.
  - 두 화면은 기존 HomeHero 이어 보기 카드와 같은 방식으로 인라인 스크립트가 전환한다. 깜빡임을 줄이도록 `<html>`에 클래스를 붙이는 방식을 권장한다.
  - 기존 `HomeHero`와 `LevelCards`는 대시보드로 흡수한다. 중복 섹션은 홈에서 뺀다.
- `CategoryCards.astro`(주제 타일 8개)에 편수와 진행 막대를 넣는다. "n / m" 형식이며, 위 `data-atc-count` 규약을 쓴다. 진행이 0이면 막대를 흐리게만 보이게 한다.
- 홈 아래쪽 구성은 다음 순서로 한다.
  1. 주제 타일
  2. 작은 상자 두 개: "직무별 가이드" 칩 10개, 처음이라면 경로 3개
  3. "최근 확인·수정한 글" 3줄 + 모두 보기
- 홈 섹션 사이 여백은 44~56px로 한다.
- 검증: Playwright로 홈 두 언어를 각각 1440×900과 390×844에서 찍는다. 첫 방문과 다시 온 경우(localStorage에 진행 기록을 넣고) 둘 다 찍는다. 저장 위치는 scratchpad의 `ia/after2/`.

## M2 — 상단 메뉴 + 모바일 하단 탭
- `Header.astro` 오버라이드(이미 있음)에 PC 상단 메뉴 6개를 넣는다.

  | 메뉴 (한국어 / 영어) | 연결 |
  | --- | --- |
  | 홈 / Home | 언어 홈 |
  | 배우기 / Learn | `/start/beginner/` 또는 경로 허브. 학습 경로 3개를 한 페이지에서 고르게 하는 링크면 된다. 새 페이지가 필요하면 만들지 말고 `/start/beginner/`로 연결한 뒤 보고한다 |
  | 주제별 / Topics | `/tutorials/` |
  | 직무별 / Roles | `/roles/` |
  | 새 소식 / What's new | `/weekly/` |
  | 도구함 / Toolbox | `/start/prompts/` |

  - 현재 위치는 `aria-current`로 강조한다. URL 접두사로 판단한다. 예를 들어 /claude/ 같은 주제 페이지에서는 주제별을 강조한다.
  - 폭이 좁으면 메뉴를 숨긴다(약 1100px 미만). 검색, 테마, 언어 선택은 유지한다.
- 모바일(≤ 800px)에는 하단 고정 탭 바를 넣는다: 홈 / 배우기 / 주제 / 검색 / 새 소식.
  - 아이콘과 라벨을 함께 쓰고, 탭 높이는 최소 44px로 한다. safe-area inset을 반영한다.
  - 검색 탭은 Starlight 검색 모달을 연다.
  - **튜토리얼 페이지에서는 숨긴다.** 기존 모바일 하단 독(완료/다음)이 이미 있기 때문이다.
  - 탭 바가 본문이나 푸터를 가리지 않게 body 아래 여백을 준다.
- 1단계에서 남은 문제를 고친다. 모바일 튜토리얼 메타 줄에서 "완료로 표시" 버튼이 따로 한 줄을 차지하니, 작은 아이콘형으로 같은 줄에 넣는다. `TutorialMeta.astro`와 custom.css로 처리한다. 기존 `.atc-done-btn` 바인딩은 유지한다.
- 다크 모드를 확인한다. 스크린샷은 `ia/after2/`에 `nav-` 접두사로 저장한다.

## M3 — 섹션 허브 + Claude 하위 그룹
- `src/data/topic-groups.ts`를 새로 만든다. Claude 33편을 5~6개 하위 그룹으로 묶는다. 그룹 이름은 영어와 한국어 둘 다 둔다. 기준은 각 글의 title과 description이다. 예:
  - 기본·요금
  - 작업 공간(프로젝트·아티팩트·파일·리서치)
  - 앱·연동(데스크톱·모바일·커넥터·Google·Office)
  - 에이전트·자동화(Cowork·Chrome·컴퓨터 사용·Tag·Meetings·반복 작업)
  - Claude Code·API
  - 팀·관리자
- 목록에 없는 새 C 글(루틴이 추가할 수 있음)은 마지막 "기타 / More" 그룹으로 자동으로 들어가게 한다.
- **사이드바**: `astro.config.mjs`의 Claude 그룹을 위 데이터로 만든 하위 그룹으로 바꾼다. 하위 그룹은 접힘이 기본이고, 현재 글이 속한 그룹은 Starlight가 자동으로 펼친다. config에서 TS 파일을 import하기 어려우면 `.mjs` 데이터 파일로 만들어 양쪽에서 쓴다. 폴더 안 파일 목록은 `fs.readdirSync`로 읽어 누락분을 "기타"에 넣는다.
- **섹션 허브**: 섹션 index 페이지(`claude/index.mdx` 등 주제 8개, 두 언어)의 카드 목록을 허브로 바꾼다.
  - 맨 위에 진행 헤더를 둔다: "N편 중 M편 완료" 막대와 "이어서: 〈다음 안 본 글〉" 버튼(`data-atc-count`, `data-atc-next` 규약).
  - `TutorialGrid.astro`에 `compact`·`groupBy` 옵션을 추가한다. 섹션 페이지는 키 큰 카드 대신 한 줄짜리 목록 행을 쓴다(번호, 제목, 레벨, 시간, 완료 ✓). 기존 `data-slug` 완료 표시와 호환되게 한다.
  - Claude 섹션은 위 하위 그룹별 소제목으로 나눈다. 다른 섹션은 그룹 없이 번호순으로 둔다.
  - `/tutorials/` 전체 목록 페이지는 기존 카드 그대로 둔다. 다만 모바일(≤ 800px)에서는 compact 행을 기본으로 한다.
- 검증: `/ko/claude/`와 `/ko/basics/`를 1440과 390에서 찍는다(진행 기록 있음과 없음). 저장 위치는 `ia/after2/`, 접두사는 `hub-`.
