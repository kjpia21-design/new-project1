# 접근성·성능 점검 (2026-10-13)

방법: 빌드 후 `astro preview`(포트 4620) + Playwright(Chromium) + axe-core(WCAG 2.0/2.1 A·AA, best-practice).
대상: 홈, tutorials, claude/c01, basics/01, media/12, start/glossary, 404, claude-news. 375px·1280px × 라이트·다크.

## 발견
- 라이트 모드 강조색(#d4431e) 대비 4.47:1 (링크·배지 텍스트), 강조색 배경 위 흰 글씨 4.38:1 로 AA(4.5) 미달. 거의 모든 페이지.
- 체크리스트 진행 막대(role=progressbar)에 접근 가능한 이름 없음.
- /tutorials/ 카드 제목이 h1 다음 바로 h3 (제목 순서 건너뜀).
- 375px에서 가로 스크롤되는 표에 키보드 포커스 불가 (scrollable-region-focusable).
- 이미지: 본문 `<img>` 없음(alt 문제 없음). 큰 이미지·폰트 파일 없음(페이지당 약 0.3~0.4MB, 100KB 초과 응답 없음).
- 가로 스크롤(페이지 전체): 없음. 키보드 포커스 표시: 탭 12회 모두 outline 있음. 터치 영역: 헤딩 앵커 링크 24×35px(최소 24px 충족), 체크박스 입력 19px이지만 라벨 전체가 클릭 영역.

## 수정
- `src/styles/custom.css`: 라이트 강조색 #c53a16, 강조 고대비 #922810 (AA 충족).
- `src/components/Checklist.astro`: progressbar에 `aria-label`.
- `src/components/TutorialGrid.astro`: 필터 모드(/tutorials/)에서는 카드 제목을 h2로.
- `src/components/Footer.astro`: 넘치는 표에 tabindex/role=region/aria-label을 붙이는 작은 스크립트.
- 재검사: 라이트·다크 × 375/1280 전 페이지에서 axe 위반은 Starlight 기본 skip-link의 `region`(경미) 1건만 남음.

## 남은 것
- CLS: /tutorials/ 0.12, 홈 0.04. 원인은 CDN의 Pretendard(동적 서브셋) 글꼴이 늦게 적용되며 필터 버튼 줄바꿈이 바뀌는 것. 글꼴 셀프호스팅 또는 size-adjust 폴백이 필요하며 astro.config.mjs(기획 담당) 변경이 따라서 보류.
